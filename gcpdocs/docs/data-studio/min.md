Returns the minimum value from a set of numbers.
## Sample usage
`MIN(Users per day)`
## Syntax
`MIN( X )`
### Parameters
  * `X` - a numeric field or expression.


### Notes
  * `X` cannot be an aggregated field or the result of an aggregation function.


## Example  
| Example formula  | Input  | Output  |  
| --- | --- | --- |  
| ` MIN(Users per day) `  | 
  * 95
  * 100
  * 92

 | 92  |
