This page provides an overview of the steps you need to take to start a new Data Studio Pro subscription.
## Before you begin
To set up a self-service subscription to Data Studio Pro, you must meet all of the following requirements:
  * You must be a Google Workspace or Cloud Identity user with a [Managed Google account](https://support.google.com/work/android/answer/6371476) to subscribe to or use Data Studio Pro.
  * You will need to provide a valid Google Cloud project that is linked to a billing account. [Learn how to set up a Google Cloud billing account](https://docs.cloud.google.com/billing/docs/how-to/create-billing-account).
  * You must have the Owner (`roles/owner`) or Looker Studio Pro Manager (`roles/lookerstudio.proManager`) IAM role on the Google Cloud project that you use for Data Studio Pro.
  * Your organization must own the Google Cloud project that you use for Data Studio Pro.
  * You must belong to the same organization that owns the Google Cloud project that you use for the subscription. (For example, you can't make someone who is outside your organization an owner on the project and have that outside user subscribe to Data Studio Pro on behalf of the organization.)
  * The Google Cloud project that you use for Data Studio Pro must not be in use for a Pro subscription.


For more information about granting Cloud IAM roles, see the [Manage access to projects, folders, and organizations](https://docs.cloud.google.com/iam/docs/granting-changing-revoking-access) documentation page. You might also be able to get the required permissions by using [custom roles](https://docs.cloud.google.com/iam/docs/creating-custom-roles) or other [predefined roles](https://docs.cloud.google.com/iam/docs/understanding-roles).
## Ways to subscribe
You can subscribe to Data Studio Pro in the following ways:
  * [From within Data Studio](https://docs.cloud.google.com/data-studio/start-a-new-pro-subscription/#subscribe-studio)
  * [From the Google Cloud console](https://docs.cloud.google.com/data-studio/start-a-new-pro-subscription/#subscribe-cloud)
  * [From the Google Workspace Admin console](https://docs.cloud.google.com/data-studio/start-a-new-pro-subscription/#subscribe-workspace)


### Subscribe to Data Studio Pro from Data Studio
To subscribe to Data Studio Pro from within the product, follow these steps:
  * [Sign in to Data Studio](https://datastudio.google.com).
  * In the left navigation, click **Pro subscription**.
  * Click **Add subscription**.


### Subscribe to Data Studio Pro from the Google Cloud console
To subscribe to Data Studio Pro from the Google Cloud console, follow these steps:
  * Navigate to the Data Studio homepage: <https://console.cloud.google.com/looker-studio/home>
  * If necessary, select the Google Cloud project to use with Data Studio Pro.
  * Click **Get started**.


### Subscribe to Data Studio Pro from the Google Workspace Admin console
To subscribe to Data Studio Pro from the Google Workspace Admin console, follow the instructions in [Add & set up Data Studio Pro](https://support.google.com/a/answer/16695590) (opens in the Workspace Help Center).
