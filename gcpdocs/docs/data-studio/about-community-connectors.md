#  About community connectors Stay organized with collections  Save and categorize content based on your preferences.
The Data Studio Community Connectors program is an open source project with the mission of bringing Data Studio users access to public and open datasets around the world. The Community Connectors program allows anyone to build their own connections to any internet-accessible data source.
You can develop and use community connectors to create reports and dashboards with data from sources such as the following:
  * Platforms for social media, CRM, search, finance, HR, advertising, etc.
  * Public and other open datasets
  * Private company data
  * Any data source or service that can be accessed over the internet by using [Apps Script](https://developers.google.com/apps-script/)


> **Note for Google Workspace users:** To view data in a chart that is based on a community connector, Apps Script must be enabled for your organization. When Apps Script is disabled, community connectors can't fetch data and you'll see an error in the chart.
Learn more about the Community Connectors program on our [developer site](https://developers.google.com/looker-studio/connector/).
Users with the [Service Settings administrator privilege](https://support.google.com/a/answer/1219251#service_settings) can [set policies for how users add or create data sources from third-party connectors](https://support.google.com/looker-studio/answer/14339933).
