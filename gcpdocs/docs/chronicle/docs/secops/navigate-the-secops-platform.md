# Navigate the Google SecOps platform

Supported in:

Google SecOps 

To quickly access context-sensitive documentation directly related to the page you're viewing in the platform, click  info  **Info** and select **Documentation**.

To navigate around the platform, hold the pointer over the sliding left navigation bar and then click to access all of the Google SecOps pages. This page provides the correct navigational paths if you have opted in to the **Consolidated Settings and Navigation** feature in the [Public Preview](https://docs.cloud.google.com/chronicle/docs/secops/preview-features-manage) page.
