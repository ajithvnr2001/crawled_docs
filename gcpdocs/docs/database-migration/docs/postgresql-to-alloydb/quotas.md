## Overview

This page provides information about the Database Migration Service quotas and limits. Quotas are applied per-project; limits are applied to the instance or to the project, depending on the limit.

## Limits

Up to 2,000 connection profiles and 1,000 migration jobs can exist at any given time. To create space for more, migration jobs (including completed ones) and connection profiles need to be deleted.
