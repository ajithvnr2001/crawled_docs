#  Supported Swift versions Stay organized with collections  Save and categorize content based on your preferences. 

The Google Cloud client libraries for Swift support the last three minor releases of Swift (Swift 6.2, 6.3, and 6.4). This document provides information and best practices to keep your toolchain and libraries up to date.

## Minimum supported Swift version

The minimum supported version is Swift 6.2. For more information about Google Cloud client libraries, see [Client libraries explained](https://docs.cloud.google.com/apis/docs/client-libraries-explained).

The Swift client libraries increment the major version when dropping compatibility with a Swift major version. For more information about the use of major and minor versions, see the [Semantic Versioning specification](https://semver.org/) at `semver.org`.

The libraries are tested against the Swift versions available at the time the client libraries are released. To find out which versions were used in testing, see the [`google-cloud-swift` README on GitHub](https://github.com/googleapis/google-cloud-swift#readme).

## Recommended version for new development

When starting a new project, we recommend choosing the current release of Swift. Using the current release ensures that your runtime is within the supported Swift releases and receives critical security patches.

## Keep your production systems current

To ensure that you receive critical security and bug fixes, keep your production systems on supported Swift toolchains. In the documentation on Swift.org, see how to use [`swiftly update`](https://www.swift.org/swiftly/documentation/swiftly/update-toolchain/) to automatically update your version of Swift, and use [`swift package update`](https://docs.swift.org/swiftpm/documentation/packagemanagerdocs/resolvingpackageversions/) to automatically update the Swift dependencies in your project.
