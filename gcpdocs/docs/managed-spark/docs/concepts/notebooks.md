#  Use notebooks with Managed Service for Apache Spark Stay organized with collections  Save and categorize content based on your preferences. 

Managed Service for Apache Spark lets you run interactive data exploration, prototype machine learning workflows, and develop Spark applications by using [Jupyter notebooks](https://jupyter.org/). This integration provides direct access to scalable compute clusters and serverless environments for distributed data processing.

  * To work with clusters, you can [install and run a Jupyter notebook on a Managed Service for Apache Spark cluster](https://docs.cloud.google.com/managed-spark/docs/tutorials/jupyter-notebook).
  * For domain-specific workloads, you can [run a genomics analysis in a JupyterLab notebook on Managed Service for Apache Spark](https://docs.cloud.google.com/managed-spark/docs/tutorials/genomics-single-cell).
  * For serverless development, you can [use the Managed Service for Apache Spark JupyterLab plugin for serverless batch and interactive notebook sessions](https://docs.cloud.google.com/managed-spark/docs/quickstarts/jupyterlab-sessions).
  * You can also [create a Managed Service for Apache Spark-enabled Vertex AI Workbench instance](https://docs.cloud.google.com/vertex-ai/docs/workbench/instances/create-dataproc-enabled) to run notebooks within a unified data science platform.
