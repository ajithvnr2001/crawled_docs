The Aiwyn Tax data store for Gemini Enterprise lets you calculate US tax returns and access tax jurisdiction and namespace schemas via Aiwyn Column API.
## Limitations
  * When creating a new app or adding a data store to an existing one, it's recommended to associate only one data store with actions belonging to a single connector type.


  * Enforcing a VPC Service Controls perimeter on existing Aiwyn Tax data stores is not supported. To enforce VPC Service Controls, you must delete and recreate the data stores. For more information on VPC Service Controls and how to use actions after enabling VPC Service Controls, see [Secure your app with VPC Service Controls](https://docs.cloud.google.com/gemini/enterprise/docs/use-vpc-service-controls).


  * The Aiwyn Tax data store is supported only in the `global`, `us`, and `eu` locations.


  * This connector does not require authentication (Public API).


## What's next
  * To create and configure a data store with Aiwyn Tax, see [Set up a Aiwyn Tax data store](https://docs.cloud.google.com/gemini/enterprise/docs/connectors/aiwyn_tax/set-up-data-store).
