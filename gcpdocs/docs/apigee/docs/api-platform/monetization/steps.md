#  Steps to use Apigee monetization Stay organized with collections  Save and categorize content based on your preferences.
_This page applies to**Apigee** and **Apigee hybrid**._
_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)
The following table summarizes the steps to use Apigee monetization.   
| Step  | Description  |  
| --- | --- |  
| [Enable Apigee monetization](https://docs.cloud.google.com/apigee/docs/api-platform/monetization/enable)  | Before you can use Apigee monetization, you must purchase and enable it.  |  
| [Enforce monetization limits in API proxies](https://docs.cloud.google.com/apigee/docs/api-platform/monetization/enforce-monetization-limits)  | Attach the polices to the API proxies to enforce monetization limits.  |  
| [Enforce monetization quotas in API products](https://docs.cloud.google.com/apigee/docs/api-platform/monetization/enforce-monetization-quotas-api-products)  | Configure the quota for monetization in the API product.  |  
| [Manage rate plans for API products](https://docs.cloud.google.com/apigee/docs/api-platform/monetization/manage-rate-plans)  | Configure the billing details, fees, and charges that are incurred for the use of APIs offered in a monetized API product.  |  
| Enable purchase and management of API product subscriptions  | Perform one of the following: 
  * [Integrate Apigee monetization in your Drupal-based developer portal](https://docs.cloud.google.com/apigee/docs/api-platform/monetization/integrate-developer-portal) using the Apigee Monetization module.
  * Build a custom portal to [purchase and manage API product subscriptions using the API](https://docs.cloud.google.com/apigee/docs/api-platform/monetization/purchase-api-products-api) or manage the purchasing process manually.

 |  
| [Debug monetization using Debug](https://docs.cloud.google.com/apigee/docs/api-platform/monetization/debug-trace)  | Debug monetization using Debug.  |  
| [Generate monetization reports](https://docs.cloud.google.com/apigee/docs/api-platform/monetization/generate-reports)  | Generate monetization reports to analyze data usage and prepare invoices for billing.  |
