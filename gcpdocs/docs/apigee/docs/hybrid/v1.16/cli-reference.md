## `apigeectl` deprecation notice
`apigeectl` is deprecated in Apigee hybrid version 1.12 and later. Use Helm to install and manage Apigee hybrid instead. See [Apigee hybrid Helm charts reference](https://docs.cloud.google.com/apigee/docs/hybrid/v1.16/helm-reference).
For a description and command reference see [`apigeectl`](https://docs.cloud.google.com/apigee/docs/hybrid/v1.11/cli-reference) in the hybrid v1.11 documentation.
