## October 30, 2026

Feature

Cloud FTP is available in the following regions:

  * `asia-northeast1`
  * `asia-south2`
  * `australia-southeast1`
  * `australia-southeast2`
  * `europe-west9`
  * `me-west1`
  * `us-south1`
  * `us-west2`



For more information, see [Cloud FTP locations](https://docs.cloud.google.com/cloud-ftp/locations).

## August 26, 2026

Announcement

Cloud FTP is generally available ([GA](https://cloud.google.com/products#product-launch-stages)). Cloud FTP provides a managed, cloud-based solution to securely move data in and out of Cloud Storage by using SSH File Transfer Protocol (SFTP). For more information, see [Cloud FTP overview](https://docs.cloud.google.com/cloud-ftp/overview).
