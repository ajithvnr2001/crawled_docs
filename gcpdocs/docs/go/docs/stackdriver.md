#  Observability overview for Go Stay organized with collections  Save and categorize content based on your preferences. 

[Google Cloud Observability](https://docs.cloud.google.com/stackdriver) provides monitoring, logging, and diagnostics for Go applications.

Go libraries are available for the following Google Cloud Observability services:

  * Error Reporting
  * Cloud Logging
  * Cloud Monitoring
  * Cloud Trace



## Error Reporting

[Error Reporting](https://docs.cloud.google.com/error-reporting/docs) for Go aggregates and displays errors produced in your running Go applications. To get started with Error Reporting, see [Instrument Go apps for Error Reporting](https://docs.cloud.google.com/error-reporting/docs/setup/go).

## Cloud Logging

[Cloud Logging](https://docs.cloud.google.com/logging/docs) for Go lets you store, search, analyze, monitor, and alert on log data and events in Go applications. We provide Cloud Client Libraries for Go with standard library logger support. To get started with Cloud Logging, see the [Setting up Cloud Logging for Go](https://docs.cloud.google.com/logging/docs/setup/go).

## Cloud Monitoring

[Cloud Monitoring](https://docs.cloud.google.com/monitoring/docs) for Go collects metrics, events, and metadata from Go applications. Cloud Monitoring ingests that data and generates insights using dashboards, charts, and alerts.

To get started with Cloud Monitoring, see the [Cloud Client Libraries for the Cloud Monitoring API](https://docs.cloud.google.com/monitoring/docs/reference/libraries) for installation and usage of the Go library.

## Cloud Trace

[Cloud Trace](https://docs.cloud.google.com/trace/docs) is a distributed tracing system for Google Cloud that collects latency data from Go applications and displays it in near real time in the Google Cloud console. To get started with Cloud Trace, see [Go instrumentation sample](https://docs.cloud.google.com/trace/docs/setup/go-ot) in the Trace documentation.
