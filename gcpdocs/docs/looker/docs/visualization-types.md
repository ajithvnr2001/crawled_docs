#  Visualization types Stay organized with collections  Save and categorize content based on your preferences. 

Looker has many visualizations that you can use to make sense of your data. Each type of visualization has different settings that you can use to customize its appearance. The following links provide information about each visualization and its settings.

**Tip:** For information about choosing a visualization type that best fits your data, see the [Selecting an effective data visualization](https://docs.cloud.google.com/looker/docs/visualization-guide) documentation page.

## Chart Config Editor

If you have the [`can_override_vis_config` permission](https://docs.cloud.google.com/looker/docs/admin-panel-users-roles#can_override_vis_config), you can use the [Chart Config Editor](https://docs.cloud.google.com/looker/docs/chart-config-editor) to create the following visualization types:

  * [Bullet](https://docs.cloud.google.com/looker/docs/bullet-chart-config-editor)
  * [Dependency wheel](https://docs.cloud.google.com/looker/docs/dependency-wheel-chart-config-editor)
  * [Item](https://docs.cloud.google.com/looker/docs/item-chart-config-editor)
  * [Sankey](https://docs.cloud.google.com/looker/docs/sankey-chart-config-editor)
  * [Solid gauge](https://docs.cloud.google.com/looker/docs/solid-gauge-chart-config-editor)
  * [Streamgraph](https://docs.cloud.google.com/looker/docs/streamgraph-chart-config-editor)
  * [Sunburst](https://docs.cloud.google.com/looker/docs/sunburst-chart-config-editor)
  * [Treemap](https://docs.cloud.google.com/looker/docs/treemap-chart-config-editor)
  * [Venn diagram](https://docs.cloud.google.com/looker/docs/venn-chart-config-editor)



## Custom visualizations

**Note:** This page lists Looker's built-in visualization types. If your Looker developer has added any [custom visualization](https://docs.cloud.google.com/looker/docs/admin-panel-platform-visualizations) types to Looker, you may see additional options in the ellipsis (...) menu in the **Visualization** pane of the Explore page.
