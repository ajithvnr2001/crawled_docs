## Cloud Customer Care offerings
Support offerings are available from Google Cloud that can include 24/7 coverage, phone support, and access to technical account services. For more information, see [Getting Cloud Customer Care](https://docs.cloud.google.com/support/docs).
## Check official documentation
If you encounter any errors or have any questions, we recommend you to review the following resources:
  * [Known issues](https://docs.cloud.google.com/application-integration/docs/known-issue)
  * [Errors and error handling](https://docs.cloud.google.com/application-integration/docs/error-handling)
  * [Frequently asked questions](https://docs.cloud.google.com/application-integration/docs/faq)


## Get help from Google Cloud community 
You can post your questions and discuss about Application Integration in the Google Cloud community at [Integration Services Cloud Forum](https://www.googlecloudcommunity.com/gc/Integration-Services/bd-p/cloud-integration-services). 
## Provide product feedback from the Google Cloud console
If you want to provide any specific product feedback, click **Send feedback** in the **Support** menu of the Google Cloud console. Clicking **Send feedback** displays the **Send feedback** dialog where you can enter your feedback.
