## Functions

[`BooleanValue(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/tools/xml_parser_utils/BooleanValue): Returns boolean value. [`GetAttribute(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/tools/xml_parser_utils/GetAttribute): Wrapper function to retrieve attributes from XML nodes. [`GetChild(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/tools/xml_parser_utils/GetChild): Returns first child of node with tag. [`GetChildNodeText(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/tools/xml_parser_utils/GetChildNodeText): Finds child XML node with desired tag and returns its text. [`GetNodeText(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/tools/xml_parser_utils/GetNodeText): Returns the node text after stripping whitespace. [`GetNodes(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/tools/xml_parser_utils/GetNodes): Gets all children of a node with the desired tag. [`GetTag(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/tools/xml_parser_utils/GetTag): Strips namespace prefix.
