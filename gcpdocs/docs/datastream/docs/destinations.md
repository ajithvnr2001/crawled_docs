#  Destinations Stay organized with collections  Save and categorize content based on your preferences. 

Datastream lets you stream historical and ongoing change data from your sources into BigQuery, Cloud Storage, or Apache Iceberg tables in BigQuery. Before you configure a destination, you can review how Datastream writes data and check the destination-specific requirements and known limitations.

## What's next

  * Learn more about the [BigQuery destination](https://docs.cloud.google.com/datastream/docs/destination-bigquery) and how to [configure a BigQuery destination](https://docs.cloud.google.com/datastream/docs/configure-bigquery-destination).

  * Learn how to [configure a Cloud Storage destination](https://docs.cloud.google.com/datastream/docs/destination-gcs).

  * Learn how to [configure an Apache Iceberg destination](https://docs.cloud.google.com/datastream/docs/destination-blmt).
