#  Agent Assist UI modules overview Stay organized with collections  Save and categorize content based on your preferences.
Agent Assist now offers **UI modules** , an out-of-the-box option for integrating Agent Assist features into your agent UI system. You have the ability to integrate all features in a single panel or customize your integration by implementing selected features separately. See the [UI modules tutorial](https://docs.cloud.google.com/gemini-enterprise-cx/agent-assist/ui-modules) for more information about getting started with this integration method.
