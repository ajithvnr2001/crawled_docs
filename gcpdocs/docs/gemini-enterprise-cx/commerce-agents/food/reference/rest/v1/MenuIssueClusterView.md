#  MenuIssueClusterView Stay organized with collections  Save and categorize content based on your preferences. 

Specifies which fields of a MenuIssueCluster are returned.

Enums  
---  
`MENU_ISSUE_CLUSTER_VIEW_UNSPECIFIED` | The default view, which depends on the method: FULL for `GetMenuIssueCluster` and BASIC for `ListMenuIssueClusters`.  
`MENU_ISSUE_CLUSTER_VIEW_BASIC` | Returns all fields except `entityIssues`.  
`MENU_ISSUE_CLUSTER_VIEW_FULL` | Returns all fields, including `entityIssues`.
