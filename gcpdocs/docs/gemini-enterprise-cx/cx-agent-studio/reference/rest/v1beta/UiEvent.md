  * JSON representation



Represents a UI event payload.

JSON representation  
---  
      
    
    {
      "mimeType": string,
      "jsonPayload": string
    }  
  
Fields  
---  
`mimeType` |  `string` The media type (MIME type) indicating the format of the UI event payload (e.g., "application/json+a2ui").  
`jsonPayload` |  `string` The JSON payload representing the A2UI surface.
