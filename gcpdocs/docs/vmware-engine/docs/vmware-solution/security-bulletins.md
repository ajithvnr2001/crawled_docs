## GCP-2026-079

**Published:** 2026-11-05

### Description

Description | Severity | Notes  
---|---|---  
Per advisory [VMSA-2026-0008](https://support.broadcom.com/web/ecx/support-content-notification/-/external/content/SecurityAdvisories/0/39445), Broadcom has identified an out-of-bounds write remote code execution vulnerability in the SDDC Manager Node.js Brotli decoder. This impacts only [VMware solution on Google Cloud](https://docs.cloud.google.com/vmware-engine/docs/vmware-solution/overview) running VMware Cloud Foundation 9.1.x and does not impact Google Cloud VMware Engine.

#### What should I do?

To remediate, apply the Broadcom-recommended workarounds outlined in the [VMSA-2026-0008](https://support.broadcom.com/web/ecx/support-content-notification/-/external/content/SecurityAdvisories/0/39445) advisory. | Critical | 

  * [VMSA-2026-0008](https://support.broadcom.com/web/ecx/support-content-notification/-/external/content/SecurityAdvisories/0/39445)
  * CVE-2026-111497
