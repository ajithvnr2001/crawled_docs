### Kubernetes updates

#### k8s-api

Updated `k8s-api` cohort from version 1.36.4-gke.400 to 1.36.5-gke.400.

  * **Features** : 
    * Updated StatefulSet logic to restore only the `.spec` portion from a `ControllerRevision`.
    * Added support for configuring cgroup v2 `memory.high` settings for the `containerd` service and `kubepods` slice on control plane nodes to improve memory resource allocation.
    * Instrumented the aggregated OpenAPI v2 handler with `apiserver_request_total` to provide better visibility and monitoring for `/openapi/v2` endpoints.
  * **Bug fixes** : 
    * Fixed the `ConvertToNative` function for Mutating admission policies.
    * Added a guard in `kube-proxy` (Windows kernel mode) to handle load balancers that lack port mappings.
    * Improved backslash escaping for Windows-specific paths.
    * Resolved an issue where Job pods could not be removed if finalizer removal failed.
    * Fixed a potential integer overflow in Dynamic Resource Allocation (DRA) during per-claim device-limit checks.
    * Prevented node-specific Kubelet configurations from being leaked into global ConfigMaps.
  * **Security fixes** : 
    * Addressed a confused deputy vulnerability in the StatefulSet controller that could allow cross-namespace pod creation by ensuring only the `.Spec` field is restored from `ControllerRevision`: [CVE-2026-2270](https://www.cve.org/CVERecord?id=CVE-2026-2270).
    * Improved security for Windows nodes by refusing UNC symlink targets in `subPath` resolution, preventing forced NTLM authentication and unauthorized SMB session initialization (MITRE ATT&CK T1187).
  * **Miscellaneous** : 
    * Updated container base images to use Go 1.26.8 and distroless iptables.
