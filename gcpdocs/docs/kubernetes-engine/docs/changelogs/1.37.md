## 1.37.2-gke.1042000

The following sections describe changes in this patch version when compared with the previous patch version, 1.37.1-gke.3020000. For information about upstream Kubernetes changes, see the [Kubernetes v1.37.2 changelog](https://github.com/kubernetes/kubernetes/blob/master/CHANGELOG/CHANGELOG-1.37.md#v1372).

### Kubernetes updates

#### k8s-api

Updated `k8s-api` cohort from version 1.37.1-gke.1700 to 1.37.2-gke.600.

  * **Bug fixes** : 
    * Included extended resource claims in `Pod` claim iteration and taint eviction for Dynamic Resource Allocation (DRA).
    * Increased the `MaxHeaderValueCount` for `kube-apiserver` to 16,384 to support users with many group memberships during authentication and impersonation.
    * Optimized `kube-proxy` to avoid overwriting the `nf_conntrack_max` sysctl setting if the existing system value is already greater than the required minimum.
    * Updated the `Job` controller to ensure expectations are cleared when a `Job` is deleted, helping to ensure reliable resource recreation.
    * Reverted `gcfs-snapshotter` and `gcfsd` to previous versions and disabled user namespace support to resolve an issue where Ubuntu nodes using Local SSD ephemeral storage and Image streaming failed to start Pods following a reboot.
    * Increased the startup timeout for the Image streaming daemon (`gcfsd`) to 30 minutes, helping to prevent restart loops on nodes with a high number of cached layers that previously caused Pods to fail with `CrashLoopBackOff` or `CreateContainerError`.
    * Fixed a node startup sequencing issue where `gcfsd` and `gcfs-snapshotter` daemons could start before Local SSD was bound to `/var/lib/containerd` on rebooted Ubuntu nodes, which prevented Pods from starting.
  * **Security fixes** : 
    * Updated the Go runtime to version 1.26.10 and updated the `distroless-iptables` image to address security vulnerabilities in the `crypto/x509` package.
  * **Miscellaneous** : 
    * Enabled optional configuration of `fault_around_bytes` on amd64 control plane nodes to help reduce memory overhead in the `kubepods.slice` by limiting speculative page prefaulting.

### Kubernetes updates

#### k8s-api

Updated `k8s-api` cohort from version 1.37.1-gke.300 to 1.37.1-gke.900.

  * **Features** : 
    * Added `apiserver_request_total` metrics instrumentation for the aggregated OpenAPI v2 handler to improve monitoring and visibility of API server performance.
    * Optimized node bootstrap logging in `configure.sh` and `configure-helper.sh` by reducing external process forks, resulting in a reduction of approximately 0.8s–1.1s in total bootstrap latency.
  * **Bug fixes** : 
    * Updated the kubelet to reconcile node status and default labels on cached nodes before initial registration, ensuring early static pods can be admitted without failing predicates when nodes are pre-created by external controllers.
  * **Miscellaneous** : 
    * Reduced node startup latency by optimizing the management of the GKE Node Live Update Reconciler systemd service, removing the need for a manual systemd daemon-reload during initialization.
    * Added support for configuring cgroup v2 `memory.high` limits on control plane nodes via systemd drop-ins for `containerd` and `kubepods`.
