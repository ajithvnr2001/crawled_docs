## 1.34.12-gke.1698000

The following sections describe changes in this patch version when compared with the previous patch version, 1.34.12-gke.1539000. For information about upstream Kubernetes changes, see the [Kubernetes v1.34.12 changelog](https://github.com/kubernetes/kubernetes/blob/master/CHANGELOG/CHANGELOG-1.34.md#v13412).

### Component updates

The following sections provide information about updates to specific GKE system components in this patch version.

#### accelerator-operator

Updated `accelerator-operator` component from version 1.34.13 to 1.34.15.

  * **Features** : 
    * Limited the object cache to `Node` objects with the RDMA label and NCCL installers created by the `accelerator-operator`.
  * **Bug fixes** : 
    * Increased the leader election timeout to help ensure stability.
  * **Security fixes** : 
    * Updated the `google.golang.org/grpc` Go module to resolve [CVE-2026-84304](https://www.cve.org/CVERecord?id=CVE-2026-84304) and [CVE-2026-84445](https://www.cve.org/CVERecord?id=CVE-2026-84445).
