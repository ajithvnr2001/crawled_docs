NAME
    

gcloud beta service-health impacts - represents an impact to an asset affected by a service health event 
SYNOPSIS
    

`gcloud beta service-health impacts` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Represents an impact to an asset affected by a service health event. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-health/impacts/describe)`
     `(BETA)` Get details of an impact affecting a project. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-health/impacts/list)`
     `(BETA)` List impacts under a given project and location. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha service-health impacts](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-health/impacts)
