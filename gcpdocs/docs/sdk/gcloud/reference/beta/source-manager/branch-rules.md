NAME
    

gcloud beta source-manager branch-rules - manage Secure Source Manager branch rules 
SYNOPSIS
    

`gcloud beta source-manager branch-rules` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Secure Source Manager branch rules. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/branch-rules/create)`
     `(BETA)` Create a Secure Source Manager branch rule. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/branch-rules/delete)`
     `(BETA)` Delete a Secure Source Manager branch rule. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/branch-rules/describe)`
     `(BETA)` Describe a Secure Source Manager branch rule. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/branch-rules/list)`
     `(BETA)` List Secure Source Manager branch rules. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/branch-rules/update)`
     `(BETA)` Update a Secure Source Manager branch rule. 
REGIONAL ENDPOINTS
     This command group supports regional endpoints. To use regional endpoints for this command, use the `--endpoint-mode=regional-preferred` flag. To use regional endpoints by default, run `$ [gcloud config set](https://docs.cloud.google.com/sdk/gcloud/reference/config/set) regional/endpoint_mode regional-preferred`. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha source-manager branch-rules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/branch-rules)
