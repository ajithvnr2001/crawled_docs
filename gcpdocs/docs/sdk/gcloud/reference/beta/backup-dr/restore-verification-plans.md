NAME
    

gcloud beta backup-dr restore-verification-plans - manage Backup and DR Restore Verification Plans 
SYNOPSIS
    

`gcloud beta backup-dr restore-verification-plans` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Backup and DR Restore Verification Plans. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/restore-verification-plans/create)`
     `(BETA)` Create a Restore Verification Plan. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/restore-verification-plans/delete)`
     `(BETA)` Delete a Restore Verification Plan. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/restore-verification-plans/describe)`
     `(BETA)` Describe a restore verification plan. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/restore-verification-plans/list)`
     `(BETA)` List restore verification plans in a project. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud backup-dr restore-verification-plans](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/restore-verification-plans)
    
    
    [gcloud alpha backup-dr restore-verification-plans](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/restore-verification-plans)
