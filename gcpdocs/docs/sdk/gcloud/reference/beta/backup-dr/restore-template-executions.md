NAME
    

gcloud beta backup-dr restore-template-executions - manage Cloud Backup and DR Restore Template Executions 
SYNOPSIS
    

`gcloud beta backup-dr restore-template-executions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Backup and DR Restore Template Executions. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/restore-template-executions/describe)`
     `(BETA)` Show details of the restore template execution. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/restore-template-executions/list)`
     `(BETA)` List Cloud Backup and DR restore template executions. 
`[trigger-restore-cleanup](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/restore-template-executions/trigger-restore-cleanup)`
     `(BETA)` Trigger restore cleanup for a restore template execution. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud backup-dr restore-template-executions](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/restore-template-executions)
    
    
    [gcloud alpha backup-dr restore-template-executions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/restore-template-executions)
