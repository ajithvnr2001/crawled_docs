NAME
    

gcloud app-lifecycle-manager - commands for App Lifecycle Manager 
SYNOPSIS
    

`gcloud app-lifecycle-manager` `GROUP` [`GCLOUD_WIDE_FLAG …`]
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[releases](https://docs.cloud.google.com/sdk/gcloud/reference/app-lifecycle-manager/releases)`
     Manage App Lifecycle Manager releases. 
`[rollout-kinds](https://docs.cloud.google.com/sdk/gcloud/reference/app-lifecycle-manager/rollout-kinds)`
     Manage App Lifecycle Manager rollout kinds. 
`[rollouts](https://docs.cloud.google.com/sdk/gcloud/reference/app-lifecycle-manager/rollouts)`
     Manage App Lifecycle Manager rollouts. 
`[saas](https://docs.cloud.google.com/sdk/gcloud/reference/app-lifecycle-manager/saas)`
     Manage App Lifecycle Manager SaaS offerings. 
`[tenants](https://docs.cloud.google.com/sdk/gcloud/reference/app-lifecycle-manager/tenants)`
     Manage App Lifecycle Manager tenants. 
`[unit-kinds](https://docs.cloud.google.com/sdk/gcloud/reference/app-lifecycle-manager/unit-kinds)`
     Manage App Lifecycle Manager unit kinds. 
`[unit-operations](https://docs.cloud.google.com/sdk/gcloud/reference/app-lifecycle-manager/unit-operations)`
     Manage App Lifecycle Manager unit operations. 
`[units](https://docs.cloud.google.com/sdk/gcloud/reference/app-lifecycle-manager/units)`
     Manage App Lifecycle Manager units. 
NOTES
     This variant is also available: 
    
    
    [gcloud beta app-lifecycle-manager](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager)
