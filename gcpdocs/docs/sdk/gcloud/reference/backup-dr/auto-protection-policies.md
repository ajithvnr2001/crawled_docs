NAME
    

gcloud backup-dr auto-protection-policies - manage Backup and DR AutoProtectionPolicies 
SYNOPSIS
    

`gcloud backup-dr auto-protection-policies` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Backup and DR AutoProtectionPolicies. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/auto-protection-policies/create)`
     Create a Backup and DR AutoProtectionPolicy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/auto-protection-policies/delete)`
     Delete a Backup and DR AutoProtectionPolicy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/auto-protection-policies/describe)`
     Describe a Backup and DR AutoProtectionPolicy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/auto-protection-policies/list)`
     List Backup and DR AutoProtectionPolicies. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/auto-protection-policies/update)`
     Update a Backup and DR AutoProtectionPolicy. 
NOTES
     These variants are also available:
