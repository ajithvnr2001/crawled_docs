NAME
    

gcloud backup-dr restore-templates - manage Cloud Backup and DR Restore Templates 
SYNOPSIS
    

`gcloud backup-dr restore-templates` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Cloud Backup and DR Restore Templates. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/restore-templates/create)`
     Create a Restore Template. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/restore-templates/delete)`
     Delete a Restore Template. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/restore-templates/describe)`
     Show details of the restore template. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/restore-templates/list)`
     List Cloud Backup and DR restore templates. 
`[run](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/restore-templates/run)`
     Run a Restore Template. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/restore-templates/update)`
     Update a Restore Template. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha backup-dr restore-templates](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/restore-templates)
    
    
    [gcloud beta backup-dr restore-templates](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/restore-templates)
