#  gcloud agent-registry skills Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud agent-registry skills - manage Skill resources 
SYNOPSIS
    

`gcloud agent-registry skills` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Skill resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[revisions](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/skills/revisions)`
     Manage Skill Revision resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/skills/add-iam-policy-binding)`
     Add IAM policy binding for a skill. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/skills/create)`
     Create skills. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/skills/delete)`
     Delete skills. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/skills/describe)`
     Describe skills. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/skills/get-iam-policy)`
     Get the IAM policy for a skill. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/skills/list)`
     List skills. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/skills/remove-iam-policy-binding)`
     Remove IAM policy binding from a skill. 
`[search](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/skills/search)`
     search skills. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/skills/set-iam-policy)`
     Set the IAM policy for a skill. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/skills/update)`
     Update skills. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha agent-registry skills](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/skills)
