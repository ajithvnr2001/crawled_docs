NAME
    

gcloud preview compute zone-vm-extension-policies extensions - read only commands for Vm Extensions used in Zone Vm Ext Policies 
SYNOPSIS
    

`gcloud preview compute zone-vm-extension-policies extensions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Commands for info on Vm Extensions used in Vm Extension Policies. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/zone-vm-extension-policies/extensions/describe)`
     `(PREVIEW)` Describe a vm extension for a given zone. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/zone-vm-extension-policies/extensions/list)`
     `(PREVIEW)` List Vm Extensions in a zone. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud alpha compute zone-vm-extension-policies extensions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/zone-vm-extension-policies/extensions)
