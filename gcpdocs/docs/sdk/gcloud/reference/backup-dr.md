NAME
    

gcloud backup-dr - manage Backup and DR resources 
SYNOPSIS
    

`gcloud backup-dr` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Backup and DR resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[applied-auto-protection-policies](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/applied-auto-protection-policies)`
     Manage Backup and DR AppliedAutoProtectionPolicies. 
`[auto-protection-bindings](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/auto-protection-bindings)`
     Manage Backup and DR auto protection bindings. 
`[auto-protection-policies](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/auto-protection-policies)`
     Manage Backup and DR AutoProtectionPolicies. 
`[backup-plan-associations](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/backup-plan-associations)`
     Manage Backup and DR backup plan associations. 
`[backup-plan-revisions](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/backup-plan-revisions)`
     View Backup and DR backup plan revisions. 
`[backup-plans](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/backup-plans)`
     Manage Backup and DR backup plans. 
`[backup-vaults](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/backup-vaults)`
     Manage Backup and DR backup vaults. 
`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/backups)`
     Manage Backup and DR backups. 
`[binding-matching-resources](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/binding-matching-resources)`
     Manage Backup and DR binding matching resources. 
`[data-source-references](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/data-source-references)`
     Command group for Backup and DR Data Source References. 
`[data-sources](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/data-sources)`
     View Backup and DR data sources. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/locations)`
     Manage Backup and DR locations. 
`[management-servers](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/management-servers)`
     Manage Backup and DR management server. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/operations)`
     Manage Backup and DR operations. 
`[resource-backup-config](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/resource-backup-config)`
     Show protection summary for resources in a particular location and project. 
`[restore-template-executions](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/restore-template-executions)`
     Manage Cloud Backup and DR Restore Template Executions. 
`[restore-templates](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/restore-templates)`
     Manage Cloud Backup and DR Restore Templates. 
`[restore-verification-plan-associations](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/restore-verification-plan-associations)`
     Manage Backup and DR Restore Verification Plan Associations. 
`[restore-verification-plans](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/restore-verification-plans)`
     Manage Backup and DR Restore Verification Plans. 
`[service-config](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/service-config)`
     Manage Backup and DR Service configuration.
