NAME
    

gcloud oracle-database odb-networks odb-dns-zones - manage Odb Dns Zone resources 
SYNOPSIS
    

`gcloud oracle-database odb-networks odb-dns-zones` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Odb Dns Zone resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/odb-networks/odb-dns-zones/create)`
     Create a new OdbDnsZone. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/odb-networks/odb-dns-zones/delete)`
     Delete an OdbDnsZone. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/odb-networks/odb-dns-zones/describe)`
     Get details of an OdbDnsZone. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/odb-networks/odb-dns-zones/list)`
     List all OdbDnsZones.
