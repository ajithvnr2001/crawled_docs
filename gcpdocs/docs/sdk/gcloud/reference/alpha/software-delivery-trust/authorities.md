NAME
    

gcloud alpha software-delivery-trust authorities - manage Software Delivery Trust verification authorities 
SYNOPSIS
    

`gcloud alpha software-delivery-trust authorities` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` An Authority represents a trusted verification identity, containing public keys used to verify attestations for software artifacts. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-key](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/software-delivery-trust/authorities/add-key)`
     `(ALPHA)` Add a public key to an existing Software Delivery Trust verification authority. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/software-delivery-trust/authorities/create)`
     `(ALPHA)` Create a Software Delivery Trust verification authority. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/software-delivery-trust/authorities/delete)`
     `(ALPHA)` Delete a Software Delivery Trust verification authority. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/software-delivery-trust/authorities/describe)`
     `(ALPHA)` Retrieve details of a Software Delivery Trust verification authority. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/software-delivery-trust/authorities/list)`
     `(ALPHA)` List all Software Delivery Trust verification authorities in a given location. 
`[remove-key](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/software-delivery-trust/authorities/remove-key)`
     `(ALPHA)` Remove a public key from an existing Software Delivery Trust verification authority. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/software-delivery-trust/authorities/update)`
     `(ALPHA)` Update a Software Delivery Trust verification authority. 
REGIONAL ENDPOINTS
     This command group supports regional endpoints. To use regional endpoints for this command, use the `--endpoint-mode=regional-preferred` flag. To use regional endpoints by default, run `$ [gcloud config set](https://docs.cloud.google.com/sdk/gcloud/reference/config/set) regional/endpoint_mode regional-preferred`. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
