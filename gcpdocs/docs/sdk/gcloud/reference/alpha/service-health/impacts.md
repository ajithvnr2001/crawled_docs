NAME
    

gcloud alpha service-health impacts - represents an impact to an asset affected by a service health event 
SYNOPSIS
    

`gcloud alpha service-health impacts` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Represents an impact to an asset affected by a service health event. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-health/impacts/describe)`
     `(ALPHA)` Get details of an impact affecting a project. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-health/impacts/list)`
     `(ALPHA)` List impacts under a given project and location. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta service-health impacts](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-health/impacts)
