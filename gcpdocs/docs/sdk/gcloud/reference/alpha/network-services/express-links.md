NAME
    

gcloud alpha network-services express-links - manage Network Services Express Links 
SYNOPSIS
    

`gcloud alpha network-services express-links` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Network Services Express Links. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/express-links/create)`
     `(ALPHA)` Create an express link. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/express-links/delete)`
     `(ALPHA)` Delete express link. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/express-links/describe)`
     `(ALPHA)` Describe an express link. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/express-links/export)`
     `(ALPHA)` Export an express link. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/express-links/import)`
     `(ALPHA)` Import an express link. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/express-links/list)`
     `(ALPHA)` List express links. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/express-links/update)`
     `(ALPHA)` Update an express link. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta network-services express-links](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/express-links)
