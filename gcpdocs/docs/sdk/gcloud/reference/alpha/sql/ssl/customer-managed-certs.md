NAME
    

gcloud alpha sql ssl customer-managed-certs - provide commands for managing customer managed certificates of Cloud SQL instances 
SYNOPSIS
    

`gcloud alpha sql ssl customer-managed-certs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Provide commands for managing customer managed certificate bundles of Cloud SQL instances, including updating, listing, and deleting certificate bundles. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/ssl/customer-managed-certs/delete)`
     `(ALPHA)` Delete a customer managed certificate bundle for a Cloud SQL instance. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/ssl/customer-managed-certs/list)`
     `(ALPHA)` List all customer managed certificate bundles for a Cloud SQL instance. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/ssl/customer-managed-certs/update)`
     `(ALPHA)` Create or update a customer managed certificate bundle for a Cloud SQL instance. 
REGIONAL ENDPOINTS
     This command group supports regional endpoints. To use regional endpoints for this command, use the `--endpoint-mode=regional-preferred` flag. To use regional endpoints by default, run `$ [gcloud config set](https://docs.cloud.google.com/sdk/gcloud/reference/config/set) regional/endpoint_mode regional-preferred`. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud sql ssl customer-managed-certs](https://docs.cloud.google.com/sdk/gcloud/reference/sql/ssl/customer-managed-certs)
    
    
    [gcloud beta sql ssl customer-managed-certs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/ssl/customer-managed-certs)
