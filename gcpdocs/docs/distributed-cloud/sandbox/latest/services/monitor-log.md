#  Monitor and log metrics Stay organized with collections  Save and categorize content based on your preferences. 

Monitoring and logging features in Google Distributed Cloud (GDC) Sandbox let you collect metrics and logs, configure alert rules, and visualize telemetry data on dashboards. These observability tools help you track workload health, detect performance anomalies, and troubleshoot application issues across your projects.

To set up metric and log collection, see [Collect metrics](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdch/application/ao-user/collect-metrics) and [Collect operational logs](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdch/application/ao-user/collect-logs). To build dashboards and inspect data, see [Query and view metrics](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdch/application/ao-user/query-and-view-metrics) and [Query and view logs](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdch/application/ao-user/query-and-view-logs). For incident tracking and notifications, see [Create alert rules](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdch/application/ao-user/create-alert-rules).
