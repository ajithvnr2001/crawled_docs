## NAME
gdcloud appliance rotate - Rotate appliance secrets.
## SYNOPSIS

```
gdcloud appliance rotate COMMAND [flags]

```

### GDCLOUD WIDE FLAGS
These flags are available to all commands: `--help`.
For more information, see the [gdcloud CLI reference overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/appliance/resources/gdcloud-reference/gdcloud) page.
### COMMANDS
`COMMAND` is one of the following:

```
switch-certificate
    Rotate the Mellanox switch HTTPS API certificate.
switch-credentials
    Rotate the Mellanox switch account credentials.

```
