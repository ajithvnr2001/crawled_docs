#  gdcloud admin Stay organized with collections  Save and categorize content based on your preferences.
## NAME
gdcloud admin - Command group to perform administrative tasks
## SYNOPSIS

```
gdcloud admin GROUP [flags]

```

### GDCLOUD WIDE FLAGS
These flags are available to all commands: `--help`.
For more information, see the [gdcloud CLI reference overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/appliance/resources/gdcloud-reference/gdcloud) page.
### GROUPS
`GROUP` is one of the following:

```
auth
    Command group for the admin authentication

```
