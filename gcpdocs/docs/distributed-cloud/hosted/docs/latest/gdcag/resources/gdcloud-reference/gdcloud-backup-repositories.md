#  gdcloud backup repositories Stay organized with collections  Save and categorize content based on your preferences.
## NAME
gdcloud backup repositories - Manage backup repositories for cluster and virtual machine.
## SYNOPSIS

```
gdcloud backup repositories COMMAND [flags]

```

### GDCLOUD WIDE FLAGS
These flags are available to all commands: `--help`.
For more information, see the [gdcloud CLI reference overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/gdcloud-reference/gdcloud) page.
### COMMANDS
`COMMAND` is one of the following:

```
create
    Create a backup repository.
describe
    Display information for the backup repository.
list
    List all backup repositories.
update
    update a backup repository.

```
