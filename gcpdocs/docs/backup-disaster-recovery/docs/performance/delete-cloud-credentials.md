#  Delete Cloud credentials from the appliance management console Stay organized with collections  Save and categorize content based on your preferences.
Use these instructions to delete an existing Google Cloud credential:
  1. From the Backup and DR appliance management console, click the **Manage** menu and select **Credentials** from the drop-down menu.
The **Credentials** page opens listing all credentials saved on appliances managed by appliance management console.
  2. Select the credential that you want to delete and then select **Delete**.
The **Edit Credential** page opens.
A message opens listing the appliances that have the credential registered. You are prompted to confirm that you want to unregister the Google Cloud credential from those appliances.
  3. Click **OK** to unregister and delete the credential.
