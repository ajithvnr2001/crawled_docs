## October 29, 2026

Feature

Device Run for iOS supports [video recording](https://docs.cloud.google.com/developer-device-platform/device-run/ios#configure-test-run) of test runs with the `--video` flag.

## October 21, 2026

Feature

Device Run offers the ability to run [Android executables](https://docs.cloud.google.com/developer-device-platform/device-run/android-executable), as well as [instrumentation tests](https://docs.cloud.google.com/developer-device-platform/device-run/android-instrument) on Android.

## October 08, 2026

Feature

The Device Run API now provides the [`sessions.batchGet`](https://docs.cloud.google.com/developer-device-platform/reference/device-run/rest/v1alpha/projects.locations.sessions/batchGet) method, which retrieves up to 500 automation sessions in a single request. Sessions are returned in the same order as requested.

## September 30, 2026

Announcement

Developer Device Platform has become the home for users [migrating from Firebase Test Lab](https://docs.cloud.google.com/developer-device-platform/migrate). See also our [Command and flag translation](https://docs.cloud.google.com/developer-device-platform/migrate/flag-command-translation) and [AI migration skill](https://docs.cloud.google.com/developer-device-platform/migrate/migration-skill) for guidance and assistance.

## September 24, 2026

Feature

Discover and use specific versions of [AndroidX Test Orchestrator](https://docs.cloud.google.com/developer-device-platform/device-run/android-instrument#enable-orchestrator) with Device Run.

## September 17, 2026

Feature

Device Run supports [shared storage](https://docs.cloud.google.com/developer-device-platform/device-run/share-storage) so you may use resources outside of the core Google Cloud project with Developer Device Platform.

## September 16, 2026

Feature

Device Run lets you run XCTests on [iOS devices](https://docs.cloud.google.com/developer-device-platform/device-run/ios) just as you can run instrumentation tests on Android devices.

## September 15, 2026

Feature

The Developer Device Platform offers a [Troubleshooting FAQ](https://docs.cloud.google.com/developer-device-platform/troubleshooting) describing common issues and workarounds, as well as a related list of [IP blocks](https://docs.cloud.google.com/developer-device-platform/resources/ip-blocks) from which the service operates.

## September 02, 2026

Feature

The [Device Streaming API documentation](https://docs.cloud.google.com/developer-device-platform/device-streaming) is available in the Developer Device Platform site.

## September 01, 2026

Feature

The Device Catalog offers an [interactive table](https://docs.cloud.google.com/developer-device-platform/device-catalog#available-devices) of all devices in the Developer Device Platform lab.

## August 12, 2026

Announcement

The Developer Device Platform Preview enables remote device orchestration in an enterprise-scale, cloud-native device farm for developers to build and test applications without the overhead of purchasing myriad test devices.

See the [Introducing the Developer Device Platform for agentic mobile app development](https://cloud.google.com/blog/topics/developers-practitioners/announcing-developer-device-platform-on-google-cloud) blog post and the [Developer Device Platform product page](https://cloud.google.com/products/developer-device-platform) for a summary of the product.

The Preview launch offers these features:

  * [Device Catalog](https://docs.cloud.google.com/developer-device-platform/device-catalog) \- Describe all of the device types in the Developer Device Platform lab and delve into each type
  * [Device Run](https://docs.cloud.google.com/developer-device-platform/device-run) \- Run tests on devices in the Developer Device Platform lab and see the results in Google Cloud
  * [Find Logs](https://docs.cloud.google.com/developer-device-platform/device-run/find-logs) \- See your results at the command line and in the Google Cloud console
  * [Device Streaming API](https://docs.cloud.google.com/device-streaming/docs) \- Connect to remote physical Android devices and interact with your app as if it is connected to your local machine
  * [Agentic Development with Device Streaming](https://docs.cloud.google.com/developer-device-platform/agent-skill) \- Use Developer Device Platform agent skill to find, reserve and connect to devices in Developer Device Platform



Jump in with our [Quickstart](https://docs.cloud.google.com/developer-device-platform/quickstart) and see our [API Reference](https://docs.cloud.google.com/developer-device-platform/apis) for complete details.

This command line offering aimed at Android is just the beginning. We plan to provide Google Cloud console integration and iOS support. Stay tuned here for updates.
