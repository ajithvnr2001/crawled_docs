# Nodos personalizados

Copiar páginaCopiar página

Elige la ruta adecuada para crear, extender y publicar nodos personalizados de ComfyUI.

Copiar páginaCopiar página

Esta sección solo cubre cómo desarrollar nodos personalizados. Si te interesa cómo usarlos, consulta [Instalar nodos personalizados](https://docs.comfy.org/es/installation/install_custom_node) en la sección Empezar.

Los nodos personalizados amplían ComfyUI con nuevo comportamiento del servidor, funciones de interfaz e integraciones. Elige una ruta según lo que quieras hacer.

## Crear nodos personalizados

Aprende el modelo cliente-servidor, las categorías de nodos, el backend en Python y el frontend en JavaScript antes de crear tu nodo.

## Empaquetar y publicar

Prepara un paquete de nodos, publícalo en el Comfy Registry y administra las versiones y lanzamientos.
