##

Capacidades clave

  * **Generación de sonido por prompt de texto** : describe el sonido y obtén el audio
  * **Ambientes sonoros** : genera atmósferas de fondo y tonos de sala
  * **Efectos foley** : crea efectos de sonido personalizados para producción de video y videojuegos
