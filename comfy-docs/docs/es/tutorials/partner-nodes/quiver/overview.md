# Quiver AI: generación de SVG | Nodos asociados de ComfyUI

Copiar páginaCopiar página

Aprende a usar los nodos asociados de Quiver en ComfyUI para generar gráficos vectoriales SVG con IA a partir de texto e imágenes de referencia.

Copiar páginaCopiar página

Quiver es una plataforma de gráficos vectoriales impulsada por IA que genera SVG de alta calidad a partir de descripciones de texto e imágenes raster, ahora disponible como nodos asociados en ComfyUI. Con modelos desde **Arrow 1.1** (rápido) hasta **Arrow 1.1 Max** (alta fidelidad) y **Arrow Preview** (experimental), produce ilustraciones vectoriales independientes de la resolución sin necesidad de edición manual.

Para usar los Nodos asociados, debes asegurarte de haber iniciado sesión correctamente y de estar utilizando un entorno de red permitido. Consulta la sección [Descripción general de los Nodos asociados](https://docs.comfy.org/es/tutorials/partner-nodes/overview) de la documentación para conocer los requisitos específicos de uso de los Nodos asociados.

Capacidades principales

  * **Texto a SVG** : genera gráficos vectoriales SVG totalmente editables a partir de descripciones en lenguaje natural; perfecto para iconos, logotipos, ilustraciones y elementos de UI.
  * **Imagen a SVG** : convierte imágenes raster (PNG, JPG) en gráficos vectoriales SVG limpios y escalables trazando formas, colores y degradados.
  * **Arrow 1.1** : modelo estándar que ofrece una generación de SVG rápida y eficiente, adecuada para la mayoría de los casos de uso.
  * **Arrow 1.1 Max** : variante de alta calidad para obtener resultados vectoriales detallados y precisos en ilustraciones complejas.
  * **Arrow Preview** : acceso anticipado a funciones experimentales y a las próximas mejoras del modelo.
