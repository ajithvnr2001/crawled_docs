Esta página reúne en una sola tabla los proveedores de modelos detrás de los Nodos asociados de Comfy: estado de verificación, licencia comercial para uso en Cloud y local, y residencia de datos. Es una estructura que estamos completando activamente, no una referencia finalizada. Algunas columnas reflejan hechos confirmados hoy; otras son marcadores de posición hasta que hayamos verificado los detalles con cada proveedor. Para consultar los precios por proveedor, visita [Precios de los Nodos asociados](https://docs.comfy.org/es/tutorials/partner-nodes/pricing). Esta página cubre los proveedores detrás de los Nodos asociados. Para saber cuánto tiempo almacena Comfy las entradas y salidas de los Nodos asociados, consulta [Retención de datos](https://docs.comfy.org/es/tutorials/partner-nodes/data-retention). Para conocer los proveedores que atienden cada modelo de Comfy Router, consulta [Proveedores de servicio](https://docs.comfy.org/es/development/comfy-router/providers).

## 

​

Qué significa cada columna

  * **Verificado** : “Sí” significa que Comfy tiene un contrato firmado con este proveedor. El contrato establece que el proveedor no usa tu contenido para entrenar o mejorar sus modelos cuando accedes a él a través de Comfy. El proveedor también otorga a Comfy indemnización por propiedad intelectual. “No” significa que se aplican los términos y la política de privacidad del propio proveedor. Esto no significa que el proveedor entrene con tus datos. “Pendiente” significa que aún no hemos confirmado el estado de este proveedor.
  * **Licencia comercial (Cloud)** : si está confirmado el uso comercial a través de Comfy Cloud para los modelos de ese proveedor.
  * **Licencia comercial (local)** : si está confirmado el uso comercial para uso local y autoalojado de los modelos de ese proveedor. “Solicitud” significa que el uso comercial requiere una solicitud o una licencia aparte, en lugar de estar incluido automáticamente.
  * **Residencia de datos** : dónde procesa datos un proveedor de forma predeterminada hoy. “Pendiente” significa que aún no hemos confirmado la ubicación con ese proveedor.

“Pendiente” en una columna de licencia significa que aún no hemos confirmado esa licencia. Eso cambiará a una marca de verificación, un guion o “Solicitud” a medida que confirmemos cada alianza.
