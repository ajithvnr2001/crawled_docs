# LLMs en flujos de trabajo de ComfyUI

Elige el LLM adecuado para tu caso de uso: redacción de prompts, comprensión de imágenes, chat y tareas agénticas en flujos de trabajo de ComfyUI

Copiar páginaCopiar página

Los Nodos asociados de ComfyUI te dan acceso a modelos de lenguaje grandes (LLM) alojados por proveedores como Anthropic, Google, OpenAI y OpenRouter. Estos nodos reciben texto e imágenes como entrada y devuelven texto, así que puedes usarlos para redactar prompts, describir imágenes y conversar junto con tus nodos de generación. Esta página te ayuda a elegir el modelo adecuado para cada tarea.

## 

​

Explorar socios de LLM

## Claude

Razonamiento sólido y seguimiento de instrucciones de Anthropic

## Gemini

Razonamiento multimodal que interpreta imágenes y devuelve prompts de texto enriquecidos

## OpenAI Chat

Modelos de chat con razonamiento general sólido y comprensión de imágenes

## OpenRouter LLM

Accede a muchos proveedores de LLM distintos mediante una sola integración

## 

​

Qué puedes hacer con los LLM

  * **Redacción de prompts** : Genera o refina prompts para tus flujos de trabajo de imagen, video y 3D
  * **Descripción y comprensión de imágenes** : Describe imágenes o responde preguntas sobre su contenido
  * **Conversación** : Chatea con un modelo multimodal dentro de tu flujo de trabajo
  * **Tareas agénticas** : Divide, planifica y orquesta pasos de generación entre nodos



## 

​

Elegir un modelo por proveedor

  * **Claude** (Anthropic): razonamiento sólido y seguimiento de instrucciones; excelente para la ingeniería de prompts estructurada
  * **Google Gemini** (Google): razonamiento multimodal que interpreta imágenes y devuelve prompts de texto enriquecidos
  * **OpenAI Chat** (OpenAI): modelos de chat con razonamiento general sólido y comprensión de imágenes
  * **OpenRouter LLM** (OpenRouter): accede a muchos proveedores de LLM distintos mediante una sola integración
