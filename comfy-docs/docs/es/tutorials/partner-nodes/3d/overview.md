# Modelos 3D en ComfyUI

Copiar páginaCopiar página

Elige el modelo 3D adecuado para tu caso de uso: texto a 3D, imagen a 3D, reconstrucción de personajes y exportación de mallas

Copiar páginaCopiar página

Los Nodos asociados de ComfyUI te dan acceso a modelos de generación 3D alojados de proveedores como Hunyuan 3D, Meshy, Rodin y Tripo, para que puedas crear mallas con textura a partir de un prompt de texto o una imagen de referencia sin necesidad de una GPU local. Esta página te ayuda a elegir el modelo adecuado para texto a 3D, imagen a 3D o reconstrucción de personajes.

El modelo de generación 3D de Tencent

## Meshy 7

## Meshy 6

Generación de texto a 3D e imagen a 3D

## Rodin

Reconstruye modelos 3D detallados a partir de imágenes, incluidos personajes

## Tripo P2

Generación 3D nativa con topología de quads y texturizado por niveles

## Tripo P1

Texto a 3D e imagen a 3D rápidos con topología limpia

## Tripo 3.1

Texto a 3D e imagen a 3D de Tripo

## Tripo Model Generation

El nodo de generación de modelos de Tripo

## 

​

Qué puedes hacer con los modelos 3D

  * **Text-to-3D** : Genera un recurso 3D a partir de una descripción de texto
  * **Image-to-3D** : Reconstruye un modelo 3D con textura a partir de una o varias imágenes de referencia
  * **Exportar** : Descarga mallas para motores de juego, herramientas DCC y flujos de trabajo de impresión 3D



## 

​

Elegir un modelo según la tarea

### 

​

Generación 3D de uso general

  * **Tripo P1 / Tripo 3.1** (Tripo): generación rápida de texto a 3D y de imagen a 3D con topología limpia
  * **Meshy 7 / Meshy 6** (Meshy): de texto a 3D y de imagen a 3D con resultados estilizados y texturizados con PBR
  * **Hunyuan 3D 3.0** (Hunyuan 3D): el modelo de generación 3D de Tencent



### 

​

Reconstrucción de imagen a 3D

  * **Rodin Model Generation** (Rodin): reconstruye modelos 3D detallados a partir de imágenes, incluidos recursos de humanos y de personajes
  * **Meshy 7** (Meshy): de imagen a 3D con alta fidelidad de texturas
