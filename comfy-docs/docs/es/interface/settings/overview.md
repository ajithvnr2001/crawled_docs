# Descripción general de las configuraciones de ComfyUI

Esta sección cubre las descripciones detalladas de las configuraciones en el menú de configuraciones del frontend de ComfyUI. Todas las configuraciones de usuario se guardan automáticamente en el archivo `ComfyUI/user/default/comfy.settings.json`. Puedes usar el atajo de teclado `Ctrl + ,` para abrir el panel de configuraciones y luego hacer clic en las opciones de configuración correspondientes para ajustarlas. Dado que los nodos personalizados también pueden registrar sus propias categorías de configuración en el menú, nuestra documentación oficial actualmente solo incluye el contenido de las configuraciones nativas. Además, algunas opciones de configuración **solo tienen efecto en Comfy Desktop** , lo cual hemos señalado en las páginas correspondientes.

Menú de configuraciones de ComfyUI

## Usuario

Configuraciones de usuario relacionadas con la cuenta de ComfyUI, que se usan principalmente para iniciar sesión en la cuenta de ComfyUI y utilizar los Nodos asociados

## Créditos

Entrada para comprar créditos e historial de saldo de créditos, solo visible después de iniciar sesión en la cuenta de ComfyUI

## Comfy

Descripción detallada de las opciones de configuración principales de ComfyUI

## Lite Graph

Descripción detallada de las opciones de configuración del Lienzo (Lite Graph) en ComfyUI

## Apariencia

Modifica las opciones de apariencia de ComfyUI, como temas, colores de fondo, posición de la barra lateral, etc.

## Extensión

Administrar el estado de habilitación o deshabilitación de los complementos de extensión del frontend en ComfyUI

## 3D

Algunas opciones de configuración para la inicialización de nodos 3D

## Comfy Desktop

Configuraciones de actualización del escritorio, configuraciones de espejo, etc. (solo tienen efecto en Comfy Desktop)

## Editor de máscara

Ajusta las preferencias de uso del editor de máscara

## Combinación de teclas

Modifica las configuraciones de atajos de teclado de ComfyUI

## Acerca de

Consulta la información de la versión actual de ComfyUI, la información del entorno de ejecución del dispositivo, etc., lo cual es muy útil para la retroalimentación diaria

## Configuración del Servidor

Modifica el archivo de configuración de ComfyUI, esta configuración solo tiene efecto en Comfy Desktop
