El nodo PrimitiveInt proporciona una forma sencilla de trabajar con valores enteros en tu flujo de trabajo. Toma una entrada entera y genera el mismo valor, lo que resulta útil para pasar parámetros enteros entre nodos o establecer valores numéricos específicos para otras operaciones.

## 

​

Entradas

Parámetro| Descripción| Tipo de datos| Requerido| Rango  
---|---|---|---|---  
`valor`| El valor entero a generar (predeterminado: 0). El valor permanece fijo y no cambia automáticamente después de la generación.| INT| Sí| -9223372036854775807 a 9223372036854775807
