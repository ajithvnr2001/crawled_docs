#### Autorizaciones

​

X-API-Key

string

header

requerido

API key authentication. Generate an API key from your account settings at <https://platform.comfy.org/profile/api-keys>. Pass the key in the X-API-Key header.

#### Parámetros de consulta

​

prefix

string

Filter tags by prefix

​

limit

integer

predeterminado:100

Maximum number of tags to return (1-1000)

Rango requerido: `1 <= x <= 1000`

​

offset

integer

predeterminado:0

Number of tags to skip for pagination

Rango requerido: `x >= 0`

​

order

enum<string>

predeterminado:count_desc

Sort order for tags

Opciones disponibles: 

`count_desc`, 

`name_asc`

​

include_zero

boolean

predeterminado:false

Include tags with zero usage count

​

include_public

boolean

predeterminado:true

Whether to include public/shared assets when counting tags

requerido

Total number of tags

​

has_more

requerido
