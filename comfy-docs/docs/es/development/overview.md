# ComfyUI para desarrolladores: SDK, API de servidor y nube

Copiar páginaCopiar página

Construye sobre ComfyUI con los SDK oficiales de Python y TypeScript, ejecútalo como servidor, usa las API de la nube o conecta agentes de IA vía MCP.

Copiar páginaCopiar página

ComfyUI es un motor de inferencia GenAI modular que puedes ejecutar como servidor, usar mediante API, ampliar con Nodos personalizados y gestionar desde la línea de comandos. La mayoría del trabajo con la API sigue dos pasos: poner ComfyUI en marcha en algún lugar y luego ejecutar flujos de trabajo contra él desde tu aplicación.
