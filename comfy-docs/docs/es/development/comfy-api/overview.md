# Versiones de Comfy API: v2 y la API v1 de Cloud obsoleta

Copiar páginaCopiar página

Compara las versiones de Comfy API: la API HTTP v2 recomendada para ejecutar flujos de trabajo de ComfyUI sin interfaz y la API v1 de Cloud, obsoleta.

Copiar páginaCopiar página

La API pública para ejecutar ComfyUI sin interfaz ha evolucionado con el tiempo. Para nuevas integraciones, usa [Comfy API v2](https://docs.comfy.org/es/api-reference/v2/overview). Es compatible con ComfyUI de código abierto a través del [API Proxy](https://docs.comfy.org/es/development/comfyui-server/api-proxy), Comfy Cloud y las [implementaciones de Comfy API en la Developer Platform](https://docs.comfy.org/es/development/serverless/overview). Las versiones anteriores incluyen la [API v1 de Cloud](https://docs.comfy.org/es/development/cloud/overview), que está obsoleta.

## Comfy API v2

La API HTTP versionada para ejecutar flujos de trabajo desde cualquier lenguaje, en cualquier entorno. Empieza aquí.

## API v1 de Cloud (obsoleta)

La API de Comfy Cloud anterior, que sigue disponible para integraciones existentes.
