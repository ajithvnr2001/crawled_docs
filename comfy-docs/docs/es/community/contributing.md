# Contribuir

Copiar páginaCopiar página

Aprende a contribuir a Comfy explorando los repositorios de la organización de GitHub, compartiendo flujos de trabajo o desarrollando nodos personalizados.

Copiar páginaCopiar página

Todas las contribuciones son bienvenidas, y no necesitas escribir código para ayudar.

## 

​

Cómo contribuir

  * **Comparte un flujo de trabajo** : publica un flujo de trabajo que hayas creado para que otros usuarios puedan ejecutarlo y aprender de él.
  * **Desarrolla un nodo personalizado** : crea un nodo y publícalo en el [Comfy Registry](https://docs.comfy.org/es/registry/overview).
  * **Mejora la documentación de nodos** : la documentación de los nodos integrados está en el [repositorio embedded-docs](https://github.com/Comfy-Org/embedded-docs), y los nodos personalizados pueden incluir sus propias [páginas de ayuda](https://docs.comfy.org/es/custom-nodes/help_page).
  * **Reporta un error o solicita una función** : abre un problema en el [repositorio de ComfyUI](https://github.com/Comfy-Org/ComfyUI/issues).
  * **Responde preguntas** : ayuda a otros usuarios en los canales que se indican en [Enlaces de la comunidad](https://docs.comfy.org/es/community/links).

Explora todo lo que mantiene el proyecto en la [organización de GitHub Comfy-Org](https://github.com/Comfy-Org).
