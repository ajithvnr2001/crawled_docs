## 关于 ComfyUI

由 [comfyanonymous](https://github.com/comfyanonymous) 和其他[贡献者](https://github.com/Comfy-Org/ComfyUI/graphs/contributors)编写。

**ComfyUI** 是面向视觉 AI 的开源、基于节点的界面和推理引擎。你将模型和操作作为工作流中的节点连接起来，从而控制图像、视频、音频和 3D 生成的每一步。Comfy 围绕它构建了以下产品：

  * [ComfyUI](https://github.com/Comfy-Org/ComfyUI)：开源引擎和界面。可以在你自己的电脑或服务器上免费运行。
  * [Comfy Desktop](https://docs.comfy.org/zh/installation/desktop/overview)：适用于 Windows、macOS 和 Linux 的应用，可安装 ComfyUI 并在你的电脑或 Comfy Cloud 上打开它。
  * [Comfy Cloud](https://docs.comfy.org/zh/get_started/cloud)：运行在云端 GPU 上的 ComfyUI，无需安装任何内容。
  * [Comfy Router](https://docs.comfy.org/zh/development/comfy-router/quickstart)：一个 API、一个密钥，即可使用前沿的图像、视频和音频模型。
  * [Comfy API](https://docs.comfy.org/zh/development/deploy/overview)：部署你的工作流，并从你自己的应用程序中运行它们。
  * [Comfy MCP 与 Comfy CLI](https://docs.comfy.org/zh/agent-tools)：将 AI 智能体和脚本连接到 ComfyUI，可在本地或 Comfy Cloud 上使用。
  * [Comfy Registry](https://docs.comfy.org/zh/registry/overview)：扩展 ComfyUI 的自定义节点的公共索引。
