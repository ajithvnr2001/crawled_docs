# 커스텀 노드

페이지 복사페이지 복사

ComfyUI 커스텀 노드를 구축, 확장, 게시하기 위한 올바른 경로를 선택하세요.

페이지 복사페이지 복사

이 섹션에서는 커스텀 노드를 개발하는 방법만 다룹니다. 커스텀 노드 사용 방법은 시작하기 섹션의 [커스텀 노드 설치](https://docs.comfy.org/ko/installation/install_custom_node)를 참조하세요.

커스텀 노드는 새로운 서버 측 동작, 사용자 인터페이스 기능, 통합 기능을 추가하여 ComfyUI를 확장합니다. 수행하려는 작업에 따라 경로를 선택하세요.

## 커스텀 노드 구축

노드를 구축하기 이전에 클라이언트-서버 모델, 노드 카테고리, Python 백엔드, JavaScript 프론트엔드를 학습하세요.

## 패키징 및 게시

노드 패키지를 준비하고, Comfy Registry에 게시하고, 버전과 릴리스를 관리하세요.

## 

​

시작점 선택

  * **커스텀 노드가 처음이라면:** [커스텀 노드 개요](https://docs.comfy.org/ko/custom-nodes/overview)부터 시작하세요.
  * **백엔드를 구축하는 경우:** [Python (백엔드)](https://docs.comfy.org/ko/custom-nodes/backend/server_overview)를 참조하세요.
  * **UI를 확장하는 경우:** [JavaScript (UI)](https://docs.comfy.org/ko/custom-nodes/js/javascript_overview)를 참조하세요.
  * **패키지를 게시하는 경우:** [Registry 개요](https://docs.comfy.org/ko/registry/overview)부터 시작하세요.
