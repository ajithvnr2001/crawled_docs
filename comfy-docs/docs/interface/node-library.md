# Node Library - Browse and Add Nodes

Copy pageCopy page

Browse Essentials and All nodes in the ComfyUI Node Library sidebar, bookmark favorites, and drag nodes onto the canvas.

Copy pageCopy page

The **Nodes** entry in the left sidebar opens the Node Library. Use it to find every node available in your ComfyUI instance: Comfy Core, Partner Nodes, and the custom nodes you have installed. The panel is searchable. ![The Node Library on the All nodes tab with the Bookmarked section at the top](https://mintcdn.com/dripart/svxMC8DHZXobTT5E/images/interface/overview/node_library_bookmarked.png?fit=max&auto=format&n=svxMC8DHZXobTT5E&q=85&s=4bb7a0777285a561a570906885c965cb) ![ComfyUI Node Library panel with the Essentials tab open, showing the INPUTS & OUTPUTS tiles](https://mintcdn.com/dripart/svxMC8DHZXobTT5E/images/interface/overview/node_library_essentials.png?fit=max&auto=format&n=svxMC8DHZXobTT5E&q=85&s=7d4f2cf43b931ebc1024fb54d0713432) The panel has two tabs when the **Essentials** tab is available:

  * **Essentials** : a curated grid of the nodes most workflows need, grouped by task. The sections are Inputs & Outputs, Generate (Image, Video, Text, Audio, 3D), Control & Guidance (Image), and Editing & Utilities (Image Transform, Image Utilities, Image Filters & Effects, Image Color, Image Selection & Masking, Video Transform, Video Compose, Video Selection & Masking, 3D Transform). Hover a tile to preview the node before you use it. Drag a tile onto the canvas to add the node to your workflow. Use the filter button to show only the media types you work with, and the list button to jump straight to a section.
  * **All nodes** : the full node list. Filter it by Comfy Nodes, Partner Nodes, Extensions, or Blueprints, and switch the sort between the default categorized order and A-Z.

Click the bookmark icon on a node in **All nodes** to add it to the **Bookmarked** section at the top of the list. ![ComfyUI Node Library panel on the All nodes tab, showing the Bookmarked, Comfy Nodes, Partner Nodes, and Extensions groups](https://mintcdn.com/dripart/svxMC8DHZXobTT5E/images/interface/overview/node_library_all_nodes.png?fit=max&auto=format&n=svxMC8DHZXobTT5E&q=85&s=05826517cb8747125332737b7ef0476d) The **Essentials** tab appears when the ComfyUI backend enables it, which is the case on Comfy Cloud and in nightly builds. A self-hosted stable install shows only **All nodes**. You can return to the previous panel in `Settings` —> `Comfy` —> `Node Library` by disabling `New Node Library Design`.
