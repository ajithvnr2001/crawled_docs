# インターフェース概要

ページをコピーページをコピー

ComfyUI UI の地図：ワークスペース領域、機能コンポーネント、設定、アカウントとクレジット、Cloud 専用機能へのリンク。

ページをコピーページをコピー

ビジュアル UI は多くの人が [ComfyUI Server](https://docs.comfy.org/ja/development/comfyui-server/comms_overview) を操作する手段です。このページは UI の地図です。各領域とコンポーネントの詳細はリンク先を参照してください。 ![ComfyUI Basic Interface](https://mintcdn.com/dripart/EeFKEryMLH5667kk/images/interface/overview/comfyui_new_interface.jpg?fit=max&auto=format&n=EeFKEryMLH5667kk&q=85&s=4d18b1d3d8044ca37fc71f7e89d143e7) [ComfyUI フロントエンド](https://github.com/Comfy-Org/ComfyUI_frontend) は独立プロジェクトとして保守されています。

ローカリゼーション

英語、中国語、ロシア語、フランス語、日本語、韓国語に対応しています。**設定** を開き、`Comfy` → `Locale` で言語を選びます。 ![ComfyUI Localization Support](https://mintcdn.com/dripart/eWfBNjjL5jL2h2ib/images/interface/overview/locale.jpg?fit=max&auto=format&n=eWfBNjjL5jL2h2ib&q=85&s=f7bdc0a03f437ea74bd9c69e3b9bc6d7)

## 

​

ワークスペース地図

![番号 1–6 付きの ComfyUI ワークスペース](https://mintcdn.com/dripart/svxMC8DHZXobTT5E/images/interface/overview/comfyui-new-interface-main.png?fit=max&auto=format&n=svxMC8DHZXobTT5E&q=85&s=6982fc75dedc493b140fe44816557e5e) スクリーンショットの番号は下表の領域に対応します：

#| 領域| 内容  
---|---|---  
**1**| **左サイドバー**|  Assets、Node Library、Model Library、Workflows、Apps、（有効時）Job History  
**2**| **キャンバス**|  ノードを配置・接続するグラフとキャンバス操作  
**3**| **右サイドパネル**|  選択中のパラメータ、ノード情報、設定、エラー（トップバーのプロパティ切り替えで開く）  
**4**| **トップバー**|  開いているワークフロー、Run / キュー、ログイン、プロパティ切り替え  
**5**| **左下**|  Help Center、ボトムパネル、設定  
**6**| **右下**|  キャンバス操作：パン、ミニマップ、リンク表示、ズーム、フィット

左サイドバー

左レールのアイコンは上から下へ並びます。**Job History** は `Comfy.Queue.QPOV2` が有効なときだけ先頭に表示されます： ![左サイドバーのアイコン順: 有効時は Job History、続けてアセット、ノード、モデル、ワークフロー、アプリ](https://mintcdn.com/dripart/svxMC8DHZXobTT5E/images/interface/overview/sidebar_order.png?fit=max&auto=format&n=svxMC8DHZXobTT5E&q=85&s=660e8ca23ca81dbf9a3daf5c8a518f0d)
