# カスタムノード

ページをコピーページをコピー

ComfyUI カスタムノードの構築、拡張、公開に適切なパスを選択します。

ページをコピーページをコピー

このセクションではカスタムノードの開発方法のみを扱います。カスタムノードの使用方法については、はじめにのセクションの[カスタムノードのインストール](https://docs.comfy.org/ja/installation/install_custom_node)を参照してください。

カスタムノードは、新しいサーバーサイドの動作、ユーザーインターフェイス機能、および統合機能を追加することで ComfyUI を拡張します。やろうとしていることに応じてパスを選択してください。

## カスタムノードを構築する

ノードを構築する前に、クライアント・サーバーモデル、ノードカテゴリ、Python バックエンド、JavaScript フロントエンドについて学びます。

## パッケージ化と公開

ノードパッケージを準備し、Comfy Registry に公開して、バージョンとリリースを管理します。
