# コーディングエージェント向け Comfy Skills

ページをコピーページをコピー

Comfy Skills リポジトリを通じて公開される、Comfy のエージェントスキルとプラグイン。

ページをコピーページをコピー

[**Comfy Skills**](https://github.com/Comfy-Org/comfy-skills) は、Comfy のエージェントスキルとプラグインの拠点です。スキルとは、エージェントが必要に応じて読み込むパッケージ化された知識で、モデルのガイダンス、ワークフローのパターン、既製のコマンドなどが含まれます。プロンプトをゼロから書かなくても、あらゆるエージェントが ComfyUI をより上手く扱えるようになります。 このリポジトリには以下が含まれています：

  * **Claude Code プラグイン** ：例えば **comfy-cloud** があります。これは Comfy Cloud MCP 接続と `/comfy-cloud:*` スラッシュコマンドを一度のインストールで追加します。
  * **エージェントスキル** ：特定のタスク向けの焦点を絞った指示。現在のモデルの推奨やワークフロー構築のノウハウなど、モデルの変更に合わせて最新の状態に保たれます。
  * **コミュニティからの貢献** ：Comfy コミュニティによるスキルとプラグイン。

Claude Code で使用するには：
    
    
    /plugin marketplace add Comfy-Org/comfy-skills
    /plugin install comfy-cloud@comfy-skills
    

プラグインのスラッシュコマンドとセットアップの詳細については、[Comfy MCP](https://docs.comfy.org/ja/agent-tools/mcp) を参照してください。
