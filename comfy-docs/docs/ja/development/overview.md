# ComfyUI 開発者向け：SDK、サーバー API、クラウド

ページをコピーページをコピー

公式の Python / TypeScript SDK で ComfyUI 上に構築し、サーバーとして実行、Cloud API の呼び出し、MCP による AI エージェント接続が可能です。

ページをコピーページをコピー

ComfyUI はモジュール式の GenAI 推論エンジンで、サーバーとして実行したり、API 経由でアクセスしたり、カスタムノードで拡張したり、コマンドラインから管理したりできます。API を使った作業のほとんどは 2 つのステップで進みます。まず ComfyUI をどこかで起動し、次に自分のアプリケーションからワークフローを実行します。

​

ユースケース

## API キーを取得

Cloud API、パートナーノード、MCP で使用する認証情報を作成します。

## モデルを実行

Comfy Router を通じてホスト型モデルで生成します。

## SDK でワークフローを実行

Python または TypeScript SDK からデプロイを呼び出します。

## ComfyUI ワークフローをデプロイ

マネージドインフラストラクチャまたはセルフホストの ComfyUI で、自分のワークフローを実行します。

## AI エージェントを構築

MCP とエージェントツールを通じて、エージェントを ComfyUI に接続します。

## モデルをブラウズ

Comfy.org で利用できるモデルをブラウズします。
