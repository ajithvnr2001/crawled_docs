# ComfyUI のデプロイ

ページをコピーページをコピー

Comfy Cloud、マネージド Comfy API デプロイ、セルフホストを比較して、ComfyUI の実行方法を選択します。

ページをコピーページをコピー

常時利用可能なマネージド ComfyUI には Comfy Cloud を、エンドポイントとしてデプロイするバージョン管理された環境には Comfy API を、自身で管理するインフラストラクチャにはセルフホストを選びます。

## Comfy Cloud

Build やデプロイを作成せずにワークフローを実行します。

## Comfy API

モデルとカスタムノードをパッケージ化し、マネージドで自動スケーリングするエンドポイントとして提供します。

## セルフホスト

自身のハードウェア、レンタル GPU、またはコンテナ上で ComfyUI を実行します。

3 つの選択肢はいずれも [API フォーマットのワークフロー](https://docs.comfy.org/ja/development/api-development/workflow-api-format)を実行します。Comfy に環境を管理させるか、自身で管理するかに基づいて選択してください。
