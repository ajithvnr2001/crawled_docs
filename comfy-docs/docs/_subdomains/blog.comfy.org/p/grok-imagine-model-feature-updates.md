Now available with Partner Nodes are two new features for the Grok Imagine Video model! The Grok Reference-to-Video node allows up to 7 reference images and generates consistent videos using those inputs. The Grok Video Extend node takes an input video of up to 15 seconds and extends the video up to an additional 10 seconds while maintaining coherent motion and audio.

[Video Extend on ComfyCloud](https://links.comfy.org/47MHpjG)

[Reference-to-Video on ComfyCloud](https://links.comfy.org/4d6jpvw)

  
The speed of these models is very impressive and allows for quick generation and iteration. Using Grok Video Extend at 10 seconds, the generation takes ~60 seconds. With Reference-to-Video, 10 second generation times at 720p take ~100 seconds. Check out the examples below to see both of the new features in action!  


## **Get Started**

  1. **Update** ComfyUI to the latest version or visit [Comfy Cloud](https://links.comfy.org/4d6jpvw)

  2. **Find** the Grok Reference-to-Video or Grok Video Extend nodes in the Node Library or Templates in the left sidebar.

  3. **Drop a node** on your canvas and start creating.
