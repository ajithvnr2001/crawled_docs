We're excited to announce that on March 28, **ComfyUI-Manager** will be moving to the **Comfy-Org** GitHub organization as **Comfy-Org/ComfyUI-Manager**. This represents a natural evolution as we continue working to improve the custom node experience for all ComfyUI users.

## **What This Means For You**

This change is primarily about improving support and development velocity. There are a few practical considerations:

  * **Automatic GitHub redirects** will ensure all existing links, git commands, and references to the repository will continue to work seamlessly without any action needed

  * **For developers:** Any existing PRs and issues will be transferred to the new repository location

  * **For users:** ComfyUI-Manager will continue to function exactly as before—no action needed

  * **For workflow authors** : Resources that reference ComfyUI-Manager will continue to work without interruption




## **Our Vision for Custom Nodes**

Custom nodes are what make ComfyUI truly special—they represent the innovation and creativity of our community. Since its inception, **ComfyUI-Manager** has been the essential bridge connecting users with this vibrant ecosystem of custom nodes. As ComfyUI has grown, the Manager has become increasingly central to the user experience.

[Dr.Lt.Data](https://github.com/ltdrdata), who has been the driving force behind ComfyUI-Manager from the beginning, will continue to maintain and develop it. By formally bringing ComfyUI-Manager into **Comfy-Org** , we're recognizing its essential role and ensuring Dr.Lt.Data has additional support from the broader Comfy-Org team.

## **Progress on Multiple Fronts**

Making custom node discovery, installation, and usage more seamless is a core focus for us. Bringing ComfyUI-Manager into **Comfy-Org** is just one part of our broader efforts to improve the custom node experience:

  * The **[Comfy Node Registry](https://registry.comfy.org/)** continues to expand, now providing access to all the same nodes you'd find in ComfyUI-Manager

  * Enhanced **Custom Node Registry** features including better moderation and improved developer tools

  * **Pre-built packages** for Windows that eliminate common dependency issues across different setups

  * More comprehensive solutions for the most frequently encountered custom node errors




## **Looking Forward**

This is just the beginning. In the near future, you can expect to see:

  * Enhanced installation safety with snapshot functionality, allowing you to easily restore your previous setup if needed

  * Coordinated release cycles that align **ComfyUI-Manager** updates with ComfyUI core updates

  * Native integration of **ComfyUI-Manager** into ComfyUI, available right out of the box

  * Streamlined custom node management directly within the ComfyUI interface




* * *

We're committed to ensuring that custom nodes remain a cornerstone of what makes ComfyUI powerful while making them more accessible and reliable for everyone.

Thank you for being part of this journey with us!
