## Q&A

### What is FLUX 3 Image Klein?

FLUX 3 Image Klein is the compact, open-weights image model in Black Forest Labs’ FLUX 3 family. It has 5.6B parameters, runs on a single consumer GPU, and handles text-to-image generation and image editing in one model. It generates natively at 4K and supports bounding box layout control and multiple reference images.

### How do I use FLUX 3 Image Klein in ComfyUI?

Update ComfyUI to the latest version, download the FLUX 3 Image Klein weights from Hugging Face, and load the FLUX 3 Image Klein template. FLUX 3 Image Klein runs on ComfyUI’s standard loaders: Load Diffusion Model for the checkpoint, Load CLIP with type set to flux3 for the Qwen3-VL 4B text encoder, and Load VAE. No API key is needed.

### Can I use FLUX 3 Image Klein commercially?

It depends on your revenue. FLUX 3 Image Klein is released under the FLUX Kommunity License, which allows free non-commercial use. If you and your affiliates have under US$5M in annual revenue, you can also use the images you generate commercially, provided you filter or review outputs and disclose AI generation where the law requires it. Any other commercial use, including commercial fine-tunes, needs a license from Black Forest Labs at [bfl.ai/licensing](https://bfl.ai/licensing).

### How much does FLUX 3 Image Klein cost in ComfyUI?

FLUX 3 Image Klein is open weights, so running it locally in ComfyUI costs nothing per image beyond your own hardware. On Comfy Cloud it draws on your plan’s compute; see the [ComfyUI pricing page](https://comfy.org/pricing/) for current rates. Cost and licensing are separate questions: the FLUX Kommunity License governs commercial use wherever you run it.

### How does FLUX 3 Image Klein compare to FLUX.2 [klein]?

FLUX 3 Image Klein improves on FLUX.2 [klein] 9B in Black Forest Labs’ internal text-to-image evaluations while using fewer parameters, 5.6B against 9B. It also brings over control features from the larger FLUX 3 Image model, including bounding boxes, and generates natively at 4K.

### Is FLUX 3 Image Klein the same as the FLUX 3 Image Partner Node in ComfyUI?

No. The FLUX 3 Image Partner Node calls Black Forest Labs’ hosted API and runs the larger FLUX 3 Image model. FLUX 3 Image Klein is the open-weights model you download and run yourself, locally or on Comfy Cloud. Both are available in ComfyUI.

### Which versions of FLUX 3 Image Klein are available?

FLUX 3 Image Klein ships as an undistilled base checkpoint for fine-tuning, further training, and research, and as a distilled checkpoint for faster generation. Both come with INT8, FP8 and NVFP4 quantized builds that use less memory. All of them run on the same ComfyUI loaders.

### Does FLUX 3 Image Klein generate at 4K?

Yes. FLUX 3 Image Klein generates natively at 4K rather than upscaling to it. Fine detail holds up when you zoom in, crop, or print.

### What are bounding boxes in FLUX 3 Image Klein?

Bounding boxes let you mark regions of the canvas and say what goes in each, so FLUX 3 Image Klein follows your layout instead of choosing its own. They are useful for compositions with several subjects, product shots, and designs with text in fixed positions.

### What does the FLUX 3 prompt upsampler do?

The prompt upsampler is a separate model that expands a short prompt into a detailed one before FLUX 3 Image Klein generates. In ComfyUI it loads through Load CLIP with type set to flux3. Try the same short prompt with and without it to see the difference.

### Can I fine-tune FLUX 3 Image Klein or train LoRAs on it?

Yes. The undistilled base checkpoint of FLUX 3 Image Klein is built for fine-tuning and further training, and LoRAs trained on it load through ComfyUI’s standard LoRA loader. Under the FLUX Kommunity License, fine-tuning for commercial use requires a separate license from Black Forest Labs.
