## Q&A

### What is ChatGPT Images 2.5?

ChatGPT Images 2.5 is an OpenAI image model for generating new visuals and editing existing images from natural-language instructions. In ComfyUI, it runs through Partner Nodes and can be combined with the rest of your workflow.

### How do I run ChatGPT Images 2.5 in ComfyUI?

Open [Comfy Cloud](https://cloud.comfy.org/?template=api_openai_gpt_image_25_flare_t2i&utm_source=comfy.org&utm_medium=referral&utm_campaign=gpt-image-2-5), add the OpenAI image Partner Node to a workflow, enter a prompt, and connect any reference images you want to use.

### Can ChatGPT Images 2.5 edit an existing image?

Yes. Supply an image and describe the change you want, from replacing objects and restyling a scene to focused masked edits. You can keep the result in the same graph for further processing.

### Can I use reference images?

Yes. Reference images can guide the subject, composition, materials, or visual language of a generation. Describe which qualities should carry into the result.

### How should I prompt ChatGPT Images 2.5?

Write a clear creative brief: name the subject, setting, composition, lighting, medium, and any text that must appear. For edits, state what should change and what must stay untouched.

### Why use ChatGPT Images 2.5 in a ComfyUI workflow?

The generated image becomes one step in a larger, repeatable pipeline. Route it into masking, compositing, upscaling, animation, or another model while keeping every step visible and adjustable.
