## Q&A

### What is Qwen-Image 2.1?

Qwen-Image 2.1 is an open-weight image model from Alibaba's Qwen team. It runs 7B parameters on an optimized MMDiT architecture, outputs RGBA images with a real alpha channel, generates at native 2K, and handles both generation and editing in a single checkpoint.

### How do I use Qwen-Image 2.1 in ComfyUI?

Update ComfyUI to the latest version and download the Qwen-Image 2.1 weights from Hugging Face into your models folder. Add the Text Encode Qwen Image 2.1 node, found under model/conditioning/qwen image, or load the [Qwen-Image 2.1 template](https://cloud.comfy.org/?template=image_qwen_image_2_1_t2i&utm_source=comfy.org&utm_medium=referral&utm_campaign=qwen-image-2-1). Comfy Cloud runs the same workflow without a local download.

### How much does Qwen-Image 2.1 cost in ComfyUI?

Qwen-Image 2.1 is open weights, so running it locally in ComfyUI costs nothing per image beyond your own hardware. On Comfy Cloud it draws on your plan's compute — see the [ComfyUI pricing page](https://comfy.org/pricing/) for current rates.

### Can I use Qwen-Image 2.1 commercially?

No. Qwen-Image 2.1 is released under the [Qwen Research License Agreement](https://huggingface.co/Qwen/Qwen-Image-2.1/blob/main/LICENSE), which grants a royalty-free license "FOR NON-COMMERCIAL PURPOSES ONLY" and directs commercial licensing inquiries to the model maker. The license also requires products built with the model to display "Built with Qwen" in their documentation. Check the license yourself before using output in any commercial work.

### Can Qwen-Image 2.1 generate transparent images?

Yes. Qwen-Image 2.1 outputs four-channel RGBA, so transparency comes out of the model itself rather than a background-removal pass. Sprites, logos, icons, and product cutouts land with alpha already correct, ready to composite. On the input side, the Text Encode Qwen Image 2.1 node passes full RGBA to the VAE and composites alpha over white for the vision tower.

### What resolution does Qwen-Image 2.1 output?

Qwen-Image 2.1 generates natively at 2K — 2048×2048 direct output, not upscaled from a smaller render. For edits, the node's resolution setting controls the size reference images are resized to: it defaults to 1024, accepts up to 4096 in steps of 32, and 0 keeps each reference at its own size.

### How many reference images can Qwen-Image 2.1 take?

The Text Encode Qwen Image 2.1 node opens image inputs as you fill them, up to 16. Each one is read by the text encoder and spliced into the sequence as a VAE latent, so a character, a product, a background plate, and a style reference can all drive a single edit. Start from the [image-edit template](https://cloud.comfy.org/?template=image_qwen_image_2_1_image_edit&utm_source=comfy.org&utm_medium=referral&utm_campaign=qwen-image-2-1) on Comfy Cloud.

### Why does my Qwen-Image 2.1 edit come out shifted?

Use the latent output on the Text Encode Qwen Image 2.1 node rather than an empty latent of your own. That output is sized to the first reference image, and sampling at any other size shifts the edit.

### How do I run Qwen-Image 2.1 with less memory?

At 7B parameters Qwen-Image 2.1 is built for consumer GPUs, and the experimental Qwen Image 2.1 Cache node tunes it further. Set the KV cache to auto, gpu, cpu, or off, and pick a storage precision: int8 halves the cache at about bf16 accuracy, int4 quarters it but roughly doubles per-step error.
