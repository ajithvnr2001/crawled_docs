## Q&A

### Can the Nvidia VFX nodes run on any GPU?

No. The nvidia-vfx library requires an Nvidia RTX GPU powered by Nvidia's proprietary technology. The RTX Video Frame Generation is supported on Nvidia 40 series and later only.

### Are the nodes open source?

Yes. All three nodes are published on [GitHub](https://github.com/Comfy-Org/ComfyUI_Nvidia_VFX_Nodes) and install as a ComfyUI custom node. The nodes are licensed Apache-2.0, so they are free for commercial use. The nvidia-vfx library they depend on is distributed by Nvidia under its own proprietary license.

### Where do I find example workflows?

The custom node ships with example workflows for each node. Open them from ComfyUI after installing.
