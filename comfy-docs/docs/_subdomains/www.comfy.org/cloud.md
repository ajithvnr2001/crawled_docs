## FAQs

What is Comfy Cloud / ComfyUI Cloud?+

Comfy Cloud is a version of ComfyUI that we officially host — no setup, no GPU required. Run your workflows instantly on high-performance cloud GPUs.

How is Cloud different from running ComfyUI locally?+

Cloud runs on powerful remote GPUs and is accessible from any device. Comfy Desktop runs entirely on your computer, giving you full control and offline use.

Which version should I choose, Comfy Cloud or Comfy Desktop?+

Comfy Cloud has zero setup, is easy to share with your team, and is faster than most GPUs you can run on a desktop workstation. You can immediately run the best models and workflows from the community on Comfy Cloud. Comfy Desktop is infinitely customizable, works offline, and you don't need to worry about queue times. However, depending on what you want to create, you might need to have a good GPU and some amount of technical knowledge to install community-created custom nodes.

Do I need a GPU or a strong computer to use Comfy Cloud?+

No, you can start creating instantly from your browser, no matter what computer you use.

What machine or GPU does Comfy Cloud run on?+

Comfy Cloud runs on Blackwell RTX 6000 Pros — 96GB VRAM, with a library of 900+ pre-installed models and support for many of the most-used custom nodes from the ComfyUI community. We expand node support regularly based on demand and compatibility.

Can I use my existing workflows with Comfy Cloud?+

Yes, your workflows work across Desktop and Cloud. Just note that only the most popular custom nodes are supported for now, but more will be added soon.

Are all ComfyUI extensions and custom nodes supported?+

You can always check Cloud to see the list of extensions and models that we support, for free. Most popular ones are available, and new ones are added over time.

Can I use my own models or checkpoints?+

You can always check Cloud to see the list of extensions and models that we support, for free. Currently, we support a wide variety of preinstalled models. For those on the Creator, Pro, or Team plans, you can bring in your own fine-tuned LoRAs from CivitAI or HuggingFace to perfect your own style. Direct file upload for larger models is on our roadmap.

Can I run long or multiple workflows?+

Each workflow has a max runtime of 30 minutes on Standard and Creator, raised to 1 hour on Pro. Jobs over the limit are cancelled automatically to keep the system fair and stable. You can queue up to 100 workflows at once, and run 1 / 3 / 5 concurrently via API on Standard / Creator / Pro. Need higher API rate limits? Contact enterprise@comfy.org.

How is my user data stored and secured in Comfy Cloud?+

By default, all your inputs, outputs, and workflows are private to your account. For enhanced security features or enterprise-level options, please contact our team via support@comfy.org for more details.

Will ComfyUI always be free to run locally?+

Yes, absolutely. ComfyUI will always be free and open source. You can deploy it however you want, such as downloading it from GitHub, using Docker, custom setups, etc. Comfy Cloud is an optional hosted service for those who prefer convenience, accessibility, or don't have powerful GPUs.

How much does Comfy Cloud cost?+

Plans start at $20/mo with a credit-based model. For full pricing details — credits, plans, Team plan, billing, and refunds — see the [Pricing FAQs](https://www.comfy.org/pricing/#faq).
