# Local / Desktop troubleshooting

Last updated 3 days ago

> This article covers common troubleshooting steps for ComfyUI Local and Desktop.

## Q. ComfyUI isn’t starting or loading properly

Before trying advanced troubleshooting:

  * Restart ComfyUI

  * Refresh your browser

  * Confirm your system meets the recommended requirements

  * Check whether your installation is up to date




For full troubleshooting guidance:

👉 See[**Comfy Docs - Troubleshooting**](https://docs.comfy.org/troubleshooting/overview)

* * *

## Q. The Desktop app won't start after installation

Try the following depending on your operating system:

**Windows**

  * Try running the app as administrator once




**macOS**

  * If you see a security warning, go to **System Settings → Privacy & Security → Open Anyway**




**Linux**

  * Make sure `fuse2` is installed




Also check whether you're using the latest Desktop version.

👉[**Download Comfy**](https://comfy.org/download)

* * *

## Q. Comfy Desktop closes by itself after an update (Windows)

On Windows, Comfy Desktop 1.0.46 and earlier can get stuck if an update download didn't finish. The app briefly shows an update screen, then closes without an error every time you open it. Because it closes before it can download the fix, it can't repair itself.

To recover, install the latest version manually:

  1. Download the latest Windows installer

  2. Run the installer. You don't need to uninstall the old version first.

  3. Open Comfy Desktop




Your installations, models, and settings are kept.

👉[**Download Comfy Desktop for Windows**](https://dl.todesktop.com/241130tqe9q3y/windows)

👉[**See Comfy Docs - Desktop FAQ**](https://docs.comfy.org/installation/desktop/faq)

* * *

## Q. My GPU is not detected

Try the following:

  * Update your GPU drivers

  * Confirm your installation type supports GPU acceleration

  * Verify your hardware is supported




For troubleshooting steps:

👉 See [**Comfy Docs - Troubleshooting**](https://docs.comfy.org/troubleshooting/overview)

For system requirements:

👉 See [**Comfy Docs - System Requirements**](https://docs.comfy.org/installation/system_requirements)

* * *

## Q. An installation fails to update

Try:

  * Checking your internet connection

  * Creating a manual snapshot first

  * Restoring to a previous snapshot and retrying




If the issue continues:

👉[**Comfy Docs - Troubleshooting**](https://docs.comfy.org/troubleshooting/overview)

* * *

## Q. How do I uninstall Comfy Desktop?

Comfy Desktop and its installations are stored separately.

To fully remove Comfy Desktop:

  1. Remove installations from inside the app (**Right click → Remove**) or delete installation folders manually

  2. Uninstall the Desktop app using your operating system




Examples:

  * Windows → Add / Remove Programs

  * macOS → Move to Trash

  * Linux → Use your package manager
