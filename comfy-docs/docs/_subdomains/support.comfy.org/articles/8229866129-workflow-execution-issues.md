# Workflow / execution issues

Last updated 1 month ago

This article helps troubleshoot common workflow and execution issues.

## Q. My workflow won't open or import

If a workflow does not open correctly:

Try:

  * Confirming the workflow file is supported

  * Checking whether required nodes are available

  * Re-importing the workflow




For workflow handling:

👉 See [**Import & export workflows**](https://support.comfy.org/articles/2229074405-import-export-workflows)

* * *

## Q. My workflow opens but doesn't run

This may happen due to:

  * Missing nodes

  * Missing models

  * Environment differences

  * Workflow configuration issues




For troubleshooting:

👉 See [**Import & export workflows**](https://support.comfy.org/articles/2229074405-import-export-workflows)**/** [**Local/Desktop Troubleshooting**](https://support.comfy.org/articles/6804469981-local-desktop-troubleshooting)

* * *

## Q. I'm seeing missing nodes or missing models

Workflows may depend on:

  * Installed custom nodes

  * Specific models

  * Environment-specific setup




For details:

👉 See [**Installing custom nodes**](https://docs.comfy.org/installation/install_custom_node)**/** [**Custom nodes on Cloud**](https://support.comfy.org/articles/6791455062-custom-nodes-on-cloud)

* * *

## Q. My workflow behaves differently between Local and Cloud

Some workflows may behave differently depending on:

  * Available nodes

  * Installed models

  * Environment configuration




For compatibility details:

👉 See [**Custom nodes on Cloud**](https://support.comfy.org/articles/6791455062-custom-nodes-on-cloud)

* * *
