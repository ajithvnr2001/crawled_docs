# Missing nodes / workflow won't load

Last updated 4 months ago

> This article explains common reasons why workflows may not load correctly.

## Q. My workflow opened with missing nodes

If a workflow opens with missing nodes, it usually means the required nodes are not available in your current environment.

Try checking:

  * Whether all required custom nodes are installed

  * Whether the workflow was created in Cloud or Local

  * Whether required models are available




For installation guidance for custom nodes:

👉 See[ **Comfy Docs - Install Custom Nodes**](https://docs.comfy.org/installation/install_custom_node)

* * *

## Q. I imported a workflow but it doesn’t work correctly

Workflows are generally compatible across environments, but issues may happen if they depend on:

  * Unsupported custom nodes

  * Missing models

  * Environment-specific configuration




Review the workflow requirements and compare them with your current setup.

* * *

## Q. My workflow works locally but not in Cloud

Comfy Cloud supports a managed set of nodes and models.

If your workflow depends on unsupported resources, some nodes may not load or execute.

To check supported Cloud nodes:

  * Open Comfy Cloud

  * Open the **Nodes** tab from the left sidebar




If there's a node, model, or workflow you'd like supported in Cloud:

**👉**[**Request Custom Nodes**](https://forms.fillout.com/t/qePaxpWyQwus)
