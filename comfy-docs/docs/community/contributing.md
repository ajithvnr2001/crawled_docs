# Contributing

Copy pageCopy page

Learn how to contribute to Comfy by exploring the GitHub organization’s repositories, sharing workflows, or developing custom nodes.

Copy pageCopy page

We welcome contributions of all kinds, and you do not need to write code to help.

## 

​

How to contribute

  * **Share a workflow** : publish a workflow you built, so other users can run it and learn from it.
  * **Develop a custom node** : build a node and publish it to the [Comfy Registry](https://docs.comfy.org/registry/overview).
  * **Improve node documentation** : built-in node docs live in the [embedded-docs repository](https://github.com/Comfy-Org/embedded-docs), and custom nodes can ship their own [help pages](https://docs.comfy.org/custom-nodes/help_page).
  * **Report a bug or request a feature** : open an issue in the [ComfyUI repository](https://github.com/Comfy-Org/ComfyUI/issues).
  * **Answer questions** : help other users in the channels listed on [Community links](https://docs.comfy.org/community/links).

Browse everything the project maintains on the [Comfy-Org GitHub organization](https://github.com/Comfy-Org).
