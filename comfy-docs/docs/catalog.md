# Comfy model and product catalog for AI agents

Copy pageCopy page

Index of the Comfy catalog: products, Comfy Router models by output, open-weights models to run locally, and what’s new in each product.

Copy pageCopy page

This catalog is written for AI agents. Each page starts with plain tag lines (`Product:`, `Model ID:`, `Output:`, `License:`) so you can filter pages with the docs filesystem tool, for example `rg -l "Output: video" /catalog/models`.

Page| What it answers  
---|---  
[/catalog/products](https://docs.comfy.org/catalog/products)| What products Comfy has and where each one’s docs start  
[/catalog/router/3d](https://docs.comfy.org/catalog/router/3d)| Which 3D generation models Comfy Router serves  
[/catalog/router/audio](https://docs.comfy.org/catalog/router/audio)| Which audio generation models Comfy Router serves  
[/catalog/router/image](https://docs.comfy.org/catalog/router/image)| Which image generation models Comfy Router serves  
[/catalog/router/text](https://docs.comfy.org/catalog/router/text)| Which text generation models Comfy Router serves  
[/catalog/router/video](https://docs.comfy.org/catalog/router/video)| Which video generation models Comfy Router serves  
[/catalog/local/models](https://docs.comfy.org/catalog/local/models)| Which open-weights models run locally, with files and folders  
`/catalog/models/<provider>/<model>`| Where one model runs (Router, local, Cloud, Partner Nodes), its templates, nodes, and where to find Router prices  
[/catalog/changes/router](https://docs.comfy.org/catalog/changes/router)| What’s new in Comfy Router  
[/catalog/changes/nodes](https://docs.comfy.org/catalog/changes/nodes)| What’s new in Node reference  
[/catalog/changes/workflows](https://docs.comfy.org/catalog/changes/workflows)| What’s new in Workflow templates  
[/catalog/changes/local](https://docs.comfy.org/catalog/changes/local)| What’s new in ComfyUI  
[/catalog/changes/cloud](https://docs.comfy.org/catalog/changes/cloud)| What’s new in Comfy Cloud  
  
Model IDs are Comfy Router IDs (`provider/model`), such as `kling/kling-v3`. Open-weights models without a Router version use `<provider>/<model>`, such as `bfl/flux-2-dev`. Provider IDs match Comfy’s partner catalog. 306 model pages, generated 2026-11-21.
