Model ID: ideogram/ideogram-v3 Provider: ideogram Product: router Input: text Output: image License: closed Ideogram V3 is a image generation model from Ideogram. It takes text as input and produces image. It has no open weights. It runs on Ideogram’s servers, so you use it through Comfy Router.

## Call it with Comfy Router

  * `POST https://api.comfy.org/v2/models/ideogram/ideogram-v3`. Live request schema: `GET /v2/models/ideogram/ideogram-v3/openapi.json`.



## Pricing

Comfy Router charges the model maker’s list price, billed from your workspace credits (211 credits = $1 USD). Current per-model prices are on [router.comfy.org](https://router.comfy.org).

  * Price a call before you run it: `POST https://api.comfy.org/v2/models/ideogram/ideogram-v3/estimate`.
  * Billing facts, such as whether a refused request is charged: the `billing` field from `GET https://api.comfy.org/v2/models/ideogram/ideogram-v3`.

See [Comfy Router pricing](https://docs.comfy.org/development/comfy-router/pricing) and [Billing](https://docs.comfy.org/development/comfy-router/billing#model-billing-facts).
