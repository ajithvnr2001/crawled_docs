## Comfy MCP

将任何 AI 代理连接到 ComfyUI，无论是在 Comfy Cloud 上还是在您自己的机器上。**从这里开始。**

## Comfy Agent

ComfyUI 内置助手，用于构建、编辑和运行工作流。**已在 Cloud 上正式发布。** 本地版（Comfy Desktop）即将推出。

## Comfy CLI

终端中的 ComfyUI。安装和更新 ComfyUI，管理模型和节点，并通过脚本、CI 或批处理作业生成。

什么是 MCP？

**Model Context Protocol (MCP)** 是一个开放标准，允许 AI 助手通过标准化接口与外部工具和服务交互。AI 代理无需为每个服务学习自定义 API 格式，MCP 提供了一种统一的工具暴露方式。 将 MCP 服务器连接到 Claude Desktop、Claude Code、Cursor 或 Amp 后，AI 助手可以：

  * **生成图像** ：根据文字描述
  * **创建视频** ：从文字或图像生成
  * **生成 3D 模型** ：从文字或图像生成
  * **生成音频和音乐** ：使用 AI 模型
  * **搜索模型和模板** ：为任务找到合适的工具

……全部通过自然语言对话完成，无需手动编写 API 调用。
