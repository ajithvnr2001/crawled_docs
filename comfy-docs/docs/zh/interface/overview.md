本地化

ComfyUI 支持英语、中文、俄语、法语、日语和韩语。打开 **设置** ，在 `Comfy` → `Locale` 选择语言。 ![ComfyUI Localization Support](https://mintcdn.com/dripart/eWfBNjjL5jL2h2ib/images/interface/overview/locale.jpg?fit=max&auto=format&n=eWfBNjjL5jL2h2ib&q=85&s=f7bdc0a03f437ea74bd9c69e3b9bc6d7)

## 

​

工作区地图

![带编号 1–6 的 ComfyUI 工作区](https://mintcdn.com/dripart/svxMC8DHZXobTT5E/images/interface/overview/comfyui-new-interface-main.png?fit=max&auto=format&n=svxMC8DHZXobTT5E&q=85&s=6982fc75dedc493b140fe44816557e5e) 截图中的编号与下表区域一一对应：

#| 区域| 说明  
---|---|---  
**1**| **左侧边栏**|  资产、节点库、模型库、工作流、Apps，以及（开启时）Job History  
**2**| **画布**|  放置与连接节点的图，以及画布控制  
**3**| **右侧面板**|  当前选中项的参数、节点信息、设置与报错（从顶栏属性面板开关打开）  
**4**| **顶栏**|  打开的工作流、Run / 队列、登录、属性面板开关  
**5**| **左下**|  Help Center、底栏（日志 / 快捷键）、设置  
**6**| **右下**|  画布控制：平移、小地图、连线显示、缩放、适应视图
