复制页面复制页面

本节只介绍如何开发自定义节点。如果你想知道如何使用自定义节点，请参阅入门部分的[安装自定义节点](https://docs.comfy.org/zh/installation/install_custom_node)。

自定义节点通过新的服务器端行为、用户界面功能和集成来扩展 ComfyUI。根据您想要实现的目标选择一条路径。

## 构建自定义节点
