# ComfyUI-Manager Overview

Copy pageCopy page

An extension to manage custom nodes, models, and more in ComfyUI

Copy pageCopy page

**ComfyUI-Manager** is an extension designed to enhance the usability of [ComfyUI](https://github.com/Comfy-Org/ComfyUI). It offers management functions to **install, remove, disable, and enable** various custom nodes of ComfyUI. Furthermore, this extension provides a hub feature and convenience functions to access a wide range of information within ComfyUI. ![ComfyUI-Manager dialog](https://mintcdn.com/dripart/H4QqpI0-Odea2uWk/images/manager/new_comfyui_manager.png?fit=max&auto=format&n=H4QqpI0-Odea2uWk&q=85&s=9ad648456e3aecf82b52911e2886260a)

## 

​

Key features

  * **Custom node management** : Install, update, remove, and disable custom nodes
  * **Model management** : Download and manage models from various sources
  * **Snapshot management** : Save and restore installation states
  * **Missing node detection** : Automatically detect and install missing nodes from workflows
