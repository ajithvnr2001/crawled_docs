# Comfy API Versions: v2 and the Deprecated v1 Cloud API

Copy pageCopy page

Compare the Comfy API versions: the recommended v2 HTTP API for running ComfyUI workflows headlessly, and the deprecated v1 Cloud API.

Copy pageCopy page

The public API for running ComfyUI headlessly has evolved over time. For new integrations, use [Comfy API v2](https://docs.comfy.org/api-reference/v2/overview). It is supported on open-source ComfyUI through the [API Proxy](https://docs.comfy.org/development/comfyui-server/api-proxy), Comfy Cloud, and [Comfy API deployments on the Developer Platform](https://docs.comfy.org/development/serverless/overview). Older versions include the [v1 Cloud API](https://docs.comfy.org/development/cloud/overview), which is deprecated.

## Comfy API v2

The versioned HTTP API for running workflows from any language, on any surface. Start here.

## v1 Cloud API (deprecated)

The older Comfy Cloud API, still available for existing integrations.

See also: [Comfy API deployments](https://docs.comfy.org/development/serverless/overview) · [Comfy SDKs](https://docs.comfy.org/development/api-development/sdks) · [Getting an API Key](https://docs.comfy.org/development/api-development/getting-an-api-key)
