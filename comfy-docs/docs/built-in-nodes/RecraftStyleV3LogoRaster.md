# RecraftStyleV3LogoRaster - ComfyUI Built-in Node Documentation

Copy pageCopy page

This node selects the logo raster style and a specific substyle for generating logo images.

Copy pageCopy page

This node selects the logo raster style and a specific substyle for generating logo images. It specializes in creating logo designs with raster-based visual treatments. The chosen style is returned as a Recraft style setting that can be passed to other Recraft nodes.
