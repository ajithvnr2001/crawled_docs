# FluxDisableGuidance - ComfyUI Built-in Node Documentation

Copy pageCopy page

This node completely disables the guidance embed on Flux and Flux-like models.

Copy pageCopy page

This node completely disables the guidance embed on Flux and Flux-like models. It takes conditioning data as input and sets its guidance value to None, effectively turning off guidance-based conditioning for the generation process.

## 

​

Inputs

Parameter| Description| Data Type| Required| Range  
---|---|---|---|---  
`conditioning`| The conditioning data to process and remove guidance from| CONDITIONING| Yes| -  
  
## 

​

Outputs

Output Name| Description| Data Type  
---|---|---  
`conditioning`| The modified conditioning data with guidance disabled| CONDITIONING
