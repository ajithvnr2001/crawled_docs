# Wan2VideoEditApi - ComfyUI Built-in Node Documentation

Copy pageCopy page

The Wan 2.7 Video Edit node edits a video using text instructions, reference images, or style transfer.

Copy pageCopy page

The Wan 2.7 Video Edit node edits a video using text instructions, reference images, or style transfer. It sends the input video (plus any reference images) to the Wan 2.7 video-edit service and returns a newly generated video based on the chosen resolution, aspect ratio, and duration settings.

Reference Inputs

Parameter| Description| Data Type| Required| Range  
---|---|---|---|---  
`reference_images`| Growable slot: connect 0 to 4 images (`image1`…`image4`) to guide the edit. The count limit is 4 for the wan2.7-videoedit model.| IMAGE| No| 0 to 4 items  
  
**Constraints:**

  * `audio_setting` and `watermark` are advanced options.
  * The `prompt` must contain at least 1 character.
  * The input `video` must be between 2 and 10 seconds in duration.
  * The `reference_images` growable slot accepts a maximum of 4 images.
