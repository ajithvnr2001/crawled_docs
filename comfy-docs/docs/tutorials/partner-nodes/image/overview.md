This page helps you pick the right model for text-to-image, image editing, upscaling, or background removal.

## 

​

What you can do with image models

  * **Text-to-image** : Generate images from a text prompt
  * **Image editing** : Modify an existing image: change content, restyle, or follow a reference
  * **Image-to-image** : Transform an input image into a new version while keeping its structure
  * **Upscaling & enhancement**: Increase resolution or improve quality
  * **Utility workflows** : Background removal, relighting, and more



## 

​

Choosing a model by task

### 

​

General-purpose text-to-image

If you want the best overall quality from a simple text prompt, start with one of these:

  * **FLUX.1 Kontext** (Black Forest Labs): state-of-the-art generation with strong prompt adherence; supports multiple input images for context-aware editing
  * **FLUX 1.1 Pro Ultra** (Black Forest Labs): high-end generation in the FLUX family
  * **GPT-Image-2 / GPT-Image-1** (OpenAI): strong text-to-image and image editing with a single API
  * **Qwen Image 3.0 Pro** (Qwen): fast, high-quality generation from Alibaba’s Qwen family



### 

​

Image editing & inpainting

These models are designed to modify existing images:

  * **Nano Banana Pro / Nano Banana 2 / Nano Banana 2 Lite** (Google): Google’s Gemini-based image editing and generation, great for follow-up edits in a conversation
  * **Luma Uni-1** (Luma): create and modify images with natural language instructions
  * **Muse Image 1.0** (Meta): instruction-based editing that combines up to 10 reference images in a single edit
  * **Ideogram 4.0** (Ideogram): strong at rendering text in images; supports editing with an image input



### 

​

Background removal & utility

  * **Bria Background Removal** (Bria): remove image backgrounds cleanly
  * **Bria Fibo / Bria Image Editing** (Bria): editing and restoration utilities
  * **Topaz Image Enhance Wonder 3.5 / Bloom 2** (Topaz): upscale and restore image quality



### 

​

Speed & budget

  * **Nano Banana 2 Lite** (Google): lighter, faster variant of the Nano Banana family
  * **Recraft V4 / Recraft Text-to-Image** (Recraft): design-oriented generation with style control
  * **Seedream 5.0 Pro / Lite** (ByteDance): fast generation from ByteDance
