## Instant Voice Cloning: detect watermark

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Instant Voice Cloning (beta) now exposes **`POST /voices/watermark/detect`**. Upload a clip to check whether it carries the Sarvam STFT watermark embedded by Instant Voice Cloning generation.

  * Multipart `file` upload; max 10 MB; analysis capped at 120 seconds.
  * Response `data.verdict` is `watermarked`, `not_detected`, or `inconclusive` (short clips under about 5 seconds are usually inconclusive).
  * Auth via `api-subscription-key`. Rate limited to 5 requests per minute. Consumes no credits.



See the [Detect Watermark](https://docs.sarvam.ai/api-reference/voice-cloning/detect-watermark) API reference.
