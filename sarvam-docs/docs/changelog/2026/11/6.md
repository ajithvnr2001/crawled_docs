## Instant Voice Cloning: remove background noise

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Instant Voice Cloning (beta) now documents **`remove_background_noise`** end to end:

  * **`POST /voices/create`** — defaults to `true`. ML vocal extraction runs before the voice is saved; the response includes `background_noise_removed`. Pass `false` to keep the original clip. Existing integrations that never set the flag now get denoised reference audio by default. Studio-only aliases `noise_reduction` / `enable_noise_reduction` are rejected on the public create contract.
  * **`POST /voices/clone`** , **`/voices/clone/stream`** , and WebSocket **`configure`** — optional; defaults to `false`. Applies only when you send `ref_audio` (ignored for a saved `voice_id`). Turning it on adds roughly 1 second of latency before synthesis for a typical reference clip.
  * **`GET /voices/{voice_id}`** — `noise_reduction_applied` reflects whether denoise ran for that voice.



Requires `sarvamai` ≥ `0.1.45` (Python) or ≥ `1.1.18` (TypeScript) for these fields. See [Prepare Reference Audio](https://docs.sarvam.ai/api/api-guides-tutorials/voice-cloning/how-to/prepare-reference-audio) and the [ElevenLabs Instant Voice Cloning migration](https://docs.sarvam.ai/api/migrations/from-elevenlabs/voice-cloning).

## Provisioned Throughput and Kimi K3.1 Pro on Token Factory

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Token Factory models are now labelled **Serverless** (any API key can call them, billed per token) or **Provisioned Throughput**. Models that were labelled beta are now on [Provisioned Throughput](https://docs.sarvam.ai/api/token-factory/models#provisioned-throughput): capacity set up for your workload and enabled for your organisation. Access works as before; [contact us](https://docs.sarvam.ai/api/getting-started/help) to request it.

  * **[`kimi-k3.1-pro`](https://docs.sarvam.ai/api/token-factory/models/kimi-k3.1-pro)** replaces `kimi-k3`, on Provisioned Throughput at ₹200 input, ₹20 cached input, and ₹950 output per 1M tokens.
  * `kimi-k3`, `mimo-v2.6-flash`, and `mimo-v2.6-pro` are no longer offered. For the lowest per-token price, use [`glm5.3-flash`](https://docs.sarvam.ai/api/token-factory/models/glm-5-3-flash).



## Qwen 3.8 27B, Clef, and EmbeddingGemma 2 on Provisioned Throughput

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Three new Token Factory models are available on [Provisioned Throughput](https://docs.sarvam.ai/api/token-factory/models#provisioned-throughput). [Contact us](https://docs.sarvam.ai/api/getting-started/help) for access. Prices are per 1M tokens.

  * **[`qwen38-27b`](https://docs.sarvam.ai/api/token-factory/models/qwen-3-8-27b)** : a 27B reasoning model with text and image input, a 262,144-token context window, and tool calling, on Chat Completion V2 and Responses. ₹18 input, ₹5 cached input, ₹230 output.
  * **[`clef`](https://docs.sarvam.ai/api/token-factory/models/clef)** : a 27B decision model on the [Decisions API](https://docs.sarvam.ai/api/token-factory/decisions-api). Like Sarvam Prism, it returns a calibrated probability for every option, and it also answers questions about images. ₹20 input, no output charge.
  * **[`embeddinggemma-2`](https://docs.sarvam.ai/api/token-factory/models/embeddinggemma-2)** : 768-dimension text embeddings on the OpenAI-compatible `POST /v2/embeddings`. ₹2 input, no output charge.
