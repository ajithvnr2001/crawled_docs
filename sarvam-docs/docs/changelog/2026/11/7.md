## Lower price for DeepSeek V4.1 Flash 1017

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

[`deepseekv4.1-flash-1017`](https://docs.sarvam.ai/api/token-factory/models/deepseek-v4.1-flash-1017) now costs ₹14 input, ₹0.25 cached input, and ₹55 output per 1M tokens, down from ₹25, ₹0.5, and ₹105. See [Pricing](https://docs.sarvam.ai/api/getting-started/pricing).

For faster output, the [interactive variant](https://docs.sarvam.ai/api/token-factory/models/deepseek-v4.1-flash-1017#interactive-variant), `deepseekv4.1-flash-1017-interactive`, generates more than 200 tokens per second (about 80 on the standard model) and costs ₹25 input, ₹0.5 cached input, and ₹105 output per 1M tokens.

## One completion per chat request

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Chat Completions now return one completion per request on every model, on both `/v1` and `/v2`. Requests with `n` greater than `1` return `400 invalid_request_error`. To get several completions, send separate requests. See [V2 feature support](https://docs.sarvam.ai/api/token-factory/chat-completions#v2-feature-support).
