## Queue Messages and Steer a Running Turn

[Cowork](https://docs.sarvam.ai/changelog?filter=Cowork)

You can now send a message while your agent is still working. Queue it to run the moment the current reply finishes, or choose **Send now** to steer the agent in the middle of a task. Queued messages run in the order they start, and none are lost, merged, or run twice. See [Chat](https://docs.sarvam.ai/cowork/build/chat).
