## Translation Model Options

[Content Studio](https://docs.sarvam.ai/changelog?filter=Content%20Studio)

The **Translation Model** list under **Advanced options** in the Create a dub window now includes **Sarvam Auto** , the new default, which balances quality and efficiency. **Sarvam Plus** gives the highest translation quality and **Sarvam Lite** is faster and lighter. See [Creating a Dub](https://docs.sarvam.ai/creative-dubbing-create).

## Scheduled Agents Deliver Their Files

[Cowork](https://docs.sarvam.ai/changelog?filter=Cowork)

Fixed an issue where agents on a schedule, such as a daily report, posted their text but dropped the files they created. Files now arrive with the message, every time. See [Scheduled Tasks](https://docs.sarvam.ai/cowork/build/scheduled-tasks).
