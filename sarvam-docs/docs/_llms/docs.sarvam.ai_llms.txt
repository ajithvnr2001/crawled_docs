## Models

Every model is trained and evaluated on Indian languages, accents, and code-mixed
usage, not adapted from an English-first baseline.

[Compare models →](/api/getting-started/models)

[Saaras v3 Speech-to-text](/api/api-guides-tutorials/models/saaras)

23 languages (22 Indian + English), with transcribe, translate, verbatim, translit, and codemix output modes.

[Bulbul v3 Text-to-speech](/api/api-guides-tutorials/models/bulbul)

Natural voices for 11 languages (10 Indian + English), with customizable pitch, pace, and speaker.

[Sarvam-105B Chat](/api/token-factory/models/sarvam-105b)

Flagship 105B-parameter chat model: the highest quality Indian language understanding, reasoning, and generation.

[Mayura Translation](/api/api-guides-tutorials/models/mayura)

High-quality translation between 11 languages (10 Indian + English) with context preservation.

[Sarvam Vision Document intelligence](/api/api-guides-tutorials/models/sarvam-vision)

Document model with accurate OCR and structured output across 23 languages.

## What's new

[Full changelog →](/changelog)

[July 2026 Auto Speaker Count for Enterprise](/creative-dubbing-create)

On the Enterprise plan, choose Auto (detect speakers) under Number of speakers and Content Studio detects the number of speakers for you.

Read the changelog →

[October 2026 Optional language on Instant Voice Cloning](/api/api-guides-tutorials/voice-cloning/supported-languages)

Omit `language_code` on clone, stream, and WebSocket to detect the language from the text. Pass the code when pronunciation has to be exact.

[October 2026 Forwarded Call Recordings, Call Traces, and Provider Details in the Analytics API](/voice-agents/api/analytics/overview)

Download the recording of a transferred call's forwarded leg, get a step-by-step event trace of any call, and match calls to your telephony provider's records with the new provider details.

[October 2026 Bulbul V3 End of Life for Voice Agents](/voice-agents/build/voice-language)

Bulbul V3 reaches end of life on Voice Agents on November 10, 2026. Switch your agents to Bulbul V4 before then.
