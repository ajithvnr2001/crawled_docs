## Questions before you go live

### How is inference priced?

Pricing is in INR per million tokens, excluding GST. Switch the currency to USD to see the same rates converted at ₹90 per US dollar. Each model has separate rates for input, cached input and output tokens.

### What counts as input, cached input and output?

Input tokens are sent to the model. Cached input covers eligible tokens reused from a cached prefix. Output tokens are generated by the model.

### Are reasoning tokens billed?

Yes. For reasoning models, reasoning tokens are billed at the model’s output rate.

### How can I estimate my monthly workload cost?

Divide each token total by one million, multiply by the corresponding rate, then add the amounts. Use monthly totals for uncached input, cached input and output. GST is additional. [Use the calculator](https://www.sarvam.ai/token-factory/calculator)

### Can the same API credits be used across models?

Yes. API credits are shared across models. Usage is charged at the input, cached input and output rates of the model you call.

### Do these prices apply to serverless inference?

Yes. The catalogue lists usage-based token rates for models served through Token Factory’s serverless API.

### What availability SLA comes with Token Factory?

Token Factory guarantees 99.95% uptime, backed by an SLA. Contact the Sarvam team to discuss live traffic, latency targets and support requirements. [Discuss SLA](https://www.sarvam.ai/contact-us?product=token-factory&request=inference)
