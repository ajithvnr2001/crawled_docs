## Questions before you go live

### How do I choose the right model?

Compare model capabilities, context limits, token prices and the published benchmark configurations. Then test answer quality, tool use and response times on your own workload. [See published benchmarks](https://artificialanalysis.ai/models)

### Can I try a model before integrating it?

Open a model page and select Try in playground to test it in Indus. Each model page also includes API examples and migration steps. [Open the playground](https://indus.sarvam.ai/api-playground/chat-completions)

### Can I move an existing application to Token Factory?

If you already call models through [OpenRouter](https://docs.sarvam.ai/api/token-factory/migrations/from-openrouter/overview), [Fireworks AI](https://docs.sarvam.ai/api/token-factory/migrations/from-fireworks/overview) or [Together AI](https://docs.sarvam.ai/api/token-factory/migrations/from-together/overview), start with that migration guide. Use the OpenAI-compatible API with your Sarvam endpoint, API key and selected model ID. Validate supported parameters, tool calls and outputs before moving live traffic.

### Where is inference processed?

Inference runs on Sarvam-operated GPUs in India. Requests are not forwarded to the original model developer’s overseas API. External tools connected by your application have their own processing locations.

### Is zero data retention available?

Zero data retention is available on request. Under an agreed arrangement, prompts and responses are not retained. Operational logs are scoped separately in the terms for your deployment.

### What uptime SLA is available?

Token Factory guarantees 99.95% uptime, backed by an SLA. Share your traffic, latency targets and support requirements with the Sarvam team. [Discuss SLA](https://www.sarvam.ai/contact-us?product=token-factory&request=inference)
