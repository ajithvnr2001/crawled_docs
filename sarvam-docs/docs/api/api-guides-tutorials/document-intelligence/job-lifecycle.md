# Jobs & Errors

Ask a question|Copy page|[View as Markdown](https://docs.sarvam.ai/api/api-guides-tutorials/document-intelligence/job-lifecycle.md "View this page as plain text")|More actions

This page is for Model APIs.

Document AI jobs are asynchronous. You submit a job, wait for it to finish, then fetch the output. The same three steps apply to Parse, Extract, Split, and Classify.

[1](https://docs.sarvam.ai/api/api-guides-tutorials/document-intelligence/job-lifecycle#submit)

### Submit

Call `parse()`, `extract()`, `split()`, or `classify()`. One call creates and submits the job, and returns a `job_id` with an initial status.

[2](https://docs.sarvam.ai/api/api-guides-tutorials/document-intelligence/job-lifecycle#poll)

### Poll

Call `get_status()` with the `job_id` until the job reaches a [terminal state](https://docs.sarvam.ai/api/api-guides-tutorials/document-intelligence/job-lifecycle#job-states).

[3](https://docs.sarvam.ai/api/api-guides-tutorials/document-intelligence/job-lifecycle#fetch)

### Fetch

Call `get_results()` for structured data, or `get_download_url()` for the output file (Parse and Extract only). See [Fetch the output](https://docs.sarvam.ai/api/api-guides-tutorials/document-intelligence/job-lifecycle#fetch-the-output).

## Job states

State| Description  
---|---  
`pending`| Job created, queued for processing  
`running`| Job is being processed  
`completed`| All pages processed successfully  
`partially_completed`| Some pages succeeded, some failed  
`failed`| All pages failed or a job-level error occurred  
`rejected`| Job rejected before processing (e.g. validation or entitlement)  
  
Split and Classify jobs report `accepted` when created and `completed` when finished. Their status includes `type` (`split` or `classify`), `phase`, and `progress`, and `usage` has `pages_processed` and `pages_source`.

Terminal states are `completed`, `partially_completed`, `failed`, and `rejected`.

      "job_id": "019fb81e-2543-70bd-a737-b5a2d62a3bb7",

      "pipeline": "parse",

## Fetch the output

Each operation returns its output through a different call:

Operation| Fetch with| You get  
---|---|---  
Parse| `get_download_url()`| A link to a ZIP with the primary file, per-page metadata, and a manifest  
Extract| `get_results()`| The field values you defined. `get_download_url()` returns the output file  
Split| `get_results()`| The child documents (`segments`)  
Classify| `get_results()`| The decision, or one per page  
  
Calling either before the job reaches a terminal state returns `409`.

## What to do in each terminal state

State| What to do  
---|---  
`completed`| Fetch the output. For Split and Classify, also check `review_required` before accepting the result automatically  
`partially_completed`| Fetch the output, then check `usage.pages_failed` to see how many pages are missing, and resubmit those pages if you need them  
`failed`| There is no output to fetch. Check the error, fix the cause, and submit again  
`rejected`| The job never started processing, usually because of validation or entitlement. Fix the request or your plan access and submit again  
  
Poll every few seconds (the examples use 5) and read `usage` in the status response to show progress on long documents.

## Error Handling

###### Error Handling Code Example
    
    
    import json, os
    
    from sarvamai import SarvamAI
    
    from sarvamai.core.api_error import ApiError
    
    client = SarvamAI(api_subscription_key=os.environ["SARVAM_API_KEY"])
    
    try:
    
        with open("./insurance-policy.pdf", "rb") as f:
    
            job = client.doc_ai.extract(
    
                file=[("insurance-policy.pdf", f, "application/pdf")],
    
                schema=json.dumps({
    
                    "type": "object",
    
                    "properties": {
    
                        "policy_number": {"type": "string", "description": "Insurance policy number"},
    
                    },
    
                }),
    
                output_format="json",
    
            )
    
        # ... poll get_status() until terminal ...
    
        results = client.doc_ai.get_results(job_id=job.job_id)
    
        print(results.result)
    
    except ApiError as e:
    
        if e.status_code == 400:
    
            print(f"Bad request or invalid schema: {e.body}")
    
        elif e.status_code in (402, 403):
    
            print("Billing or entitlement error")
    
        elif e.status_code == 409:
    
            print("Results requested before the job reached a terminal state")
    
        elif e.status_code == 413:
    
            print("File too large")
    
        elif e.status_code == 429:
    
            print("Rate limit exceeded")
    
        else:
    
            print(f"Error {e.status_code}: {e.body}")
    
    except FileNotFoundError:
    
        print("Document file not found: ./insurance-policy.pdf")

### Error Codes

The full error-code table, retry guidance, and SDK exception reference live on the central [Errors & Troubleshooting](https://docs.sarvam.ai/api/getting-started/errors-troubleshooting) page. Errors specific to this API:

HTTP Status| Description  
---|---  
`400`| Invalid request or schema (includes documents exceeding the page limit)  
`402` / `403`| Billing or entitlement error  
`404`| Resource unavailable (e.g. job not found)  
`409`| Results or download requested before the job reached a terminal state  
`413`| File too large  
`422`| Invalid file format or corrupted file. For Split and Classify, also an invalid page range or an option this deployment does not offer  
`429`| Rate or admission limit  
`503`| Billing unavailable
