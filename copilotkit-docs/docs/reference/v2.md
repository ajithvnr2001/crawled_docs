# API Reference

API Reference for the CopilotKit v2 React API.

Copy MarkdownOpen

The v2 React API (`@copilotkit/react-core/v2`) gives you hooks and components for apps that talk to agents over the [AG-UI](https://docs.ag-ui.com) protocol.

## Provider SetupCopy Anchor Link

Wrap your application with `<CopilotKitProvider>` to configure the v2 runtime connection:

Copy Text
    
    
    import { CopilotKitProvider } from "@copilotkit/react-core/v2";
    
    function App() {
      return (
        <CopilotKitProvider runtimeUrl="/api/copilotkit" agentId="default">
          <YourApp />
        </CopilotKitProvider>
      );
    }

The [`<CopilotKit>`](https://docs.copilotkit.ai/reference/components/CopilotKit) export is the v1 compatibility wrapper, not an alias for `<CopilotKitProvider>`. Use `agentId` on the v2 provider; the compatibility wrapper uses `agent` and retains the v1 error-handler contract.

## Import SurfacesCopy Anchor Link

Use the main v2 entry when your app renders CopilotKit's web UI components or A2UI surfaces:

Copy Text
    
    
    import {
      CopilotKitProvider,
      CopilotChat,
      useAgent,
    } from "@copilotkit/react-core/v2";

Use the headless entry when you build a fully custom chat surface and only need platform-agnostic hooks. This avoids the built-in chat rendering stack and its CSS:

Copy Text
    
    
    import {
      useAgent,
      useCopilotKit,
      useFrontendTool,
      useRenderToolCall,
    } from "@copilotkit/react-core/v2/headless";

The headless entry exports the provider context, chat configuration provider, `useAgent`, tool hooks, suggestions, threads, capabilities, and shared types. It does not export `CopilotKitProvider`, `CopilotKit`, `CopilotChat`, `CopilotPopup`, `CopilotSidebar`, `useDefaultRenderTool`, or A2UI render helpers.

## StylingCopy Anchor Link
