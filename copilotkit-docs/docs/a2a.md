## Build with A2A

A2A gives your agents a protocol for talking to each other. What it does not give you is the surface your users talk through. The capability below builds on what your A2A agents already emit.

### Declarative UI

Your agents describe what to show rather than how to render it. CopilotKit turns those A2UI descriptions into React components in your own app.

[Read the docs](https://docs.copilotkit.ai/a2a/generative-ui)

Chat surfaces, headless UI, frontend tools and shared state work with A2A too. [And more](https://docs.copilotkit.ai/a2a/build-with-agents)
