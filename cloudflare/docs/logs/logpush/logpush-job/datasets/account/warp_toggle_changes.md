## AccountID

Type: `string`

The Cloudflare account ID when the toggle happened.

Type: `string`

The account name when the toggle happened.

## DeviceID

Type: `string`

Physical device ID.

## Hostname

## SerialNumber

Type: `string`

The device serial number.

## Timestamp

Type: `int or string`

Time the event was ingested.

Type: `bool`
