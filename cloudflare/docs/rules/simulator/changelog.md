## 2024-04-15

**Rules simulator now supports Workers**

Starting today, customers can use Rules simulator to confirm if a request to a specific URL within their zone is routed through a [Workers script](https://developers.cloudflare.com/workers/).

## 2024-03-18

**Rules simulator now supports BYOIP zones**

Customers can now use Rules simulator to simulate HTTP/S requests through their [BYOIP](https://developers.cloudflare.com/byoip/) zones.

## 2024-03-12

**Rules simulator now supports grey-clouded hostnames**

Even if the hostname is [not proxied by Cloudflare](https://developers.cloudflare.com/dns/proxy-status/#dns-only-records), Rules simulator will now return all the configurations that Cloudflare would have applied to the request.
