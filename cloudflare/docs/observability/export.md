# Export

Last updated Oct 2, 2026|Copy as Markdown|[View as Markdown](https://developers.cloudflare.com/observability/export/index.md)|[Agent setup](https://developers.cloudflare.com/agent-setup/)

Use Logpush for logs generated by Cloudflare products. Use OpenTelemetry for logs and traces from Cloudflare Observability and Workers.

### [Logpush](https://developers.cloudflare.com/logs/logpush/)

Send Cloudflare logs to supported storage and analytics destinations.

### [OpenTelemetry export](https://developers.cloudflare.com/observability/export/opentelemetry/)

Send Cloudflare Traces, Workers traces, and Workers logs to an OpenTelemetry destination.
