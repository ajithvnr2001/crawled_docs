# Basin Pipelines

Last updated Oct 1, 2026|Copy as Markdown|[View as Markdown](https://developers.cloudflare.com/workers/wrangler/commands/pipelines/index.md)|[Agent setup](https://developers.cloudflare.com/agent-setup/)

Manage your [Basin Pipelines](https://developers.cloudflare.com/basin-pipelines/) resources using Wrangler.

For `get` commands in the Basin Pipelines namespace (`basin pipelines get`, `basin pipelines streams get`, and `basin pipelines sinks get`), you can pass either a resource ID or resource name.

npmyarnpnpm
    
    
    npx wrangler basin pipelines setup
    
    
    yarn wrangler basin pipelines setup
    
    
    pnpm wrangler basin pipelines setup

npmyarnpnpm
    
    
    npx wrangler basin pipelines list
    
    
    yarn wrangler basin pipelines list
    
    
    pnpm wrangler basin pipelines list

npmyarnpnpm
    
    
    npx wrangler basin pipelines streams list
    
    
    yarn wrangler basin pipelines streams list
    
    
    pnpm wrangler basin pipelines streams list

npmyarnpnpm
    
    
    npx wrangler basin pipelines sinks list
    
    
    yarn wrangler basin pipelines sinks list
    
    
    pnpm wrangler basin pipelines sinks list

For the complete command list, refer to [Basin Pipelines Wrangler commands](https://developers.cloudflare.com/basin-pipelines/reference/wrangler-commands/).
