## DeepSeek V4.1 Flash 1017 now available on Workers AI

[Workers AI](https://developers.cloudflare.com/workers-ai/)

Copy as Markdown|[View as Markdown](https://developers.cloudflare.com/index.md)|[Agent setup](https://developers.cloudflare.com/agent-setup/)

[`@cf/deepseek-ai/deepseek-v4.1-flash-1017`](https://developers.cloudflare.com/workers-ai/models/deepseek-v4.1-flash-1017/) is now available on Workers AI. DeepSeek V4.1 Flash is a multimodal Mixture-of-Experts model with 552B backbone parameters. It activates 8B parameters per token during prefill and 16B during decode, which keeps input-heavy agentic workloads fast and low-cost.

The 1017 release is an update to DeepSeek V4.1 Flash with improvements across reasoning, coding, agentic tasks, and visual benchmarks, and it completes tasks with shorter outputs.

**Key capabilities:**

  * **Vision** : Send images alongside text in the same request.
  * **Reasoning** : Reasoning is on by default at `high` effort. Set `reasoning_effort` to `low` or `max` to change the effort, or to `none` to turn reasoning off.
  * **Function calling** : Build agents that invoke tools and APIs across multiple conversation turns.
  * **Long context** : A full 1,048,576 token context window.



DeepSeek V4.1 Flash requires the [Workers Paid plan](https://developers.cloudflare.com/workers/platform/pricing/#workers) or prepaid [AI Gateway credits](https://developers.cloudflare.com/ai-gateway/features/unified-billing/). The default rate limit is 20 requests per minute with standard Workers AI billing and 50 requests per minute with prepaid AI Gateway credits. For details, refer to [limits](https://developers.cloudflare.com/workers-ai/platform/limits/#paid-models).

Use DeepSeek V4.1 Flash through the [Workers AI binding](https://developers.cloudflare.com/workers-ai/configuration/bindings/) (`env.AI.run()`), the REST API, the [OpenAI-compatible endpoint](https://developers.cloudflare.com/workers-ai/configuration/open-ai-compatibility/), or [AI Gateway](https://developers.cloudflare.com/ai-gateway/).

For more information, refer to the [DeepSeek V4.1 Flash model page](https://developers.cloudflare.com/workers-ai/models/deepseek-v4.1-flash-1017/) and [pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/).
