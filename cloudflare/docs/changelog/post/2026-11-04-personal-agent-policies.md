## Granular access controls for the top Personal Agents

[Bots](https://developers.cloudflare.com/bots/)

Copy as Markdown|[View as Markdown](https://developers.cloudflare.com/index.md)|[Agent setup](https://developers.cloudflare.com/agent-setup/)

The **Configure AI bot policies** setting is now named **AI Crawler and Agent access policies**.

Personal agents act on a person's behalf, fetching information or browsing in response to a request. The updated policies let you set actions for the top Personal Agents individually. This gives you control over agent access while allowing visitors to use agents to find answers or compare products using your site's content.

Customize how Personal Agents access your site via **Security** > **Settings** > **AI Crawler and Agent access policies**.

For more information, check out our [blog ↗︎](https://blog.cloudflare.com/personal-agents-visibility-control) or refer to our documentation for [AI Crawler and Agent access policies](https://developers.cloudflare.com/bots/additional-configurations/block-ai-bots/).
