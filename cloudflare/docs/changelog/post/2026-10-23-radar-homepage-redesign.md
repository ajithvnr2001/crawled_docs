## Redesigned Cloudflare Radar homepage

[Radar](https://developers.cloudflare.com/radar/)

Copy as Markdown|[View as Markdown](https://developers.cloudflare.com/changelog/post/2026-10-23-radar-homepage-redesign/index.md)|[Agent setup](https://developers.cloudflare.com/agent-setup/)

The [**Cloudflare Radar**](https://developers.cloudflare.com/radar/) homepage has been redesigned to make global Internet data easier to explore for broader audiences, including journalists, policymakers, and everyday users, while preserving the depth that technical users rely on.

![Animation scrolling through the redesigned Cloudflare Radar homepage](https://developers.cloudflare.com/cdn-cgi/image/onerror=redirect,width=1000,height=557,format=webp/_astro/radar-homepage-redesign.DJcX0rdO.gif)

  * **Interactive map** : Shows Internet traffic and outages around the world, and acts as a starting point for exploring specific countries and trends.
  * **Curated insights section** : Tabbed navigation that highlights summary statistics across Radar data, with a call to action to explore each area in depth.
  * **Updated interface** : Built with [Kumo ↗︎](https://kumo-ui.com/) components, the same ones used across Cloudflare products.



As we continue the redesign, all Radar pages will see improvements. Share feedback at [radar@cloudflare.com](mailto:radar@cloudflare.com).

For more details, read the [blog post ↗︎](https://blog.cloudflare.com/radar-redesign/) or visit [Cloudflare Radar ↗︎](https://radar.cloudflare.com/).
