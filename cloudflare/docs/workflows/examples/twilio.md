# Integrate Workflows with Twilio

Integrate Workflows with Twilio. Learn how to receive and send text messages and phone calls via APIs and Webhooks.

Last updated Jan 27, 2026|Copy as Markdown|[View as Markdown](https://developers.cloudflare.com/workflows/examples/twilio/index.md)|[Agent setup](https://developers.cloudflare.com/agent-setup/)

Using the following [repository ↗︎](https://github.com/craigsdennis/twilio-cloudflare-workflow), learn how to integrate Cloudflare Workflows with Twilio, a popular cloud communications platform that enables developers to integrate messaging, voice, video, and authentication features into applications via APIs. By the end of the video tutorial, you will become familiarized with the process of setting up Cloudflare Workflows to seamlessly interact with Twilio's APIs, enabling you to build interesting communication features directly into your applications.
