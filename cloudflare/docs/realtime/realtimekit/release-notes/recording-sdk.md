## 2026-10-19

**RealtimeKit Recording SDK 0.0.4**

**Fix**

  * Fixed an issue where recordings could remain in the INVOKED state or fail when Web SDK initialization took longer than expected. During import, the Recording SDK now notifies the hosting infrastructure that it intends to record.



## 2026-07-28

**RealtimeKit Recording SDK 0.0.3**

**Enhancements**

  * Improved debug mode.



## 2026-07-02

**RealtimeKit Recording SDK 0.0.2**

**Compatibility**

  * Added support for RealtimeKit Web Core 2.x, which uses `meeting.join()` instead of the removed `meeting.joinRoom()` method.



## 2025-07-14

**RealtimeKit Recording SDK 0.0.1**

**Features**

  * Initial release of the RealtimeKit Recording SDK. Supports RealtimeKit Web Core versions through 1.5.1.
