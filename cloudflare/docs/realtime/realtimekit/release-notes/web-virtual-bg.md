## 2026-10-19

**RealtimeKit Web Virtual Background 0.0.3**

**Enhancement**

  * Virtual background assets now load from `rtk-assets.realtime.cloudflare.com`, sharing an asset hostname with Web UI Kit. Refer to the [Network allowlist](https://developers.cloudflare.com/realtime/realtimekit/network-allowlist/) for domain requirements.



## 2025-05-29

**RealtimeKit Web Virtual Background 0.0.2**

**Feature**

  * Initial supported release of [`@cloudflare/realtimekit-virtual-background`](https://www.npmjs.com/package/@cloudflare/realtimekit-virtual-background). It adds virtual backgrounds to RealtimeKit meetings. Refer to [Video effects](https://developers.cloudflare.com/realtime/realtimekit/core/video-effects/) for setup and usage.
