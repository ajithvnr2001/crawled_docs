## DNS Domains

As described in [RFC 2606 ↗︎](https://datatracker.ietf.org/doc/html/rfc2606) and [RFC 6761 ↗︎](https://datatracker.ietf.org/doc/html/rfc6761), a number of domains such as `example.com` and `example.org` are maintained for documentation purposes. Sometimes you also need to differentiate between a customer domain and your own application domain, so Cloudflare has also registered some domains for you to use.

Examples:

  * `example.com`
  * `example.org`
  * `myappexample.com`
  * `mycustomerexample.com`



IANA also maintains more example domains in their [domain names documentation ↗︎](https://www.iana.org/domains/reserved).

## IPv4 ranges

According to the Internet Engineering Task Force (IETF), there are specific [IPv4 ranges used for documentation ↗︎](https://datatracker.ietf.org/doc/html/rfc5737):

Examples:

  * `192.0.2.0/24`
  * `198.51.100.0/24`
  * `203.0.113.0/24`



These IP addresses are reserved and will not take anyone to live origins.

## Autonomous System Numbers (ASNs)

According to the Internet Assigned Numbers Authority (IANA), there are specific [ASN ranges reserved for documentation ↗︎](https://datatracker.ietf.org/doc/html/rfc5398):

  * `64496-64511` (16-bit ASN range)
  * `65536-65551` (32-bit ASN range)
