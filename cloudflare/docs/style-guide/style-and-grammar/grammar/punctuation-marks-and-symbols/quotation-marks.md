# Quotation marks

Last updated Aug 20, 2026|Copy as Markdown|[View as Markdown](https://developers.cloudflare.com/style-guide/style-and-grammar/grammar/punctuation-marks-and-symbols/quotation-marks/index.md)|[Agent setup](https://developers.cloudflare.com/agent-setup/)

OverviewUsage

In general, avoid the `'s` construction to show possession by an inanimate object. Doing so personifies the object.

Example: the device's address.

## Usage

Do not use `“ ” ‘ ’`, which are double or single typographer's ("curly") quotation marks. Use standard quotation marks instead.
