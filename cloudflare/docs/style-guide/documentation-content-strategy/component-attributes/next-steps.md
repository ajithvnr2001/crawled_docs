## Definition

The end result of a procedure and the actionable steps to take after completing it.

## When to use it

Use next steps in [how-to](https://developers.cloudflare.com/style-guide/documentation-content-strategy/content-types/how-to/) and [tutorial](https://developers.cloudflare.com/style-guide/documentation-content-strategy/content-types/tutorial/) pages, at the end of the page.

## Structure

Write one to two sentences that answer:

  * What happens now?
  * What was the end result of the procedure?
  * What should the reader do next?



## Example
    
    
    You now have a Worker deployed to your account. Next, add a custom domain so visitors can reach it, or explore Workers KV to store data at the edge.

## Related

Next steps should link to related pages based on the content type of the current page. For example, a how-to page should link to relevant troubleshooting or configuration pages, and a get-started page should link to next-level how-to pages.

For the full set of required cross-linking patterns by content type, and for link mechanics, refer to [Cross-linking requirements](https://developers.cloudflare.com/style-guide/style-and-grammar/formatting/structure/links/#cross-linking-requirements).
