16 de abril de 2026## [Artifacts: almacenamiento con control de versiones integrado con Git](https://blog.cloudflare.com/es-la/artifacts-git-for-agents-beta/)

Ofrece a tus agentes, desarrolladores y automatizaciones un espacio para guardar su código y sus datos. Acabamos de lanzar Artifacts: almacenamiento con control de versiones integrado con Git diseñado para agentes.
