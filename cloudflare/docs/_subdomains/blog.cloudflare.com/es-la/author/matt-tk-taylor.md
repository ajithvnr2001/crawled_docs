2 de octubre de 2026## [Forge, el proceso de código abierto para generar SDK, interfaces de línea de comandos, documentación y mucho más](https://blog.cloudflare.com/es-la/forge-open-source-generation-pipeline/)

Forge es un proceso de generación de código abierto, modular y extensible que se ejecuta en CI para generar SDK, CLI y documentación directamente a partir de definiciones de las API. Al trasladar la generación a los repositorios individuales de cada equipo, Forge mantiene las herramientas de desarrollo continuamente sincronizadas.
