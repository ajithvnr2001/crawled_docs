La velocidad sí importa. Sabemos que cuando su sitio web o aplicación se vuelve más rápido, los usuarios tienen una mejor experiencia, y usted obtiene más conversiones y más ingresos. En Cloudflare, cada día nos enfocamos más en la velocidad y creamos nuevas funciones para obtener el mayor rendimiento posible.

Pero para mejorar la velocidad, primero es necesario medirla. Es por eso que lanzamos [Browser Insights](https://www.cloudflare.com/website-optimization/): una nueva herramienta para medir el rendimiento de su sitio web desde la perspectiva de sus usuarios. Browser Insights le permite hacer un análisis a fondo para comprender dónde, cuándo y por qué las páginas web son lentas. Puede habilitarlo hoy mismo, de forma gratuita, con solo un clic.

## **¿Por qué creamos Browser Insights?**

Supongamos que usted tiene un sitio de comercio electrónico y desea mejorar sus tasas de conversión. Observa que hay mucho tráfico de visitantes en Perú, pero tienen una conversión peor que la que tienen los usuarios en América del Norte. Tal vez crea que se necesita mucho tiempo para cargar su página de pago, y eso hace que los clientes abandonen antes de hacer el pago. ¿Cómo comprobaría que esto está sucediendo?

Hay algunas formaras de hacerlo: puede comprobar los registros de su servidor para ver la información de sincronización, o bien cargar la página varias veces en su navegador para ver qué está lento.

Sin embargo, estos métodos tienen algunas desventajas:

  * Si solo observa los datos del lado del servidor, pasa por alto los factores que afectan la experiencia del usuario final: ¿cuánto tiempo le tomó al navegador web cargar todos los scripts necesarios, ejecutarlos y pintar la página?
  * Si realiza la medición solo desde una computadora (o desde una pequeña cantidad de ellas), pasa por alto la diversidad de la población informática; por ejemplo, "¿cómo funciona esto en un teléfono con una conexión 3G?"



Para resolver estos problemas, utilizamos _Real User Monitoring_. Esto nos da lo mejor de ambos mundos: podemos ejecutar un temporizador dentro de navegadores web reales. Este temporizador captura el tiempo que tardan en cargar las páginas web, desde sus usuarios reales.

## **¿Cómo funciona?**

Browser Insights se puede habilitar con solo tocar un interruptor en la sección "Velocidad" del panel de control:

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![Introducing Browser Insights Embedded Image - PFvxi2](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW47J3PQE19XR9BSJ8YH23BV.png&w=715&h=249&f=webp&fit=cover&position=center)

Cuando está habilitado, agregamos un pequeño fragmento de código de JavaScript a cada carga de página HTML que utiliza la [API de rendimiento](https://developer.mozilla.org/en-US/docs/Web/API/Performance) estándar para recopilar información de tiempo. Entonces, podemos comenzar a mostrarle métricas sobre el rendimiento de sus páginas web en el mundo real:

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![Introducing Browser Insights Embedded Image - fGRKXS](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW468X7K7EJN5XF9J1306F4V.png&w=715&h=366&f=webp&fit=cover&position=center)

Este gráfico ofrece mucha información. En un alto nivel, hay dos tipos principales de métricas

  * Las métricas de nivel de solicitud como tiempo de conexión TCP o tiempo de solicitud. Estas métricas se cuentan en cada carga de página y se ven afectadas por la infraestructura de Internet, como la red móvil de sus usuarios finales o la velocidad de sus servidores.
  * Las métricas de nivel de página, como el tiempo de carga de la página, que tiene en cuenta las numerosas solicitudes necesarias para cargar una página web, más el tiempo necesario para analizar HTML y ejecutar JavaScript.



Para obtener más información sobre lo que significan estos tiempos y cómo los elegimos, consulte [nuestra publicación de blog complementaria](https://blog.cloudflare.com/browser-performance-api).

## **Estudiar a fondo los datos**

Además de ver varias _métricas_ sobre el rendimiento de su página web, es útil profundizar en las _dimensiones_ que afectan el rendimiento, como la URL y el país. Esto significa que puede filtrar el rendimiento de una página específica (como su página de inicio o página de pago) y ver las ubicaciones donde su sitio carga más rápido y más lento.

Volviendo a nuestro ejemplo anterior, queremos ver cómo se compara el rendimiento en Perú con América del Norte:

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![Introducing Browser Insights Embedded Image - 4uu6Tj](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW458YAJWCGJ0E933D66TBVT.png&w=715&h=613&f=webp&fit=cover&position=center)

En efecto, podemos confirmar que hay un tráfico significativo desde Perú, pero las páginas web tardan un promedio de aproximadamente 13 segundos en cargarse, en comparación con solo 4,2 segundos para los usuarios en los EE. UU. ¡Teoría confirmada! Ahora podemos filtrar todas nuestras métricas a solo Perú para comprender mejor lo que está sucediendo:

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![Introducing Browser Insights Embedded Image - 5Fx1Mi](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW49CME3PFBGNAXP84HAKEY7.png&w=715&h=430&f=webp&fit=cover&position=center)

Cómo verá, "Procesamiento" fue lo que más aumentó, hasta llegar a 12 segundos. Los tiempos de solicitud también son más altos, posiblemente porque nos estamos conectando a un servidor de origen en los EE. UU. Las páginas web están conformadas por muchas solicitudes individuales, por lo que resulta lógico que, cuando se combinan, conducen a tiempos de carga más lentos. En este ejemplo, el almacenamiento en caché de contenido más rápido posiblemente conduciría a cargas de página mucho mejores.

## **¿Qué se ofrecerá en el futuro?**

Nuestro lanzamiento de hoy es solo la punta del iceberg para Browser Insights. En el futuro cercano queremos agregar mucho más información para ayudarlo a comprender exactamente qué está ralentizando su sitio web y qué puede hacer para que sea más rápido. Tenemos pensado agregar:

  * **Más métricas y dimensiones** , incluidas las métricas de nivel de página, como “Time to First Paint”, y más dimensiones, como el navegador y el tipo de red.
  * **Análisis de recursos secundarios**. La página web promedio carga más de 100 recursos secundarios, y podemos proporcionar un gráfico en cascada para mostrar exactamente qué está lento.
  * **Pruebas A/B** para mostrarle cómo los posibles cambios de configuración afectarán el rendimiento de su propio tráfico
  * **Recopilación de errores** para supervisar problemas en la capa de red, en JavaScript, etc.
  * **Alertas** que le avisen cuando el rendimiento se encuentre por debajo de un umbral predefinido
  * **Información desarrollada por Cloudflare** que le indica _por qué_ algo podría estar lento; por ejemplo, cómo su índice de aciertos de caché afecta el tiempo de carga de la página



## **Proteger la privacidad del usuario**

La misión de Cloudflare de ayudar a construir una mejor Internet se basa en la importancia que le damos a infundir confianza entre nuestros clientes, los usuarios finales de nuestros clientes y la comunidad de Internet a nivel mundial. Tenemos un modelo de negocio transparente que se alinea con los intereses de nuestros clientes: ganamos dinero al proteger y acelerar las propiedades de Internet de nuestros clientes. No vendemos los datos de nuestros clientes (ni de sus usuarios finales).

Browser Insights requiere que los navegadores de los usuarios finales reporten la información de tiempo a Cloudflare. Diseñamos Browser Insights para que solo reporte la información mínima necesaria para mostrar a nuestros clientes cómo están funcionando sus sitios web. Las únicas métricas que recopila Browser Insights son sobre el tiempo. No rastreamos a los usuarios finales individuales a través de las propiedades de Internet de nuestros clientes. Le recomendamos que abra el Inspector en su navegador web favorito para saber lo que estamos enviando de vuelta.
