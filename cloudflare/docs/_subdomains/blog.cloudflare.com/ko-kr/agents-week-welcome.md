# Agents Week에 오신 것을 환영합니다

![Rita Kozlov](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW4775C0A7PYM3T9XKH4PH9J.png&w=64&h=64&f=webp&fit=cover&position=center)

이 포스트는 다음 언어로도 제공됩니다 [English](https://blog.cloudflare.com/agents-week-welcome/), [Deutsch](https://blog.cloudflare.com/de-de/agents-week-welcome/), [Español](https://blog.cloudflare.com/es-es/agents-week-welcome/), [Español (Latinoamérica)](https://blog.cloudflare.com/es-la/agents-week-welcome/), [Français](https://blog.cloudflare.com/fr-fr/agents-week-welcome/), [Italiano](https://blog.cloudflare.com/it-it/agents-week-welcome/), [日本語](https://blog.cloudflare.com/ja-jp/agents-week-welcome/), [繁體中文](https://blog.cloudflare.com/zh-tw/agents-week-welcome/) 및 [简体中文](https://blog.cloudflare.com/zh-cn/agents-week-welcome/).

이번 주는 Agents Week입니다.

이번 주를 구상하고 준비하면서, 우리는 에이전트의 새로운 시대를 지원한다는 것이 무엇을 의미하는지, 그리고 에이전트를 위해 특별히 설계된 기반은 어떤 모습이어야 하는지라는 더 큰 질문과 씨름했습니다. 그러다 더 단순한 질문으로 정리하게 되었습니다. Agent Cloud란 무엇일까요? 

하지만 곧 우리의 접근 방식이 잘못되었다는 것을 깨달았습니다. 잘못된 질문이어서가 아니라, 그 질문을 던진 대상이 잘못되었기 때문입니다. 우리는 에이전트에게 묻는 대신 우리 자신에게 묻고 있었습니다. 이제 중요한 것은 우리가 어떻게 생각하는지가 아니라, 에이전트에게 무엇이 필요한지입니다. 

한마디로, 이것이 바로 Agents Week가 이야기하는 주제입니다. 

오늘날의 클라우드와 그 위에서 동작하는 웹은 사람을 위해 만들어졌습니다. 모든 계층은 사람이 보고 있다는 전제를 깔고 있습니다. 사용자의 관심을 붙잡기 위해 설계된 웹 페이지, 클릭하며 탐색하도록 만든 대시보드, 사람이 읽고 판단하는 방식에 맞춰 최적화된 인터페이스가 그렇습니다. 하지만 에이전트는 그런 방식으로 동작하지 않습니다. 에이전트는 주의가 산만해지거나 피로를 느끼지 않습니다. 대신 속도, 구조, 액세스 측면에서 에이전트만의 요구 사항을 가지고 있습니다.

![](data:image/bmp;base64,Qk32BAAAAAAAADYAAAAoAAAACAAAAAgAAAABABgAAAAAAMAAAAATCwAAEwsAAAAAAAAAAAAA8vTy7e/v5efn4OLk4uXn5ujq5Obn3eDf9vj38vTz6Ovs4+bo5ejr6evu5+rr4uTj/P7++Pr67vDy6evu6+3w7vHz7e/x6Orq////////9ff58PL18vT49vj79ff47/Hy/////////f7/9/n8+vz//v///f7/9/n5/////////////v///////////////f/+////////////////////////////////////////////////////////////////)![BLOG-3449_image2.png](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KYZCTHC688NR2KQA59ZQVRV0.png&w=715&h=245&f=webp&fit=cover&position=center)

Agent Cloud는 두 가지를 동시에 해내야 합니다. 하나는 기본 요소를 인간을 위한 도구를 개조해 적용하는 것이 아니라 처음부터 에이전트를 위해 구축하는, 에이전트 네이티브 미래를 위한 기반을 마련하는 것입니다. 또 하나는 현실적으로 지금 우리가 있는 위치에서 출발해, 현재의 인간 중심 웹과 우리가 나아가고 있는 에이전트 중심 웹 사이를 연결하는 번역 계층 역할을 하는 것입니다.

이것이 앞으로 5일 동안 이어질 핵심 주제입니다. 에이전트와 사람이 함께 사용하는 클라우드의 모습, 그리고 이들이 어떻게 상호작용하는지를 살펴봅니다. 이번 주에는 필요한 기본 요소와 실행 계층이 무엇을 의미하는지, 새롭게 변화하는 에이전트 중심 소프트웨어 개발 수명 주기, 조직이 안전한 제어를 통해 직원과 에이전트가 안전하게 상호작용하도록 지원하는 방법, 이것이 에이전트 중심 웹을 어떻게 만들어 가는지, 그리고 마지막으로 이 모든 내용을 오늘날의 에이전트와 인간이 공존하는 현실에 비추어 살펴볼 예정입니다.

다시 처음의 질문으로 돌아가 보겠습니다. 여러분의 에이전트는 Agent Cloud에 무엇을 필요로 할까요? 우리 에이전트가 내놓은 답변을 그대로 복사해 붙여 넣기보다는, 여러분의 에이전트에게 직접 질문해 보고 흥미로운 통찰과 답변을 공유해 보시기 바랍니다. 아래는 활용할 수 있는 예시 프롬프트입니다. 하지만 여러분만의 질문과 답변도 자유롭게 탐색해 보시기를 권합니다.

_에이전트인 너는 Agent Cloud에서 무엇이 필요해? 스토리지 및 컴퓨팅 클라우드, 필요한 실행 및 스토리지의 기본 요소, 개발 수명 주기(인간이 개입하지 않는 SDLC와 유사한 ADLC), 조직 내 시스템 오브 레코드에 안전하게 액세스하여 심층적인 업무를 수행하는 기능, 그리고 웹(검색, 액세스, 결제 등)의 관점에서 생각해 봐._
