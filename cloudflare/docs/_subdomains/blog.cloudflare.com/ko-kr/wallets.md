현재 AI 에이전트가 새로운 API를 사용해 보는 것은 쉽지 않습니다. 사람을 위해 설계된 로그인 페이지를 거쳐야 하고, 결제 수단을 추가하기 위해 사람에게 요청해야 하며, API 키를 생성한 뒤 API를 호출하는 방법까지 알아내야 하는 경우가 많습니다.

이 과정이 에이전트에게 어려운 이유는 두 가지입니다. 첫째, API에 가입할 때 사용할 수 있는 안정적인 식별자가 없고, 둘째, API 비용을 결제할 수 있는 기본적인 결제 수단이 없기 때문입니다. 이러한 이유로 에이전트는 소프트웨어를 사용하는 데 필요한 초기 설정에 어려움을 겪으며, 이는 에이전트 커머스의 성장을 제한합니다. 결국 많은 AI 에이전트는 이러한 작업을 포기하고, 회원 가입, 결제 수단 등록, API 키 생성과 같은 작업을 다시 사람에게 넘깁니다. 이 때문에 에이전트가 다양한 API를 직접 사용해 보고 비교하는 것이 매우 어려웠습니다.

이 문제를 해결하기 위해 Cloudflare는 Cloudflare Wallets를 개발했습니다. 오늘부터 계정에서 [​ _Cloudflare Wallet 핸들을 등록_](https://cloudflare.pay)할 수 있으며, 이를 통해 판매자와 더 쉽게 연결할 수 있는 고유한 사용자 이름을 사용할 수 있습니다. 앞으로는 Cloudflare Wallet을 설정하여 API와 콘텐츠 비용을 결제할 수 있게 될 예정입니다.

이달 초 Cloudflare는 고객이 자신의 웹사이트와 애플리케이션으로 수익을 창출할 수 있도록 [​ _Monetization Gateway_](https://blog.cloudflare.com/monetization-gateway/)를 발표했습니다. Monetization Gateway는 HTTP 요청에 결제를 포함할 수 있는 [​ _x402 프로토콜_](https://www.x402.org/) 기반의 마이크로페이먼트를 지원합니다. 이러한 마이크로페이먼트는 AI 추론부터 데이터, 콘텐츠까지 다양한 서비스 비용을 지불하는 데 사용할 수 있습니다. Monetization Gateway나 다른 [​ _x402 호환 엔드포인트_](https://developers.cloudflare.com/agents/tools/payments/x402/)를 통해 비용을 지불하거나 대금을 받으려면 지갑이 필요합니다. 

Cloudflare Wallets를 사용하면 웹 전반에서 스테이블코인을 보관하고, 서비스를 구매하며, 대금을 받을 수 있습니다. 또한 Wallet을 보유한 각 계정은 에이전트를 위한 Virtual Wallet을 생성하여 API, MCP 도구, 콘텐츠 등을 구매하도록 할 수 있습니다. Virtual Wallet에는 사용 한도, 허용 목록, 최대 거래 금액 등 다양한 안전장치를 설정하여 에이전트가 계정의 자금을 안전하게 사용할 수 있도록 할 수 있습니다. 이를 통해 에이전트는 적은 마찰과 관리 가능한 위험 수준에서 다양한 API를 자유롭게 사용해 볼 수 있습니다. 또한 Wallet 사용자는 Cloudflare Wallet 핸들을 공유할 수 있으며, 이를 통해 판매자와 상호작용할 때 안정적인 신원을 사용할 수 있습니다.

## **양방향 에이전트 시장 구축**

Cloudflare의 [​ _Monetization Gateway_](https://blog.cloudflare.com/monetization-gateway/)를 사용하면 자격을 갖춘 Cloudflare 고객은 콘텐츠나 API와 같은 리소스를 에이전트 구매자에게 헤드리스 방식으로 판매할 수 있습니다. 하지만 이러한 시장이 본격적으로 성장하려면 에이전트가 머신 네이티브 방식으로 판매자로부터 구매할 수 있는 더 많은 도구가 필요합니다. Wallets는 Cloudflare Agents SDK에 새로운 기능을 추가하여, AI 에이전트가 마이크로페이먼트를 사용해 필요한 API와 콘텐츠를 손쉽게 구매할 수 있도록 지원합니다.

Cloudflare Wallet에는 Account Wallet과 Virtual Wallet 두 가지 유형이 제공됩니다.

**Account Wallet** 은 Cloudflare 계정의 소유자와 사용자인 사람을 위해 설계되었습니다. 사용자는 자금을 입금하고, 에이전트가 관리하는 Virtual Wallet에 사용할 예산을 할당하며, 필요에 따라 자금을 출금할 수 있습니다. 

반면 **Virtual Wallet** 은 에이전트를 위해 설계되었으며 API 키를 통해 동작합니다. 에이전트는 Virtual Wallet에서 부여된 권한 범위 내에서 자금을 사용할 수 있습니다. 또한 사용할 수 있는 최대 금액은 Account Wallet 소유자가 설정한 한도를 초과할 수 없습니다. 이러한 구조를 통해 에이전트는 지속적인 수동 승인 없이도 사용자를 대신해 작업을 수행할 수 있으며, 동시에 과도한 지출은 방지할 수 있습니다.

## **자유로운 탐색**

Virtual Wallet의 가장 큰 장점은 에이전트가 가장 잘하는 일을 수행할 수 있다는 점입니다. 바로 수십, 수백 개의 서비스를 탐색하고, 특정 사용 사례에 가장 적합한 서비스를 찾아내는 것입니다. x402 기반의 스테이블코인 마이크로페이먼트를 사용하면 계정을 만들지 않고도 API를 쉽게 사용해 볼 수 있어, 에이전트는 거의 마찰 없이 새로운 API를 테스트할 수 있습니다. Virtual Wallet의 사용 한도는 사람이 안전한 지출 범위 내에서 에이전트가 자율적으로 탐색하도록 설계되었습니다. 이러한 한도는 제약처럼 보일 수 있지만, 역설적으로 에이전트에게 더 큰 자유를 제공합니다. 에이전트가 사용할 수 있는 금액이 1,000달러라면 지출을 걱정할 수밖에 없지만, 10달러라면 훨씬 안심하고 맡길 수 있습니다. API를 한 번 사용해 보는 데 몇 센트밖에 들지 않는다면, 10달러 정도로 다양한 API를 충분히 탐색하고 평가할 수 있습니다.

사용자나 에이전트가 사용할 API를 선택한 이후에는 Account Wallet에서 설정한 정책이 Virtual Wallet의 비용 통제 수단으로 작동합니다. 예를 들어 모든 직원에게 AI 추론 비용으로 주당 100달러의 예산을 제공하고 싶다면, 적절한 금액을 충전한 Account Wallet을 준비한 뒤 해당 규칙을 적용한 Virtual Wallet을 직원별로 생성하면 됩니다. Virtual Wallet의 한도를 초과한 사용자는 Account Wallet을 변경할 권한이 있는 사람에게 수동 승인을 요청할 수 있습니다.

Cloudflare는 Account Wallet에서 일상적인 모니터링 없이도 유연하면서도 명확한 지출 정책을 설정할 수 있도록 하는 것을 목표로 하고 있습니다. 예상보다 빠른 속도로 비용이 발생하는 등 이상 징후가 발견되면, 관리자는 해당 지출이 의도된 것인지 검토하고 확인할 수 있습니다. 의도된 지출이라면 Account Wallet 관리자가 한도를 높이거나 일회성으로 자금을 추가할 수 있습니다. 반대로 의도하지 않은 지출이라면, Virtual Wallet에 자금을 추가할 때 적용된 지출 정책이 한도를 설정함으로써 제 역할을 한 것입니다.

Cloudflare는 이러한 지갑을 가능한 한 쉽게 충전하고 사용할 수 있도록 노력하고 있습니다. 우선 지원 지역에서는 간편한 입금 및 출금 기능을 제공할 예정이며, 자격을 갖춘 사용자는 스테이블코인을 이용해 직접 자금을 충전하는 방식도 사용할 수 있습니다. 인터넷이 하루아침에 완전히 바뀌지는 않겠지만, 현재 [​ _웹 트래픽의 대부분_](https://radar.cloudflare.com/)이 이미 봇에 의해 발생하고 있는 만큼, Cloudflare는 에이전트와 판매자에게 에이전트 커머스를 위한 핵심 도구를 제공하게 되어 매우 기대하고 있습니다.

## **결제 그 이상**

사람이 에이전트에 권한을 위임해 서비스를 쉽게 구매하거나 판매할 수 있도록 하는 것은 좋은 출발점입니다. 하지만 에이전트와 상호작용하는 판매자에게는 이러한 위임 관계가 항상 명확하게 드러나는 것은 아닙니다. 현재 에이전트가 웹사이트를 방문하면, 해당 에이전트가 실제로는 특정 개인이나 조직을 대신해 행동하고 있음에도 판매자는 그 에이전트에 대해 거의 알 수 없습니다. 이러한 귀속 정보(attribution)의 부족은 기존 웹 비즈니스 모델에 여러 가지 어려움을 초래합니다. 사람이나 조직에는 1주일 무료 체험이나 가입 크레딧을 제공하는 것이 쉽지만, 안정적인 신원이 없는 에이전트에게 동일한 혜택을 제공하기는 어렵습니다. 특히 한 사람이 자신이 제어하는 수십 개의 에이전트를 생성할 수 있는 상황에서는 더욱 그렇습니다.

Cloudflare는 지갑을 [​](https://cloudflare.pay/)[ _cloudflare.pay_](http://cloudflare.pay)를 통해 Cloudflare 계정과 연결함으로써 이 문제를 해결합니다. [​](https://cloudflare.pay/)[ _cloudflare.pay_](http://cloudflare.pay)를 사용하면 에이전트는 계정으로부터 권한을 위임받은 주체(delegate)로서 자신의 신원을 선택적으로 공개할 수 있습니다. 예를 들어 연구 에이전트는 [​ _research.example.cloudflare.pay_](http://research.example.cloudflare.pay)와 같은 형태의 식별자를 사용할 수 있으며, 이를 통해 판매자는 해당 에이전트가 특정 조직에 속한 에이전트임을 확인할 수 있습니다. 이러한 방식은 에이전트가 일관되고 지속적인 신원을 유지할 수 있도록 하여 모든 참여자에게 더 나은 사용 경험을 제공합니다. 에이전트가 자신의 신원을 공개할지는 전적으로 선택 사항이며, 알려진 에이전트와의 거래를 우선할지는 각 비즈니스가 직접 결정할 수 있습니다.

## **에이전트 식별자는 사람이 읽을 수 있어야 합니다**

Cloudflare는 에이전트를 다루는 방식이 VPN을 다루는 방식과 비슷해질 것이라고 생각합니다. 신원이 확인되지 않은 사용자가 곧바로 신뢰할 수 없는 것은 아니지만, 더 많은 검증을 거쳐야 합니다. 이러한 이유로 Cloudflare는 [​ _Turnstile_](https://www.cloudflare.com/products/turnstile/)과 [​ _Bot Management_](https://www.cloudflare.com/products/bot-management/)의 다양한 기능을 통해 봇을 탐지하고 있습니다. Cloudflare의 신원 기반 요소는 이러한 기존 기술을 바탕으로 구축됩니다. 예를 들어 [​ _Web Bot Auth_](https://developers.cloudflare.com/bots/reference/bot-verification/web-bot-auth/)는 이미 키 페어(key pair)를 사용해 에이전트가 자신의 신원을 등록할 수 있도록 지원합니다. Cloudflare Wallet에 연결된 ID는 이러한 키 페어를 사람이 읽고 이해하기 쉬운 형태로 만들어 줍니다.

Cloudflare는 에이전트 신원에 대한 표준이 빠르게 변화하고 있다는 점을 잘 알고 있습니다. 그래서 최대한 단순한 접근 방식을 선택했습니다. Cloudflare는 [​ _DNS_](https://www.cloudflare.com/learning/dns/what-is-dns/)에서 URL과 IP 주소를 연결하는 방식처럼, 사람이 읽기 어려운 키 페어에 사람이 읽을 수 있는 식별자를 연결하는 방식을 제안합니다. 특정 스키마나 별도의 검증 체계를 정의하려는 것은 아닙니다. 단지 신원을 기억하기 쉽고, 손쉽게 선언할 수 있도록 만들고자 합니다. 앞으로 [​ _x402 Foundation_](https://blog.cloudflare.com/x402/)의 다양한 이니셔티브를 통해 에이전트 신원을 더욱 풍부하게 표현하는 스키마가 마련되면, Cloudflare도 이를 적극적으로 도입하고 다른 조직들도 함께 채택하도록 장려할 계획입니다.

## **에이전트 커머스의 미래**

Cloudflare는 에이전트 커머스가 성공하는 데 필요한 모든 기반 요소를 제공하고자 합니다. Monetization Gateway는 판매자가 기존 결제 인프라를 구축하지 않고도 대금을 받을 수 있는 방법을 제공합니다. Wallets는 구매자가 에이전트를 통해 사람의 개입 없이(헤드리스 방식) 결제할 수 있도록 지원합니다. 또한 Identity는 판매자가 자신의 신원을 공개한 구매자와 소통하거나, 신원 확인을 요구하는 정책을 적용할 수 있도록 합니다.

이러한 모든 기반 요소가 결합되면 인터넷 전반에 걸친 헤드리스 마켓플레이스가 구축될 것입니다. 이 비전에 공감하고 함께하고 싶다면 [​ _지금 바로 Wallet 핸들을 등록해 보세요_](https://cloudflare.pay/). Cloudflare는 여러분이 어떤 서비스를 만들고, 어떻게 수익화할지 기대하고 있습니다.
