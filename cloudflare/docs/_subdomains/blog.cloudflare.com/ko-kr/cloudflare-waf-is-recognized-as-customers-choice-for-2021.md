# Cloudflare의 WAF, 2021년도 '소비자의 선택'에 선정

![Michael Tremante](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW47VPCZP5RNHE8YF2FDVBTK.jpg&w=64&h=64&f=webp&fit=cover&position=center)

[Michael Tremante](https://blog.cloudflare.com/ko-kr/author/michael-tremante/)

3분 읽기

URL 복사

이 포스트는 다음 언어로도 제공됩니다 [English](https://blog.cloudflare.com/cloudflare-waf-is-recognized-as-customers-choice-for-2021/), [Deutsch](https://blog.cloudflare.com/de-de/cloudflare-waf-is-recognized-as-customers-choice-for-2021/), [Español](https://blog.cloudflare.com/es-es/cloudflare-waf-is-recognized-as-customers-choice-for-2021/), [Français](https://blog.cloudflare.com/fr-fr/cloudflare-waf-is-recognized-as-customers-choice-for-2021/), [日本語](https://blog.cloudflare.com/ja-jp/cloudflare-waf-is-recognized-as-customers-choice-for-2021/), [繁體中文](https://blog.cloudflare.com/zh-tw/cloudflare-waf-is-recognized-as-customers-choice-for-2021/) 및 [简体中文](https://blog.cloudflare.com/zh-cn/cloudflare-waf-is-recognized-as-customers-choice-for-2021/).

![Cloudflare’s WAF is recognized as customers’ choice for 2021](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW44A8KN0GQKE8ARFR0CFFC5.png&w=1200&h=628&f=webp&fit=cover&position=center)![](data:image/bmp;base64,Qk32BAAAAAAAADYAAAAoAAAACAAAAAgAAAABABgAAAAAAMAAAAATCwAAEwsAAAAAAAAAAAAA/////vz87O3x4+Xq6Ont8fDx8fDv6ero//////7/7e/z5Obs6+vu9fLy9fPx6+zr////////7/L35unv7u7w+vb0+vf07/Dv////////9Pf86+708/P1//v5//z59fX0////////+/3/8vX6+fn7///+///++vv6////////////+fv//v7////////////+/////////////v//////////////////////////////////////////////////)

[웹 애플리케이션 방화벽(WAF)](https://www.cloudflare.com/waf/)을 구축하고 있는 Cloudflare 팀은 지난 한 해 동안 계속해서 혁신을 추진했습니다. 이제 우리는 이러한 작업에 대해 공개적으로 인정을 받았습니다.

Cloudflare WAF의 사용 편의성, 규모, 혁신적인 제어는 긍정적인 고객 리뷰로 이어졌으며, Cloudflare는 2021년도 Gartner Peer Insights 소비자의 선택 WAF 부문에 선정되었습니다. 보고서 증정본은 [여기](https://www.cloudflare.com/gartner-customerschoice-waf-2021/)에서 다운로드할 수 있습니다.

영예롭게도 Gartner Peer Insights 소비자의 선택으로 선정된 것은 고객이 벤더와 제품을 높게 평가한 것을 반영한 결과입니다. 수집된 데이터는 IT 기업 전문가들이 가장 높이 평가하는 최고 수준의 벤더 소프트웨어 제품 정보를 모은 것입니다.

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![Cloudflare’s WAF is recognized as customers’ choice for 2021](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW46W5KX2J8QYKBNR8QY5CPW.png&w=500&h=401&f=webp&fit=cover&position=center)

Cloudflare는 지속해서 긍정적인 피드백을 받았으며 이는 Cloudflare의 제품 원칙과 일맥상통합니다. [고객은](https://www.gartner.com/reviews/market/web-application-firewalls/vendor/cloudflare/product/cloudflare-waf/reviews) Cloudflare의 WAF를 다음과 같이 평가했습니다.

  * **“뛰어난 호스팅의 WAF, 벤더보다는 파트너에 가까운 회사”** — _서비스 산업의 주요 사이트 안정성 아키텍트 [[전체 리뷰](https://www.gartner.com/reviews/market/web-application-firewalls/vendor/cloudflare/product/cloudflare-waf/review/view/3501511)],_
  * **“간단하지만 아주 효과적인 WAF 솔루션”** _— 금융 산업의 부사장 [[전체 리뷰](https://www.gartner.com/reviews/market/web-application-firewalls/vendor/cloudflare/product/cloudflare-waf/review/view/1366292)],_
  * _**“뛰어난 지원을 제공하며 쉽고 강력한 솔루션”** — 리테일 산업의 기술 부사장 [[전체 리뷰](https://www.gartner.com/reviews/market/web-application-firewalls/vendor/cloudflare/product/cloudflare-waf/review/view/3501341)],_
  * _**“안전하고 직관적이며 즐거운 웹 보안 및 가속화”** — 제조 산업의 기술 제품 관리 선임 이사 [[전체 리뷰](https://www.gartner.com/reviews/market/web-application-firewalls/vendor/cloudflare/product/cloudflare-waf/review/view/3501369)],_



2020년은 Cloudflare의 보안 제품 출시 측면에서 [활발한 해](https://blog.cloudflare.com/cloudflare-named-the-innovation-leader-in-holistic-web-protection/)였습니다. 몇 가지 예를 들어보겠습니다.

  * [IP 목록](https://blog.cloudflare.com/introducing-ip-lists/)은 네트워크 목록 관리를 위해 재사용 가능한 1급 자료 구조를 통해 더 많은 구성 유연성을 제공합니다.
  * [페이로드 암호화](https://blog.cloudflare.com/encrypt-waf-payloads-hpke/)를 통해 고객은 사용자의 개인정보를 보호하는 동시에 포렌식을 위해 WAF가 차단한 요청의 모든 페이로드를 기록할 수 있습니다.
  * 고객은 자신의 SIEM에서 직접 거의 실시간으로 [보안 이벤트 스트림](https://blog.cloudflare.com/stream-firewall-events-directly-to-your-siem/)이 가능합니다.
  * [Data Localization Suite](https://blog.cloudflare.com/introducing-the-cloudflare-data-localization-suite/)를 통해 사업체에서는 에지에서 자체적인 데이터가 보관되고 보호되는 장소에 대한 규칙과 제어를 설정할 수 있습니다.
  * 방화벽 규칙을 [HTTP 헤더](https://developers.cloudflare.com/firewall/cf-firewall-language/fields#http-header-fields) 및 [HTTP 본문](https://developers.cloudflare.com/firewall/cf-firewall-language/fields#http-body-fields) 모두에 대해 완전한 정규식 기능으로 작성할 수 있습니다.
  * [API Shield](https://blog.cloudflare.com/introducing-api-shield/)를 통해 API 엔드포인트에서 쉽게 상호 TLS 인증을 배포할 수 있습니다.
  * 이제 [gRPC 프록시 지원](https://blog.cloudflare.com/announcing-grpc/)으로 gRPC 트래픽을 보호할 수 있습니다.



우리는 2021년도 Gartner Peer Insights 소비자의 선택 WAF 부문에 선정되어 매우 기쁩니다. 팀 전체를 대표하여 지속적인 지원에 대해 모든 Cloudflare 고객에게 감사한 마음을 전하고 싶습니다.

Cloudflare WAF에 대한 자세한 정보는 [여기에서 문의하세요](https://www.cloudflare.com/enterprise). Cloudflare를 실제로 사용하여 평가할 준비가 되었다면 [여기](https://dash.cloudflare.com/sign-up)에서 등록하세요.
