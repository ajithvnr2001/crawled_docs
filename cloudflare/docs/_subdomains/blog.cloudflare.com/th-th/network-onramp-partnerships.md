วันนี้เรารู้สึกตื่นเต้นที่จะได้ประกาศให้ทราบถึง [พันธมิตรเครือข่าย On-ramp](https://www.cloudflare.com/network-onramp-partners/) ล่าสุดของเราสำหรับ Cloudflare One [Cloudflare One](https://blog.cloudflare.com/introducing-cloudflare-one/) ถูกออกแบบมาเพื่อช่วยให้ลูกค้าเข้าถึงเครือข่ายทั่วโลกอย่างปลอดภัยและเหมาะสมที่สุด เราทราบถึงคำสัญญาในการเปลี่ยนลิงก์ MPLS กับเครือข่ายระดับโลกที่ปลอดภัย มีประสิทธิภาพและน่าจดจำจะเปลี่ยนแปลงเครือข่ายแบบองค์กร เพื่อตระหนักถึงวิสัยทัศน์ดังกล่าว เรากำลังจะเปิดตัวพันธมิตรซึ่งลูกค้าสามารถเชื่อมต่อไปยังเครือข่ายทั่วโลกของ Cloudflare’ จากอุปกรณ์ WAN & SD-WAN ที่เชื่อถือได้ที่มีอยู่แล้วและยังสามารถเชื่อต่อระหว่างกันแบบส่วนตัวผ่านศูนย์กลางข้อมูลที่พวกเขาตั้งอยู่ร่วมกัน

วันนี้เราจะเปิดตัวพันธมิตร WAN และ SD-WAN ร่วมกับ VMware, Aruba และ Infovista เรายังเพิ่ม Digital Realty, CoreSite, EdgeConneX, 365 Data Centers, BBIX, Teraco และ Netrality Data Centers ไปยังพันธมิตรเครือข่าย Interconnect เดิมของเราซึ่งประกอบด้วย Equinix ECX, Megaport, PacketFabric, PCCW ConsoleConnect และ Zayo อีกด้วย ปัจจุบันพันธมิตร Network On-ramp ของ Cloudflareได้ขยายผู้ให้บริการเชื่อมต่อชั้นนำ 15 รายใน 70 แห่งที่ไม่ซ้ำกัน ซึ่งทำให้ลูกค้าทำการการรับส่งข้อมูลบน Cloudflare ในวิธีที่ปลอดภัยและมีประสิทธิภาพไม่ว่าจะอยู่ที่ใดได้โดยง่าย

### เชื่อมต่อไปยัง Cloudflare โดยใช้ผู้ให้บริการ WAN หรือ SD-WAN ที่คุณมีอยู่แล้ว

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![Cloudflare’s Network On-ramp partnerships now span 15 leading connectivity providers in 70 unique locations, making it easy for our customers to get their traffic onto Cloudflare in a secure and performant way, wherever they are.](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW456MNZZD6WV4ZJHCV7Z6DZ.png&w=715&h=438&f=webp&fit=cover&position=center)

ด้วย [Magic WAN](http://www.cloudflare.com/magic-wan) ลูกค้าสามารถเชื่อมต่อกับศูนย์ข้อมูล สำนักงาน อุปกรณ์รวมถึงคุณสมบัติของคลาวด์บนเครือข่าย Cloudflare ได้อย่างปลอดภัยและยังสามารถกำหนดค่านโยบายเส้นทางเพื่อรับบิตไปยังที่ต้องการได้ทั้งหมดภายในโซลูชัน SaaS เพียงหนึ่งเดียว: ไม่จำเป็นต้องมีค่าใช้จ่าย MPLS หรือช่วงเวลานำการผลิตรวมถึงไม่ต้องมีบทลงโทษด้านประสิทธิภาพจากปัญหาการรับส่งข้อมูลที่เป็นทรอมโบนอีกต่อไป ในวันนี้หลายองค์กรใช้อุปกรณ์ SD-WAN แบบมีติดตั้งจริงหรือแบบเสมือนเพื่อกำหนดเส้นทางหรืออุโมงค์การรับส่งข้อมูลระหว่างสำนักงาน ศูนย์ข้อมูลและคลาวด์สาธารณะ นับจากวันนี้ลูกค้าเหล่านี้สามารถยกระดับการลงทุนในโครงสร้างพื้นฐานที่มีอยู่ก่อนหน้าได้ — ทั้งแบบกายภายพหรือแบบเสมือนบนคลาวด์ — เพื่อเชื่อมต่อการรับส่งข้อมูลไป Magic WAN โดยใช้คำสั่งง่ายๆ เพียงไม่กี่คำสั่ง

พิจารณาการตั้งค่าแบบง่ายด้านล่าง Magic WAN + พันธมิตรเครือข่าย Onramp อนุญาตให้คุณเชื่อมต่อกับระบบของตนเองและคลาวด์ VPC ในซับเนต RFC1918 โดยใช้อุปกรณ์ทั้งแบบติดตั้งจริงและเสมือนด้วยการเชื่อมต่ออย่างรวดเร็วและปลอดภัยโดย Magic WAN ยิ่งไปกว่านั้น Magic Firewall ยังอนุญาตให้คุณทำการกำหนดค่าและบังคับใช้กฎไฟล์วอลล์ที่ edge และผ่านไปยังการรับส่งข้อมูลที่ผjานไปทาง Magic WAN ได้อย่างต่อเนื่อง เครือข่ายอันกว้างขวางของ Cloudflare ที่แผ่ออกไปในกว่า 200 เมืองยังหมายถึงศูนย์ข้อมูลที่ใกล้ที่สุดอยู่ไม่ไกล

**เครือข่ายส่วนตัว 3 เครือข่ายที่ใช้อุปกรณ์ฮาร์ดแวร์ของพันธมิตรร่วมกัน ได้แก่ พันธมิตรเสมือน AMI และเราเตอร์ Linux ทั่วไปที่เชื่อมต่ออยู่กับ Cloudflare Magic WAN ผ่านศูนย์ข้อมูล Cloudflare ที่ใกล้ที่สุด**

แม้ว่าการตั้งค่าที่เรียบง่ายและความเข้ากันได้นั้นยอดเยี่ยม แต่แผนงานที่ใช้ร่วมกันของเรากับพันธมิตรของเรานั้นมุ่งมั่นจะไปให้ไกลกว่านั้น วันนี้ การเชื่อมต่อเหล่านี้ถูกจัดทำผ่าน Anycast GRE และเราจะทำการประกาศให้ทราบถึงการสนับสนุน IPSec ที่จะเกิดขึ้นเร็วๆ นี้ซึ่งจะอนุญาตให้ลูกค้าสามารถเชื่อมต่อได้หลากหลายวิธี

ในการเปิดตัวในอนาคต การเข้าถึงอุปกรณ์พันธมิตรจะใช้เพียงข้อมูลอนุญาตเพื่อพิสูจน์ว่าพวกเขาเป็นส่วนหนึ่งของเครือข่ายลูกค้า Magic WAN และจะสามารถติดต่อไปยังการจัดการ API ของ Magic WAN รวมถึงกำหนดค่าด้วยตัวเองได้ — เป็นการตระหนักถึงวิสัยทัศน์ plug’n’play ของเครือข่ายคลาวด์อย่างแท้จริง นอกจากนี้ลูกค้า Magic WAN ยังสามารถใช้ประโยชน์จากการเพิ่มระดับความปลอดภัยด้วย Zero Trust ของ Cloudflare เพื่อการเข้าถึงแอปพลิเคชันและการใช้งานท่องอินเทอร์เน็ตที่เป็นการรวมการเข้าถึงเครือข่ายของ Zero Trust (ZTNA), Secure Web Gateway (SWG), Remote Browser Isolation (RBI), ความปลอดภัย DNS, ไฟล์วอลล์ L4 รวมถึงผลิตภัณฑ์อื่นๆ เมื่อมีการกำหนดให้เข้าสู่แพลตฟอร์มไร้รอยต่อเดียวกัน

## เชื่อมต่อโครงข่ายแบบส่วนตัวไปยัง Cloudflare ผ่าน PNI

การทำอุโมงค์การรับส่งข้อมูไปยังศูนย์ข้อมูล Cloudflare ที่ใกล้ที่สุด (ซึ่งอยู่ไม่เคยห่าง เนื่องจากเรามีศูนย์กระจายอยู่ในเมืองกว่า 200 เมือง) คือหัวใจของ Cloudflare Magic WAN เราใช้โปรโตคอลอินเทอร์เน็ตมาตรฐานเช่น GRE และ IPSec (จะมาเร็วๆ นี้) เพื่อส่งการรับส่งข้อมูลระหว่างเครือข่ายของเราและโครงสร้างพื้นฐานของลูกค้าอย่างปลอดภัย ในขณะที่การรักษาความปลอดภัยระดับโปรโตคอลนั้นยอดเยี่ยม เมื่อใดก็ตามที่คุณมีการเชื่อมต่ออินเทอร์เน็ตกับโครงสร้างพื้นฐาน นั่นหมายความว่าคุณเพิ่มพื้นที่การโจมตีให้กับการกำหนดค่าผิดพลาด

สำหรับองค์กรที่ต้องการระดับความปลอดภัยและประสิทธิภาพสูงสุดสามารถรวม Magic WAN เข้ากับ [Cloudflare Network Interconnect Partner](https://www.cloudflare.com/network-interconnect-partnerships/)สำหรับการใช้งานแบบส่วนตัว, เครือข่ายแบบ 2 เลเยอร์ที่ปลอดภัยและเชื่อถือได้ระหว่าง edge ของ Cloudflare และเครือข่ายของลูกค้า การเชื่อมต่อแบบส่วนตัวคืออีกหนึ่งอาวุธในการสร้างการป้องกันเชิงลึกสำหรับเครือข่ายของคุณ

เมื่อปีที่แล้วเรา [ได้ประกาศ](https://blog.cloudflare.com/cloudflare-network-interconnect-partner-program/) พัธมิตรการเชื่อมต่อโครงข่ายเครือข่ายรอบแรกของเรา ในวันนี้เราเพิ่ม Digital Realty, CoreSite, EdgeConneX, 365 Data Centers, BBIX, Teraco, และ Netrality Data Centers เพื่อให้บริการ:

  * Colocation คู่กับ Cloudflare ใน 70 แห่ง
  * ลดเวลานำการเชื่อมต่อข้ามเครือข่าย
  * สถาปัตยกรรมอ้างอิงการเชื่อมต่อ



ด้วยพันธมิตรใหม่ของเรา วันนี้ลูกค้ามีตัวเลือกมากขึ้นสำหรับการเชื่อมต่อที่เป็นส่วนตัวและปลอดภัยผ่านการแลกเปลี่ยนคลาวด์ (ซอฟต์แวร์ที่กำหนดคำสั่ง VLAN ผ่าน Dashboard) หรือด้วยการเชื่อมต่อแบบกายภาคที่เป็นส่วนตัว

### WAN ของอนาคตมาถึงแล้ววันนี้

ตลอด 10 ปีที่ผ่านมา Cloudflare ได้สร้างเครือข่ายที่เป็นหนึ่งในเครือข่ายที่เร็วที่สุด น่าเชื่อถือที่สุดและปลอดภัยที่สุดเครือข่ายหนึ่งของโลก สัปดาห์นี้เราได้ประกาศคุณสมบัติด้านประสิทธิภาพและความปลอดภัยเพิ่มเติมอีกหลายอย่างที่ให้ลูกค้าสามารถใช้ประโยขน์ด้านความปลอดภัยและความต้องการเครือข่ายได้ทั่วโลกได้เท่าเทียมกันมากขึ้น พันธมิตรเครือข่าย On-ramp ให้ตัวเลือกการบริการแบบส่วนตัว ปลอดภัยและประสิทธิภาพสูงเพื่อการเชื่อต่อแหล่งการรับส่งข้อมูลของคุณไปยัง Cloudflare

เพื่อร่วมเป็นส่วนหนึ่งของพันธมิตร On-ramp กรุณาติดต่อเราที่ [onramppartners@cloudflare.com](mailto:onramppartners@cloudflare.com) เราอยากฟังเรื่องเกี่ยวกับแพลตฟอร์มที่คุณใช้และที่อยากเห็นว่าเราร่วมเป็นส่วนหนึ่ง - ติดต่อเราได้[ที่นี่](https://cloudflare.com/network-onramp-partners)

หากคุณต้องการเรียนรู้เพิ่มเติมเกี่ยวกับพันธมิตรเครือข่าย On-ramp, PNIs/CNIs แบบมีตัวตน, พันธมิตร/CNIs เสมือน รวมถึงวิธีที่พวกเขาควบรวมกับ Magic WAN ติดต่อทีมบัญชีของคุณหรือติดต่อไปที่ [interconnection@cloudflare.com](mailto:interconnection@cloudflare.com) หากต้องการรายละเอียดเพิ่มเติมเกี่ยวกับ Magic WAN โปรดกรอกแบบฟอร์มติดต่อเราบน [หน้าผลิตภัณฑ์](https://www.cloudflare.com/magic-wan)
