16\. Mai 2023## [Cloudflare R2 und MosaicML ermöglichen das Training von LLMs auf jedem Rechner, überall auf der Welt, ohne Wechselkosten](https://blog.cloudflare.com/de-de/cloudflare-r2-mosaicml-train-llms-anywhere-faster-cheaper/)
