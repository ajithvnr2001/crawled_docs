# CloudflareのWAFが、Customers’ Choice for WAF 2021として認定

![Michael Tremante](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW47VPCZP5RNHE8YF2FDVBTK.jpg&w=64&h=64&f=webp&fit=cover&position=center)

[Webアプリケーションファイアウォール (WAF)](https://www.cloudflare.com/ja-jp/waf/) を構築しているCloudflareのチームは、この1年間、革新を続けています。本日、私たちの活動が公に認められました。

Cloudflare WAFが提供する使いやすさ、規模、革新的な制御は、お客様から高く評価され、2021年のWAF部門でGartner Peer Insights Customers' Choice Distinctionを獲得しています。本レポートは、[こちら](https://www.cloudflare.com/ja-jp/gartner-customerschoice-waf-2021/)から無料でダウンロードできます。

Gartner Peer Insights Customers' Choice Distinctionは、顧客から高い評価を得ているベンダーと製品を認定するものです。収集されたデータは、IT企業の専門家が最も高く評価しているベンダーのソフトウェア製品のトップレベルの統合を表しています。

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![Cloudflare’s WAF is recognized as customers’ choice for 2021](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW46W5KX2J8QYKBNR8QY5CPW.png&w=500&h=401&f=webp&fit=cover&position=center)

受け取った好意的なフィードバックは一貫しており、Cloudflareの製品原則につながるものです。CloudflareのWAFに関する[お客様の意見](https://www.gartner.com/reviews/market/web-application-firewalls/vendor/cloudflare/product/cloudflare-waf/reviews)は、以下の通りです。

  * **「素晴らしいホスト型WAFを提供する、ベンダーというよりもパートナーのような企業」** — _サービス業界のサイトリライアビリティプリンシパルアーキテクト [[レビュー全文](https://www.gartner.com/reviews/market/web-application-firewalls/vendor/cloudflare/product/cloudflare-waf/review/view/3501511)]_
  * **「分かりやすく、非常に効果的なWAFソリューション」** _— 金融業界のVP [[レビュー全文](https://www.gartner.com/reviews/market/web-application-firewalls/vendor/cloudflare/product/cloudflare-waf/review/view/1366292)]_
  * _**「簡単で強力、卓越したサポート」** — 小売業界のVPテクノロジー [[レビュー全文](https://www.gartner.com/reviews/market/web-application-firewalls/vendor/cloudflare/product/cloudflare-waf/review/view/3501341)_ _]_
  * _**「安全で直感的な、満足のいくWebセキュリティと高速化」** — 製造業界の技術製品管理部門シニアディレクター[[レビュー全文](https://www.gartner.com/reviews/market/web-application-firewalls/vendor/cloudflare/product/cloudflare-waf/review/view/3501369)_ _]_



2020年は、Cloudflareのセキュリティ製品が[数多くリリースされた年](https://blog.cloudflare.com/cloudflare-named-the-innovation-leader-in-holistic-web-protection/)でした。その一部を以下に紹介します。

  * [IPリスト](https://blog.cloudflare.com/introducing-ip-lists/)では、ネットワークリストを管理するための再利用可能な最高レベルのデータ構造により、より柔軟な構成が可能です。
  * [ペイロードの暗号化](https://blog.cloudflare.com/encrypt-waf-payloads-hpke/)により、お客様は、ユーザーのプライバシーを考慮しながら、フォレンジックを目的とし、WAFによってブロックされたリクエストのペイロードをすべて記録できます。
  * お客様は、[セキュリティイベント](https://blog.cloudflare.com/stream-firewall-events-directly-to-your-siem/)をほぼリアルタイムで直接SIEMにストリーミングすることができます。
  * [Data Localization Suite](https://blog.cloudflare.com/ja-jp/introducing-the-cloudflare-data-localization-suite-ja-jp/)では、データの保存先と保護先について、エッジでルールとコントロールを設定することができます。
  * [HTTP ヘッダー](https://developers.cloudflare.com/firewall/cf-firewall-language/fields#http-header-fields)と[HTTP ボディ](https://developers.cloudflare.com/firewall/cf-firewall-language/fields#http-body-fields)の両方に対して、完全な正規表現でファイアウォールのルールを記述することができます。
  * [API Shield](https://blog.cloudflare.com/ja-jp/introducing-api-shield-ja-jp/)では、APIエンドポイントで相互TLS認証を簡単にデプロイすることができます。
  * [gRPCプロキシのサポート](https://blog.cloudflare.com/announcing-grpc/)により、gRPCトラフィックの保護が可能です。



この度、Gartner Peer Insights Customers' Choice for WAF 2021に認定されました。チーム全員を代表して、日頃のお客様のご支援に感謝申し上げます。

Cloudflare WAFの詳細については、[こちらをご覧ください](https://www.cloudflare.com/ja-jp/enterprise/)。Cloudflareの現場評価については、[こちら](https://dash.cloudflare.com/sign-up) からご参加ください。
