# 8Chanのサービス終了

![Matthew Prince](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW44KQ4Z9PY1TR0ERGW96HZR.jpeg&w=64&h=64&f=webp&fit=cover&position=center)

[Matthew Prince](https://blog.cloudflare.com/ja-jp/author/matthew-prince/)

9分で読了

URLをコピー

この記事は以下でも利用可能です [English](https://blog.cloudflare.com/terminating-service-for-8chan/)、[Deutsch](https://blog.cloudflare.com/de-de/terminating-service-for-8chan/)、[Español](https://blog.cloudflare.com/es-es/terminating-service-for-8chan/)、[Français](https://blog.cloudflare.com/fr-fr/terminating-service-for-8chan/)、[简体中文](https://blog.cloudflare.com/zh-cn/terminating-service-for-8chan/).

テキサス州エルパソとオハイオ州デイトンで起きた銃乱射事件は恐ろしい悲劇です。エルパソの銃乱射事件の場合、テロ銃撃犯の容疑者は8chanとして知られるフォーラムのウェブサイトに触発されていたと報じられています。証拠を見る限りでは、容疑者は20人が犠牲となったウォルマートへの恐ろしい攻撃を開始する直前、そのサイトに長文を投稿したようです。

残念なことに、過去にもこういったことが起きています。ニュージーランドのクライストチャーチのテロ攻撃でも、事件発生の前に8chanでほぼ同じことが起こっていました。エルパソの銃撃犯はクライストチャーチの事件に言及しており、投稿内容がほとんど野放し状態の8chanの、過去の虐殺を称賛するやり取りに触発されたとみられています。また、カリフォルニア州のパウェイで発生したシナゴーグ銃撃事件でも、容疑者は、8chanに憎しみに満ちた「公開状」を投稿しました。8chanは、繰り返し、憎しみの巣窟であることを自ら証明しています。

8chanは、Cloudflareのサービスを利用する1900万以上のインターネットプロパティの一つです。太平洋標準時の今夜午前0時をもって、8chanとの契約を打ち切るという通知を送りました。根拠は単純です。8chanは明らかに無法であり、その無法状態が数々の悲劇的な死を引き起こしたからです。たとえ、8chanが憎しみに満ちたコミュニティを野放しにすることは法律違反にあたらないとしても、法の精神を冒涜し、これを楽しむ環境を作り出しているのです。

私たちはこうした判断を軽視しません。Cloudflare はネットワークプロバイダーです。より良いインターネットの構築を支援するという目標を追及するために、広くセキュリティサービスの提供をすることは重要だと考えました。これによってできる限り多くのユーザーを守り、サイバー攻撃の発生を防止するのです。Webサイトの内容にかかわらず。 多くのお客様は当社のネットワーク上で独自のプラットフォームを実行しています。当社の方針がお客様の方針よりも保守的であれば、結果としてお客様がご自身のサービスを運営し、方針を策定することを妨げることにつながります。当社は、不本意ながらも非難されるべきコンテンツも容認しますが、悲劇的な事件を直接触発し、設計上無法であることが実証されているプラットフォームとは一線を画します。8chanはその一線を超えました。よって、当社サービスの利用は許可できないのです。

## **次に何が起こるか**

残念ながら、当社はこうした状況を過去にも経験しており、今後何が起きるのか、大体予想がつきます。ちょうど2年ほど前に、Cloudflareのネットワークから、別の不愉快なサイトを閉め出す決意をしました。[Daily Stormer](https://new.blog.cloudflare.com/why-we-terminated-daily-stormer/)というサイトです。 その結果、そのサイトの運営は一時的に中断されましたが、Cloudflareの競合他社を利用して、すぐにオンラインに戻りました。当時、その競合他社は法的手続きに応じなかったという事実を特長として自社を宣伝しました。今日もまだ、Daily Stormerは利用可能であり、依然として不愉快です。そして、過去最多の読者を獲得したと誇らしげに発表しました。Daily Stormerは、もはやCloudflareの問題ではありませんが、インターネットの問題であることに変わりはありません。

8chanでも同じことが起こるのは、疑問の余地がありません。当社のネットワークから8chanを削除することで、当社にとっての問題はなくなりますが、オンラインでヘイトサイトがはびこることへの対処にはなり得ません。これでは銃乱射事件の発生原因への対処にはなり得ません。一部の人がそれほどまでに幻滅し、そして憎しみに変わっていくことへの対処にはなり得ません。この行動によって当社の問題はなくなりましたが、インターネット全体の問題は解決できていません。

Daily Stormerの件から2年、当社は、インターネットのより深い問題を解決しようと、法執行機関や市民社会組織と協力して解決策を探してきました。とりわけ、当社はネットワーク上でヘイトサイトの可能性のあるものを監視し、危害の恐れを示すコンテンツがあったときに法執行機関に通知することで、協力をしています。当社は恐ろしい暴力行為を防ぐことができることを願い、情報を共有するために法的な手順の範囲内で今後も協力を続けます。これが当社の責任であると考えており、Cloudflareの規模と浸透度を考えると、さらに深い問題の解決に向けて前進を続けていくことを期待しています。

## **法の支配**

当社はコンテンツに介入することについては非常に心苦しく感じていますし、これは最小限にとどめるつもりです。これは米国憲法修正第1条（「言論の自由」などの条項）の概念によるものだとの推論がありますが、そうではありません。それは間違っています。第一に、当社は民間企業であり、修正第1条に拘束されません。第二に、当社のお客様の大半、そして収益の50%以上は、米国外の、修正第1条やそれに準ずる自由至上主義的言論の自由が適用されない場所からきています。この件においてもその他でも、修正第1条との関わりは、唯一、当社が誰と取引を行うかまたは行わないのかを当社が選択できる権利を持つという点だけです。当社にだれとでも取引をするように義務付けるものではありません。

それよりも、当社の懸念の根本にあるのは、遥かに普遍的な考え方である法の支配です。法の支配は、政策の透明性と一貫性を必要とします。法の支配は、政府がその合法性を維持する枠組みとして明確にされてきました。一方、当社は自社の方針を考える際の試金石として、それを利用してきました。

当社は、非常に効果的な技術ソリューションを持ち、手頃な価格で使いやすいセキュリティ、パフォーマンス、信頼性を提供することで成功を収めています。その結果、インターネットの大部分が当社のネットワークを利用しています。[上位100万の10%、上位10万の17%、上位1万では19%のインターネットプロパティが](https://w3techs.com/technologies/history_overview/proxy/all)現在当社サービスを利用しています。フォーチュン1000の企業の10%がCloudflareのお客様と取引があります。

Cloudflareは政府ではありません。当社が企業として成功してきたからと言って、どのようなコンテンツが良いか悪いかの決定を下す政治的な正当性を持っているわけではありません。また、持つべきではないと思っています。コンテンツをめぐる問題は、政治的に正当な解決策を必要とする現実的な社会問題です。当社は、世界各国の立法府が、適切な法的手続きを通して自国で受け入れられるものとそうでないものの境界線を決めていく中で、引き続き関与していきます。そして、当社はその境界線が設定された時、その場所で、それを遵守します。

例えば、ヨーロッパはこの分野をリードしてきました。欧州各国によるオンラインにおけるヘイトやテロに関わるコンテンツへの取り組みを見るに、FacebookやYouTubeといった、コンテンツをとりまとめ、普及させる企業には、コンテンツをただ伝えるにすぎない企業とは異なる義務を課すべきだという認識があります。Cloudflareのように、コンテンツを伝えるだけの場合はユーザーの目に触れないため、自社のポリシーに関して透明性と一貫性を保つことができません。

法の支配を無視したり積極的に阻止したりするプラットフォームに対して、法律はどの対処すべきなのか？という質問にまだ答えが出ていません。それはDaily Stormerと8chanで見た状況に近いものです。それらは、無法なプラットフォームです。このような場合、プラットフォームが無法で監視されないように設計されており、プラットフォームが実際に危害を引き起こす力があることを実証している場合、法律に加えて救済策が必要かもしれません。当社や他のテクノロジー企業は、政策当局と協力して、問題の理解を促進し、こうした救済策の定義に寄与する必要があります。また、場合によっては、技術開発を進めて、メカニズムによる法の執行につなげることを意味するかもしれません。

## **Cloudflareの義務**

Cloudflareの使命は、より良いインターネットの構築を支援することです。ある程度、顧客としての8chanを打ち切ることは簡単です。8chanは類のない無法者で、無法であることは恐ろしい悲劇をいくつも引き起こしています。もう、たくさんです。

難しいのは、今後も透明性を保って実施できる方針を明確にして、一貫して前進していくことです。当社、そしてインターネットの大部分を利用可能にしている他のテクノロジー企業は、自分たちが誇りに思っていない部分に対処するためのソリューションを提案する義務があります。それが当社の義務であり、それにコミットしています。

残念ながら、当社が今取れる行動はオンライン上のヘイトの問題を解決できません。まず間違いなく8chanをインターネットから排除することもできないでしょう。それでも、これが正しいことなのです。オンラインのヘイトは深刻な問題です。対処するために積極的な取り組みを行っている団体もあります。

  * [Perspective API](https://www.perspectiveapi.com/#/home)
