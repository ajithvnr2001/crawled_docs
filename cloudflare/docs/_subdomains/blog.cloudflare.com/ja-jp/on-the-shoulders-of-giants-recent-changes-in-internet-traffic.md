# 先人から学び、さらに前へ進む：インターネットトラフィックにおける最近の変化

![Louis Poinsignon](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW45XKBQHBMEVSAS1MAW42NT.jpg&w=64&h=64&f=webp&fit=cover&position=center)

![On the shoulders of giants: recent changes in Internet traffic](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW44BGDTP3MSE99X9K4MRS22.png&w=1610&h=1066&f=webp&fit=cover&position=center)![](data:image/bmp;base64,Qk32BAAAAAAAADYAAAAoAAAACAAAAAgAAAABABgAAAAAAMAAAAATCwAAEwsAAAAAAAAAAAAA////////8/P14ufs4Obt5+zx7u7v8ezo////9vf72d/rvsrguMjhxtLm1dvm3N3g9fr+5u31vMvjj6rUhaXUnrbbuMfexs7a8/r+4uv2tMbifqDTb5nTjq3arsHdvsra/f//7/b+ytfso7rfmbTfrMLlwtDnztbj////////7fL81uHy0d7y2uX25Or26evw/////////////P//+f7//f////////z8////////////////////////////////)

新型コロナウイルスの緊急事態が続き、多くの国や都市が検疫所や拡大防止の防疫線を設けたことで、インターネットは多くの人にとって、家族や友人と連絡を取り合う一番の手段となりました。また、数多くの企業が在宅勤務する従業員を抱えているため、世界経済の重要な原動力となっています。

ビデオ会議、ストリーミングサービス、ニュース配信、電子商取引Webサイトのトラフィックは急増しています。家庭用ブロードバンドネットワークからのトラフィックが増加し、企業や大学からのトラフィックは減少しています。

Cloudflareのチームは通常通りの運用を続けており、ネットワークオペレーティングセンター（NOC）は200以上の都市でハードウェアを運用し、トラフィックパターンの変化を監視しています。

インターネットトラフィックの大きな変化は、珍しいことではありません。オリンピックやワールドカップのような大規模なスポーツイベントやユーロビジョンソングコンテストのような文化イベント、また、ラマダン（イスラム教の断食月）は毎日の断食明けの時間も、トラフィックが変化します。

インターネットは、絶えず変化する環境に対応するように構築されています。絶えず変化する負荷パターンに対応するために、作成、試験、デバッグ、設計というプロセスから構築されています。

ここ数週間、Cloudflareネットワークチームは新しいパターンがいくつかあることに気づいたため、このパターンについてご紹介することにしました。

### 国全体が、リーダーの動きに注目する

先週金曜日の夕方、アメリカ大統領が米国で非常事態宣言を発表しました。それからすぐに、当社の米国データセンターは、通常の20%以上のトラフィックに対応しました。赤色の線は金曜日を示し、グレー色の線は比較として、その前の日を示しています。

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![On the shoulders of giants: recent changes in Internet traffic Embedded Image - kua930](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW465D8JJE3BVQWEZS3WN53C.png&w=715&h=328&f=webp&fit=cover&position=center)

3月15日（日曜日）、オランダ政府は現地時間の午後5時30分に必要不可欠ではない事業の停止をラジオで発表しました（午後4:30 UTC時間）。日曜日の通常トラフィックで、急激な低下が次のように発生しました。

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![On the shoulders of giants: recent changes in Internet traffic Embedded Image - 8bFNa0](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW44SWW68XJ7F9HT01KKS961.png&w=715&h=294&f=webp&fit=cover&position=center)

3月12日（ピンク色の曲線）と3月16日（赤色の曲線）の現地時間午後8時（午後7時 UTC時間）にフランスの大統領が二回、フランス国内で発表しました。3月16日の都市封鎖宣言によって、フランス国内のトラフィックが半分に低下し、その後、トラフィックの急増が発生しました。

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![On the shoulders of giants: recent changes in Internet traffic Embedded Image - pSxJLd](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW44XS44DG2CM739JPFXEE59.png&w=715&h=280&f=webp&fit=cover&position=center)

### 隔離中におけるトラフィックの進化

都市封鎖が始まってからイタリア国内で1日あたりのトラフィックが20~40%増加しました。

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![On the shoulders of giants: recent changes in Internet traffic Embedded Image - vlCCBZ](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW483TJ9N51DB6KH2HTW8ZS1.png&w=715&h=536&f=webp&fit=cover&position=center)

大学が閉校となり、国立リサーチネットワークは今も（ほぼ）週末のような静けさが続いています（紫色）。赤色は今日、灰色は（前週と重なる）前の日です。

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![On the shoulders of giants: recent changes in Internet traffic Embedded Image - h4ruP1](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW46JQXKHDRPKSYFT6E835X5.png&w=715&h=242&f=webp&fit=cover&position=center)

[インターネット相互接続点](https://en.wikipedia.org/wiki/Internet_exchange_point)、インターネットインフラストラクチャの重要な部分で、インターネットサービスプロバイダーとコンテンツプロバイダーが（サードパーティを経由するのではなく）直接データを交換するところでも、トラフィックにスパイクが見られました。多くは、パブリックトラフィックグラフを提供しています。

アムステルダム（[AMS-IX](https://www.ams-ix.net/ams/documentation/total-stats)）、ロンドン（[LINX](https://portal.linx.net/stats/lans)）そしてフランクフルト（[DE-CIX](https://www.de-cix.net/en/locations/germany/frankfurt/statistics)）では、3月9日前後に10~20%の増加がありました。

ミラノ（[MXP-IX](https://www.mix-it.net/statistiche/)）で、隔離が始まった2020年3月9日の水曜日、相互接続点が40%の増加を示しています。

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![On the shoulders of giants: recent changes in Internet traffic Embedded Image - 7kfffe](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW4744NXQXWYCSJDF4FAEC5T.png&w=597&h=264&f=webp&fit=cover&position=center)

緊急事態は、否応なくインターネットサービスや私たちの生活に影響を与えます。この増加を正確に数値化することは難しいものの、地域や州政府の対応によって10%から40%までの数値を観察しています。

Webサイトやアプリといった個々のサービスが時々停止したにも関わらず、インターネットの中核部は堅牢です。トラフィックは、企業や大学のネットワークから家庭用ブロードバンドへと移行しつつあります。しかし、インターネットは変化に対応できるように設計されています。
