### How does it (the Internet) work

  * **Cloudflare’s view of the Rogers Communications outage in Canada ([✍️](https://blog.cloudflare.com/cloudflares-view-of-the-rogers-communications-outage-in-canada/)** **2022)** One of the largest ISPs in Canada, Rogers Communications, had a huge outage on July 8, 2022, that lasted for more than 17 hours. From our view of the Internet, [**we show**](https://blog.cloudflare.com/cloudflares-view-of-the-rogers-communications-outage-in-canada/) why we concluded it seemed caused by an internal error and how the Internet, being a network of networks, all bound together by [BGP](https://www.cloudflare.com/learning/security/glossary/what-is-bgp/), was related to the disruption.
  * ******Understanding how Facebook disappeared from the Internet ([✍️](https://blog.cloudflare.com/october-2021-facebook-outage/)** **2021).****** “Facebook can't be down, can it?”, we thought, for a second, on October 4, 2021.   * **Welcome to Speed Week and a Waitless Internet** **([✍️](https://blog.cloudflare.com/fastest-internet/)** **2021).** There’s no object, as far as we, humans, know, that is faster than the [speed of light](https://en.wikipedia.org/wiki/Speed_of_light).   * **Welcome to Crypto Week ([✍️](https://blog.cloudflare.com/crypto-week-2018/)** **2018).** If you want to know why cryptography is so important for the Internet, [**here’s**](https://blog.cloudflare.com/crypto-week-2018/) a good place to start. ### Blast from the past (some history)

  * **Introducing DNS Resolver, 1.1.1.1 (not a joke) ([✍️](https://blog.cloudflare.com/dns-resolver-1-1-1-1/)** **2018).** The first consumer-focused service Cloudflare has ever released, our DNS resolver, [1.1.1.1](https://1.1.1.1/) — a recursive DNS service — was [launched](https://blog.cloudflare.com/announcing-1111/) on April 1, 2018, and [**this is**](https://blog.cloudflare.com/dns-resolver-1-1-1-1/) the technical explanation. With this offering, we started fixing the foundation of the Internet by building a faster, more secure and privacy-centric public DNS resolver. And, just this month, we’ve added [privacy proofed features](https://blog.cloudflare.com/geoexit-improving-warp-user-experience-larger-network/) (a geolocation accuracy “pizza test” included).
  * **Cloudflare goes InterPlanetary - Introducing Cloudflare’s IPFS Gateway ([✍️](https://blog.cloudflare.com/distributed-web-gateway/)** **2018).** We [**introduced**](https://blog.cloudflare.com/distributed-web-gateway/) Cloudflare’s IPFS Gateway, an easy way to access content from the InterPlanetary File System (IPFS). This served as the platform for many new, at the time, highly-reliable and security-enhanced web applications. It was the first product to be released as part of our [Distributed Web Gateway](https://www.cloudflare.com/distributed-web-gateway) project and is a different perspective from the traditional web.IPFS is a peer-to-peer file system composed of thousands of computers around the world, each of which stores files on behalf of the network. And, yes, it can be used as a method for a possible Mars (Moon, etc.) Internet in the future. About that, the same goes for code that will need to be running on Mars, something we mention about Workers [here](https://blog.cloudflare.com/cloudflare-workers-unleashed/).
  * **LavaRand in Production: The Nitty-Gritty Technical Details ([✍️](https://blog.cloudflare.com/lavarand-in-production-the-nitty-gritty-technical-details)** **2017).** Our lava lamps wall in the San Francisco office is much more than [a wall of lava lamps](https://www.fastcodesign.com/90137157/the-hardest-working-office-design-in-america-encrypts-your-data-with-lava-lamps) (the YouTuber Tom Scott did a 2017 [video](https://www.youtube.com/watch?v=1cUUfMeOijg) about it) and in [**this blog**](https://blog.cloudflare.com/lavarand-in-production-the-nitty-gritty-technical-details) we explain the in-depth look at the technical details (there’s a less technical [one](https://blog.cloudflare.com/randomness-101-lavarand-in-production/) on how randomness in cryptography works).
  * ******Introducing Cloudflare Workers ([✍️](https://blog.cloudflare.com/introducing-cloudflare-workers/)** **2017).****** There are several announcements each year, but [this blog](https://blog.cloudflare.com/introducing-cloudflare-workers/) (associated with the explanation, [Code Everywhere: Why We Built Cloudflare Workers](https://blog.cloudflare.com/code-everywhere-cloudflare-workers/)) was referenced this week by some as one of those with a clear impact.
