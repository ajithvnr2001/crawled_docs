### **智慧體的興起與機器支付的普及**

如今，大多數軟體企業透過訂閱或預付費點數銷售產品。這些商業模式要求買家進行相當大的前期經濟投入，因此買家只能訂閱少數符合預算的服務。然而，這種商業模式與網際網路流量的主要來源——智慧體——的運作方式並不契合。

智慧體追求結果，無論是來自直接問題還是隱性需求。為了實現目標，智慧體可能會造訪新網站、呼叫 MCP 工具或擷取資料串流。全球各地的企業都希望處於關鍵路徑中，幫助智慧體獲得更好的結果。這有助於企業在新使用者所在之處觸及他們、從對智慧體回答的貢獻中獲得報酬，並在無頭智慧體商務領域占據領先地位。

企業需要將商業模式與智慧體的消費模式對齊，才能把握這一機遇。支付必須與智慧體的消費單位相符：按請求、按搜尋查詢、按權杖計費。現今主流的支付基礎設施無法支援這一需求。這些支付基礎設施假設買家能夠接受高延遲、僅進行大額交易，且買家是賣家已知或可識別的實體。智慧體所需恰恰相反：低成本、快速且可靠的支付基礎設施，能在人工干預最少的情況下安全地擴展規模。

賣家和買家都將被激勵以消費為導向調整商業模式，並使用能幫助他們實現這一目標的支付網路。如今，穩定幣交易及其底層區塊鏈網路已能夠滿足這些要求。隨著時間推移，我們可能會看到現有網路引入新方案或新型支付網路湧現。Monetization Gateway 的存在就是為了確保賣家能專注於自身產品，讓買家獲得可預期的購買體驗。

### **基於 Monetization Gateway 進行開發**

Monetization Gateway 讓賣家能夠對 Cloudflare 網路背後的任何資源向智慧體按用量收費。它專為每次請求即代表一次使用的資源而設計，例如 API、工具和資料。高價值內容則不同：一個頁面可能被爬取一次，卻被使用千次。為此，[ _Pay Per Use_](http://blog.cloudflare.com/pay-per-use)提供了一個由經過驗證的可信買家組成的網路，每次使用都會回報並付費。

該閘道使用 HTTP 402 Payment Required 狀態碼，使買家可以透過 HTTP 內嵌方式為資源提供支付，與請求資源本身同步進行。這是一個重要的區別，因為不存在跳轉至結帳頁面的重新導向，也無需呼叫單獨的支付 API。

賣家定義哪些請求需要付款、費用金額以及付款接收地址。買家收到支付指示，簽署授權，並在支付結算後獲得資源。

最簡單的理解方式是將其視為「智慧體專用付費牆」。賣家只需幾秒鐘和幾次點按即可上線，確定要收費的目標群體，並確保買家在完成支付前無法存取相關資源。

除了易於實作之外，我們還為賣家提供了一整套開箱即用的定價和變現功能。您可以編寫符合請求任何部分（如 URL、請求標頭或查詢參數）的定價規則，並從多種定價方案中選擇。其餘工作由我們處理：透過[ _Coinbase x402 Facilitator_](https://docs.cdp.coinbase.com/x402/seller/facilitator)進行支付驗證和結算，處理失敗和重試，提供分析報告，以及跟進 x402 協議的變更。支付在 [_Base_](https://www.base.org/)區塊鏈上以 USDC 結算，USDC 是一種與美元掛鉤的穩定幣。未來，我們計劃幫助賣家讓自己的服務可供智慧體探索，公開所有交易記錄，支援更多支付基礎設施，並整合身分原語。

讓我們看看客戶今天如何在生產環境中使用它。

### **Cloudflare AI Gateway：為推理付費**

[ _Cloudflare的AI Gateway_](https://www.cloudflare.com/products/ai-gateway/)是一個控制平面和模型市集，讓開發者只需一個API金鑰即可存取數百個 AI 模型。我們的目標是在生態系統中營運最豐富的模型目錄，並讓盡可能多的客戶使用。AI Gateway 允許客戶[ _購買點數_](https://developers.cloudflare.com/ai-gateway/features/unified-billing/)，可用於所有 AI Gateway 消費。但隨著越來越多的智慧體持有電子錢包，以維持點數餘額作為唯一使用方式會帶來不必要的摩擦。

從今天起，美國境內的 Cloudflare 客戶可以透過新增請求標頭 `PAYMENT-METHOD: x402`，在請求時為特定模型集的推理付費。詳細說明請參閱我們的 [_AI Gateway Developer Docs_](https://developers.cloudflare.com/ai-gateway/features/machine-payments/)。未來，您可以期待看到 HTTP 402 狀態碼原生整合至更多Cloudflare基礎設施產品中。
    
    
    $ curl -iX POST "https://api.cloudflare.com/client/v4/accounts/$CLOUDFLARE_ACCOUNT_ID/ai/run" \
      --header "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
      --header "Payment-Method: x402" \
      --header "Content-Type: application/json" \
      --data '{
        "model": "z-ai/glm-4.7-flash",
        "input": {
          "max_tokens": 9001,
          "messages": [
            {
              "role": "user",
              "content": "What is Cloudflare?"
            }
          ]
        }
      }'

AI Gateway 擁有複雜的定價引擎，負責每個權杖的計費方式。我們共同設計了 Monetization Gateway，以滿足來源端控制定價的需求。啟用此設定後，Monetization Gateway 直接從賣家（AI Gateway）請求定價資訊。對 AI Gateway 而言，這意味著可以依賴其現有定價模組，無需在 Monetization Gateway 中維護規則目錄。

## Ceramic.ai：為網路搜尋付費

>  _「網路是為人類買家而建的，那種會註冊並輸入信用卡的人。智慧體需要自主行動，支付正是實現這一目標的方式。搜尋是每個智慧體最先需要的功能之一，因此也應該是智慧體最先能夠購買的功能之一。」——Dr. Anna Patterson，創辦人，Ceramic.ai_

如果推理是思考，那麼搜尋就是現實查核。[ _Ceramic.ai_](http://Ceramic.ai)提供專為智慧體建構的網路搜尋 API。[Ceramic.ai ](http://Ceramic.ai)維護著一個包含超過 400 億個頁面的專有索引，並針對機器呼叫方對其技術堆疊的每一層進行了最佳化，可在 50 毫秒內傳回搜尋結果。以這樣的速度，智慧體可以在整個任務過程中反覆搜尋。

這使搜尋成為智慧體原生支付的天然契合點。搜尋是智慧體購買的最具彈性的功能之一。一個簡單的問題可能只需一次查詢，而複雜的研究任務可能需要數百次。當智慧體可以自行為搜尋付費時，就不再需要根據預先設定的預算來分配查詢次數。它可以根據任務決定搜尋深度，在需要更多證據時多花費一些。

[Ceramic.ai ](http://Ceramic.ai)使用 Monetization Gateway 的固定定價變現方案，讓智慧體無需API金鑰即可執行搜尋。使用[ _示範_](https://github.com/CeramicTeam/ceramic-x402-search-agent)和 [_Ceramic.ai 文件_](https://docs.ceramic.ai)了解更多資訊。

### Stocktwits：為股票訊號付費

>  _「智慧體改變了資料的消費方式。客戶無需簽署訂閱或談判企業授權，智慧體可以在需要時請求所需的確切內容。對個別請求收費的能力為 Stocktwits 開闢了一種全新的資料開放方式。」——Howard Lindzon，創辦人兼執行長，Stocktwits_

當股票開始波動時，交易者首先問的問題之一是：其他人都在說什麼？

18 年來，這一對話一直在 [_Stocktwits_](https://stocktwits.com/)上進行。Stocktwits 於 2008 年推出，率先引入了現金標籤（如 $[NET](https://stocktwits.com/symbol/NET)），以圍繞個股組織市場對話。如今，超過 1000 萬人使用 Stocktwits 追蹤市場、分享想法，並了解其他投資人的討論。

由於 Stocktwits 專為投資人打造，它能即時呈現散戶投資人正在關注和討論的內容。Stocktwits 將這些活動轉化為訊號，包括：

  * **情緒：** 關於某支股票代號的近期貼文主要是看漲還是看跌
  * **訊息量：** 某支股票代號相對其典型活動產生了多少討論
  * **追蹤者：** 有多少 Stocktwits 使用者追蹤某支股票代號，衡量散戶持續關注度
  * **趨勢：** 哪些股票代號正在最快速地吸引關注



這些訊號長期以來透過 Stocktwits 現有的資料產品提供。Monetization Gateway 為新型客戶——即需要按需取得市場背景的 AI 智慧體——創造了額外的發佈管道。例如，一個監控投資組合或研究投資標的的智慧體，可以查看 $NET 周邊討論是否升溫、情緒是偏向看漲還是看跌，或有多少投資人追蹤該股票代號。無需傳統資料授權，開發者只需為其智慧體實際發出的個別請求付費。

最初，Stocktwits 為這些請求建立了一個獨立的面向智慧體的路徑，並在其前端部署了 Cloudflare 的 Monetization Gateway。現有的 API 和企業資料產品保持不變。每個請求單獨定價，使 Stocktwits 能夠在保留現有資料產品和授權模式的同時，讓AI智慧體可以存取其市場訊號。[ _立即查閱他們的文件以開始使用_](https://api-docs.stocktwits.com/#tag--Monetization-Gateway-\(x402\))。

### **API2PDF：為API存取付費**

[ _API2PDF_](https://api2pdf.com/)是一個 REST API，幫助開發者從 HTML 和 Office 文件產生 PDF。自 2018 年上線以來，API2PDF 觀察到越來越多的 AI 智慧體將開發者引導至其服務，現已將其視為一級客戶。

API2PDF 的基於消費的定價模型根據完成每個請求所需的頻寬和運算資源向客戶收費。以前，客戶在使用該服務前需要建立帳戶並取得API金鑰。第一個月後還需提供信用卡，導致轉換率下降超過 50%。API2PDF 現在使用 Monetization Gateway，當使用者或智慧體在沒有 API 金鑰的情況下發出請求時，傳回 HTTP 402 回應。由於每個請求的運算和頻寬成本是可變的，API2PDF 使用可變定價告知智慧體單次請求可能產生的最高費用。客戶完成支付後，API2PDF 處理請求並僅結算實際消耗量。

智慧體面臨與開發者相同的自建還是購買的決策。需要 PDF 的智慧體可以消耗權杖自行產生，或花費不到一分錢委託 API2PDF 這類專業API來正確完成。
    
    
    $ curl -iX POST https://v2.api2pdf.com/chrome/pdf/html --header "Content-Type: application/json" --data '{"html":"<p>Hello from an AI agent</p>"}'

    content-type: application/json
