今天，我們很高興地為新創公司提供高達 250,000 美元的抵免額度，以用於 Cloudflare 的[ _開發人員平台_](https://www.cloudflare.com/developer-platform/products/)。在這個新的抵免額度系統中，您可以清楚地看到使用情況和相關費用，以便在 250,000 美元的抵免額度用完後或一年後（以先發生者為準）規劃可預測的未來。

您可以在[ _此處_](https://www.cloudflare.com/forstartups/)查閱資格條件並申請加入新創公司計畫。

## 這些抵免額度可以用來做什麼？

抵免額度適用於所有開發人員平台產品，以及 [_Argo_](https://developers.cloudflare.com/argo-smart-routing/) 和 [_Cache Reserve_](https://developers.cloudflare.com/cache/advanced-configuration/cache-reserve/)。此外，我們還為參與者提供最多三個 [_Enterprise 方案層級的領域_](https://www.cloudflare.com/plans/)，其中包括 CDN、DDoS、DNS、WAF、Zero Trust 以及參與者可以為其網站啟用的其他[ _安全性和效能產品_](https://www.cloudflare.com/application-services/products/)。

### Cloudflare 的速度和效能

我們知道，創始人在創業時需要獲得一切能得到的幫助。除了開發人員平台之外，您還可以使用新創公司計畫來獲得我們的速度和效能產品。在您的網站或應用程式上，能否在幾[ _毫秒_](https://developers.cloudflare.com/speed/)內讓客戶到達他們需要的位置，是最終能否完成銷售的關鍵。您可以在[ _這裡_](https://developers.cloudflare.com/fundamentals/basic-tasks/test-speed/)測試您的速度，並在[ _這裡_](https://developers.cloudflare.com/learning-paths/get-started/performance/optimize-speed/)瞭解如何使用 [_Images_](https://developers.cloudflare.com/images/)、[ _Argo_](https://developers.cloudflare.com/argo-smart-routing/) 和 [_Early Hints_](https://developers.cloudflare.com/cache/advanced-configuration/early-hints/) 等解決方案來最佳化您的速度和效能。

### Cloudflare 提供的安全性

除此之外，還有更多功能：除了開發人員平台產品和速度工具之外，您還可以透過新創公司計畫使用 Cloudflare 的許多安全功能。其中包括 [_Web 應用程式防火牆_](https://developers.cloudflare.com/waf/) ([_WAF_](https://www.google.com/aclk?sa=l&ai=DChcSEwj6jt32op2IAxXk1cIEHQVsCf8YABAAGgJwdg&co=1&ase=2&gclid=Cj0KCQjw28W2BhC7ARIsAPerrcIntApH-BAsWuajq8owh4eTi3Z1hH6S3xeg51-QEKIIuOYtfAxN7TUaAvSvEALw_wcB&sig=AOD64_2mwuQ5V4e7y1VboIJtoTEiFHnEkg&q&nis=4&adurl&ved=2ahUKEwjOpdj2op2IAxU5LEQIHf_dDqIQ0Qx6BAgYEAE))、[ _DDoS 警示_](https://developers.cloudflare.com/ddos-protection/reference/alerts/)、搭售的[ _保護計畫_](https://www.cloudflare.com/plans/)等。新創公司計畫還包括 [_Zero Trust_](https://www.cloudflare.com/plans/zero-trust-services/) 解決方案。瞭解其他人如何透過 Cloudflare Zero Trust [_保護其技術和工具_](https://www.cloudflare.com/case-studies/?usecase=Enable+zero+trust+security+for+workforce)。

## 誰可以使用抵免額度？ 

可在[ _此處_](https://www.cloudflare.com/forstartups/)找到資格條件，其中包括：

  * 構建基於軟體的產品或服務的公司
  * 在過去 5 年（2019-2024 年）內成立
  * 籌集資金介於 50,000 至 5,000,000 美元之間
    *  _請注意，對於尚未籌集至少 50,000 美元的新創公司，可能還有其他機會獲得較低的抵免額度。如果您尚未籌集 50,000 美元，但對 Cloudflare 新創公司計畫感興趣，請使用促銷代碼「BOOTSTRAPPED」申請_
  * 擁有 LinkedIn 檔案、有效網站和電子郵件地址
  * 能夠助力申請的額外條件：成為已批准加速器的一部分

## Cloudflare 為什麼要為創始人和新創公司提供支援？ 

創始人和開發人員已經面臨著足夠多的挑戰，不應該再擔心在早期測試技術和開始構建會產生驚人的成本。世界觸手可及，您應該能夠不受限制地進行構建和創作。將資金投資於創新，而不是支援創新的基礎架構和技術。

新創公司計畫非常瞭解這種創始人的經歷，因為該團隊的成員曾經也都是創始人。Cloudflare 致力於此類計畫，以支援創始人構建 _下一個偉大產品_ 。Cloudflare 提供高達 250,000 美元的抵免額度，讓人們能夠利用我們提供的更多功能：消除摩擦、節省資金並在數小時內（而不是數天內）啟動應用程式的開發人員體驗。

我們希望為世界各地的創始人提供支援。
