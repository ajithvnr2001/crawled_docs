十六年前，Cloudflare 還是一千多家新創公司之一，懷揣著在 TechCrunch Disrupt 舞台上亮相的夢想。

從表面上看，我們並不是顯而易見的選擇。Cloudflare 做的是基礎架構：讓網站跑得更快，並保護它們免受攻擊——而這在當時並不被大眾市場所理解。基礎架構往往是隱形的，直到它變得舉足輕重的那一刻才會被察覺。然而，在 2010年9月27日，Matthew Prince 和 Michelle Zatlyn 走上 Startup Battlefield 的舞台，向公眾正式發布了 Cloudflare。演講進行中，人們開始陸續註冊。隨後更多人湧入。當評委的提問結束時，已有數百個網站加入了 Cloudflare，我們最初的五個資料中心正經受著即時的考驗。此後七天，流經我們網路的流量增長了近十倍，Cloudflare 從全球第 1000 大網站躍升至前 50 名。

那一天，Cloudflare 沒有贏得主獎盃。在頒獎典禮上，TechCrunch 創辦人 Mike Arrington 把我們的工作形容為類似「給網際網路修消音器」——說實話，他說的不無道理。但隨後，他將我們評為最具創新力的公司。正如 Matthew 後來所寫：「你或許拿不到那座獎盃，但你將收穫另一樣遠比它重要的東西。」

在一家公司的生命歷程中，有些時刻，有人給你一個房間、一支麥克風和少許時間，讓你講述那件你已魂牽夢縈了數月乃至數年的事情。大多數時候，什麼魔法都不會發生。但有時，恰當的人在恰當的時機聽到了它，一個原本只存在於少數人腦海中的想法，便開始在世界上流動起來。

今年十月，Cloudflare 迎來 16 週年。我們希望給五家早期階段的新創公司一個屬於自己的舞台。

## **隆重介紹 The Cold Start**

[ _The Cold Start_](https://www.cloudflare.com/connect/cold-start/?cf_page=introducing-the-cold-start%2F)是一場真實的路演競賽，將於下月在 San Francisco 的 Cloudflare Connect 舉行。我們將從中遴選五家早期階段企業，為每家提供五分鐘的舞台，講清楚他們在做什麼、為什麼它需要存在，以及為什麼他們是應該去做這件事的人。

比起完美的路演簡報，我們更希望看到條理清晰、表達有力的有趣想法。你不需要三十張投影片、一個精確得可疑的 TAM 估算，也不需要一個精心排練的故事——講述你的童年如何為顛覆應收帳款產業做好了鋪墊。我們想要理解的是願景：世界發生了什麼改變使它成為可能，你看到了別人錯過的什麼，以及為什麼你無法停止思考它。

五位決賽入圍者將在 Cloudflare Connect 的觀眾面前，以及三位在公司、基礎架構與網際網路領域深耕多年的人面前，闡述各自的主張：

  * Matthew Prince，Cloudflare 聯合創辦人兼 CEO
  * Michelle Zatlyn，Cloudflare 聯合創辦人兼總裁
  * Dane Knecht，Cloudflare 技術長



評審將選出一家新創公司，獎勵 $500,000 的 Cloudflare 信用额度、舊金山的一塊廣告看板展示位，並獲得當晚 VIP 演講者晚宴的邀請函。

五家公司，各五分鐘，台下坐滿全神貫注的聆聽者。

### **我們在尋找什麼？**

The Cold Start 開放給總部位於美國和加拿大、募資金額少於 1,000 萬美元且充滿雄心的早期新創公司。除此之外，我們有意將範圍定義得足夠寬泛——最有趣的公司，很少會以整齊劃一的分類形式出現。

我們希望看到那種一旦有人終於把它做出來就顯得理所當然的想法，以及那些乍聽之下略顯異想天開的想法。我們希望看到看似無聊、卻總有一天人人都離不開的基礎架構；幾年前根本無法存在的產品；奇妙的新型互動介面；全新的軟體建構方式；既有針對龐大現有市場的，也有面向尚無人命名的市場的。

最重要的是，我們想遇見那些發現了世界上某件事並決心有所行動的人。

在申請過程中，我們會請你介紹自己，提供一句話路演，解釋你在建構什麼以及為什麼，說明你的融資和營收階段，展示 Cloudflare 如何融入你的技術堆疊，並指向任何能幫助我們了解你和你工作的資訊。

目標很簡單：讓我們明白你所建構的東西為何應該存在。

** _申請現已開放，截止日期為 2026年10月2日（週五）。_**

## **舊金山的五分鐘**

The Cold Start 將作為 [_Cloudflare Connect_](https://www.cloudflare.com/connect/?cf_page=introducing-the-cold-start%2F) 的一部分，於 2026年10月19日（週一）太平洋夏令時下午 4 時至 5 時，在舊金山的 Moscone West 舉行。Cloudflare 將為五位決賽選手報銷飛往舊金山參加比賽的機票費用。

Connect 大會匯聚了所有正在建構並思考網際網路未來發展的人才。今年的講者陣容包括：AI 先驅李飛飛博士 (Dr. Fei-Fei Li)；Idealab 創辦人 Bill Gross；組織心理學家暨作家 Adam Grant；AMD 技術長 Mark Papermaster；Vue.js 與 Vite 創造者尤雨溪 (Evan You)；Lovable 共同創辦人暨技術長 Fabian Hedin；以及 OpenAI 技術人員兼 OpenClaw 創造者 Peter Steinberger。

我們為五家年輕公司保留了部分舞台時間。每家新創公司將有 5 分鐘進行路演，隨後由評委提問 3 至 5 分鐘。

這種「對稱」的安排讓我們倍感欣喜。十六年前，Cloudflare 曾經渴望有人能給一家基礎架構公司一個機會——儘管當時我們的業務故事很難向外界講清楚——讓我們在合適的場合獲得幾分鐘的展示時間。今天，我們有幸擁有了自己的舞台，而我們希望把同樣的機會傳遞給那些剛剛起步的公司。

## **從小處出發，成就非凡。**

Cloudflare 花如此多的時間與新創公司合作，有其務實的理由：非常小的團隊往往有著挑戰非常宏大事業的驚人能力。

問題在於，雄心勃勃的軟體越來越依賴於一種基礎架構，而就在不久前，只有全球最大的科技公司才負擔得起自建這些基礎架構。全球運算能力、儲存、網路、安全、即時系統、AI 推論，以及在你做的東西突然爆紅時也能撐住的能力——這些都不應該要求一家公司先變得龐大才能擁有。

我們認為，你應該從第一天起就能取得這些能力。

這正是 [_Cloudflare for Startups_](https://www.cloudflare.com/startups/?cf_page=introducing-the-cold-start%2F) 背後的初衷之一——符合條件的早期階段公司可獲得最長一年、價值最高 $350,000 的 Cloudflare 積分。這也是我們持續擴展 Cloudflare 開發人員平台的原因之一：如果一個小團隊在週二建構出某個東西，網際網路在週三決定喜歡它，那麼這個小團隊在週四就應該專注於產品本身，而不是倉促地成為全球基礎架構專家。

Cloudflare 從一個略顯大膽的前提起步：讓網際網路上最大企業所擁有的效能、安全與全球運算能力，從第一天起就能為所有人所用。2010年，我們在一個舞台上獲得了解釋這件事為何重要的機會。

十六年後，我們擁有了規模大得多的網路、略顯龐大的團隊，以及效能卓越得多的斷路器。

現在，我們想聽聽你在建構什麼。
