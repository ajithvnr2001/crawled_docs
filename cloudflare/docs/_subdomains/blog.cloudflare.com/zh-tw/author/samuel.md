2026年10月2日## [隆重推出 Forge：用於生成 SDK、CLI、文件等的開源生成流水線](https://blog.cloudflare.com/zh-tw/forge-open-source-generation-pipeline/)

Forge 是一款開源的可插拔生成流水線，在 CI 中執行，可直接從 API 定義生成 SDK、CLI 和文件。透過將生成流程上移至各團隊獨立的程式碼儲存庫，Forge 使開發者工具始終保持同步。
