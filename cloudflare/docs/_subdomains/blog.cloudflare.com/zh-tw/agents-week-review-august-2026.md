在 Agents Week 開始之際，Rita[​](https://blog.cloudflare.com/agents-week-welcome/) [_分享_](https://blog.cloudflare.com/agents-week-welcome/)道：智慧體代表了運算的下一個演進階段——它不僅是 AI 的新應用，更是一種全新的軟體類別，正在重塑人們與科技的互動方式，以及軟體與網際網路的交互模式。在[​ _過去一年_](https://www.cloudflare.com/innovation-week/ai-week-2025/updates/)左右的時間裡，我們致力於探索這場轉變對開發者及打造 AI 原生應用程式的客戶意味著什麼，以及支撐這一切所需的基礎架構。隨著智慧體變得越來越強大且自主，挑戰已不僅限於模型本身，更延伸至身分識別、通訊、協調、記憶體、可觀測性與安全性等層面。

過去一週，我們分享了如何將這些拼圖在 Cloudflare 平台上整合起來，以服務於智慧體網際網路。每一天，我們都推出了新的工具、產品與構想，致力於打造一個人類與智慧體能夠[​ _攜手合作、而非相互衝突_](https://blog.cloudflare.com/the-agentic-internet/)的網際網路。

### **8 月 3 日，星期一**

週一聚焦於建構與執行智慧型自主應用程式的基礎，即智慧體所依賴的執行環境與基礎架構。

[ _您的智慧體需要一台電腦，而不是一個容器——推出 @cloudflare/computer_](https://blog.cloudflare.com/zh-tw/cloudflare-computer/)|  @cloudflare/computer 引入了一種專為智慧體設計的新型執行環境，能為任務選擇最合適的環境。  
---|---  
[ _Workers RPC 現在支援 Python 和 JavaScript_](https://blog.cloudflare.com/python-workers-rpc/)|  Python 與 JavaScript Workers 現在可以直接對話，大幅簡化了多語言專案的開發。  
[ _更小、更快、更安全：大規模執行 Kimi 和 GLM_](https://blog.cloudflare.com/smaller-faster-safer-models/)|  探討我們如何在不犧牲品質、可靠性與安全性的前提下，更高效地提供大型模型服務。  
[ _推出 Billable Usage API：為 Cloudflare 提供程式化的成本可視性_](https://blog.cloudflare.com/zh-tw/billable-usage-api/)|  一種更簡便的方式，用於追蹤我們各項自助式產品的用量與成本。   
[ _Cloudflare Workers 和 Containers 現已支援傳入 TCP 連線和 gRPC_](https://blog.cloudflare.com/grpc-workers/)|  使用 Cloudflare Workers 來託管語音 AI 後端或其他即時語音智慧體。  
  
### **8 月 4 日，星期二**

週二介紹了智慧體開發生命週期 (ADLC) 以及將智慧體軟體從原型推向生產環境所需的基礎元件。

[ _Cloudflare 推出智慧體開發生命週期_](https://blog.cloudflare.com/zh-tw/agent-development-lifecycle/)|  以 ADLC 取代傳統的 SDLC（軟體開發生命週期）；我們對於將智慧體從原型推向正式環境的觀點，以及支撐下一世代「軟體工廠」的基礎元件。  
---|---  
[ _隆重推出：Cloudflare Agents_](https://blog.cloudflare.com/agents-on-cloudflare/)|  在 Cloudflare 上建構智慧體，並透過追蹤 (tracing)、重播 (replay) 以及生產環境中的「人類介入核准」機制，即時監控每一次執行。  
[ _您的智慧體現在可以透過本機追蹤來除錯 Workers_](https://blog.cloudflare.com/local-tracing/)|  將分散式追蹤引入本地開發環境，讓智慧體能在上線前更輕鬆地發現並修復問題。  
[ _宣佈推出 Cloudflare Wallets：適用於智慧體網際網路的可程式化錢包_](https://blog.cloudflare.com/zh-tw/wallets/)|  Wallets 為智慧體提供了一種安全機制，使其能作為新興智慧體經濟的參與者執行交易。  
[ _在您的平台上，透過 Cloudflare 為數百萬個程式碼庫執行 CI/CD_](https://blog.cloudflare.com/ci-workflows/)|  可程式化的 CI/CD；以程式碼而非設定檔編寫的管線，並配備一個能修復失敗並將修補程式暫存以待審查的智慧體。  
[ _Cloudflare 如何利用 AI 落實工程標準_](https://blog.cloudflare.com/engineering-standards-enforcement/)|  分享我們如何在整個開發流程中運用 AI 自動化，以維持程式碼標準與流程的一致性，協助我們的軟體工廠大規模交付高品質且一致的程式碼。  
[ _我們如何打造軟體工廠，將 Astro 的 GitHub Issue 數量歸零_](https://blog.cloudflare.com/astro-issue-triage/)|  自動化分析、分類與路由問題，將軟體維護的繁瑣工作降至最低，最大化開發人員生產力。  
  
### **8 月 5 日，星期三**

週三將 Zero Trust 的範疇從使用者與裝置擴展至智慧體本身——同時分享了 Cloudflare 內部如何執行這套機制。

[ _智慧體存取模型_](https://blog.cloudflare.com/the-agent-access-model/)|  一個框架，規範智慧體如何代表使用者安全地存取資源與服務——適用於這個日益由智慧體組成的網際網路。   
---|---  
[ _我們如何透過 Cloudflare OS 重新構思工作模式_](https://blog.cloudflare.com/how-we-use-ai-with-cloudflare-os/)|  分享我們如何將 AI 嵌入內部營運模式，讓團隊在不必犧牲安全性或監管的情況下，更聰明、更快速地工作。  
[ _Cloudflare OS：適用於智慧體、應用程式和工作的開放平台_](https://blog.cloudflare.com/zh-tw/cloudflare-os/)|  我們將團隊用來建置應用程式、自動化作業及安全存取內部系統的平台開源釋出。   
[ _利用具身分識別能力的分析機制，捕捉異常 AI 行為_](https://blog.cloudflare.com/zh-tw/identity-aware-ai-gateway/)|  將 AI 活動關聯至真實的使用者與系統，讓異常行為與成本飆升更容易被察覺。  
[ _WriteGuard：針對 MCP 伺服器的細粒度控制_](https://blog.cloudflare.com/mcp-portal-writeguard-private-beta/)|  將我們內部部署的工具開放給客戶使用，以更嚴格地控管高風險的工具呼叫，降低智慧體進行非預期變更的機率。  
  
### **8 月 6 日，星期四**

週四定義了「智慧體網際網路」的願景，以及網站擁有者、內容發布者與智慧體如何共同打造一個對人類與智慧體皆宜的網路。

[ _打造開放的智慧體網際網路：可讀、可發現、可呼叫、可付費_](https://blog.cloudflare.com/zh-tw/the-agentic-internet/)|  一種智慧體網際網路模型，讓發布者保持控制權，智慧體獲得所需的實用存取權，並透過開放通訊協定讓雙方能夠交易。  
---|---  
[ _為任何網站提供 WebMCP 介面_](https://blog.cloudflare.com/webmcp/)|  WebMCP 預覽，它引入了一種嶄新（且極其簡單）的方法，讓網站與網頁應用程式能被智慧體發現與使用。  
[ _從排名到被推薦：讓您的網站準備好在 AI 智慧體時代蓬勃發展_](https://blog.cloudflare.com/zh-tw/aeo/)|  將 SEO 調整為 AEO（Answer Engine Optimization，答案引擎最佳化）做法，以改善網頁內容被智慧體發現、理解和呈現的方式。  
[ _推出 Kitesurf：執行於 Cloudflare Workers V8 Isolates 之中的智慧體專用瀏覽器_](https://blog.cloudflare.com/kitesurf/)|  一款專為智慧體打造的瀏覽器，捨棄了像素級的完美渲染，換取更低的記憶體與 CPU 佔用。  
[ _新一代 MCP_](https://blog.cloudflare.com/mcp-v2/)|  MCP 迎來了重寫。MCPv2 標誌著 MCP 支援能力的演化，簡化了智慧體應用程式的部署與擴展。  
[ _Cloudflare AI Search：為您的智慧體打造專屬資料搜尋引擎_](https://blog.cloudflare.com/ai-search-easier/)|  AI Search 只需一條指令，即可將您的檔案或網站轉變為智慧體就緒的搜尋引擎。  
  
### **8 月 7 日，星期五**

週五聚焦於現況分析：智慧體在網路上實際做了什麼、AI 在應用程式中的哪裡執行、誰在為生態系統做出貢獻，以及用於分析網際網路資料的新工具。

[ _揭開智慧體網際網路上的良好與不良行為_](https://blog.cloudflare.com/zh-tw/good-and-bad-agentic-behaviors/)|  機器人不總是壞的，人類也不總是好的；將防禦思維從「一次性風險評估」重構為「持續性信任評估」。  
---|---  
[ _將 Workers AI 與 AI Gateway 統一為單一 AI 控制平面_](https://blog.cloudflare.com/workers-ai-gateway-unification/)|  一個綁定、一個錢包、一個儀表板，即可呼叫任何 AI 模型；以模型為優先的路由機制即將推出。  
[ _宣布 Cloudflare Ambassadors、Community Engineers 計畫，以及額外 100 萬美元的開源資助_](https://blog.cloudflare.com/community-program-refresh/)|  我們更新的社群計畫推出了兩項新專案：針對社群領袖的 Cloudflare Ambassadors，以及針對開源維護者的 Community Engineers，並將在未來兩年內追加 100 萬美元的開源資金。  
[ _推出 Radar Researcher：一款用於探索網際網路資料的 AI 工具_](https://blog.cloudflare.com/introducing-radar-researcher/)|  Radar 的 AI 研究助理：輸入自然語言提問，即可產生互動式圖表。  
  
### **Agents Week 雖已結束，但我們的腳步未停**

五天過去，針對 Rita 提出的「[ _你的智慧體需要從 Agent Cloud 獲得什麼？_](https://blog.cloudflare.com/agents-week-welcome/)」這個問題，答案已初現雛形。它需要一個執行層與運行其上的基礎元件、一個日益自動化的開發生命週期、為工作者（人類與智慧體）提供的安全存取機制、一個智慧體網際網路，以及維繫這一切的人類與社群。未來仍有無限可能，但前進的方向已愈發清晰：一個原生支援人類與代其行動之智慧體的網際網路。

我們的工作不會止步於此。請持續關注我們的[​ _更新記錄_](https://developers.cloudflare.com/changelog/)以獲得最新消息。如果您正與我們一同建構這願景的任何一環，我們很樂意聽到您的聲音！歡迎在[​](https://x.com/cloudflaredev) [_X_](https://x.com/cloudflaredev) 或[​](https://discord.com/invite/cloudflaredev) [_Discord_](https://discord.com/invite/cloudflaredev) 上與我們聯繫。
