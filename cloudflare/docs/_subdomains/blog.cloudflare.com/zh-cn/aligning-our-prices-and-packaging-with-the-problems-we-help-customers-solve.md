Cloudflare 的目标简单而大胆，帮助构建更好的互联网。这一使命促使我们建设[ _世界上最大的网络之一_](https://www.cloudflare.com/network/)，[ _为内容提供商挺身而出_](https://blog.cloudflare.com/content-independence-day-no-ai-crawl-without-compensation/)，坚持不懈创新，让世界各地所有人都能使用更安全、更快速、更可靠的互联网。

然而，打造世界一流的产品只是我们战斗的一部分。要完成我们的使命，就意味着让用户能够获取这些产品，包括一个公平、可预测且与我们提供的价值一致的定价模型。如果我们的包装令人费解，或者我们的定价让您因使用服务而费力，那么我们就没有履行我们的[ _使命_](https://www.cloudflare.com/about-overview/)。确保这种一致性的最佳方式是什么？

倾听我们客户的声音

多年来，您的反馈塑造了我们的产品路线图，帮助我们发展到在单个、统一的平台和网络基础设施上提供四个解决方案领域——[ _应用服务_](https://www.cloudflare.com/application-services/#application-services-case-products) 、[ _网络服务_](https://www.cloudflare.com/network-services/#network-services-products) 、[ _Zero Trust 服务_](https://www.cloudflare.com/zero-trust/#platform-capabilities)和我们的[ _开发人员平台_](https://www.cloudflare.com/plans/developer-platform/) ——[ _近 100 个产品_](https://developers.cloudflare.com/products/)。最近，我们听到了一个新的主题：简化的需求。您问我们：“100 种产品很多。能不能说得更规范一些？”以及“您的定价能否使更简单直接？”

我们听到了这样清晰的反馈。因此，我们非常高兴地推出 **Externa** 和 **Interna** ，这两个[ _用例捆绑包_](http://cloudflare.com/plans/enterprise)新系列旨在简化您的 Cloudflare 使用体验。

## 两大挑战，两种解决方案

我们与首席信息官、首席技术官和首席信息安全官交谈时，他们面临的挑战几乎总是可以归结为连接和保护两个基本领域：(1) 外部、面向公众的基础设施和 (2) 内部、私有系统。

过去，业界通过销售数十种单点产品来解决这些问题，外加一系列创可贴式解决方案。一个供应商的 WAF，另一个供应商的 DDoS 清洗器，第三方的 VPN。结果便是造成混乱的复杂性，供应商锁定，以及漏洞百出的安全态势。成本高昂、低效且不安全。

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![BLOG-2871 image 2](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW484VWSD8CXFYTQ8973CS3Z.png&w=715&h=290&f=webp&fit=cover&position=center)

我们认为这种情况本末倒置。我们的全新解决方案提供一种更简单、更集成的方法：

  * [** _Externa_**](http://cloudflare.com/plans/enterprise/externa) 用于连接和保护企业中面向公共互联网的部分，例如网站、API、应用程序和网络，它们是企业的前门和门面
  * [** _Interna_**](http://cloudflare.com/plans/enterprise/interna) 用于连接和保护您的内部专用系统和资源，包括处于组织核心的员工、设备、数据和网络



这些软件包代表了我们对现代连接和安全架构应该是什么样子的规范性观点。而且，搭配使用时效果最佳。

### Externa：连接和保护面向公众的外部系统

通过 Externa，我们正在解决连接和保护面向公众基础设施的复杂性。这里的一个关键原则是公平。我们发现，客户在 DDoS 攻击后收到的费用高达天文数字，因为他们对所有流量收费，无论是干净的还是恶意的。这就像消防部门向您收取他们用于拯救您房屋的水的费用。我们不会、也从未这样做过，这就是为什么使用 Externa，您仅为合法流量付费。

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![BLOG-2871 image 4](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW462XGW3SRBP7SCTFH836VV.png&w=715&h=251&f=webp&fit=cover&position=center)

我们认为，简单、集成的模型将降低总拥有成本并增强安全态势。各种临时解决方案需要大量管理开销。Externa 将我们的 WAF、DDoS、API 安全、网络、应用程序性能服务等捆绑到一个简单的程序包中，其计量单位可随价值扩展。

这对您有何意义？

  * **无攻击流量税：** 即使在大规模 DDoS 攻击期间，您的成本保持可预测。
  * **简单、以价值为导向的价格单位：** 无源站获取费用、每个请求的重复费用，或按规则付费。
  * **简化连接成本：** 免费的专用互连轻松接入，无论您在何处托管。



安全不应止步于您的边界，每个 Externa 套餐中均包含 50 个 Interna 用户，后者是我们的 SASE 解决方案套餐。

### Interna：连接并保护内部专用系统

通过 Interna，我们正在修复网络和安全性支离破碎的经济问题。旧模型是为每个人都进入办公室而构建的。世界已经改变：在今天的混合工作环境中，您的内部网络不再局限于办公室和数据中心。无论您的员工和数据所在位置，它都可追随您的步伐。但是，许多供应商仍然是对同一个用户收取两次费用：一次针对席位，当他们使用办公室网络时。

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![BLOG-2871 image 5](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW472FY9XJ3AFF5H4HY4G3XN.png&w=715&h=257&f=webp&fit=cover&position=center)

我们认为您永远不应该为用户带宽付费。我们的模型能够识别用户就是用户，无论他们身在何处；我们不会对带宽收取双重费用；实际上，我们会从您的 WAN 计量表中减去用户设备客户端生成的流量。我们更进了一步：每个 Interna 用户许可证都有助于共享带宽池，您可以用来构建一个现代、安全、快速的企业 WAN。有了 Interna，您原本用于安全性的预算现在也可用于构建公司网络了。

这对您有何意义？

  * **无需为用户带宽付费：** 单一每席位价格涵盖您的用户，无论他们在何处工作，降低您的 WAN 账单并消除混合办公的不利影响。
  * **每种许可证都可以扩展您的 WAN：** 来自用户许可证的汇集带宽帮助您取代昂贵的专用 WAN 合同。
  * **全方位安全性：** 数字体验监测 (DEM) 及内联和基于 API 的云访问安全代理 (CASB) 等高级功能都包括在内，而不是昂贵的附加组件。

## Cloudflare 的统一优势

我们的独特优势始终是我们的网络。通过一个平台和一个全球网络为数百万客户提供服务，从 [_Free 计划_](https://www.cloudflare.com/plans/free/)的个人开发者到全球最大的企业，这赋予我们令人难以置信的影响力。这使我们能够提供强大的[ _免费服务_](https://blog.cloudflare.com/cloudflares-commitment-to-free/)并[ _保护记者和非营利组织_](https://www.cloudflare.com/galileo/)。这也是我们的平台在结构上更好的原因：我们的 AI 模型基于来自 [_20% 网络_](https://w3techs.com/technologies/history_overview/proxy/all/q)的数据训练，提供比以往孤立平台更有效的威胁检测。

我们认为，相同的结构优势应该帮助各种规模的企业无需妥协即可扩展规模。随着公司发展壮大，他们常常面临一个艰难的选择：最初使用的各种单点产品是否会变得过于复杂，无法管理，还是他们选择的集成平台会变得过于有限？您要求提供一条更具规范性的路径，以解决这一错误选择。

有了我们新的 Externa 和 Interna 捆绑包，这种权衡消失了。每个系列中的 Essentials、Advantage 和 Premier 等级旨在为各种规模的企业提供一条清晰的路径，使企业能够采用可无缝扩展的适合阶段的网络和安全解决方案。随着您的业务发展，您的等级升级，从 Essentials 提升到 Advantage 再到 Premier，从而获得更多高级功能。这是简单的增长。
