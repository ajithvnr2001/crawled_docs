[Queues](https://developers.cloudflare.com/queues/) 是一个全球消息队列服务，允许应用程序使用 Cloudflare Workers 可靠地发送和接收消息。它提供至少一次消息传递，支持消息的批处理，并且不收取带宽出口费用。

Cloudflare Stream [现已支持基于](https://developers.cloudflare.com/stream/webrtc-beta/) WebRTC 的流媒体直播，亚秒级延迟，无限并发观看。

[Page Rules 的未来](https://blog.cloudflare.com/future-of-page-rules/)

我们计划用四个专门的产品替换 Page Rules，提供更多的规则配额、更多的功能和更细的粒度。

[缓存规则](https://blog.cloudflare.com/introducing-cache-rules/)

进一步发展 Cloudflare 上基于规则的缓存，提供更多可配置的缓存规则。

[Configuration Rules](https://blog.cloudflare.com/configuration-rules/)

Configuration Rules 支持过去必须在 Cloudflare Worker 中编写自定义代码才能实现的用例，包括 A/B 测试配置、为一组文件扩展名启用功能等等。

[源规则](https://blog.cloudflare.com/origin-rules/)

一个新产品，允许覆盖匹配 HTTP 请求的主机标头、服务器名称指示（SNI）、目标端口和的 DNS 解析。
