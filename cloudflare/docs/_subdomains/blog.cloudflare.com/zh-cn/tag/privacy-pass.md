两年前的这个星期，Cloudflare引入了机会性加密技术，该功能为那些还没有转变为HTTPS的网站提供了额外的安全和性能优势。事实上，在过去，一些网站只使用HTTP ---是不是很奇怪？这里的“机会性”意味着服务器通过HTTP Alternative Service请求头宣告了对HTTP / 2的支持，希望任何识别该协议的浏览器都可以在后续的域请求中利用这些优势。
