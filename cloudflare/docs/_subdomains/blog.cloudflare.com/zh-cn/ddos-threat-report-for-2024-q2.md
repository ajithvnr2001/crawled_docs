### 简要回顾 - 什么是 DDoS 攻击？

在深入探讨之前，我们回顾一下什么是 DDoS 攻击。[分布式拒绝服务](https://www.cloudflare.com/learning/ddos/what-is-a-ddos-attack/) (DDoS) 攻击是一种网络攻击，目的是切断或破坏互联网服务（例如网站或移动应用程序），使用户无法使用这些服务。通常采用的攻击方式是使受害者的服务器不堪重负，无法处理过多流量，这些流量通常来自互联网上的多个源，进而导致服务器无法处理合法用户流量。

### 威胁行为者的复杂老练，推动了 DDoS 攻击数量的持续增长

2024 年上半年，Cloudflare 缓解了 850 万次 DDoS 攻击：第一季度 450 万次，第二季度 400 万次。总体而言，第二季度 DDoS 攻击数量环比下降了 11%，但同比增长了 20%。

## DDoS 攻击特征

### 网络层 DDoS 攻击手段

虽然基于 DNS 的 DDoS 攻击数量季度环比减少了 49%，但它仍然是最常见的攻击手段，其中 [DNS 洪水](https://www.cloudflare.com/learning/ddos/dns-flood-ddos-attack/)和 [DNS 放大](https://www.cloudflare.com/learning/ddos/dns-amplification-ddos-attack/)攻击合计占 37%。[SYN 洪水](https://www.cloudflare.com/learning/ddos/syn-flood-ddos-attack/)次之，占 23%；随后是 RST 洪水，占 10% 多一点。SYN 洪水与 RST 洪水都是基于 TCP 的 DDoS 攻击。所有基于 TCP 的 DDoS 攻击数量总共占网络层 DDoS 攻击总数的 38%。

### HTTP DDoS 攻击手段

运营大型网络的优势之一是我们可以发现许多流量和攻击。这有助于我们优化检测和缓解系统来保护客户。Cloudflare 在第一季度使用针对自身已知僵尸网络的专有启发式方法缓解了一半数量的 [HTTP DDoS 攻击](https://www.cloudflare.com/learning/ddos/http-flood-ddos-attack/)。这些启发式方法会指导我们的系统如何生成实时特征来匹配不同类型的攻击。

另有 29% 的 HTTP DDoS 攻击使用了虚假用户代理、冒充浏览器，或来自无头浏览器。另有 13% 的攻击具备可疑的 HTTP 属性，触发了我们的自动化防御系统；以及 7% 的攻击被标记为一般洪水。需要注意的一点是，这些攻击手段或攻击组织不一定具有排他性。例如，已知的僵尸网络也会冒充浏览器以及具备可疑的 HTTP 属性，但这是我们对 HTTP DDoS 攻击进行分类的初步尝试。

### DDoS 攻击持续时间

绝大多数 DDoS 攻击的持续时间比较短。超过 57% 的 HTTP DDoS 攻击以及 88% 的网络层 DDoS 攻击在 10 分钟内结束。这凸显了对自动化内联检测和缓解系统的需求。因为如果由人来响应警报、分析流量，以及应用手动缓解措施，十分钟远远不够。

在图表的另一端，我们可以看到，大约四分之一的 HTTP DDoS 攻击持续时间超过一小时，近五分之一的攻击持续时间超过一天。而持续时间较长的网络层 DDoS 攻击数量明显减少，只有 1% 的网络层 DDoS 攻击持续时间超过 3 小时。

尽管大多数攻击规模较小，但较大型的容量耗尽攻击的数量有所增加。每 100 次网络层 DDoS 攻击中，有一次超过 100 万个数据包/秒 (pps)；每 100 次网络层 DDoS 攻击中，有两次超过 500 兆比特/秒。在第 7 层（应用程序层），每 1000 次 HTTP DDoS 攻击中，有 4 次超过每秒 100 万个请求。

## 关键要点

大多数 DDoS 攻击规模小且速度快。然而，即便是此类攻击，也可能会扰乱不遵循 [DDoS 防御最佳实践](https://developers.cloudflare.com/ddos-protection/best-practices/respond-to-ddos-attacks/)的在线服务。

此外，威胁行为者的复杂、老练能力正在增强，这可能是因为使用生成式 AI 和开发人员辅助工具，让他们可以编写更优质的攻击代码，导致防御 DDoS 攻击的难度增加。甚至在攻击复杂程度提高之前，许多组织都难以自行防御此类威胁。但他们不需要这样做。Cloudflare 随时可以提供帮助。Cloudflare 投入了大量资源（所以客户无需投入），确保我们的自动化防御系统以及整个 Cloudflare 产品组合的安全性，从而帮助客户防范现有和新兴威胁。
