Cloudflare 负责打造 [web 应用程序防火墙（WAF）](https://www.cloudflare.com/waf/)的团队在过去一年来不断创新。今天，我们的工作得到了公众的认可。

Cloudflare WAF 提供的易用性、规模和创新控制换来了客户的积极评价，为我们赢得 2021 年度 Gartner Peer Insights 的 WAF “客户之选”荣誉称号。您可以在[这里](https://www.cloudflare.com/gartner-customerschoice-waf-2021/)下载报告的免费副本。

Gartner Peer Insights “客户之选”荣誉称号表彰得到客户高度评价的供应商和产品。收集的数据代表 IT 企业专业人士最看重的一系列顶级供应商软件产品。

2020 年，Cloudflare 发布了[大量](https://blog.cloudflare.com/cloudflare-named-the-innovation-leader-in-holistic-web-protection/)安全产品。例如：

  * [IP 列表](https://blog.cloudflare.com/introducing-ip-lists/)：通过可复用的一级数据结构来管理网络列表，提供更大的配置灵活性；
  * [有效负载加密](https://blog.cloudflare.com/encrypt-waf-payloads-hpke/)：允许客户记录被 WAF 拦截的请求的全部有效负载用于取证目的，同时确保用户隐私受到保护；
  * 客户能够接近实时地[将安全事件传输到](https://blog.cloudflare.com/stream-firewall-events-directly-to-your-siem/)他们的 SIEM；
  * [数据本地化套件（Data Localization Suite）](https://blog.cloudflare.com/zh-cn/introducing-the-cloudflare-data-localization-suite-zh-cn/)：允许企业在边缘设置有关在何处储存和保护数据的规则和控制；
  * 可编写具备完整正则表达式能力的防火墙规则，包括基于 [HTTP 标头](https://developers.cloudflare.com/firewall/cf-firewall-language/fields#http-header-fields)和[HTTP 主体](https://developers.cloudflare.com/firewall/cf-firewall-language/fields#http-body-fields)；
  * [API Shield](https://blog.cloudflare.com/zh-cn/introducing-api-shield-zh-cn/) 使您能轻松地在 API 端点部署双向 TLS 身份验证；
  * 提供 [gRPC 代理支持](https://blog.cloudflare.com/zh-cn/announcing-grpc-zh-cn/)，现已能够保护 gRPC 流量；



我们很高兴能获得 2021 年度 Gartner Peer Insights 的 WAF “客户之选”荣誉称号。谨代表整个团队，感谢所有客户一向以来的支持。
