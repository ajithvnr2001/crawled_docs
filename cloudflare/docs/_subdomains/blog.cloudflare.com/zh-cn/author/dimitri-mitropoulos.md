2026年10月1日## [隆重推出 Forge：用于生成 SDK、CLI、文档等的开源生成流水线](https://blog.cloudflare.com/zh-cn/forge-open-source-generation-pipeline/)

Forge 是一款开源的可插拔生成流水线，在 CI 中运行，可直接从 API 定义生成 SDK、CLI 和文档。通过将生成流程上移至各团队独立的代码仓库，Forge 使开发人员工具持续保持同步。
