在 Developer Week 2025 结束之际，我们能够自豪地回顾我们为开发人员平台新增的功能。交付能帮助开发者更智能地构建、更快速地发布的产品、功能和工具，为我们带来极大的成就感。尤其是在本周期间听到你们的反馈，更是令人振奋！

我们的产品副总裁 Rita Kozlov 在[ _宣布 Developer Week 2025 拉开帷幕_](https://blog.cloudflare.com/welcome-to-developer-week-2025/)的时候，谈到持续演进的开发环境，特别是 AI 时代下。人工智能 AI 不再仅仅是一个流行词或科幻未来的老套话题 ——在现代开发领域，它已成为我们构建、创新和解决问题的核心理念（和实用工具）。AI 影响着我们发布代码的方式和频率，也使 _任何人_ 都能够编写代码。

不但见证这一技术革命，还能打造一个让开发人员参与其中的平台，让人无比振奋。我们希望听到您的反馈，并看看您使用新功能构建了什么——欢迎通过 [_Discord_](https://discord.com/invite/cloudflaredev) 或 [_X_](https://x.com/cloudflaredev) 与我们联系。

让我们回顾一下 Developer Week 2025 期间的公告：

### 星期一，4 月 7 日

公告| 摘要  
---|---  
拼合智能体技术版图：MCP 协议、身份验证和授权以及 Durable Objects 免费计划| AI Agents 工具包包括 Agents SDK 新增支持 MCP（模型上下文协议）客户端、MCP 服务器的身份验证/授权/休眠，以及 Durable Objects 免费额度。  
推出 AutoRAG：Cloudflare 上的全托管式检索增强生成| 由 Cloudflare 的全球网络和开发人员平台支持的全托管检索增强生成（RAG）管道，简化了您构建和扩展 RAG 管道的方式，助力构建具备上下文感知能力的人工智能和搜索应用。  
Cloudflare Workflows 现已正式发布：可投入生产，持久执行| Workflows —— 基于 Workers 构建的持久执行引擎——现已正式发布并生产就绪，提供新的人机交互能力，更强大的扩展性和更丰富的指标。  
Cloudflare 收购 Outerbase，以扩展数据库并改善开发人员构建智能体的体验| Cloudflare 已收购 Outerbase，扩展我们的数据库并改善开发人员构建智能体的体验。  
  
### 星期二，4 月 8 日

公告| 摘要  
---|---  
使用 Cloudflare Workers 和 Hyperdrive 构建全球 MySQL 应用| Workers 通过 Hyperdrive 连接到您的 MySQL 数据库，为区域数据库提供最佳性能，并支持您最喜欢的驱动程序和 ORM。  
跨海连接池：Hyperdrive 如何加快数据库访问速度以及我们为何免费提供它| Hyperdrive 现已提供免费层，利用关键创新实现快速全球数据库连接。  
"直接使用 Vite"… 配合 Workers 运行时| Cloudflare Vite 插件将 Vite（最流行的 Web 开发构建工具之一）与 Workers 运行时集成。今天，我们发布 1.0 版并正式支持 React Router v7。  
使用适用于 OpenNext 的 Cloudflare 适配器将 Next.js 应用部署到 Cloudflare Workers| 使用适用于 OpenNext 的Cloudflare 适配器 1.0 测试版，您可在 Cloudflare Workers 上托管您的 Next.js 14 和 15 应用。  
您的前端、后端和数据库现在全部集中在一个 Cloudflare Worker 中| Cloudflare Workers 现在支持部署静态网站与全栈有状态应用，所需基础能力一应俱全。对 React Router v7、Astro、Vue 等的框架支持以及 Cloudflare Vite 插件现已正式发布。  
跳过设置：只需短短数秒即可部署 Workers 应用| 开发人员可以使用“部署到 Cloudflare”按钮来设置和部署您的 Worker 应用。  
  
### 星期三，4 月 9 日

公告| 摘要  
---|---  
使用 Cloudflare Realtime 和 RealtimeKit 让您的应用真正实现交互| 宣布推出 Cloudflare Realtime 和 RealtimeKit，一套完整的工具包，让开发人员可以使用适用于 Kotlin、React Native、Swift、JavaScript 和 Flutter 等编程语言的 SDK，在几天内快速交付实时音频和视频应用。  
隆重推出 Cloudflare Secrets Store（测试版）：保护机密，简化工作流| 使用 Cloudflare Secrets Store （测试版）在 Cloudflare Workers 中安全存储、管理和部署帐户级机密 —— 提供基于角色的访问控制、审核日志和 Wrangler 支持。  
Cloudflare Snippets 现已正式发布| Cloudflare Snippets 现已正式发布，支持在所有付费计划中快速、免费地进行基于 JavaScript 的 HTTP 流量修改。  
隆重推出 Workers Observability：日志、指标和查询，全部集中在一个位置| Workers 可观测性能力得到增强：Workers Logs 正式发布，并推出新的查询构建器，帮助您跨所有 Workers 调查日志事件。  
网络性能更新：2025 年 Developer Week| 自 2021 年以来，我们一直在跟踪 Cloudflare 网络的速度并与其他顶级网络进行比较。让我们看看自上一次更新以来，发生了哪些变化。  
  
### 星期四，4 月 10 日

公告| 摘要  
---|---  
R2 数据目录：零出站费用的托管 Apache Iceberg 表| R2 Data Catalog 现已开放公测：这是一个直接集成到 R2 存储桶中的托管式 Apache Iceberg 数据目录。  
无边界的顺序一致性：D1 如何实现全局读取复制| Cloudflare 的托管 SQL 数据库 D1 宣布推出读取复制测试版。  
最新发布：使用 Arroyo 和 Pipelines 在 Cloudflare 上进行流式数据摄取| 我们刚刚发布了全新的流式数据摄取服务 Pipelines，并完成了对 Arroyo 的收购，这将为 Pipelines 和 R2 带来基于 SQL 的有状态转换能力。  
使用 Workers、Durable Objects 和 Queues 使 Super Slurper 速度提高 5 倍| 我们使用开发人员平台，包括利用 Cloudflare Workers、Durable Objects 和 Queues 等技术，重新设计了 Super Slurper 架构，并将数据传输速度提高了 5 倍。  
  
### 星期五，4 月 11 日

公告| 摘要  
---|---  
一个全球虚拟专用云，用于在 Workers 上构建安全的跨云应用。| 我们即将推出 Workers VPC：一个全球专用网络，允许将部署在 Cloudflare Workers 上的应用连接到您的传统云基础设施。现在，您可以解锁对外部云中现有 API 和数据的访问权限，并在 Workers 上构建全球化、现代化、跨云的应用程序。  
初创公司聚焦：利用第 5 批构建 AI 智能体并加速创新| 了解 Workers Launchpad 开发人员如何使用 Cloudflare 来扩展 AI 工作负载并简化自动化。  
Startup Program 更新：赋能创业之旅的每个阶段| Cloudflare Startup Program 提供高达 25 万美元的积分额度，支持初创公司使用 Cloudflare 开发人员平台进行构建，分为四个级别：5000 美元、2.5 万美元、10 万美元，以及 25 万美元。  
简单、可扩展、全球化：Cloudflare Workers 将于 2025 年 6 月推出容器支持| 我们将于 2025 年 6 月推出 Cloudflare Containers。在 Cloudflare 网络上运行新型工作负载，获得简单、可扩展、全球化的使用体验，并与 Workers 深度集成。  
Workers AI 获得速度提升、批量工作负载支持、更多 LoRA、新模型以及更新的仪表板| 通过采用预测解码和前缀缓存技术，我们加快了 Workers AI 的推理速度。使用新增的批量推理功能，无缝处理大量请求。通过更多 LoRA 选项构建定制 AI 应用。最后，新模型与焕然一新的仪表板标志着本届 Developer Week 期间的 Workers AI 更新圆满完成。  
我们如何通过 Cloudflare Workflows 简化 NCMEC 报告| 在我们的全国失踪和受虐儿童中心（NCMEC）报告系统中， Cloudflare 用 Cloudflare Workflows 取代了基于队列的架构，实现了一个结构清晰、可重试且更易调试和维护的工作流。  
在 Cloudflare Workers 上构建的下一代证书透明度日志| 基于证书透明度（CT）的最新进展，Cloudflare 在 Cloudflare 开发人员平台上构建了新一代 CT 日志系统。
