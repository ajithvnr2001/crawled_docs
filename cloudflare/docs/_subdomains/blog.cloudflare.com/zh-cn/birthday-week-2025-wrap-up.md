# 15 年来帮助建设更好的互联网：2025 年生日周总结

Cloudflare 十五年前怀着帮助构建更美好互联网的使命而诞生。在这段时间里，互联网发生了变化，对我们这样的团队的需求也随之改变。在今年的[ _创始人致函_](https://blog.cloudflare.com/cloudflare-2025-annual-founders-letter/)中，Matthew 和 Michelle 讨论了我们在互联网演进过程中所扮演的角色，从帮助加密流量从占互联网流量的 10% 增长到 95%，到应对人们如何消费内容等更近期的挑战。

我们每年都会在生日周发布我们认为互联网在当下和未来所需的产品和功能。往届[ _生日周_](https://blog.cloudflare.com/tag/birthday-week/)发布内容回顾：2011 年推出[ _IPv6 网关_](https://blog.cloudflare.com/introducing-cloudflares-automatic-ipv6-gatewa/)、2014 年推出[ _Universal SSL_](https://blog.cloudflare.com/introducing-universal-ssl/)、2017 年推出[ _Cloudflare Workers_](https://blog.cloudflare.com/introducing-cloudflare-workers/) 和[ _不计量 DDoS 保护_](https://blog.cloudflare.com/unmetered-mitigation/)、2020 年推出 [_Cloudflare Radar_](https://blog.cloudflare.com/introducing-cloudflare-radar/)、2021 年推出[ _零出口费用的 R2 对象存储_](https://blog.cloudflare.com/introducing-r2-object-storage/)、2022 年发布 [_Cloudflare Tunnel 的后量子升级_](https://blog.cloudflare.com/post-quantum-tunnel/)、2023 年发布 [_Workers AI_](https://blog.cloudflare.com/best-place-region-earth-inference/) 和 [_Encrypted Client Hello_](https://blog.cloudflare.com/announcing-encrypted-client-hello/)。以上只是众多发布产品的一部分示例。

今年的主题聚焦于帮助互联网为新的变现模式做好准备，这一模式鼓励优质内容的发布，在 Cloudflare 内外培育更多构建社区的机会，以及让更多功能面向所有人开放、持续提升我们所提供服务的速度和安全性等长期使命。

我们今年发布了许多新功能。如果您错过了此前发布的数十篇博客文章，以下是我们在 2025 年生日周期间所有公告内容的摘要。

支持开放 Web 的未来：Cloudflare 赞助 Ladybird 和 Omarchy| 为了支持多元化和开放的互联网，我们现正赞助 Ladybird（一款独立浏览器）和 Omarchy（一个开源 Linux 发行版和开发者环境）。  
与我们一起构建：Cloudflare 面向初创公司的新中心| 我们将在四个主要城市（旧金山、奥斯汀、伦敦和里斯本）开放办公室大门，作为初创公司的免费中心，以促进协作并与建设者社区建立联系。  
免费使用 Cloudflare 面向非营利和民间社会组织的开发人员服务| 我们将 Cloudflare for Startups 计划扩展到非营利组织和公共利益组织，为我们的开发人员工具提供免费试用额度。

Cap'n Web：用于浏览器和 Web 服务器的新 RPC 系统| 我们开源了 Cap'n Web，一个新的 JavaScript 原生 RPC 协议，为 Web 应用简化强大的无模式通信。  
回顾 Workers Launchpad 计划并热烈欢迎第六批| 我们宣布了 Workers Launchpad 第六批，这是我们的加速器计划，面向在 Cloudflare 上构建的初创企业。

### 与我们一起构建！

帮助构建更好的互联网始终不仅仅关乎技术本身。正如关于实习生或在我们办公室协同工作的公告一样，帮助构建更好互联网背后的人员社区对其未来发展也很重要。本周，我们推出了有史以来最雄心勃勃的一系列计划，支持正在创造未来的构建者、创始人和学生。

针对创始人和初创企业，我们热烈欢迎**Workers Launchpad** 的**第六批** 学员。Workers Launchpad 是我们的加速器项目，为早期阶段公司提供扩展所需的资源。但我们并未止步于此。我们正在敞开大门，在我们的旧金山、奥斯汀、伦敦和里斯本办公室启动**全新的初创企业实体中心** 。这些空间将为您提供获取指导支持、资源对接的渠道，以及由同行开发者组成的社群网络。

我们也在投资于下一代人才。我们宣布，**所有学生均可免费使用 Cloudflare 开发人员平台** ，提供无限制学习与实践所需的工具支持。为提供从校园课堂到行业职场的成长路径，我们同时宣布了 2026 年招聘**1111 名实习生** 的目标 —— 这是我们迄今为止为培育未来科技领导人才所作出的最大承诺。

正因更好的互联网服务每一个人，我们也将支持范围拓展至**非营利组织与公益组织** ，为其提供生产级开发人员工具的免费使用权限，从而能够专注于实现自身使命。

无论是怀揣远大构想的创始人、刚起步探索的学生，还是为秉持的理想事业奋斗的团队，我们都愿助力您取得成功。

### 明年再见

感谢我们的客户、社区，以及信赖我们帮助其构建、保护和加速互联网的数百万开发人员。您的好奇心与反馈，是驱动我们创新的动力。

过去 15 年，我们取得了非凡成就。而且一如既往，我们才刚刚开始！
