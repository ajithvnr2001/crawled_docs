## MCP：为下一代应用提供支持

人们并不总是期望每一项服务，无论是商店、房产中介还是其它服务，都拥有一个网站。但随着越来越多的人能够访问互联网，这种情况迅速变成了现实。

我们目前正处于类似的转型期，每个 Web 用户都可以使用 AI 工具，并利用这些工具来完成许多任务。如果您是开发人员，现在如果要编写代码，您首先想到的可能就是使用 Claude 之类的工具。那么，如果 Claude 帮助您编写代码，它也能帮助您部署代码，这似乎合情合理。

或者，如果您不是开发人员，如果 Claude 帮助您制定了食谱，那么它也能帮助您订购所需的食品杂货。

借助远程 MCP，所有这些场景目前都有可能实现。正如首批在 Web 上拓展业务的企业具有先发优势一样，首批以 MCP 为先导的企业很可能从中获益。

用户可以越快速地体验到产品的价值，他/她们就越有可能取得成功、升级并继续使用您的产品。通过 MCP 将服务与代理连接起来，如此一来，用户只需提出自己的需求，代理会处理其余事宜，从而让用户可以更快速地体验到“顿悟时刻”。

## 采用 MCP，运用 AI 优先方法来提供服务

采用 MCP 的企业会快速获得显著效益：

### 降低准入门槛

并非每个用户都有时间来熟悉仪表板或通读文档，以便了解您的产品。借助 MCP，他/她们无需这样做。他/她们只需描述自己的需求，其余事宜交由代理来处理。

### 打造个性化体验

MCP 可以跟踪用户的请求与交互，以便根据用户的使用模式和偏好来调整未来的工具调用。如此一来，您可以根据每个用户实际使用产品的方式，轻松提供更个性化、更相关的体验。

### 顺其自然推动升级

AI 代理可以解释更高级别的计划如何有助于特定用户实现 _其_ 目标，而无需依赖特征比较表。

### 发布新功能和集成

您无需在内部构建所有集成或体验。通过 MCP 来公开发布工具，您可以让用户将产品连接到其各自的其他技术栈。代理可以整合不同提供商的工具来实现集成，而无需您直接支持所有第三方服务。

## 为什么要在 Cloudflare 平台上构建 MCP？

自 MCP 推出以来，Cloudflare 一直在[ _分享_](https://blog.cloudflare.com/remote-model-context-protocol-servers-mcp/)如何帮助开发人员轻松[ _构建和部署远程 MCP 服务器_](https://developers.cloudflare.com/agents/guides/remote-mcp-server/)，从简化协议复杂性到处理身份验证和数据传输，再到[ _支持完全状态化的 MCP 服务器_](https://blog.cloudflare.com/building-ai-agents-with-mcp-authn-authz-and-durable-objects/)（默认情况下，这些服务器处于闲置状态时会进入[ _“休眠”_](https://developers.cloudflare.com/agents/model-context-protocol/mcp-agent-api/#hibernation-support)），以便最大限度地降低闲置成本。

我们将继续定期发布更新，[ _增加_](https://blog.cloudflare.com/streamable-http-mcp-servers-python/)对 MCP 标准[ _最新变更_](https://modelcontextprotocol.io/specification/2025-03-26)的支持，让您可以更轻松地将服务器投入生产：

  * **[ _支持新的 Streamable HTTP 传输_](https://developers.cloudflare.com/agents/model-context-protocol/transport/)：**MCP 服务器现在可以搭配使用最新的 Streamable HTTP 传输方式与 SSE，从而确保与最新标准兼容。我们也已更新 AI Playground 和 [_mcp-remote_](https://www.npmjs.com/package/mcp-remote) 代理，为您提供远程 MCP 客户端，让您能够轻松测试新的传输方式。
  * **[ _MCP 服务器支持 Python_](https://github.com/cloudflare/ai/tree/main/demos/python-workers-mcp)：**现在，您可以使用 Python（而不仅仅只是 JavaScript/TypeScript），在 Cloudflare 平台上构建 MCP 服务器。
  * **优化文档、入门模板和部署流程：** 我们已添加了[ _新的快速启动模板_](https://github.com/cloudflare/ai/tree/main/demos/remote-mcp-authless)，扩展了[ _文档_](https://developers.cloudflare.com/agents/model-context-protocol/transport/)以介绍新的传输方式，并且分享了根据我们的经验教训来构建 MCP 服务器的[ _最佳实践_](https://developers.cloudflare.com/agents/model-context-protocol/#best-practices)。



但我们认为，与其向您讲述，不如直接向您展示我们的客户已经构建的具体内容，以及这些客户选择将其 MCP 部署在 Cloudflare 平台的原因。
