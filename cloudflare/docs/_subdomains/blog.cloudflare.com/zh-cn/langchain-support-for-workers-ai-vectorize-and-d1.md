在 Developer Week 期间，我们宣布了 [LangChain 对 Cloudflare Workers 的支持](https://blog.cloudflare.com/langchain-and-cloudflare/)。Langchain 是一个开源框架，允许开发人员通过使用声明性 API 组合不同的模型、提供商和插件来创建强大的 AI 工作流——它与 Workers 完美契合，可用于创建 AI 驱动的全栈应用程序。

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![LangChain Support for Workers AI, Vectorize and D1](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW4922MSFB086Y7FSHDRFYPQ.png&w=715&h=402&f=webp&fit=cover&position=center)

从那时起，我们一直与 LangChain 团队合作，在 Cloudflare 的开发人员平台上更深入地集成许多工具，我们很高兴能与大家分享我们的工作成果。

今天，我们宣布推出与 LangChain 的五个新关键集成：

  1. [Workers AI 聊天模型](https://js.langchain.com/docs/integrations/chat/cloudflare_workersai)：这允许您使用 [Workers AI 文本生成](https://developers.cloudflare.com/workers-ai/models/text-generation/)来为 LangChain.js 应用程序中的聊天模型提供支持。
  2. [Workers AI 指导模型](https://js.langchain.com/docs/integrations/llms/cloudflare_workersai)：这允许您在 Langchain.js 应用程序中使用针对指导用例进行微调的 Workers AI 模型，例如 Mistral 和 CodeLlama。
  3. [文本嵌入模型](https://js.langchain.com/docs/integrations/text_embedding/cloudflare_ai)：如果您正在使用文本嵌入，那么您现在可以将 [Workers AI 文本嵌入](https://developers.cloudflare.com/workers-ai/models/text-embeddings/)与 LangChain.js 一起使用。
  4. [Vectorize Vector Store](https://js.langchain.com/docs/integrations/vectorstores/cloudflare_vectorize)：使用 Vector 数据库和 LangChain.js 时，您现在可以选择使用 Cloudflare 强大的向量数据库 [Vectorize](https://developers.cloudflare.com/vectorize/)。
  5. [Cloudflare D1 支持的聊天内存](https://js.langchain.com/docs/integrations/chat_memory/cloudflare_d1)：为了在聊天会话中保持更长期的持久性，您可以将 LangChain 的默认内存 chatHistory（支持聊天内存类，如 BufferMemory）换成 [Cloudflare D1 实例](https://developers.cloudflare.com/d1/)。



随着这五款 Cloudflare AI 工具加入 LangChain，开发人员拥有了强大的新原语，可以集成到新的和现有的 AI 应用程序中。借助 LangChain 用于混合和匹配 AI 工具和模型的富有表现力的工具，您可以使用 Vectorize、Cloudflare AI 的文本嵌入和生成模型以及 Cloudflare D1，仅用几行代码即可构建功能齐全的 AI 应用程序。

### 开始使用 Cloudflare + LangChain + Nuxt 多源聊天机器人模板

您可以从 LangChain 的 Cloudflare 聊天机器人模板开始：<https://github.com/langchain-ai/langchain-cloudflare-nuxt-template>

此应用程序展示了 Cloudflare Workers AI 的各个部分如何组合在一起，并扩展了[检索增强生成 (RAG)](https://developers.cloudflare.com/workers-ai/tutorials/build-a-retrieval-augmented-generation-ai/) 的概念，以构建一个对话式检索系统，该系统可以在多个数据源之间路由，并根据传入的问题选择最相关的数据源。此方法有助于减少因向量存储的相似性搜索而引入的离题文档所造成的干扰，如果仅使用单个数据库，则可能会发生这种情况。

基础版本完全在 Cloudflare Workers AI 堆栈上运行，采用 Llama 2-7B 模型。它使用：

  * 在 Cloudflare Workers AI 上运行的 Llama 2-7B 聊天变体
  * Cloudflare Workers AI 嵌入模型
  * 两个不同的 Cloudflare Vectorize DB（您可以添加更多！）
  * 用于托管的 Cloudflare Pages
  * 用于编排的 LangChain.js
  * 用于前端的 Nuxt + Vue



两个默认数据源是[一个详细介绍 Cloudflare 部分功能的 PDF](https://www.cloudflare.com/resources/assets/slt3lc6tev37/3HWObubm6fybC0FWUdFYAJ/5d5e3b0a4d9c5a7619984ed6076f01fe/Cloudflare_for_Campaigns_Security_Guide.pdf) 和[一篇由 OpenAI 的 Lilian Weng 撰写的讨论自主代理的博客文章](https://lilianweng.github.io/posts/2023-06-23-agent/)。

机器人会将传入的问题分类为 Cloudflare 相关、AI 相关或两者均无关，并利用相应的数据源获取更具针对性的结果。一切都是完全可定制的——您可以更改所提取数据的内容、使用的模型以及所有提示！

如果您有权访问 [LangSmith](https://smith.langchain.com/) 测试版，该应用程序还设置了跟踪功能，以便您可以轻松[查看和调试应用程序中的每个步骤](https://smith.langchain.com/public/24807f4a-4335-497e-bfbf-3a1de019b22e/r)。
