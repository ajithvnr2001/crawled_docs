今天，我们很高兴能宣布最新的 Cloudflare One [网络入口合作伙伴关系](https://www.cloudflare.com/zh-cn/network-onramp-partners/)。[Cloudflare One](https://blog.cloudflare.com/zh-cn/introducing-cloudflare-one-zh-cn/) 旨在帮助客户实现一个安全和优化的全球网络。我们知道，以一个全球、安全、高性能和可观察的网络替代 MPLS 链接的承诺将改变企业网络。为实现这个愿景，我们正在推出有关合作伙伴关系，以便客户能从他们现有受信任的 WAN 和 SD-WAN 设备连接到 Cloudflare 的全球网络，并通过他们共用的数据中心进行私有互联。

今天，我們啟動與 VMware、Aruba 和 Infovista 的 WAN 和 SD-WAN 合作夥伴關係，同時也將 Digital Realty、CoreSite、EdgeConneX、365 Data Centers、BBIX、Teraco 和 Netrality Data Centers 新增到現有的網路互連合作夥伴名單中 (Equinix ECX、Megaport、PacketFabric、PCCW ConsoleConnect 和 Zayo)。Cloudflare 網路入口合作夥伴關係目前涵蓋 70 個不同地點的 15 家領先連網提供者，無論我們的客戶位於何方，都能夠輕鬆地以安全和高效能的方式將其流量輸送給 Cloudflare。

### 使用您现有的 WAN 或 SD-WAN 提供商连接到 Cloudflare。

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![Cloudflare’s Network On-ramp partnerships now span 15 leading connectivity providers in 70 unique locations, making it easy for our customers to get their traffic onto Cloudflare in a secure and performant way, wherever they are.](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW456MNZZD6WV4ZJHCV7Z6DZ.png&w=715&h=438&f=webp&fit=cover&position=center)

透過 [Magic WAN](http://www.cloudflare.com/zh-tw/magic-wan)，客戶能將資料中心、辦公室、裝置和雲端資產安全地連線到 Cloudflare 網路，並設定路由原則將流量引向需要去的地方，而且可以全透過一個 SaaS 解決方案實現：省下 MPLS 開支，不必等待，也不再有長號效應帶來的效能損失。許多組織目前使用實體或虛擬 SD-WAN 設備在辦公室、資料中心和公用雲端之間路由流量或透過通道傳送。即日起，這些客戶只需執行幾個簡單的命令，就能利用現有基礎結構投資 (不論是實體還是雲端虛擬) 將流量連線到 Magic WAN。

請參考以下範例。借助 Magic WAN 和網路入口合作夥伴關係，您可以使用實體和虛擬裝置連線 RFC1918 子網路中的内部部署和雲端 VPC，利用 Magic WAN 帶來的加速和安全的連線。此外，還可透過 Magic Firewall 在邊緣設定防火牆規則，對流經 Magic WAN 的所有流量一致地實施這些規則。Cloudflare 擁有覆蓋 200 多個城市的廣闊網路，這也代表您的附近必定會有最接近的資料中心。

 _、合作夥伴虛擬 AMI 和通用 Linux 路由器的 3 個網路，透過最近的 Cloudflare 資料中心連線到 Cloudflare Magic WAN。_

![](data:image/svg+xml,%3Csvg%20xmlns%3D%22http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg%22%20viewBox%3D%220%200%201%201%22%3E%3Crect%20width%3D%221%22%20height%3D%221%22%20fill%3D%22rgb\(243%2C243%2C243\)%22%2F%3E%3C%2Fsvg%3E)![3 private networks, using a mixture of a partner hardware appliance, a partner virtual AMI, and a generic Linux router connected to Cloudflare Magic WAN via the nearest Cloudflare data center.](https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KW48SBKCW5MMRR94KFAGRC7C.png&w=715&h=513&f=webp&fit=cover&position=center)

简单设置和兼容性非常了不起，而我们与合作伙伴的共同路线图有更雄心勃勃的目标。今天，这些连接是通过 Anycast GRE 进行的。我们即将宣布 IPSec 支持，向客户提供多重连接方法。

在未来版本中，入口合作伙伴设备将只需要授权凭据来证明它们是某个客户 Magic WAN 网络的一部分，就能调用 Magic WAN 管理 API 并自行配置——真正实现了云网络即插即用的愿景。此外，Magic WAN 客户将能受益于分层的 Cloudflare 应用程序访问和互联网浏览零信任安全，其将零信任网络访问（ZTNA）、安全 Web 网关（SWG）、远程浏览器隔离（RBI）、DNS 安全、L4 防火墙和其他一度独立的点产品统一到一个无缝的平台上。

## **通过 PNI 建立到 Cloudflare 的私有互联**

将流量输送到最接近的 Cloudflare 数据中心（鉴于我们遍布 200 多个城市，这些数据中心总是在附近）是 Cloudflare Magic WAN 的核心。我们使用 GRE 和 IPsec（即将推出）等标准互联网协议，在我们的网络和客户的基础设施之间安全传输流量。虽然协议层安全性很高，只要您拥有面向互联网的基础设施，您就会暴露对错误配置的攻击面。

对于希望最高安全和性能的组织而言，Magic WAN 可与 [Cloudflare 互联合作伙伴](https://www.cloudflare.com/zh-cn/network-interconnect-partnerships/)结合，在 Cloudflare 边缘和客户的网络之间建立一个私有、安全和可靠的 L2 网络。私有连接是为您的网络建立纵深防御的另一件武器。

去年，我们[宣布了](https://blog.cloudflare.com/cloudflare-network-interconnect-partner-program/)第一批网络互联合作伙伴关系。今天，我们增加 Digital Realty、CoreSite、EdgeConneX、365 Data Centers、BBIX、Teraco 和 Netrality Data Centers，提供：

  * 在 70 个地点与 Cloudflare 共处
  * 缩短相互连接时间
  * 连接参考架构



通过我们的新合作关系，客户现在拥有更多私有安全连接的选择，既可使用云交换（通过仪表板订购的软件定义 VLAN），也可使用私有物理连接。

### 今天和未来的 WAN

過去 10 年來，Cloudflare 建成了世界上最快速、最可靠、最安全的網路之一。本週，我們宣佈了若干新的效能和安全功能，滿足客戶的全球安全與網路需求。新啟動的網路入口合作夥伴關係讓您能夠利用私有、安全和高效能的方案，將流量來源連線到 Cloudflare。

如果您希望成爲我們的入口合作夥伴，請透過 [onramppartners@cloudflare.com](mailto:onramppartners@cloudflare.com) 聯繫我們。我們期待進一步瞭解您正在使用和希望我們整合的平台，請點選[這裡](https://cloudflare.com/zh-tw/network-onramp-partners)來聯繫我們。如果您希望進一步瞭解我們的網路入口合作夥伴、實體 PNI/CNI、合作夥伴/虛擬 CNI 及如何將它們與 Magic WAN 整合，請聯繫您的客戶團隊或發送電子郵件至[interconnection@cloudflare.com](mailto:interconnection@cloudflare.com)。如需進一步瞭解 Magic WAN，請填寫[產品頁面](https://www.cloudflare.com/zh-tw/magic-wan)上的「連絡我們」表單。
