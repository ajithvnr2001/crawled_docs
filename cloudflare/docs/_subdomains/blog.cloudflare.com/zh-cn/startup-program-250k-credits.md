今天，我们隆重宣布为初创公司提供高达 25 万美元的积分，可在 Cloudflare [_开发人员平台_](https://www.cloudflare.com/developer-platform/products/)上使用。这个新的积分系统将让您清楚地看到，在 25 万美元的积分用完或一年后（以先到者为准）的使用量和相关费用，为可预测的未来做好计划。

请在[ _此处_](https://www.cloudflare.com/forstartups/)查看 Startup Program 的资格标准并申请。

## 积分有什么用途？

积分可用于所有开发人员平台产品以及 [_Argo_](https://developers.cloudflare.com/argo-smart-routing/) 和 [_Cache Reserve_](https://developers.cloudflare.com/cache/advanced-configuration/cache-reserve/) 。此外，我们还为参与者提供多达三个[ _企业级域_](https://www.cloudflare.com/plans/)，其中包括 CDN、 DDoS、 DNS、 WAF、 Zero Trust 以及参与者可以为他们的网站启用的其他[ _安全和性能产品。_](https://www.cloudflare.com/application-services/products/)

### Cloudflare 提供的速度和性能

我们知道，创始人在创立自己的企业时需要一切能获得的帮助。除了开发人员平台外，您还可以通过 Startup Program 使用我们的速度和性能产品。能否让客户在[ _几毫秒_](https://developers.cloudflare.com/speed/)内访问您的网站或应用中所需的位置，决定了一笔销售成功与否。您可以在[ _这里_](https://developers.cloudflare.com/fundamentals/basic-tasks/test-speed/)测试速度，并在[ _这里_](https://developers.cloudflare.com/learning-paths/get-started/performance/optimize-speed/)了解如何使用 [_Images_](https://developers.cloudflare.com/images/) 、 [_Argo_](https://developers.cloudflare.com/argo-smart-routing/) 和 [_Early Hints_](https://developers.cloudflare.com/cache/advanced-configuration/early-hints/) 等解决方案优化您的速度和性能。

### Cloudflare 提供的安全性

以上还不是全部：除了开发人员平台产品和速度工具之外，您还可以通过 Startup Program 使用 Cloudflare 的众多安全功能。其中包括 [_Web 应用防火墙_](https://developers.cloudflare.com/waf/) ([_WAF_](https://www.google.com/aclk?sa=l&ai=DChcSEwj6jt32op2IAxXk1cIEHQVsCf8YABAAGgJwdg&co=1&ase=2&gclid=Cj0KCQjw28W2BhC7ARIsAPerrcIntApH-BAsWuajq8owh4eTi3Z1hH6S3xeg51-QEKIIuOYtfAxN7TUaAvSvEALw_wcB&sig=AOD64_2mwuQ5V4e7y1VboIJtoTEiFHnEkg&q&nis=4&adurl&ved=2ahUKEwjOpdj2op2IAxU5LEQIHf_dDqIQ0Qx6BAgYEAE) )、[ _DDoS 警报_](https://developers.cloudflare.com/ddos-protection/reference/alerts/) 、捆绑[ _保护计划_](https://www.cloudflare.com/plans/) 等。Startup Program 还包括 [_Zero Trust_](https://www.cloudflare.com/plans/zero-trust-services/) 解决方案。了解其他公司如何通过 Cloudflare Zero Trust[ _保护他们的技术和工具。_](https://www.cloudflare.com/case-studies/?usecase=Enable+zero+trust+security+for+workforce)

如需更多灵感，请查看我们的 [_Built with Cloudflare 网站_](https://workers.cloudflare.com/built-with/)，其中重点介绍了其他初创公司正在构建的产品。

## 谁可以使用积分？ 

资格标准参见[ _此处_](https://www.cloudflare.com/forstartups/)，包括：

  * 构建基于软件的产品或服务的公司
  * 过去 5 年内（2019-2024 年）成立
  * 拥有 5 万- 500 万美元资金
    *  _请注意，对于尚未筹集到至少 5 万美元的初创公司，可能还有其他获得更低积分额度的机会。如果您尚未筹集到 5 万美元，但对Cloudflare初创企业计划感兴趣，请使用促销代码“BOOTSTRAPPED”进行申请_
  * 拥有 LinkedIn 档案、有效网站和电子邮件地址
  * 加分标准：属于一个认可的创业加速器项目



## 您将构建什么？

我们很期待看到您将构建的成果。请[ _与我们分享您计划开展的项目_](https://discord.com/invite/cloudflaredev)，以便我们尽可能地为您提供帮助。如果您正在积极使用 Cloudflare 的开发人员平台，我们希望能进一步了解您的正在构建的项目，并在我们的 [_Built with Cloudflare 网站_](https://workers.cloudflare.com/built-with/)上分享。

您是一家寻求额外支持、资源或资金的初创公司吗？欢迎申请我们的 ﻿[﻿ _Workers Launchpad Program_ ﻿](https://blog.cloudflare.com/tag/workers-launchpad)﻿！该计划将持续几个月，除了 Startup Program 外，参与者还可以参加实践培训营、解决方案架构师咨询、风险投资引介，以及在演示日上展示自己的机会。

## 为什么 Cloudflare 支持创始人和初创公司？ 

创始人和开发者面临的挑战已经够多了，不应该还要担心在创业初期测试技术和开始构建所产生的高昂费用。世界触手可及，您应该能够自由自在地尽情构建和创造。将资金投资于创新，而非支持创新的基础设施和技术。

Startup Program 深刻理解创始人的这种经历，因为其团队是就是由前创始人组成的。 Cloudflare 致力于推动这样的计划，旨在支持正在打造 _下一个重大项目_ 的创始人。提供高达 25 万美元的积分，大家将能够更好地利用我们提供的东西：一种减少摩擦、节省资金，并在数小时而不是数天内启动应用的开发人员体验。

我们希望支持来自世界各地的创始人。

大胆地继续构建吧！关注 [_@CloudflareDev_](https://x.com/cloudflaredev) 并加入我们的[ _开发人员 Discord_](https://discord.com/invite/cloudflaredev) 服务器。

您是一家正在使用 Cloudflare 构建的初创公司吗？[ _在此申请。_](https://www.cloudflare.com/forstartups)
