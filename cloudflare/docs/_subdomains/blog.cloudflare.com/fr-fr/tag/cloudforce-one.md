13 août 2026## [Rapport Cloudflare sur les menaces DDoS au premier semestre 2026 : les attaques atteignant les 1 Tbit/s augmentent à l'heure où les floods DNS et les tensions géopolitiques propulsent une nouvelle vague](https://blog.cloudflare.com/fr-fr/ddos-threat-report-2026-h1/)
