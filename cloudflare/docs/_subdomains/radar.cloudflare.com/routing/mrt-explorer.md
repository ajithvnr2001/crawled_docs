# MRT Explorer

Parse and explore MRT (Multi-Threaded Routing Toolkit) dump files directly in the browser

[Learn more...](https://datatracker.ietf.org/doc/html/rfc6396)

Drop or **browse** .mrt / .gz / .bz2 file

Collectors like [RIPE RIS](https://data.ris.ripe.net/) and [RouteViews](https://archive.routeviews.org/) publish MRT dump files containing BGP announcements, withdrawals, and route attributes.  
  
This tool parses MRT files entirely in the browser (nothing gets uploaded). Supports **_gzip_** and **_bzip2_** compression.  
Paste a URL, drag, browse or try a sample file to explore BGP messages, AS paths, community attributes and more.
