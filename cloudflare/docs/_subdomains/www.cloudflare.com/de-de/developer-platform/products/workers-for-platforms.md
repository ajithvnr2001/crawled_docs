# Workers für Plattformen

Ihre Plattform programmierbar machen

###### Ihre Plattform programmierbar machen

Geben Sie Ihren Kunden die Möglichkeit, im globalen Netzwerk von Cloudflare in großem Maßstab benutzerdefinierten Code zu schreiben, bereitzustellen und auszuführen.

[Jetzt entwickeln](https://dash.cloudflare.com/account-id/workers-for-platforms)

[Dokumentation lesen](https://developers.cloudflare.com/cloudflare-for-platforms/workers-for-platforms/)

## Die Vorteile von Workers für Plattformen

![ABM – Stryker – Sichern Sie Ihre KI-Initiativen mit Cloudflare – 6 Symbole – Karte 1 – Symbol](https://www.cloudflare.com/cdn-cgi/image/format=auto/https://cf-assets.www.cloudflare.com/v2/image/b429qo38r908hfbimtgte9ds52/icon_tile_internet-globe.png)

###### Bedarfsgerecht skalieren

Sie müssen keine eigene Infrastruktur oder interne Entwicklungsteams für die Ausführung von Kundencode bereitstellen – Workers for Platforms skaliert bei Bedarf automatisch mit.

![Symbolkachel – Success-Angebote](https://www.cloudflare.com/cdn-cgi/image/format=auto/https://cf-assets.www.cloudflare.com/v2/image/8a1rrgeek175javtc1gqoqj212/icon_tile_premium-success-offering.png)

###### Kunden mehr Möglichkeiten bieten

Kunden können Nutzererfahrungen anpassen, Aktionen auf Grundlage von Ereignissen auslösen oder Ihre Plattform erweitern, ohne dass Ihre Entwickler Code schreiben müssen.

![Security Shield Protection Checkmark – Symbol](https://www.cloudflare.com/cdn-cgi/image/format=auto/https://cf-assets.www.cloudflare.com/v2/image/glu3so81dd4pv78hs6hfngvl7o/icon_tile_security-shield-protection.png)

###### Nicht vertrauenswürdigen Code sicher ausführen

Kundencode wird in einer isolierten Umgebung mit integrierten Kontrollen ausgeführt, um Sicherheits- und Compliance-Risiken auszuschließen.

FUNKTIONSWEISE

## Kundencode skalierbar bereitstellen und ausführen

Workers for Platforms bietet eine verwaltete Ausführungsumgebung, in der Ihre Kunden ihren eigenen Code im globalen Netzwerk von Cloudflare bereitstellen und ausführen können.

Erstellen Sie benutzerdefinierte Logik, ereignisgesteuerte Automatisierung und [Full-Stack-Anwendungen](https://www.cloudflare.com/de-de/developer-platform/solutions/hosting/) mit Workers und Primitiven wie Speicher, Datenbanken und Protokollierung.
