# Lernzentrum
Ressourcen von Cloudflare zur Cybersicherheit und zur Funktionsweise des Internets. [Was ist Cloudflare?](https://www.cloudflare.com/de-de/learning/what-is-cloudflare/ "https://www.cloudflare.com/learning/what-is-cloudflare/")
#### Mehr über DDoS-Angriffe
Bei einem DDoS-Angriff (Distributed Denial-of-Service) überschwemmt ein Netzwerk aus Computern gemeinsam einen Zugangspunkt und verhindert, dass legitime Benutzer auf einen Service zugreifen.
  * [Was ist ein DDoS-Angriff?](https://www.cloudflare.com/de-de/learning/ddos/what-is-a-ddos-attack/)
  * [Was ist ein DDoS-Botnetz?](https://www.cloudflare.com/de-de/learning/ddos/what-is-a-ddos-botnet/)
  * [So funktioniert DDoS](https://www.cloudflare.com/de-de/learning/ddos/ddos-attack-tools/how-to-ddos/)
  * [DNS-Flooding](https://www.cloudflare.com/de-de/learning/ddos/dns-flood-ddos-attack/)


#### Mehr über CDNs
In einem Content Delivery Network (CDN) arbeitet eine Gruppe von verteilten Servern zusammen, um Internetinhalte effizient bereitzustellen, die Ladedauer zu verringern und die Zuverlässigkeit zu steigern.
  * [Was ist ein CDN?](https://www.cloudflare.com/de-de/learning/cdn/what-is-a-cdn/)
  * [CDN-Performance](https://www.cloudflare.com/de-de/learning/cdn/performance/)
  * [CDN SSL TLS Sicherheit](https://www.cloudflare.com/de-de/learning/cdn/cdn-ssl-tls-security/)
  * [CDN Zuverlässigkeit](https://www.cloudflare.com/de-de/learning/cdn/cdn-load-balance-reliability/)


#### Mehr über das DNS
Das Domain Name System (DNS) wird oft als das Telefonbuch des Internets bezeichnet. Es handelt sich dabei um das weltweite Netzwerk, das Benutzer über Domain-Namen mit Webinhalten verbindet.
  * [Was ist DNS?](https://www.cloudflare.com/de-de/learning/dns/what-is-dns/)
  * [DNS Sicherheit](https://www.cloudflare.com/de-de/learning/dns/dns-security/)
  * [DNS Servertypen](https://www.cloudflare.com/de-de/learning/dns/dns-server-types/)
  * [DNS Einträge](https://www.cloudflare.com/de-de/learning/dns/dns-records/)


#### Mehr über Web Application Security
Durch die Natur des Internets sind Webanwendungen anfällig für verschiedene Arten von Angriffen. Web Application Security setzt auf einen ganzheitlichen Ansatz zur Bekämpfung von Angriffen.
  * [Was ist Web Application Security?](https://www.cloudflare.com/de-de/learning/security/what-is-web-application-security/)
  * [Was ist eine Datenschutzverletzung?](https://www.cloudflare.com/de-de/learning/security/what-is-a-data-breach/)

  * [Brute-Force-Angriff](https://www.cloudflare.com/de-de/learning/security/threats/brute-force-attack/)


#### Mehr über Performance
Webanwendungen, die schnell laden, verzeichnen höhere Konversionsraten und eine bessere SEO-Performance. Erfahren Sie mehr über die Faktoren, welche die Anwendungsperformance beeinflussen.
  * [Warum ist die Geschwindigkeit der Website wichtig?](https://www.cloudflare.com/de-de/learning/performance/why-site-speed-matters/)

#### Mehr über Serverless
Mit Serverless-Computing können Benutzer Code schreiben und bereitstellen, ohne sich um die zugrunde liegende Infrastruktur kümmern zu müssen. Erfahren Sie, warum sich immer mehr Entwickler für eine serverlose Architektur entscheiden.
  * [Was ist Serverless Computing?](https://www.cloudflare.com/de-de/learning/serverless/what-is-serverless/)

#### Mehr über SSL
SSL, heute bekannt als TLS, ist ein Verschlüsselungsprotokoll, das über dem HTTP-Protokoll ausgeführt wird, um die Internetkommunikation zwischen Servern und Clients zu schützen.
  * [Was ist SSL?](https://www.cloudflare.com/de-de/learning/ssl/what-is-ssl/)
  * [Was ist TLS?](https://www.cloudflare.com/de-de/learning/ssl/transport-layer-security-tls/)

  * [What is HTTPS?](https://www.cloudflare.com/de-de/learning/ssl/what-is-https/)


#### Mehr über Bots
Bots sind automatisierte Anwendungen, die das Internet durchsuchen können. Einige Bots, wie zum Beispiel Suchmaschinen-Crawler, sind hilfreich. Es gibt aber auch böswillige Bots, die Websites und Anwendungen auf verschiedene Weise schädigen können.
  * [Was ist ein Bot?](https://www.cloudflare.com/de-de/learning/bots/what-is-a-bot/)
  * [Was ist Bot-Management?](https://www.cloudflare.com/de-de/learning/bots/what-is-bot-management/)
  * [Was ist Credential Stuffing?](https://www.cloudflare.com/de-de/learning/bots/what-is-credential-stuffing/)
  * [Was ist Content-Scraping?](https://www.cloudflare.com/de-de/learning/bots/what-is-content-scraping/)


#### Mehr über die Cloud
„Die Cloud“ steht für Server, auf die über das Internet zugegriffen wird, und für die Software und Datenbanken, die auf diesen Servern ausgeführt werden. Die Cloud-Server befinden sich in Rechenzentren, die weltweit verteilt sind.
  * [Was ist die Cloud?](https://www.cloudflare.com/de-de/learning/cloud/what-is-the-cloud/)
  * [Was bedeutet Multi-Cloud?](https://www.cloudflare.com/de-de/learning/cloud/what-is-multicloud/)
  * [Was bedeutet Hybrid Cloud?](https://www.cloudflare.com/de-de/learning/cloud/what-is-hybrid-cloud/)
  * [Was ist eine Cloud-Firewall?](https://www.cloudflare.com/de-de/learning/cloud/what-is-a-cloud-firewall/)
