# Cloudflare for Campaigns
##### Sorgen Sie dafür, dass die Wahl-Website Ihres Kandidaten oder Ihrer Kandidatin ebenso wie Ihr Team sicher sind.

## Maßgeschneiderte Lösungen für Ihre Kampagne
Schützen Sie Ihre Website vor feindlichen Angriffen, nutzen Sie den Lastausgleich und sichern Sie die wichtigen internen Daten Ihres Teams mit Cloudflare – alles über dasselbe intuitive Dashboard.Verfügbare Lösungen umfassen:
24/7/365 Betriebszeit-Support Inklusive im Volumen unbeschränkter DDoS-Abwehr und einem dedizierten Support-Kontakt.
**Web Application Firewall** Einschließlich OWASP- und proprietärer Cloudflare-Regelsätze sowie Unterstützung für benutzerdefinierte WAF- und Firewall-Regeln.
**Angepasstes Traffic-Blockieren** Blockieren Sie bestimmte Benutzeragenten und Regionen, in denen problematischer Traffic erkannt wird.
**Rate Limiting** Schützen Sie vor Denial-of-Service-Angriffen, Brute-Force-Anmeldeversuchen und anderen missbräuchlichen Verhaltensweisen, die auf das Application Layer abzielen.
**I'm Under Attack™ -Modus** Stellen Sie sofort Schutzmaßnahmen gegen konzertierte Angriffe sowie „I'm Under Attack“-Support auf Enterprise-Niveau.
**Bot-Schutz** Verhindern Sie automatisierte Bots und lösen Sie Captcha-Herausforderungen aus, um sicherzustellen, dass nur echter Traffic Ihre Website erreicht.
**Subdomain-Support** Vereinfachen Sie die Verwaltung der Performance und Sicherheit von Subdomains.
**Globales CDN** Nutzen Sie das globale Netzwerk von Cloudflare, das sich über335 Städte in mehr als 125 Ländern erstreckt, um Reaktionszeiten im Millisekundenbereich zu bieten.
**Load Balancing** Routen Sie den Traffic dynamisch an verschiedene Server und Clouds.
**Cloudflare-Regeln** Konfigurieren Sie Cloudflare-Einstellungen und lösen Sie bestimmte Aktionen für übereinstimmende Anfragen aus. Beispiele für die Verwendung von Regeln sind das Festlegen von Cache-Ablaufzeiten, das Ändern von Sicherheitsstufen für Bereiche Ihrer Website und das Weiterleiten von URLs.**Audit-Protokolle** Einschließlich Aktivitäten auf Kontoebene wie Login und Logout sowie Konfigurationsänderungen, die über das Cloudflare Dashboard vorgenommen werden.
**Multi-User Organisation** Verwalten Sie Ihr Cloudflare-Konto mit mehreren Konten, jedes mit präzisen Berechtigungen.
**Cloudflare Access** Ermöglicht einer Kampagne, den Benutzerzugriff auf alle Domains, Anwendungen und Pfade bei Cloudflare zu sichern, authentifizieren und zu überwachen - ganz ohne Nutzung eines VPN.
**Cloudflare Gateway DNS-Filterung** Schützen Sie Benutzer beim Navigieren im Internet, indem Sie bösartige Inhalte von mehreren Standorten aus von Ihrem Netzwerk fernhalten.
**Ansprechperson für Sicherheit im Wahlkampf** Diese spezifische Ansprechperson für Sicherheit im Wahlkampf wird direkt an unser Supportteam weitergeleitet, mit einem Eskalationspfad zum Sicherheitsteam.
### 4 bewährte Methoden zum Schutz von Websites
##### Schützen Sie Ihr Konto mit der Zwei-Faktor-Authentifizierung (2FA)
Indem Sie bei der Anmeldung eine zweite Information zur Überprüfung Ihrer Identität verlangen, verhindern Sie, dass unbefugte Benutzer auf sensible Daten in Ihrem Konto zugreifen können.
[Zwei-Faktor-Authentifizierung aktivieren](https://support.cloudflare.com/hc/en-us/articles/200167906-Securing-user-access-with-two-factor-authentication-2FA-)
##### Orangene Wolke für Ihre DNS-Einträge aktivieren. 
Dies sorgt dafür, dass Cloudflare als Proxy für Ihre Domain fungiert. Dies schützt Ihren ursprünglichen Webserver vor unerwarteten Traffic-Spitzen und Cyber-Angriffen.
[Orangene Wolke aktivieren](https://support.cloudflare.com/hc/en-us/articles/205177068-How-does-Cloudflare-work-)
##### Mit SSL-Verschlüsselung interne Daten schützen.
Secure Sockets Layer ist das Standard-Sicherheitsverfahren für die Herstellung einer verschlüsselten Verbindung zwischen einem Webserver und einem Internetbrowser. Mit Cloudflare kann Ihre Website mit einem Klick auf eine Schaltfläche HTTPS-fähig werden.
[Mehr über Cloudflare SSL erfahren](https://support.cloudflare.com/hc/en-us/articles/200170416-End-to-end-HTTPS-with-Cloudflare-Part-3-SSL-options)
##### Schalten Sie Ihre Web Application Firewall ein
WAFs fungieren als Schutzschild zwischen einer Webanwendung und dem Internet und geben Ihnen die Möglichkeit zu entscheiden, ob ein- oder ausgehender Datenverkehr zugelassen werden soll. WAFs schützen vor SQL-Injection-Angriffen, Cross-Site Scripting und Cross-Site Forgery.
[Cloudflare Specials aktivieren](https://support.cloudflare.com/hc/en-us/articles/200172016-Understanding-the-Cloudflare-Web-Application-Firewall-WAF-)

## Lösungen für jede Kampagne
Verlassen Sie sich auf Cloudflare for Campaigns, um den Anforderungen Ihrer Kampagne gerecht zu werden: von der Absicherung der Online-Präsenz der Kandidierenden bis zum Schutz interner Netzwerke und Daten. Das Angebot umfasst:
  * Schützen Sie Ihre Website vor feindlichen Akteuren mit unserer Web Application Firewall, DDoS-Abwehr und benutzerdefinierten Sperrregeln
  * Verbessern Sie die Geschwindigkeit und Zuverlässigkeit Ihrer Website, indem Sie das globale Netzwerk von Cloudflare nutzen, das sich über 335 Städte in über 125 Ländern erstreckt
  * Überwachen Sie den gesamten Datenverkehr, der Ihr Netzwerk durchläuft, und sichern Sie interne Anwendungen mit Cloudflare Zero Trust
