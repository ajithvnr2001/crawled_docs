### Frequently asked questions

###### What is Cloudflare Gateway?

Cloudflare Gateway is a cloud-native secure web gateway (SWG) that protects employees and devices from online threats like malware and ransomware. It provides multi-layered threat protection, including DNS, HTTP, and network filtering, to secure Internet traffic for both in-office and remote "work-from-anywhere" users.

###### Does Cloudflare Gateway slow down Internet browsing?

No. Unlike legacy web security solutions that cause latency by backhauling traffic to centralized data centers, Cloudflare Gateway uses single-pass inspection. Built on 1.1.1.1, one of the world's fastest DNS resolvers, it inspects and secures traffic at the network edge to ensure high-speed browsing without disruptions.

###### What types of threats does Cloudflare Gateway block?

Gateway helps block malware, ransomware, phishing, DNS tunneling, command-and-control callbacks, and zero-day threats. It uses multi-layered detection powered by real-time DNS and HTTP telemetry from trillions of daily requests, combined with machine learning threat models.

###### How does Cloudflare Gateway help manage shadow IT?

Cloudflare Gateway provides unified oversight into an organization's Internet traffic to help manage sanctioned and unsanctioned SaaS, cloud, and AI tools. IT and security teams can use this visibility to discover shadow IT, block risky applications, or safely redirect users to approved alternatives.

###### Can Cloudflare Gateway be used to secure guest Wi-Fi?

Yes. Cloudflare Gateway can be applied to guest Wi-Fi networks and branch offices to defend against cyber threats and optimize visitor performance. Administrators can easily build HTTP and DNS policies using predefined categories to enforce acceptable use rules on guest networks.

###### How does Cloudflare Gateway prevent sensitive data loss?

When combined with Cloudflare’s Data Loss Prevention (DLP) profiles, Gateway acts as a forward proxy to provide complete visibility over sensitive data. Security teams can build granular HTTP policies that inspect traffic and block sensitive data from being leaked or uploaded to unapproved web, SaaS, or private apps.
