### Frequently asked questions

###### What is remote browser isolation (RBI)?

Remote browser isolation (RBI) is a security technology that executes all web code in a remote browser session at the network edge, away from user devices. Cloudflare Browser Isolation renders untrusted websites and applications on Cloudflare's global network, streaming only safe visual content to endpoints, preventing malware, ransomware, and zero-day exploits from reaching devices.

###### How does Cloudflare Browser Isolation prevent phishing and ransomware?

By running all active web content in an isolated cloud environment, malicious payloads and ransomware are physically prevented from reaching or executing on the local endpoint. Additionally, RBI mitigates phishing by automatically opening suspicious email links in an isolated session, neutralizing credential theft even if a user clicks a malicious link.

###### Does Cloudflare Browser Isolation slow down web browsing?

No. Cloudflare Browser Isolation is built to feel fast and native. By leveraging Cloudflare's massive global edge network and advanced rendering technologies, such as sending lightweight vector draw commands instead of heavy, pixel-pushed video streams, it delivers highly responsive web performance without the latency typical of legacy isolation tools.

###### How does Cloudflare RBI protect sensitive data from being exfiltrated?

Administrators can apply granular Data Loss Prevention (DLP) controls directly within the isolated browser session. This allows security teams to restrict high-risk actions, such as blocking copy/paste, disabling file uploads/downloads, or restricting keyboard input, preventing data exfiltration across web apps, SaaS apps, and GenAI tools.

###### Can Cloudflare Browser Isolation secure third-party and BYOD access?

Yes. Cloudflare offers clientless web isolation, which safely grants contractors, vendors, and partners access to internal resources from unmanaged or BYOD devices. Because the session is isolated in the browser, sensitive company data remains protected and contained without requiring the external user to install device client software.
