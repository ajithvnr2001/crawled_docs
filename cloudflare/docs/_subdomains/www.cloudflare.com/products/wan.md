### Frequently asked questions

###### What is "coffee shop networking" in Cloudflare WAN?

Coffee shop networking means your employees get the same fast, secure network experience whether they're working from headquarters, a branch office, or a local coffee shop. Cloudflare WAN applies consistent zero trust security policies based on user identity, not network location, so remote and office workers receive identical protection and performance.

###### How does Cloudflare WAN reduce costs compared to MPLS?

Cloudflare WAN replaces expensive MPLS circuits and bulky branch hardware by using a "light branch, heavy cloud" architecture. Instead of managing physical appliance stacks at every location, you deploy lightweight cloud-managed connectors that create secure IPsec or GRE tunnels to Cloudflare's global network, significantly lowering your total cost of ownership.

###### What does "light branch, heavy cloud" architecture mean?

Light branch, heavy cloud means shifting complex routing and security processing out of your physical branch offices and into Cloudflare's global network. Your branch locations only need simple, plug-and-play connectors to establish secure tunnels, while Cloudflare's cloud handles the heavy lifting: traffic routing, security inspection, and policy enforcement, delivered as a service.

###### Can Cloudflare WAN connect to my existing network equipment?

Yes. Cloudflare WAN works with your existing routers and network firewalls using standard IPsec and GRE tunnels Or, use Cloudflare Network Interconnect for private, direct connections to the nearest Cloudflare data center. You can connect branch offices, data centers, and retail sites in minutes without replacing hardware.

###### What are Cloudflare's appliance form factor options?

Cloudflare offers two form factor options for connecting sites to the WAN platform: a hardware appliance and a virtual appliance. The hardware option is a plug-and-play, Cloudflare-certified device with pre-installed software, zero-touch provisioning, and dedicated ports, ideal for physical branch offices and retail locations. The virtual appliance runs the same software on your own infrastructure (physical servers, VMs, or public cloud environments like AWS, Azure, and GCP), giving you flexibility for data centers or existing hardware investments. Both provide centralized cloud management, automatic IPsec tunnel setup, and high availability.

###### What is the difference between Cloudflare WAN and traditional SD-WAN?

Cloudflare WAN is a natively unified SASE platform where networking and security are built together in the cloud, not bolted on through separate hardware at each branch. Traditional SD-WAN involves overkill on-premises appliances, separate security point solutions, and complex integrations, creating fragmented management and 'tunnel spaghetti.' Cloudflare WAN delivers any-to-any connectivity with security built in, centralized cloud-native management for both networking and security from one interface, and a light-branch architecture that reduces hardware costs and operational complexity.
