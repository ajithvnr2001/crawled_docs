### Frequently asked questions

###### What is Cloudflare Email Security?

Cloudflare Email Security is a cloud-native defense platform that uses AI to block phishing, business email compromise (BEC), and malware before they reach users. It provides multi-channel protection across email, SMS, and collaboration apps to prevent credential theft and unauthorized network access.

###### How is Cloudflare Email Security deployed?

Administrators can deploy Cloudflare Email Security inline (via MX records), via API (for platforms like Microsoft 365 and Google Workspace), or using a hybrid approach. This flexibility enables pre-delivery filtering, real-time link analysis, and instant post-delivery message retractions without disrupting existing mail flow.

###### How does Cloudflare protect against Business Email Compromise (BEC)?

Cloudflare Email Security uses a high-efficacy, AI-powered detection engine to analyze message context, sentiment, and sender identity. This allows it to identify and block sophisticated, text-only impersonation attacks designed to trick employees into making fraudulent payments or exposing sensitive data.

###### Does Cloudflare protect against phishing threats outside of traditional email?

Yes. Cloudflare provides comprehensive multi-channel defense to secure modern workflows. It detects and blocks malicious links, QR codes, and delayed phishing tactics across SMS, social media, Slack, and Microsoft Teams.

###### How does Cloudflare handle suspicious links and malicious attachments?

Cloudflare defends against ransomware and malware by actively filtering dangerous attachments before delivery. For suspicious email links, it natively integrates with Cloudflare Remote Browser Isolation (RBI) to open the URL in a secure, remote cloud session, ensuring malicious code cannot execute on the user's local device.
