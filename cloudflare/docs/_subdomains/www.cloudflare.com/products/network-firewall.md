## Cloudflare Network Firewall

### Cloudflare Network Firewall is a firewall-as-a-service (FWaaS) offering for on-premises networks and WANs. No more bottlenecks — instead of backhauling traffic through firewall appliances, filter layer 3 and 4 traffic with the Cloudflare network, which has locations in over 330 cities throughout the world. This allows for secure and efficient network traffic management.

[ Talk to an expert ](https://www.cloudflare.com/plans/enterprise/contact/) [ Get solution brief ](https://cfl.re/magic-firewall-brief)

**Secure entire WAN**

Enforce network security policies across your entire WAN, including headquarters, branch offices, and virtual private clouds. Cloudflare Network Firewall ensures that all network traffic is inspected and filtered according to your security policies.

**No appliances to manage**

The Cloudflare Network Firewall is delivered from the Cloudflare global network, eliminating the need to manage hardware appliances. This approach removes artificial choke points and downtime for appliance upgrades, providing a more efficient and scalable security solution.

**Deploy rules instantly**

Fine-grained filtering rules can be deployed globally in seconds. Manage rules from a single dashboard, allowing for rapid response to changing security needs and ensuring that your network is always protected.

### Apply filtering policies on the Cloudflare global network

Cloudflare Network Firewall runs everywhere in Cloudflare’s global network, letting you inspect layer 3 / 4 traffic no matter where your branch offices are located.

Retire legacy firewall appliances 

Network Firewall is deployed from the cloud, blocking attacks with no need to install or maintain hardware boxes. This allows organizations to retire legacy firewall appliances and reduce the complexity of their network security infrastructure.

Mitigate L3 DDoS attacks 

Network Firewall integrates Magic Transit to stop layer 3 DDoS attacks that can overwhelm your infrastructure. This provides comprehensive protection against DDoS attacks and ensures that your network remains available and secure.
