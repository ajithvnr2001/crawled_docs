Cloudflare 商標指南
#### Cloudflare 品牌不僅代表我們的產品與服務，也被賦予了更多意義，是本公司為建設更加美好的網際網路而不懈努力的重要體現。
這些指南適用於希望在任何宣傳、商業、教育或參考材料中使用 Cloudflare 商標或標誌的 Cloudflare 客戶、開發人員、授權經銷商和其他方。除非依據這些準則獲得明確授權或者事先獲得 Cloudflare 允許使用的書面許可，否則禁止使用 Cloudflare 商標和標誌。
Cloudflare 商標和標誌是我們寶貴的智慧財產權資產。為了維護和保護 Cloudflare 品牌，正確使用我們的商標和標誌至關重要。Cloudflare 獨家擁有因使用 Cloudflare 商標和標誌而產生的任何商譽。

#### 允許的使用
##### 以文字形式提及 Cloudflare 產品和服務
您可以僅限文字的形式 (文字標記，而非標誌) 使用 Cloudflare 商標來標識 Cloudflare 產品或服務，但須遵守以下使用指南。使用 Cloudflare 標誌 (使用下述 Web 徽章以外) 需要取得我們的書面許可。  
  
  
  

##### 作為公司名稱提及 Cloudflare, Inc.
Cloudflare, Inc. 是公司/商號名稱。您可以在書面材料中作為公司名稱來提及 Cloudflare, Inc.：首先使用帶有股份有限公司標識的完整商號名稱 (即「Cloudflare, Inc.」)，然後在同一材料中再次提及時使用 Cloudflare (省略「Inc.」標識)。在作為公司名稱提及 Cloudflare 時，請勿將 ® 符號與「Cloudflare」一起使用。  
  
  

#####    
Cloudflare 客戶使用 Web 徽章
您可使用 Cloudflare Web 徽章來告知訪客，您的網站已得到 Cloudflare 服務的保護與加速。您可以從[此頁面](https://www.cloudflare.com/zh-tw/press-kit/)獲取 Cloudflare Web 徽章。請勿以任何方式更改 Cloudflare Web 徽章 (例如，拉長加寬或改變顏色等)。  
  
  
  

##### 授權經銷商和合作夥伴使用 Cloudflare 商標
如果您是 Cloudflare 的授權經銷商或合作夥伴，並且與我們訂立的協議允許您使用 Cloudflare 商標，您必須遵循協議中規定的要求。如果您的協議未向您提供特殊的商標使用指南，請遵循以下指南。
請注意，轉售 Cloudflare 服務需要與 Cloudflare 簽訂經銷商協議。如果您不是授權經銷商或合作夥伴，您不得表明或使用 Cloudflare 商標來表明您是 Cloudflare 經銷商或合作夥伴。  
  
  
  

##### Cloudflare 供應商和廠商使用 Cloudflare 商標
未經我們書面許可，Cloudflare 的供應商和廠商不得將 Cloudflare 商標用於提供給 Cloudflare 的產品和服務。如有關於審批流程的任何疑問，請聯繫您的 Cloudflare 代表。如果您已取得 Cloudflare 允許使用 Cloudflare 商標的書面許可，則須遵循以下指南，除非您以書面形式獲得特殊的商標使用指南。
#### 經允許後，我可以如何使用這些商標？
  * 所有 Cloudflare 商標首次出現在文本中時應正確標識 (使用 ®、™ 或 ℠)。
  * 附上適當的商標歸屬聲明，例如：「Cloudflare、Cloudflare 標誌和 Cloudflare Workers 是 Cloudflare, Inc. 在美國和其他司法管轄區的商標和/或註冊商標」。此聲明應放在您使用 Cloudflare 商標的第一頁的底部。
  * 不得更改 Cloudflare 的拼寫，並且首字母 C 應始終大寫。
  * 「Cloudflare」不應用作商標名稱的一部分，不可與連字號一起使用，也不能用在應用程式或其他產品的名稱中，但可用在引用性短語中，例如：「runs on」(執行於)、「for use with」(可搭配)、「for」(適用於) 或「compatible」(相容)。
    * 錯誤：「iCloudflare」
    * 錯誤：「My Cloudflare App」
    * 正確：「My App for Cloudflare®」
    * 正確：「Hosting Company’s Special Promotion for Cloudflare® 訂閱」
  * 如果與第三方標誌一起使用，則「for Cloudflare」的尺寸必須小於第三方標誌。
  * Cloudflare 商標應用作形容詞，後接適當的通用詞語；絕不可以複數形式或所有格形式使用。
    * 錯誤：「Cloudflare Optimizer」
    * 正確：「Cloudflare 服務」
  * Cloudflare 商標絕不可用作動詞。
    * 錯誤：「we Cloudflared our site」(我們 Cloudflare 了我們的網站。)
    * 正確：「我們利用 Cloudflare 服務使我們的網站變得更更加快速、安全，而且更加智慧。」


#### 使用 Cloudflare 商標時應該避免什麼？
  * 只有如實引用方可接受，禁止誤導性引用。例如，如果實際並未使用，則不得陳述某網站使用了 Cloudflare 服務和應用程式。
  * 未經明確書面許可，您在使用任何 Cloudflare 商標或標誌時不得暗示 Cloudflare 與第三方產品或服務存在隸屬關係或為其提供背書、贊助或支援。
  * 不得以貶損方式使用 Cloudflare 商標、圖形符號、標誌、文字或圖示。
  * 任何情況下，不得將與任何 Cloudflare 商標完全相同、幾乎相同或容易混淆的字串用作網域名稱、使用者代理程式或 Cookie 的一部分。例如，cloudfliare.com 幾乎完全相同，並且容易引起混淆。此規則的任何例外情況都需要 CEO、CTO 或 CSO 核准。
  * 第三方不可使用變體或拼寫錯誤，或以任何方式引起對 Cloudflare 商標的初始利益混淆。
  * 除了授權合作夥伴或授權經銷商外，第三方不得使用 Cloudflare 標記或拼寫錯誤來競標關鍵字、Google AdWords 或其他定向廣告系統。第三方也不得在網域名稱、任何搜尋引擎最佳化、中繼標籤、搜尋字詞、程式碼或其他虛假陳述中使用 Cloudflare 標記。
  * 不得在違反任何法律或法規的網站上或材料中展示 Cloudflare 商標或品牌。
  * 不得將 Cloudflare 商標或品牌融合到自己的產品名稱、服務名稱、商標、標誌或公司名稱中。
  * 不得在待售商品上使用 Cloudflare 商標 (例如，銷售 T 恤衫、馬克杯等)
  * 不得修改或縮寫 Cloudflare 商標，將它們與任何其他符號、文字或圖像組合，或將它們整合到標語或口號中。
