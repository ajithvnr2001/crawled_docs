  * **治理 AI 代理程式** ：搶先治理員工、MCP 伺服器和內部資料之間的連線。

  * **保障每個提示詞的安全性** ：分析 AI 提示詞內容和意圖，阻止將敏感的企業資料洩露到公用模型中。

### 實現遠端存取現代化

不再依賴於拖慢混合式工作的笨拙、不安全的 VPN。對內部應用程式和基礎架構提供身分優先、量子安全存取。

  * **加速佈設** ：為承包商和 BYOD 員工提供安全、順暢的存取權限，只需幾分鐘而非數天。
  * **加快併購速度** ：更高效地整合所購網路，且無需複雜的 IP 重疊或防火牆規則。
  * **阻止勒索軟體** ：使用精細的 Zero Trust 規則取代廣泛的網路存取，以防止威脅橫向傳播。

### 封鎖電子郵件網路釣魚攻擊

採用 AI 技術的電子郵件安全性可在威脅到達您使用者的收件匣之前阻止網路釣魚、假冒、惡意程式碼和商業電子郵件入侵 (BEC)。

  * **精準封鎖** ：遏止繞過原生 Microsoft 365 或 Google Workspace 防禦的難以捉摸和針對性網路釣魚威脅。
  * **加速部署** ：立即開始使用靈活的 MX 和 API 部署方法，只需極少設定且無需調整。
  * **擴展工作區安全性** ：在電子郵件和其他協作應用程式中新增原生 SASE 控制，例如隔離有風險的 Web 連結。

### 保護 Web 瀏覽

實作 DNS 和 HTTP 篩選，以保護遠端使用者和分支機構免遭惡意程式碼、網路釣魚攻擊和惡意網站的侵害。

  * **取得即時結果** ：透過靈活的部署封鎖網際網路威脅，同時減少警示雜訊，加快價值實現時間。
  * **順暢保護** ：使用支援[世界最快公用 DNS 解析程式](https://www.dnsperf.com/#!dns-resolvers)的同一網路，強制執行靈活的安全性規則。
  * **執行可接受的使用** ：透過安全、私密的訪客體驗保護企業和賓客 Wi-Fi。只需更新您的 DNS 設定即可。

## Cloudflare SASE 常見問題集

#### 什麼是 Cloudflare One？

Cloudflare One 是一個敏捷的統一 SASE 平台，旨在連線和保護組織的員工、AI 主體和基礎架構。該平台提供單一控制平面、資料平面和基礎架構層，以消除傳統安全性和網路的摩擦和技術債務。

#### Cloudflare One 平台包含哪些主要的網路和安全服務？

Cloudflare One 融合核心 SASE 服務，例如 Zero Trust 網路存取 (ZTNA)、安全 Web 閘道 (SWG)、雲端存取安全性代理程式 (CASB)、網路即服務 (NaaS) 和防火牆即服務 (FWaaS)。該平台還包括遠端瀏覽器隔離 (RBI)、資料丟失預防 (DLP)、電子郵件安全性和數位體驗監控 (DEM)。內建 AI 安全性、後量子加密 (PQC) 和負載平衡等組合式功能。

#### Cloudflare 的 SASE 架構與第一代解決方案有何差異？

第一代安全存取服務邊緣 (SASE) 解決方案通常會依據拼湊的收購項目，提供零散的代理或不一致的原則。相較之下，Cloudflare One 在設計上透過全球連通雲實現統一，提供了組合式且程式化的架構，讓組織能夠在數小時內而非數月，即可推出安全和網路功能。

#### Cloudflare One 如何協助組織安全地採用生成式 AI？

該平台提供對 GenAI 使用的深入可見度與控制，並透過發現未經批准的工具來協助管理影子 AI。這是首個保護模型上下文通訊協定 (MCP) 伺服器連線的 SASE 平台，並且可分析 AI 提示的意圖，以阻止敏感的企業資料洩漏到公用模型中。

#### Cloudflare One 如何讓現代企業實現咖啡店網路？

Cloudflare One 將繁重的工作轉移到雲端，不再需要昂貴的 MPLS 合約和複雜的硬體。這種「輕分支、重雲端」SASE 模型允許任何位置具有相同層級的一致連線和安全性。辦公室連線「效果十分顯著」。企業透過 Cloudflare 的全球網路來路由流量，能夠簡化其基礎架構，同時確保每個使用者具備高效能的安全性。

#### Cloudflare 的 SASE 平台如何實現遠端存取現代化？

Cloudflare One 以身分優先、量子安全的方式存取內部應用程式，取代了笨拙且不安全的 VPN。這可透過精細的 Zero Trust 規則來防止威脅橫向傳播，並支援組織在幾分鐘內向承包商和自攜裝置員工授予順暢的存取權。

#### Cloudflare One 如何應對電子郵件威脅？

Cloudflare One 採用 AI 支援的電子郵件安全性，可阻止網路釣魚、假冒、惡意程式碼和商業電子郵件入侵 (BEC)。該服務藉由新增原生 SASE 控制來擴展這些防護，例如隔離電子郵件中存在風險的 Web 連結。

#### Cloudflare One 平台如何支援全球規模和效能？

Cloudflare 從全球 300 多座城市提供完整的 SASE 服務。這一全球覆蓋範圍可保護約 20% 的 Web，並為約 80% 的頂級生成式 AI 公司提供安全保障，從而為客戶帶來了具備無與倫比的威脅情報和零時差可見度的平台。
