輕鬆託管影片，提供順暢的觀看體驗。利用 Stream，您可以使用一個 API，經濟高效地上傳、儲存、編碼及傳遞即時和點播影片。您只需支付傳遞和儲存影片（分鐘數）的費用，無需支付額外的編碼或頻寬費用。

## Cloudflare 應用程式託管常見問題集

#### Cloudflare 提供哪些應用程式託管服務？

Cloudflare 提供了一系列應用程式託管解決方案，來滿足從業餘專案到大型企業應用程式的各種需求。無論使用者群位於何處，在 Cloudflare 上建置及託管的網站都安全、快捷且高效。

#### Cloudflare Pages 如何運作？

[Cloudflare Pages](https://www.cloudflare.com/zh-tw/developer-platform/products/pages/) 是一種簡單、快速的建置、測試和部署方式。藉助該服務，您可以建置完整堆疊應用程式，並立即部署您的程式碼。其提供與其他 [Cloudflare 開發人員工具和服務](https://www.cloudflare.com/zh-tw/developer-platform/)的無縫整合，從而支援開發人員以最少的設定來構建靜態和動態應用程式。Pages 提供無限制席位，讓開發人員能夠輕鬆協作開發應用程式。

#### 什麼是 Cloudflare Images？

[Cloudflare Images](https://www.cloudflare.com/zh-tw/developer-platform/products/cloudflare-images/) 是一項影像託管的端對端解決方案。該解決方案讓應用程式開發人員使用單一的統一產品，即可經濟高效地大規模儲存、最適化調整、最佳化及傳遞影像。

#### 如何在 Cloudflare 上託管影片？

Cloudflare 客戶可使用 [Cloudflare Stream](https://www.cloudflare.com/zh-tw/developer-platform/products/cloudflare-stream/) 上傳、儲存、編碼及傳遞[即時](https://www.cloudflare.com/zh-tw/developer-platform/solutions/live-streaming/)和點播影片。Stream 客戶只需依傳遞和儲存影片的時長（分鐘）付費，而無需支付額外的編碼或頻寬費用。

#### 什麼是 Cloudflare R2，以及它如何改善應用程式效能？

[Cloudflare R2](https://www.cloudflare.com/zh-tw/developer-platform/products/r2/) 是不收取輸出費用的[物件儲存體](https://www.cloudflare.com/zh-tw/learning/cloud/what-is-object-storage/)。您可將應用程式資產直接儲存在 Cloudflare 上（您的應用程式的託管位置），藉此減少從後端載入資料時的往返次數，並改善應用程式的整體效能。
