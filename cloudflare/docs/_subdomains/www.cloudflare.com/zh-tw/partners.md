## 為什麼與 Cloudflare 合作？

Cloudflare 的全球連通雲是企業轉變未來連線、保護和建置方式所需的數位核心。從解決方案提供者到技術聯盟，我們讓合作夥伴能夠藉助 Cloudflare 的全球網路，協助客戶解決最棘手的問題。Cloudflare 的全球網路為全球 20% 的 Web 提供支援，並連接全球 330 多座城市和 13,000 個網路中的數百萬個網際網路內容。我們將與合作夥伴攜手突破界限、挑戰傳統，共同塑造安全性的未來。
