# Cloudflare 為高風險網站提供網路安全保護
如果您營運著從事人權、公民社會、新聞工作或民主工作的組織，則可以申請 Galileo 專案，免費獲得 Cloudflare 的網路安全保護。
[現在申請](https://www.cloudflare.com/galileo/#galileoapplication)
## 確保高危公共利益團體保持上線
Galileo 專案於 2014 年成立，以抗擊針對重要但易受攻擊的目標（如人道主義組織、民間團體和人權衛士）發起的毀滅性網路攻擊。 
透過 Galileo 專案，Cloudflare 為 DDoS 和其他網路攻擊所針對的超過 2,900 筆易受攻擊的網際網路內容免費提供強健的安全性。 
網際網絡是傳播和擴散思想的有力工具。當記者、社會活動人士和少數群體被試圖使他們下線的惡意流量所淹沒時，網際網絡再也無法兌現其承諾。 
這些組織常常會面對來自強大且根深蒂固的對手發動的攻擊，但這些組織的運作預算卻很有限。為保護參與者免遭潛在抵制，Cloudflare 不會在未經明確允許的情況下公開參與 Galileo 專案的網站。 
如得到我們受信任的合作夥伴之一引薦或核准，我們就會透過 Galileo 專案向相關組織提供服務。這種接納不需要、也不應當被理解為我們全部多元化合作夥伴的認可。

## 申請加入 Galileo 專案
如果您代表易受攻擊的公益網站，並想要參與 Galileo 專案，請連絡我們的合作夥伴組織之一，並要求其為您提供贊助（上面已列出）。
如果您不隸屬於合作夥伴組織，請填寫此連絡人表單並提供有關以下主題的資訊：
  * 您正在尋求保護的領域——它必須是已經上線的網站
  * 您的使命、活動和非營利狀態
  * 您的組織如何為公益服務
  * 使其成為易受攻擊目標的因素


在您等待回復的同時，請查看我們的[免費方案](https://www.cloudflare.com/zh-tw/plans/)的優勢，並開始使用 Cloudflare。
