## 為您量身定做的解決方案
透過 Cloudflare 保護網站免受惡意攻擊、運用負載平衡，以及保護您團隊的重要內部資料──全部都是使用同一個直觀的儀表板來進行。
可用的解決方案包括：
24 小時全年無休的運作時間支援 包括無計量 DDoS 緩解和專屬的支援聯絡人。
**Web 應用程式防火牆** 包括 OWASP 和專屬 Cloudflare 規則集，並支援自訂 WAF 和防火牆規則。
**自訂流量封鎖** 封鎖偵測到問題流量的指定使用者代理和地區。
**限速** 阻擋阻斷服務攻擊、暴力登入嘗試，以及針對應用程式層的其他濫用行為。
**I'm Under Attack™ 模式** 立即部署可防禦協同攻擊的保護措施，還有企業級的「I'm Under Attack」支援。
**機器人防護** 阻止自動化機器人，並觸發 CAPTCHA 問題，以確保只有真正的流量才能到達您的網站。
**子網域支援** 簡化對子網域 Cloudflare 效能與安全的管理作業。
**全球 CDN** 利用我們覆蓋 125 個國家/地區 335 座城市的全球網路，實現毫秒級回應時間。
**負載平衡** 將流量動態路由到不同的伺服器和雲端。
**Cloudflare 規則** 完成 Cloudflare 設定，並為相符的要求觸發特定動作。規則使用案例範例包括設定快取到期、修改網站各部分的安全層級以及轉送 URL。
**稽核記錄** 包括帳戶層級的動作（如登入和登出），以及透過 Cloudflare 儀表板進行的設定變更。
**多使用者組織** 透過多個帳戶管理您的 Cloudflare 帳戶，每個帳戶都具備精細的權限控制。
**Cloudflare Access** 允許競選團隊保護、驗證和監控使用者對 Cloudflare 上任何網域、應用程式或路徑的存取，無需使用 VPN。
**Cloudflare Gateway DNS 過濾** 從多個位置阻止惡意內容進入您的網路，讓使用者在瀏覽網際網路時能夠獲得保護。
**選舉網路安全聯絡窗口** 此選舉網路安全專屬的聯絡窗口將轉接到我們的支援團隊，並透過向上呈報提交給網路安全團隊。
### 保護網站的四個最佳做法
##### 使用雙重驗證 (2FA) 來保護您的帳戶
登入時要求提供第二種資訊來驗證身分，可預防未授權使用者存取您帳戶中的敏感性資料。
[啟用雙因素驗證](https://support.cloudflare.com/hc/en-us/articles/200167906-Securing-user-access-with-two-factor-authentication-2FA-)
##### 對您的 DNS 記錄啟用橙雲 
啟用 DNS 記錄的橙雲時，Cloudflare 會充當您的網域的代理。這樣可保護您的原始網頁伺服器，使其免受非預期的流量暴增或網路攻擊。
[啟用橙雲](https://support.cloudflare.com/hc/en-us/articles/205177068-How-does-Cloudflare-work-)
##### 使用 SSL 加密來保護您的內部資料
安全通訊端層是用來在網頁伺服器和瀏覽器之間建立加密連結的標準網路安全技術。選擇 Cloudflare，您的網站透過一鍵啟用就能夠具備 HTTP 功能。
[進一步瞭解 Cloudflare SSL](https://support.cloudflare.com/hc/en-us/articles/200170416-End-to-end-HTTPS-with-Cloudflare-Part-3-SSL-options)
##### 開啟您的 Web 應用程式防火牆
WAF 會在 Web 應用程式和網際網路之間放置一道屏障，讓您能夠決定是否允許傳入和傳出流量通過。WAF 可抵禦 SQL 資料隱碼攻擊、跨網站指令碼攻擊和跨網站偽造等威脅。
[啟用 Cloudflare Specials](https://support.cloudflare.com/hc/en-us/articles/200172016-Understanding-the-Cloudflare-Web-Application-Firewall-WAF-)
