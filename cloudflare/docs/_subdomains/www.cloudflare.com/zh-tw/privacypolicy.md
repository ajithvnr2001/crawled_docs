### CLOUDFLARE 的承諾
我們打造更優質網路的使命根植於強調在客戶、使用者和全球網路社區之間建立互信。為獲取和維持信任，我們保證溝通透明化、提供安全保障並保護系統內資料的隱私權。
我們將您的個人信息保持個人和私密性。 我們不會出售或出租您的個人信息。 我們只會在提供我們的服務或本政策中另有說明的必要時分享或以其他方式披露您的個人信息，除非我們首先向您提供通知並有機會獲得同意。
### 1. 政策申請
本政策適用於 Cloudflare 收集、使用和透露以下資料主體範疇的個人資訊：

  * 客戶：與 Cloudflare（或其授權合作夥伴）簽訂訂閱協議，以及 Cloudflare 根據該協議向其提供服務的個人或實體。 就本政策而言，「服務」應指 Cloudflare 或其授權合作夥伴提供、銷售或銷售的所有雲端解決方案，這些解決方案旨在提高 Internet 屬性、應用程式、裝置和網路的效能、安全性和可用性，以及與前述項目相關的任何軟體、軟體開發套件和應用程式設計介面 ("API")。
  * 管理使用者：具有 Cloudflare 帳戶登入憑證的使用者和/或為客戶管理任何服務的使用者。 在某些情況下，管理使用者和客戶可能是同一個人。 在其他情況下，管理使用者可能是代表客戶行事的代理人。
  * 公共 DNS 解析器用戶：那些使用 Cloudflare 的 1.1.1.1 公共遞歸域名系統（以下簡稱「DNS」）解析器服務的用戶，包括 1.1.1.1 適用於家庭的 1.1.1.1 解析器（1.1.1.1 解析器）。" " [在此處了解有關 1.1.1.1 解析器的更多信息。](https://developers.cloudflare.com/1.1.1.1/privacy/public-dns-resolver/)
  * 終端使用者：(i) 存取或使用我們客戶的網域、網路、網站、應用程式設計介面和應用程式，或 (ii) 存取或使用服務 (例如 Cloudflare Zero Trust 終端使用者) 的客戶員工、代理人或承包商的人員。

本政策不適用於「應用程式使用者」— 那些使用 Cloudflare 面向消費者的 1.1.1.1 的個人 應用程式。 請參閱 [1.1.1.1 應用程式隱私權政策](https://www.cloudflare.com/zh-tw/application/privacypolicy/) ，深入瞭解 Cloudflare 1.1.1.1 的資料收集和使用做法 申請表格及相關的 1.1.1.1 應用程式服務。

若 Cloudflare 是反向代理伺服器，我們的 IP 位址可能出現在 WHOIS 和使用我們服務網站的 DNS 記錄上。我們是他人所控制之資訊的管道。我們的客戶和其使用者才是負責在我們網路上傳輸內容（例如，影像、文字内容、圖像等 ）的人。
### 2. 我們收集的資料（資料當事人類別）
  * 參加者
    * 姓名、電子郵件地址和其他聯絡資訊：當您造訪我們的辦公室、註冊或參加贊助活動或其他活動時，Cloudflare (和/或其代表) 參與或參與 Cloudflare 的研究 (例如使用者體驗研究)，我們可能會要求並蒐集您的個人資訊，例如您的姓名、地址、電話號碼和電子郵件地址。
    * 圖像和語音：當您參與 Cloudflare 研究時，我們可能會在您參與研究期間要求您錄製語音和/或圖像的許可。
  * 網站造訪者
    * 姓名、電子郵件地址和其他聯絡資訊：當您在我們的網站上提交網頁表格時，我們會要求並且您可以選擇向您收集個人資訊，包括註冊並同意接收我們的電子郵件通訊的機會。 如果您選擇使用網站的互動功能，包括參與調查、競賽、促銷活動、抽獎或研究、要求客戶支援、提交意見或與我們溝通，我們可能會要求您提交此類個人資訊。 我們將根據適用法律發送此類通訊。
    * 日誌文件：就像您訪問通過 Internet 提供的大多數網站和服務並與之互動一樣，當您訪問我們的網站（包括 Cloudflare 社區論壇）時，我們會收集某些信息並將其存儲在日誌文件中。 此資訊可能包括但不限於網際網路通訊協定 (IP) 位址、系統組態資訊、參照頁面的 URL，以及地區設定和語言偏好設定。
    * Cookie 和其他追蹤技術：我們可能將 Cookie 和其他資訊收集技術用於各種目的，例如提供您與我們網站互動情況的資訊以及協助我們的行銷工作。您可以查看 Cookie 的完整列表，並變更您的 Cookie 首選項，方法是按一下位於 cloudflare.com 的 Cloudflare 首頁頁腳中的「Cookie 偏好」連結（或者，在美國，點擊「您的隱私選擇」連結），或者當您從特定國家（例如歐洲經濟區和英國）造訪我們網站時顯示的橫幅中。請注意，如果您完全停用 Cookie，Cloudflare 的網站可能無法正常運作。我們也可能使用 Cookie 和類似的技術，根據您的瀏覽活動和興趣，為您在第三方網站上顯示廣告。除了透過我們的「Cookie 喜好設定」或「您的隱私選擇」連結來行使 Cookie 選擇權之外，如果您不希望 Cookie 和類似技術用於向您投放基於興趣的廣告，您可以點擊 [這裡](https://optout.networkadvertising.org/?c=1) 選擇退出（如果您位於歐盟、英國或瑞士，請點擊 [這裡](https://www.youronlinechoices.eu/)）。欲了解 Cloudflare 使用 Cookie 的更多資訊以及您的隱私權選項，請參閱我們的 [Cookie 原則](https://www.cloudflare.com/zh-tw/cookie-policy/)。
    * 在互動區域貢獻的材料：網站可能提供可公開訪問的博客，社區論壇，評論部分，論壇或其他互動功能（「互動區域」）。 如果您選擇參與任何這些互動區域，請注意，您在互動區域中發布的任何信息都可能被訪問它的其他人閱讀，收集和使用。 如果您希望從我們的任何互動區域中刪除您的個人信息，請參閱下面的第 8 節。
  * 客戶和管理使用者
    * 客戶帳戶資訊：當您註冊帳戶時，我們會收集聯絡資訊。 視訂閱等級而定，此聯絡資訊可能包括您的客戶名稱、帳戶管理員的電子郵件地址、電話號碼，以及處理服務付款與交付所需的地址。 此外，當您使用服務時，我們會收集有關您如何配置帳戶和服務的資訊（例如，您管理的網域的防火牆設定）。 就本政策而言，我們將所有這些信息統稱為「客戶帳戶信息」。 需要客戶帳戶資訊才能讓您存取 Cloudflare 帳戶和服務。 通過向我們提供任何個人信息，即表示您是此類個人信息的所有者或以其他方式獲得必要的同意向我們提供該信息。 我們還會維護管理用戶活動的日誌（例如，在客戶帳戶中配置設置時採取的操作）。
    * 付款資訊：除非客戶已付費訂閱我們的服務，否則我們不會要求客戶向我們登記付款資訊。 當您註冊我們的付費服務時，您必須提供付款和帳單資訊。 您需要提交的信息取決於您選擇的付款方式。 例如，如果您使用信用卡付款，我們將收集您的卡信息和帳單地址，儘管我們不存儲完整的信用卡號碼或個人帳戶號碼。
    * 當機報告：當我們的服務遇到非預期的錯誤時，系統可能會要求您提交當機報告，其中可能包含個人資訊。 在向我們提交報告之前，您將有機會查看報告的內容。
  * 公用 DNS 解析器使用者
    * 有限的 DNS 查詢數據：我們將收集發送給我們 1.1.1.1 解析器的有限 DNS 查詢數據。 我們的 1.1.1.1 解析器服務不會記錄個人信息，並且大部分有限的非個人可識別查詢數據僅存儲 25 小時。 您可以在[此處](https://developers.cloudflare.com/1.1.1.1/privacy/public-dns-resolver/)了解有關我們 1.1.1.1 解析器對隱私權承諾的更多資訊。
    * 請注意，我們對 1.1.1.1 的數據處理實踐 應用程式不在本政策涵蓋範圍內，與我們的 1.1.1.1 解析器資料處理實務有些不同，請參閱[此處](https://www.cloudflare.com/zh-tw/application/privacypolicy/)。
  * 終端用户
    * Cloudflare 會處理最終使用者與客戶網際網路屬性和服務的互動。 當終端使用者存取或使用使用我們一或多項服務的客戶網域、網站、API、應用程式、裝置、端點和網路，以及最終使用者存取或使用服務 (例如 Cloudflare Zero Trust) 時，會處理此資訊。 所處理的資訊可能包括但不限於 IP 位址、流量路由資料、系統組態資訊，以及其他有關客戶網站、裝置、應用程式及/或網路之流量的資訊。
    * 我們透過服務儀表板或其他線上介面向客戶提供的「一般使用者」資料特別定義為「客戶記錄」。
  * 註冊者
    * 聯絡人和網域資訊：我們會收集網域名稱和狀態、聯絡資訊（例如姓名、組織、地址、電話號碼和電子郵件地址）、名稱伺服器、DNSSEC 和核准表格等資料（即在轉移到我們的系統時完整的 WHOIS 擷取，包括啟動轉移的 IP 位址）。


網路資料。 Cloudflare 收集和存儲網絡數據，這些模型、觀察、報告、分析、統計信息、數據庫和其他由 Cloudflare 在提供服務過程中由 Cloudflare 生成的服務器、網絡或流量數據創建、編譯、分析、生成或導出的信息，包括幫助 Cloudflare 識別、分析、緩解、預防和阻止 Cloudflare 網絡上惡意活動所需的信息。 網路資料的範例包括服務運作時間和服務可用性指標、要求量、錯誤率、快取率、惡意程式碼的來源和性質，以及 IP 威脅分數。
### 3. 我們如何使用我們收集的資訊

  * 使您能夠存取和使用本網站和服務；
  * 處理和完成交易，並傳送相關資訊，包括購貨確認書和發貨單；
  * 傳送交易訊息，包括回覆您的意見、疑問和要求；提供客戶服務和支援；傳送技術通知、更新、安全警告和支援管理訊息；
  * 遵從法定義務，並調查和防範詐騙交易、未授權存取「服務」和其他非法活動；
  * 出於我們獲得您同意的其他目的。


此外，我們可能會將從參加者、網站訪客和註冊人那裡收集到的資訊，以及客戶帳戶資訊用於以下目的：

  * 處理和遞交比賽或抽獎活動的項目和獎品；
  * 基於行銷和廣告目的，監控和分析趨勢、應用和「網站」及「服務」相關活動；

我們採取一切合理措施來保護我們從您那裡收到的信息免受意外或非法破壞，丟失，更改以及未經授權的披露或訪問。 我們採取了適當的物理、技術和行政措施來保護和保護您的信息，並使用增強隱私的技術，例如加密。 如果您對個人資訊的安全性有任何疑問，可以透過 privacyquestions@cloudflare.com與我們聯絡。
### 11. 資料保留
我們會將您的個人資訊儲存一段與本政策第 3 條規定的業務目的相符的時間，或者在履行和遵守法律義務所需的時間內儲存您的個人資訊。 我們用於確定我們存儲您的個人信息多長時間的標準將根據幾個不同因素而有所不同。 在判斷資料保留時，我們通常會考慮下列事項：
  * 首先收集個人信息的目的。 例如，如果您在我們這裡擁有一個有效的帳戶，我們需要在整個時間內保留您的聯繫信息，以便為您提供支持或就您的帳戶與您聯繫；
  * 我們正在處理的個人信息的數量，性質和敏感性；
  * 未經授權使用或披露個人信息的潛在危害風險；
  * 我們是否能夠以較少的數據或通過其他方式實現處理目的
  * 可能適用於數據的法律要求，例如適用的限制法規或合同義務。


當特定資料類型的資料保留期到期時，我們將刪除或銷毀該資料。 如果由於技術原因，我們無法這樣做，我們將實施適當的安全措施，以防止任何進一步使用此類數據。
