别再依赖笨重、不安全的 VPN，它只会拖慢您的混合办公效率。为您提供以身份为核心、量子安全的内部应用与基础设施访问能力。

## Cloudflare SASE 常见问题解答

#### Cloudflare One 是什么？

Cloudflare One 是一个敏捷、统一的 SASE平台，旨在连接和保护组织的员工队伍、AI 智能体和基础设施。它提供单一的控制平面、数据平面和基础设施层，以消除传统安全和网络的摩擦和技术债务。

#### Cloudflare One 平台包含哪些主要的网络和安全服务？

Cloudflare One 融合核心 SASE 服务，例如 Zero Trust 网络访问 (ZTNA)、安全 Web 网关 (SWG)、云访问安全代理 (CASB)、网络即服务 (NaaS) 和防火墙即服务 (FWaaS)。它还包括远程浏览器隔离 (RBI)、数据丢失防护 (DLP)、电子邮件安全和数字体验监控 (DEM)。该平台内置 AI 安全、后量子加密 (PQC) 和负载平衡等可组合功能。

#### Cloudflare 的 SASE 架构与第一代解决方案有何不同？

第一代 SASE 解决方案通常由拼凑而成的代理组件构成，或因采用并购整合的技术架构，导致策略执行不一致。相比之下，Cloudflare One 设计为基于全球连通云的统一架构，提供可组合、可编程的技术架构，让企业能在数小时（而非数月）内完成安全与网络功能的部署。

#### Cloudflare One 如何帮助组织安全地采用生成式 AI？

该平台提供对生成式 AI 使用情况的深度可见性和控制，并通过发现未经批准的工具来帮助管理影子 AI。它是第一个保护与模型上下文协议 (MCP) 服务器连接的 SASE 平台，可分析 AI 提示词的意图，以阻止敏感的企业数据泄漏到公共模型中。

#### Cloudflare One 如何为现代企业提供咖啡店式网络？

Cloudflare One 将核心负载转移至云端，无需依赖成本高昂的 MPLS 合同以及复杂的硬件设备。这种“轻分支、重云端”的 SASE 模型允许任何位置都提供相同级别的一致连接和安全性。办公室网络连接“开箱即用”。通过利用 Cloudflare 全球网络路由流量，企业可以简化其基础设施，同时为每个用户提供高性能安全防护。

#### Cloudflare 的 SASE 平台可在哪些方面实现远程访问现代化？

Cloudflare One 取代了笨拙、不安全的 VPN，以身份优先、量子安全的方式访问内部应用。这可以通过精细化的 Zero Trust 规则来防止威胁横向传播，并让组织在几分钟内就能向承包商和 BYOD 员工授予无摩擦的访问权限。

#### Cloudflare One 如何应对基于电子邮件的威胁？

Cloudflare One 使用 AI 驱动的电子邮件安全，阻止网络钓鱼、假冒、恶意软件和企业电子邮件破坏 (BEC)。可以通过添加原生 SASE 控制来扩展这些保护，例如隔离电子邮件中存在风险的 Web 链接。

#### Cloudflare One 平台如何支持全球规模与性能？

Cloudflare 从全球超过 300 座城市提供完整的 SASE 服务。Cloudflare 的全球网络保护着约 20% 的互联网，并为约 80% 的头部生成式 AI 企业提供安全防护，驱动一个具备无与伦比的威胁情报能力与 zero-day 漏洞可见性的平台。
