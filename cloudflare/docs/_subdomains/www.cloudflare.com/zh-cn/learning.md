# 学习中心
有关网络安全和 Cloudflare 在互联网上如何工作的资源。[什么是 Cloudflare？](https://www.cloudflare.com/zh-cn/learning/what-is-cloudflare/ "https://www.cloudflare.com/learning/what-is-cloudflare/")
#### 了解 DDoS 攻击
在分布式拒绝服务 (DDoS) 攻击中，一组计算机组成的网络会协同工作，导致访问点不堪重负，导致合法用户无法访问服务。
  * [什么是 DDoS 攻击？](https://www.cloudflare.com/zh-cn/learning/ddos/what-is-a-ddos-attack/)
  * [什么是 DDoS 僵尸网络？](https://www.cloudflare.com/zh-cn/learning/ddos/what-is-a-ddos-botnet/)
  * [如何发动 DDoS 攻击？](https://www.cloudflare.com/zh-cn/learning/ddos/ddos-attack-tools/how-to-ddos/)
  * [DNS 洪水](https://www.cloudflare.com/zh-cn/learning/ddos/dns-flood-ddos-attack/)


#### 了解有关 CDN
在内容交付网络 (CDN) 中，一组分布式服务器可以协同工作以有效地交付互联网内容，从而提高加载速度和可靠性。
  * [什么是 CDN？](https://www.cloudflare.com/zh-cn/learning/cdn/what-is-a-cdn/)
  * [CDN 性能](https://www.cloudflare.com/zh-cn/learning/cdn/performance/)
  * [CDN SSL TLS 安全性](https://www.cloudflare.com/zh-cn/learning/cdn/cdn-ssl-tls-security/)
  * [CDN 可靠性](https://www.cloudflare.com/zh-cn/learning/cdn/cdn-load-balance-reliability/)


#### 了解 DNS
域名系统 (DNS) 常常被称为互联网电话簿。这是一个全球性网络，通过域名将用户连接到 Web 内容。
  * [什么是 DNS？](https://www.cloudflare.com/zh-cn/learning/dns/what-is-dns/)
  * [DNS 安全性](https://www.cloudflare.com/zh-cn/learning/dns/dns-security/)
  * [DNS 服务器类型](https://www.cloudflare.com/zh-cn/learning/dns/dns-server-types/)
  * [DNS 记录](https://www.cloudflare.com/zh-cn/learning/dns/dns-records/)


#### 了解 Web 应用程序安全
Internet 的性质使得 Web 应用程序容易遭受多种攻击。Web 应用程序安全性策略使用一种整体方法来缓解攻击。
  * [什么是 Web 应用程序安全？](https://www.cloudflare.com/zh-cn/learning/security/what-is-web-application-security/)
  * [什么是数据泄露？](https://www.cloudflare.com/zh-cn/learning/security/what-is-a-data-breach/)
  * [熔毁/幽灵 (Meltdown/Spectre)](https://www.cloudflare.com/zh-cn/learning/security/threats/meltdown-spectre/)
  * [暴力攻击](https://www.cloudflare.com/zh-cn/learning/security/threats/brute-force-attack/)


#### 了解性能
快速加载的 web 应用程序能获得更高的转化率和更佳的 SEO 性能。了解影响应用程序性能的因素。
  * [为什么网站速度很重要？](https://www.cloudflare.com/zh-cn/learning/performance/why-site-speed-matters/)
  * [网站速度如何促进 SEO？](https://www.cloudflare.com/zh-cn/learning/performance/how-website-speed-boosts-seo/)
  * [如何使一个网站对移动设备友好？](https://www.cloudflare.com/zh-cn/learning/performance/how-to-make-a-site-mobile-friendly/)
  * [什么是延迟？](https://www.cloudflare.com/zh-cn/learning/performance/glossary/what-is-latency/)


#### 了解无服务器
无服务器计算允许用户编写和部署代码，而不必考虑底层基础设施。了解为何越来越多开发者选择无服务器架构。
  * [什么是无服务器计算？](https://www.cloudflare.com/zh-cn/learning/serverless/what-is-serverless/)
  * [为什么使用无服务器计算？](https://www.cloudflare.com/zh-cn/learning/serverless/why-use-serverless/)
  * [函数即服务（FaaS）](https://www.cloudflare.com/zh-cn/learning/serverless/glossary/function-as-a-service-faas/)
  * [什么是边缘计算？](https://www.cloudflare.com/zh-cn/learning/serverless/glossary/what-is-edge-computing/)


#### 了解 SSL
SSL（如今称为 TLS）是一种加密协议，运行在 HTTP 协议之上，以保护服务器与客户端之间的互联网通信。
  * [什么是 SSL？](https://www.cloudflare.com/zh-cn/learning/ssl/what-is-ssl/)
  * [什么是 TLS？](https://www.cloudflare.com/zh-cn/learning/ssl/transport-layer-security-tls/)
  * [什么是 SSL 证书？](https://www.cloudflare.com/zh-cn/learning/ssl/what-is-an-ssl-certificate/)
  * [什么是 HTTPS？](https://www.cloudflare.com/zh-cn/learning/ssl/what-is-https/)


#### 了解机器人
机器人是可以浏览 Web 的自动化应用程序。某些机器人（例如搜索引擎爬网程序）是有所助益的，但还有一些恶意机器人可能以多种方式损害网站和应用程序。
  * [什么是机器人？](https://www.cloudflare.com/zh-cn/learning/bots/what-is-a-bot/)
  * [什么是机器人管理？](https://www.cloudflare.com/zh-cn/learning/bots/what-is-bot-management/)
  * [什么是凭据填充？](https://www.cloudflare.com/zh-cn/learning/bots/what-is-credential-stuffing/)
  * [什么是内容抓取？](https://www.cloudflare.com/zh-cn/learning/bots/what-is-content-scraping/)


#### 了解云
“云”是通过互联网访问的服务器，以及在这些服务器上运行的软件和数据库。云服务器分布在全球各地的数据中心。
  * [什么是云？](https://www.cloudflare.com/zh-cn/learning/cloud/what-is-the-cloud/)
  * [什么是多云？](https://www.cloudflare.com/zh-cn/learning/cloud/what-is-multicloud/)
  * [什么是混合云？](https://www.cloudflare.com/zh-cn/learning/cloud/what-is-hybrid-cloud/)
  * [什么是云防火墙？](https://www.cloudflare.com/zh-cn/learning/cloud/what-is-a-cloud-firewall/)


#### 了解 Zero Trust
不同于基于边界的传统网络安全，Zero Trust 安全默认不信任任何人和任何设备。了解组成 Zero Trust 架构的原则和技术。
  * [什么是 Zero Trust 安全？](https://www.cloudflare.com/zh-cn/learning/security/glossary/what-is-zero-trust/)
  * [什么是 ZTNA？](https://www.cloudflare.com/zh-cn/learning/access-management/what-is-ztna/)
  * [什么是 CASB？](https://www.cloudflare.com/zh-cn/learning/access-management/what-is-a-casb/)
  * [什么是数据丢失防护？](https://www.cloudflare.com/zh-cn/learning/access-management/what-is-dlp/)


#### 了解 SASE
安全访问服务边缘(SASE )是一种 IT 模型，将软件定义广域网与核心安全服务相结合，并在云边缘交付。了解 SASE 解决方案的核心能力。
  * [什么是 SASE？](https://www.cloudflare.com/zh-cn/learning/access-management/what-is-sase/)
  * [什么是 ZTNA？](https://www.cloudflare.com/zh-cn/learning/access-management/what-is-ztna/)

  * [什么是 NGFW？](https://www.cloudflare.com/zh-cn/learning/cloud/ngfw-vs-fwaas/)


#### 了解网络层
