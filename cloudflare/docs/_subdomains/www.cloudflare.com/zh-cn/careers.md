### 我们的价值
Cloudflare 相信，凭借优秀的团队、智能的技术和忠实用户，我们可以解决互联网上最为重大的问题。
#### 坚持原则
**我们坚持原则。** 我们以帮助建设更美好的互联网为己任，严格履行这个大胆无畏、雄心勃勃的使命。我们以全球思维方式创造产品和功能，并倡导推动采用最新标准的重要创新技术。
#### 求知若渴
**我们求知若渴。** 我们的团队由具有开拓精神的创新者组成，以浓厚兴趣和学习欲望来迎接互联网上最严峻的挑战。我们致力于提供卓越的客户服务，并以别出心裁、技术精湛的方式解决客户问题。
#### 公开透明
**我们公开透明。** 我们相信向客户隐瞒重要信息并无益处，始终优先考虑清晰、开放的沟通。最重要的是，我们在犯错时勇于承担责任，也会竭尽全力改正并从中吸取教训。
## Cloudflare 能力

Cloudflare 能力概述了我们在衡量成功、提供反馈和奖励绩效时所重视和参考的行为。它们是构建一种包容性公司文化的基础组成部分。
绩效 = 结果 + 行为 
评估绩效时，我们会评估**结果** 。然而，我们还考虑我们的工作方式和良好表现的标准，即行为。重要的不仅仅是做什么，还有做的方式。

### 我们的招聘流程
![招聘流程](https://cf-assets.www.cloudflare.com/slt3lc6tev37/234bZCgTnXpiSBQjr1YBwe/ad9be9a5f50f3a80b3efd50510c6eab5/OUTLINED_Orange_BDES_4945_Update_Visual_Elements_for_Careers_Site_hiring_process_alpha_r01_zh-CN_20230906.svg)
#### 认识团队
我们设计的招聘流程让你有机会认识 Cloudflare 团队中将与你直接合作的不同成员：未来的经理，团队同事，以及关键利益相关者。  
  
这些对话将帮助我们了解：你如何思考，你对什么充满热情，你能为团队带来什么技能和创新的问题解决能力。我们也希望让你了解我们——我们的面试官会随时回答你的所有问题！
#### Orange Cloud 面试
招聘流程中将包括一次 Orange Cloud 面试，重点在于 Cloudflare 能力和我们重视的行为。面试官会要求你举例说明你如何工作并产生影响，而不是评估你的职位特定技能、知识或经验。
那么，你如何准备这次面试呢？考虑一下你是如何在日常工作中展现这些价值观的，反思一下最近的情况，你是否从这些经历中吸取了教训，如果这些事情再次发生，你是否会采取不同的做法。
## 我们的工作方式和地点
![Illustration of a Cloudflare employee working from home](https://cf-assets.www.cloudflare.com/slt3lc6tev37/5ImdkAzqYkxBrYV35VR9bS/ad614138571dab7ebe5ecc8ec0239cd7/Zero_Trust_Solutions.png)
**我们为员工赋能，无论身处何地，均能出色地完成工作。**
我们致力于发展一支分布式、采用灵活工作方式的全球团队。以**公平** 和**包容** 的方式实现这一点对我们的成功至关重要。我们确定了员工的两种工作方式。这些工作方式使团队有机会建立符合其目标并能促进协作的最优工作安排。
![Illustration of a Cloudflare employee working from home](https://cf-assets.www.cloudflare.com/slt3lc6tev37/5ImdkAzqYkxBrYV35VR9bS/ad614138571dab7ebe5ecc8ec0239cd7/Zero_Trust_Solutions.png)
#### Hub 内
**您在居家工作和本地办公室工作之间灵活分配时间。**   
  
这些员工与特定的 Cloudflare Hub 相关联，但居家工作和到办公室工作的时间频率，取决于团队的工作安排。有些团队需要身处办公室以实现他们的目标。这些团队成员与特定 Cloudflare 办公室地点相关联，大部分时间在办公室工作。
#### 分散
**您可在受雇国家/地区任何地方工作，不需要进驻 Hub。**   
  
有些岗位不需要在 Cloudflare Hub 工作，可以完全远程工作。这些团队成员不与特定地点相关联，但也欢迎偶尔到办公室工作。
