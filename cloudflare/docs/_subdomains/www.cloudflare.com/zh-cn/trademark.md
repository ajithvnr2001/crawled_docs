Cloudflare 商标指南
#### Cloudflare 品牌不仅代表我们的产品与服务，也被赋予了更多意义，它是我们公司为建设更加美好的互联网而不懈努力的重要体现。
这些指南适用于希望在任何宣传、商业、教育或参考材料中使用 Cloudflare 商标或徽标的 Cloudflare 客户、开发人员、授权经销商和其他方。除非依据这些准则获得明确授权或者事先获得 Cloudflare 允许使用的书面许可，否则禁止使用 Cloudflare 商标和徽标。
Cloudflare 商标和徽标是我们宝贵的知识产权资产。为了维护和保护 Cloudflare 品牌，正确使用我们的商标和徽标至关重要。Cloudflare 独家拥有因使用 Cloudflare 商标和徽标而产生的任何商誉。

#### 允许的使用方式
##### 以文字形式提及 Cloudflare 产品和服务
您可以仅限文字的形式（文字标记，而非徽标）使用 Cloudflare 商标来标识 Cloudflare 产品或服务，但须遵守以下使用指南。使用 Cloudflare 标识（而非使用下述 Web 徽章）需要取得我们的书面许可。  
  
  
  

##### 作为公司名称提及 Cloudflare, Inc.
Cloudflare, Inc. 是公司/商号名称。您可以在书面材料中作为公司名称来提及 Cloudflare, Inc.：首先使用带有股份有限公司标识的完整商号名称（即“Cloudflare, Inc.”），然后在同一材料中再次提及时使用 Cloudflare（省略“Inc.”标识）。在作为公司名称提及 Cloudflare 时，请勿将 ® 符号与“Cloudflare”一起使用。  
  
  

#####    
Cloudflare 客户使用 Web 徽章
您可使用 Cloudflare Web 徽章来告知访问者，您的网站已得到 Cloudflare 服务的保护与加速。您可以从[此页面](https://www.cloudflare.com/zh-cn/press-kit/)获取 Cloudflare Web 徽章。请勿以任何方式更改 Cloudflare Web 徽章（例如，拉长加宽或改变颜色等）。  
  
  
  

##### 授权经销商和合作伙伴使用 Cloudflare 商标
如果您是 Cloudflare 的授权经销商或合作伙伴，并且与我们订立的协议允许您使用 Cloudflare 商标，您必须遵循协议中规定的要求。如果您的协议未向您提供特殊的商标使用指南，请遵循以下指南。
请注意，转售 Cloudflare 服务需要与 Cloudflare 签订经销商协议。如果您不是授权经销商或合作伙伴，您不得表明或使用 Cloudflare 商标来表明您是 Cloudflare 经销商或合作伙伴。  
  
  
  

##### Cloudflare 提供商和供应商使用 Cloudflare 商标
未经我们书面许可，Cloudflare 的提供商和供应商不得将 Cloudflare 商标用于提供给 Cloudflare 的产品和服务。如有关于审批流程的任何疑问，请联系您的 Cloudflare 代表。如果您已取得 Cloudflare 允许使用 Cloudflare 商标的书面许可，则须遵循以下指南，除非您以书面形式获得特殊的商标使用指南。
#### 经允许后，我可以如何使用这些商标？
  * 所有 Cloudflare 商标首次出现在文本中时应进行正确标识（使用 ®、™ 或 ℠）。
  * 附上适当的商标归属声明，例如：“Cloudflare、Cloudflare 徽标和 Cloudflare Workers 是 Cloudflare, Inc. 在美国和其他司法管辖区的商标和/或注册商标”。此声明应放在您使用 Cloudflare 商标的第一页的底部。
  * 不得更改 Cloudflare 的拼写，并且首字母 C 应始终大写。
  * “Cloudflare”不应用作品牌名称的一部分，不可与连字符一起使用，也不能用在应用程序或其他产品的名称中，但可用在引用性短语中，例如：“runs on”（运行于）、“for use with”（可搭配）、“for”（适用于）或“compatible with”（兼容）。
    * 错误：“iCloudflare”
    * 错误：“My Cloudflare App”
    * 正确：“My App for Cloudflare®”
    * 正确：“Hosting Company’s Special Promotion for Cloudflare® 订阅”
  * 如果与第三方徽标一起使用，则“for Cloudflare”的尺寸必须小于第三方徽标。
  * Cloudflare 商标应用作形容词，后跟适当的通用术语；绝不可以复数形式或所有格形式使用。
    * 错误：“Cloudflare Optimizer”
    * 正确：“Cloudflare 服务”
  * Cloudflare 商标绝不可用作动词。
    * 错误：“we Cloudflared our site”（我们 Cloudflare 了我们的网站。）
    * 正确：“我们利用 Cloudflare 服务使我们的网站变得更更加快速、安全，而且更加智能。”


#### 使用 Cloudflare 商标时应该避免什么？
  * 只有如实引用方可接受，禁止误导性引用。例如，如果实际并未使用，则不得陈述某网站使用了 Cloudflare 服务和应用程序。
  * 未经明确书面许可，您在使用任何 Cloudflare 商标或徽标时不得暗示 Cloudflare 与第三方产品或服务存在隶属关系或为其提供背书、赞助或支持。
  * 不得以贬损方式使用 Cloudflare 商标、图形符号、徽标、文字或图标。
  * 在任何情况下，不得将与 Cloudflare 商标完全相同、近似或容易混淆的字母字符串用作域名、用户代理或 Cookie 的一部分。例如，cloudfliare.com 几乎完全相同，且容易引起混淆。此规则的任何例外都需要获得 CEO、CTO 或 CSO 批准。
  * 第三方不可使用变体或拼写错误，或以任何方式引起对 Cloudflare 商标的初始利益混淆。
  * 除授权合作伙伴或授权经销商外，第三方不得使用 Cloudflare 标记或拼写错误来竞标关键字、Google AdWords 或其他定向广告系统。第三方也不得在域名、任何搜索引擎优化、元标记、搜索词、代码或其他虚假陈述中使用 Cloudflare 标记。
  * 不得在违反任何法律或法规的网站上或材料中展示 Cloudflare 商标或品牌。
  * 不得将 Cloudflare 商标或品牌融合到自己的产品名称、服务名称、商标、徽标或公司名称中。
  * 不得在待售商品上使用 Cloudflare 商标（例如，销售 T 恤、马克杯等）
  * 不得修改或缩写 Cloudflare 商标，将它们与任何其他符号、文字或图像组合，或将它们整合到标语或口号中。
