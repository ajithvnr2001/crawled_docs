# Cloudflare 为高风险网站提供网络安全保护
从事艺术、人权、公民社会、新闻工作或民主工作的组织可申请加入 Project Galileo，获得 Cloudflare 的免费网络安全保护。
[立即申请](https://www.cloudflare.com/galileo/#galileoapplication)
## 确保高危公共利益团体保持在线
Cloudflare 于 2014 年启动 Project Galileo 项目，旨在抗击针对重要但脆弱的目标（例如人道主义组织、公民社会和人权维护者）发起的破坏性网络攻击。 
通过 Project Galileo， Cloudflare 为超过 2900 个易受攻击的互联网资产提供免费、强大的安全防护，保护其免受 DDoS 和其他网络攻击破坏。 
互联网是传播和扩展思想的强大工具。当记者、社会活动人士和少数群体不断被旨在使他们下线的恶意流量所淹没时，互联网再也无法兑现其承诺。 
这些组织常常会面对强大且根深蒂固的对手发动的攻击，但这些组织运作预算有限。 为保护参与者免予潜在抵制，Cloudflare 不会在未经明确允许许可下公开参与 Project Galileo 的站点。 
如得到我们受信任合作伙伴之一引荐或批准，我们就会通过 Project Galileo 向相关组织提供服务。这种接纳不需要、也不应当被理解为我们全部多元化合作伙伴的认可。
