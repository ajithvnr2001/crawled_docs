###### 大规模自定义

无需为客户代码执行建立专门的基础设施和工程团队。Workers for Platforms自动按需扩展。

![Icon Tile - Success 产品](https://www.cloudflare.com/cdn-cgi/image/format=auto/https://cf-assets.www.cloudflare.com/v2/image/8a1rrgeek175javtc1gqoqj212/icon_tile_premium-success-offering.png)

###### 给您的客户赋能

客户可自定义体验、基于事件触发操作或扩展您的平台，而无需借助您的工程师编写代码。

###### 安全运行不受信任的代码

客户代码在一个隔离的环境中执行，具有内置控制，消除了安全性和合规性风险。

## 大规模部署和运行客户代码

Workers for Platforms 提供托管执行环境，让您的客户可在 Cloudflare 全球网络上部署并运行自有代码。

使用 Workers 和包括存储、数据库和日志记录在内的基本组件构建自定义逻辑、事件驱动的自动化和[全栈应用](https://www.cloudflare.com/zh-cn/developer-platform/solutions/hosting/)。
