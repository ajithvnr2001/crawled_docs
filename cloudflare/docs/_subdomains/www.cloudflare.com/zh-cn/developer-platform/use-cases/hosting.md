## Cloudflare 应用托管常见问题解答

#### Cloudflare 提供哪些应用托管服务？

Cloudflare 提供一系列托管解决方案，满足从个人业余项目到大型企业应用的各种需求。Cloudflare 上构建和托管的网站均安全可靠且性能卓越，无论用户身处何地。

#### Cloudflare Pages 的工作原理是什么？

[Cloudflare Pages](https://www.cloudflare.com/zh-cn/developer-platform/products/pages/) 是一种简单快捷的构建、测试和部署方式。它使您能够构建全栈应用并即时部署代码。它与其他[Cloudflare](https://www.cloudflare.com/zh-cn/developer-platform/) 开发人员工具和服务无缝集成，让开发人员能够以最少的配置构建静态和动态应用。Pages 提供无限量席位，让开发人员能够轻松协作开发应用。

#### 什么是 Cloudflare Images？

[Cloudflare Images](https://www.cloudflare.com/zh-cn/developer-platform/products/cloudflare-images/) 是一款端到端的图像托管解决方案。它让应用开发人员能够使用单个统一产品，经济高效地存储图像、调整图像大小、优化并交付图像。

#### 如何在 Cloudflare 平台上托管视频？

Cloudflare 客户可以使用 [Cloudflare Stream](https://www.cloudflare.com/zh-cn/developer-platform/products/cloudflare-stream/) 上传、存储、编码和交付[直播](https://www.cloudflare.com/zh-cn/developer-platform/solutions/live-streaming/)/点播视频。Stream 客户只需为传输和存储的视频时长（以分钟为单位）付费，无需支付额外的编码或带宽费用。

#### 什么是 Cloudflare R2？它如何提高应用性能？

[Cloudflare R2](https://www.cloudflare.com/zh-cn/developer-platform/products/r2/) 是一款不收取出口费用的[对象存储](https://www.cloudflare.com/zh-cn/learning/cloud/what-is-object-storage/)服务。通过将应用资产直接存储在托管应用的 Cloudflare 上，可以减少从后端加载数据时的往返次数，并提高应用的整体性能。
