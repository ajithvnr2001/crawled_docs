## Soluciones personalizadas para tu campaña
Protege tu sitio web de ataques hostiles, usa el equilibrio de carga, y salvaguarda los datos internos esenciales de tu equipo con Cloudflare, todo desde el mismo panel de control intuitivo.
Entre las soluciones disponibles se incluyen:
Soporte de tiempo activo ininterrumpido Incluye mitigación de DDoS ilimitada y un punto de contacto de soporte dedicado.
**WAF** Incluye conjuntos de reglas OWASP y reglas propias de Cloudflare, así como compatibilidad con reglas de WAF y firewall personalizadas.
**Bloqueo de tráfico personalizado** Bloquea a agentes de usuario específicos y las regiones donde se detecte tráfico problemático.
**Limitación de velocidad** Protege contra ataques de denegación de servicio, intentos de inicio de sesión por fuerza bruta y otros tipos de comportamientos abusivos dirigidos a la capa de aplicación.
**Modo "I'm Under Attack™** Aplicación instantánea de las protecciones contra ataques coordinados, además de soporte "I'm Under Attack" de nivel empresarial.
**Protección contra bots** Evita los bots automatizados y activa desafíos de CAPTCHA para garantizar que solo el tráfico legítimo llega a tu sitio.
**Soporte para subdominios** Facilita la gestión del rendimiento y la seguridad de Cloudflare para subdominios.
**CDN global** Aprovecha la red global de Cloudflare, que abarca 335 ciudades en más de 125 países para ofrecer tiempos de respuesta de milisegundos.
**Load Balancing** Enruta de forma dinámica el tráfico a diferentes servidores y nubes.
**Reglas de Cloudflare** Configura los ajustes de Cloudflare y ejecuta acciones específicas para las solicitudes que coincidan. El establecimiento de fechas de caducidad de la caché, la modificación de los niveles de seguridad de varias secciones de tu sitio y el reenvío de URL son solo algunos ejemplos de casos de uso.
**Registros de auditoría** Incluye acciones a nivel de cuenta como el inicio y el cierre de sesión, así como cambios de configuración realizados a través del panel de control de Cloudflare.
**Organización multiusuario** Gestiona tu cuenta de Cloudflare con varias cuentas, cada una con permisos granulares.
**Cloudflare Access** Permite que una campaña proteja, autentique y supervise el acceso de los usuarios a cualquier dominio, aplicación o ruta en Cloudflare, sin utilizar una VPN.
**Filtrado DNS con Cloudflare Gateway** Protege a los usuarios mientras navegan por Internet manteniendo el contenido malicioso alejado de tu red desde varias ubicaciones.
**Contacto de seguridad electoral** Este contacto específico de seguridad electoral se dirigirá a nuestro equipo de soporte, con una ruta escalable hacia el equipo de soluciones de seguridad.
### 4 prácticas recomendadas para proteger tu sitio web
##### Protege tu cuenta con la autenticación en dos fases (2FA)
Solicitar información extra para validar tu identidad al iniciar sesión evita que usuarios no autorizados accedan a datos confidenciales en tu cuenta.
[Habilita la autenticación en dos fases](https://support.cloudflare.com/hc/en-us/articles/200167906-Securing-user-access-with-two-factor-authentication-2FA-)
##### Asigna una nube naranja a tus registros de DNS 
Cuando tu registro de DNS tiene una nube naranja, Cloudflare actúa como servidor proxy para tu dominio. Esta práctica protege a tu servidor web de origen de picos de tráfico inesperados y ataques cibernéticos.
[Habilita la nube naranja](https://support.cloudflare.com/hc/en-us/articles/205177068-How-does-Cloudflare-work-)
##### Utiliza el cifrado SSL para proteger tus datos internos
Secure Socket Layer (capa de puertos seguros) es la tecnología de seguridad estándar para establecer una conexión cifrada entre un servidor web y un navegador. Con Cloudflare, tu sitio web puede estar habilitado para HTTPS con solo un clic.
[Más información sobre SSL de Cloudflare](https://support.cloudflare.com/hc/en-us/articles/200170416-End-to-end-HTTPS-with-Cloudflare-Part-3-SSL-options)
##### Activa tu firewall de aplicaciones web
Un firewall de aplicaciones web (WAF) funciona como un escudo entre la aplicación web e Internet, lo que te permite tomar la decisión de permitir el paso del tráfico entrante y saliente. Un WAF protege de ataques de inyección de código SQL, scripting entre sitios y falsificación de solicitud entre sitios.
[Habilitar Cloudflare Specials](https://support.cloudflare.com/hc/en-us/articles/200172016-Understanding-the-Cloudflare-Web-Application-Firewall-WAF-)
