## 複雑さはセキュリティの敵

**従来のSASEアーキテクチャが新たな技術的負債に**

分断されたネットワークを、分断されたツールでつぎはぎ的に補修しても、むしろ新たなすき間を生むだけです。第一世代のSASEは「シンプルさ」を約束しましたが、実際にはプロキシの寄せ集めや、ばらばらのポリシー管理に終わりました。AIによってデータの流れがますます加速する今、必要なのは **買収でつなぎ合わせた仕組みではなく、設計段階から統合されたアーキテクチャ** です。

## 真に統合されたSASE

**「プラットフォーム」の約束がついに実現**

Cloudflare Oneは、初期の[SASE](https://www.cloudflare.com/ja-jp/learning/access-management/what-is-sase/)プロバイダーが「できる」と言いながら実現できなかった、本当の意味での統合プラットフォームです。当社は、従来のセキュリティやネットワーク製品にありがちだった複雑さや運用の手間を、 **単一のコントロールプレーン** 、 **データプレーン** 、 **インフラストラクチャレイヤー** に統合することで解消します。導入しやすく、長く使い続けられる設計で、これまでにない一貫性のある運用体験を提供します。

### AIを安全に導入

単にAIを制限するだけでなく、大規模にAIを安全に活用できる環境を整備します。

  * **AIエージェントを統制** ：従業員、MCPサーバー、社内データ間の接続をいち早く統制できます。
  * **シャドーAIを制御** ：未承認のAIツールを検出し、アクセスを管理します。従業員を承認済みアプリにリダイレクトします。
  * **すべてのプロンプトを保護** ：AIに対するプロンプトの内容とその意図を分析し、企業の機密データが公開モデルに漏洩するのをブロックします。

### リモートアクセスを最新化

動作が重く安全性にも不安があるハイブリットワーカーの妨げとなる従来型VPNに頼るのはやめましょう。ハイブリッドワークでも、IDを中心とした量子耐性のある安全なアクセスを、社内アプリやインフラに提供します。

  * **オンボーディングの高速化** ：請負業者やBYOD従業員に、安全で煩わしさのないアクセスを数日ではなく数分ですばやく付与します。
  * **M &Aをスピードアップ** ：複雑なIPの重複調整やファイアウォールルールを排除し、買収したネットワークをより効率的に統合します。
  * **ランサムウェアを阻止** ：広範囲なネットワークアクセスをきめ細かなゼロトラストルールに置き換え、脅威の横方向の拡散を防ぎます。



[詳細を見る](https://www.cloudflare.com/ja-jp/sase/use-cases/vpn-replacement/)

![リモートアクセスを最新化](https://cf-assets.www.cloudflare.com/v2/image/3ji4n3rprp7at2kot2c9o5la5j/modernize_remote_access-image.svg)

### メールによるフィッシング攻撃をブロック

AIを活用したメールセキュリティで、フィッシング、なりすまし、マルウェア、ビジネスメール詐欺（BEC）などの脅威を、ユーザーの受信箱に到達する前にブロックします。

  * **高精度にブロック** ：Microsoft 365やGoogle Workspaceの標準対策をすり抜ける巧妙な標的型フィッシング脅威を阻止します。
  * **より迅速なデプロイ** ：最小限の設定とチューニングで、柔軟なMXおよびAPIデプロイメント方法により即座に開始できます。
  * **ワークスペースのセキュリティを拡張** ：危険なWebリンクの分離など、メールや他のコラボレーションアプリにネイティブSASE制御を追加します。



[詳細を見る](https://www.cloudflare.com/ja-jp/sase/use-cases/multi-channel-phishing/)

![メールによるフィッシング攻撃をブロック](https://cf-assets.www.cloudflare.com/v2/image/hftmh8tm994ira5e4pmhui830b/block_email_phishing_attacks-image.svg)

### Webブラウジングを保護

DNSおよびHTTPフィルタリングを実装して、リモートユーザーと支社をマルウェア、フィッシング攻撃、悪意のあるWebサイトから保護します。

  * **すぐに効果を実感** ：柔軟な導入方法により、インターネット上の脅威をブロックしながら、不要なアラートも減らし、短期間で成果を出せます。
  * **負担なく保護** ：世界[最速のパブリックDNSリゾルバー](https://www.dnsperf.com/#!dns-resolvers)を支えるネットワークと同じネットワークを使用して、柔軟なセキュリティルールを適用します。
  * **適正利用の徹底** ：企業およびゲストWi-Fiを保護し、安全でプライベートな訪問者エクスペリエンスを実現します。DNS設定を更新するだけです。



[詳細を見る](https://www.cloudflare.com/ja-jp/sase/use-cases/remote-workforces/)

## Cloudflare SASEに関するよくある質問

#### Cloudflare Oneとは？

Cloudflare Oneは、組織の従業員、AIエージェント、およびインフラを接続し保護するために設計された、俊敏な統合型SASEプラットフォームです。単一のコントロールプレーン、データプレーン、インフラレイヤーを提供することで、従来型のセキュリティとネットワーキングの摩擦や技術的負債を解消します。

#### Cloudflare Oneプラットフォームに含まれる主要なネットワーキングおよびセキュリティサービスとは？

Cloudflare Oneは、ゼロトラストネットワークアクセス（ZTNA）、セキュアWebゲートウェイ（SWG）、クラウドアクセスセキュリティブローカー（CASB）、サービスとしてのネットワーク（NaaS）、サービスとしてのファイアウォール（FWaaS）といったSASEのコアサービスを統合します。また、リモートブラウザ分離（RBI）、データ損失防止（DLP）、メールセキュリティ、デジタル体験監視（DEM）も含まれます。AIセキュリティ、ポスト量子暗号（PQC）、負荷分散などのコンポーザブルな機能が組み込まれています。

#### CloudflareのSASEアーキテクチャが第一世代ソリューションと異なる点とは？

第一世代のSASEソリューションは、多くの場合、買収した各社製品を寄せ集めた結果、プロキシの寄せ集めや一貫性のないポリシーを提供します。これに対し、Cloudflare Oneはグローバルコネクティビティクラウド上に設計されており、コンポーザブルでプログラム可能なアーキテクチャを提供しており、セキュリティとネットワーキングの機能を数か月ではなく数時間でロールアウトすることができます。

#### Cloudflare Oneは、生成系AIを安全に導入できるよう企業をどのように支援するか？

このプラットフォームは、生成AIの利用状況を詳細に可視化して制御できるほか、未承認のツールを検出することでシャドーAIの管理に役立ちます。これは、モデルコンテキストプロトコル（MCP）サーバーへの接続を保護し、AIプロンプトの意図を分析して企業の機微データがパブリックモデルに漏洩するのをブロックできる、初のSASEプラットフォームです。

#### Cloudflare Oneが現代企業のコーヒーショップネットワーキングを実現する方法とは？

Cloudflare Oneは、面倒な作業をクラウドに移行することによって、高額なMPLS契約と複雑なハードウェアの必要性が排除されます。この「light branch, heavy クラウド」SASEモデルにより、どの場所でも同じレベルの一貫した接続性とセキュリティを実現できるのです。オフィスの接続は「意図通りに機能する」。Cloudflareのグローバルネットワークを介してトラフィックをルーティングすることで、企業は、すべてのユーザーに対して高性能なセキュリティを維持しながら、インフラを簡素化することができます。

#### CloudflareのSASEプラットフォームによるリモートアクセスのモダナイゼーションとは？

Cloudflare Oneは、扱いにくく、安全性も低いVPNを、内部アプリへのID優先で量子安全なアクセスに置き換えます。これにより、きめ細かなZero Trustルールによって脅威が水平展開するのを防ぎ、企業は請負業者やBYODユーザーに摩擦のないアクセスを数分で許可できます。

#### Cloudflare Oneによるメールベースの脅威への対処法とは？

Cloudflare Oneは、AIを活用したメールセキュリティを使用して、フィッシング、なりすまし、マルウェア、ビジネスメール詐欺（BEC）を阻止します。これらの保護は、電子メールに含まれる危険なWebリンクを分離するなど、組み込みのSASE制御を追加することで拡張可能です。

#### Cloudflare Oneプラットフォームによるグローバルな規模とパフォーマンスのサポートとは？

Cloudflareは、世界300以上の都市からSASEのフルサービスを提供しています。このグローバルなフットプリントは、Webの約20%を保護し、主要な生成AI企業の約80%を保護することで、比類ない脅威インテリジェンスとzero-day可視性を備えたプラットフォームを提供しています。
