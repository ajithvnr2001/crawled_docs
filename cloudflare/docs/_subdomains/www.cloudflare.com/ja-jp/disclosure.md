# リサーチャーの皆さんへ
##### Cloudflareはセキュリティ、プライバシー、透明性に真摯に取り組んでいます。
より良くより安全なインターネットの構築にお力をお貸しいただき、ありがとうございます。
## セキュリティとプライバシーの問題発見
Cloudflareの脆弱性や、セキュリティやプライバシーに関するその他の重大な問題を発見された方は、HackerOneがホストする当社のバウンティプログラムへご報告ください。
[HackerOneサイトを訪問する](https://hackerone.com/cloudflare)
## Cloudflareアカウント
お客様のCloudflareアカウントで、パスワードとログインの問題や、アカウントが「盗まれた」と思われるなどの問題が生じた場合は、当社のサポートサイトをご利用ください。
[サポートを利用する](https://support.cloudflare.com/)
不正行為に関する問題や法執行に関する問い合わせについては、当社の[不正使用関連ポリシー](https://www.cloudflare.com/ja-jp/trust-hub/abuse-approach/)をご確認ください。
