# ラーニングセンター
サイバーセキュリティとCloudflare経由でインターネットが機能する仕組みに関するリソース[Cloudflareとは？](https://www.cloudflare.com/ja-jp/learning/what-is-cloudflare/ "https://www.cloudflare.com/learning/what-is-cloudflare/")
#### DDoS攻撃について理解する
分散サービス妨害（DDoS）攻撃では、ネットワーク化されたコンピューターが連動してアクセスポイントに過負荷を与え、正当なユーザーがサービスにアクセスできないようにします。
  * [DDoS攻撃とは？](https://www.cloudflare.com/ja-jp/learning/ddos/what-is-a-ddos-attack/)
  * [DDoSボットネットとは？](https://www.cloudflare.com/ja-jp/learning/ddos/what-is-a-ddos-botnet/)
  * [DDoSの仕組み](https://www.cloudflare.com/ja-jp/learning/ddos/ddos-attack-tools/how-to-ddos/)
  * [DNSフラッド](https://www.cloudflare.com/ja-jp/learning/ddos/dns-flood-ddos-attack/)


#### CDNについて理解する
コンテンツ配信ネットワーク（CDN）では、複数の分散サーバーが連携してインターネットコンテンツを効率的に配信することで、読み込み速度と信頼性を高めます。
  * [CDNとは？](https://www.cloudflare.com/ja-jp/learning/cdn/what-is-a-cdn/)
  * [CDNパフォーマンス](https://www.cloudflare.com/ja-jp/learning/cdn/performance/)
  * [CDN SSL TLSのセキュリティ](https://www.cloudflare.com/ja-jp/learning/cdn/cdn-ssl-tls-security/)
  * [CDNの信頼性](https://www.cloudflare.com/ja-jp/learning/cdn/cdn-load-balance-reliability/)


#### DNSについて理解する
ドメインネームシステム（DNS）とは、いわばインターネットの電話帳のようなものです。ドメイン名を介してユーザーとWebコンテンツをつなぐ世界的規模のネットワークです。
  * [DNSとは？](https://www.cloudflare.com/ja-jp/learning/dns/what-is-dns/)
  * [DNSセキュリティ](https://www.cloudflare.com/ja-jp/learning/dns/dns-security/)
  * [DNSサーバータイプ](https://www.cloudflare.com/ja-jp/learning/dns/dns-server-types/)
  * [DNSレコード](https://www.cloudflare.com/ja-jp/learning/dns/dns-records/)


#### Webアプリケーションのセキュリティについて理解する
インターネットの特性により、Webアプリケーションにはさまざまな攻撃に対する脆弱性があります。Webアプリケーションのセキュリティでは、包括的なアプローチを使用して攻撃を軽減する必要があります。
  * [Webアプリケーションセキュリティとは？](https://www.cloudflare.com/ja-jp/learning/security/what-is-web-application-security/)
  * [データ漏えいとは？](https://www.cloudflare.com/ja-jp/learning/security/what-is-a-data-breach/)
  * [メルトダウン／スペクター](https://www.cloudflare.com/ja-jp/learning/security/threats/meltdown-spectre/)
  * [ブルートフォースアタック（総当たり攻撃）](https://www.cloudflare.com/ja-jp/learning/security/threats/brute-force-attack/)


#### パフォーマンスについて理解する
すばやく読み込まれるWebアプリケーションでは、コンバージョン率が高くなり、SEOパフォーマンスが向上します。アプリケーションのパフォーマンスに影響を与える要因について学びます。
  * [サイトの速度が重要な理由とは？](https://www.cloudflare.com/ja-jp/learning/performance/why-site-speed-matters/)
  * [Webサイトの速度がSEOを押し上げる仕組みは？](https://www.cloudflare.com/ja-jp/learning/performance/how-website-speed-boosts-seo/)
  * [Webサイトをモバイルでも使いやすくするには？](https://www.cloudflare.com/ja-jp/learning/performance/how-to-make-a-site-mobile-friendly/)
  * [遅延とは？](https://www.cloudflare.com/ja-jp/learning/performance/glossary/what-is-latency/)


#### サーバーレスについて理解する
サーバーレスコンピューティングによって、ユーザーはインフラが何であるかを気にすることなく、コードを書き込んだりデプロイしたりすることができます。サーバーレスアーキテクチャを選ぶ開発者が増えている理由をご覧ください。
  * [サーバーレスコンピューティングとは？](https://www.cloudflare.com/ja-jp/learning/serverless/what-is-serverless/)

  * [エッジコンピューティングとは？](https://www.cloudflare.com/ja-jp/learning/serverless/glossary/what-is-edge-computing/)


#### SSLについて理解する
現在TLSと呼ばれるSSLは、サーバーとクライアント間のインターネット通信を保護するためにHTTPプロトコル上で実行される暗号化プロトコルです。
  * [SSLとは？](https://www.cloudflare.com/ja-jp/learning/ssl/what-is-ssl/)
  * [TLSとは？](https://www.cloudflare.com/ja-jp/learning/ssl/transport-layer-security-tls/)

  * [[HTTPSとは？](https://www.cloudflare.com/ja-jp/learning/ssl/what-is-https/)


#### ボットについて理解する
ボットとは、Webを閲覧できる自動化されたアプリケーションのことを意味します。検索エンジンのクローラーといった一部のボットは有益なものです。しかし、さまざまな方法でサイトやアプリケーションに害を及ぼす可能性のある悪意のあるボットも存在します。
  * [ボットとは？](https://www.cloudflare.com/ja-jp/learning/bots/what-is-a-bot/)
  * [ボット管理とは？](https://www.cloudflare.com/ja-jp/learning/bots/what-is-bot-management/)

  * [コンテンツスクレイピングとは？](https://www.cloudflare.com/ja-jp/learning/bots/what-is-content-scraping/)


#### クラウドについて理解する
「クラウド」という用語は、インターネット経由でアクセスするサーバーとそうしたサーバー上で実行されるソフトウェアやデータベースのことを指します。クラウドサーバーは世界中のデータセンター内にあります。
  * [クラウドとは？](https://www.cloudflare.com/ja-jp/learning/cloud/what-is-the-cloud/)
