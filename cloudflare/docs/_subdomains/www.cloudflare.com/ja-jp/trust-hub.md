# Cloudflareの信頼ハ⁠ブ
##### お客様の信頼を得るために役立つポリシー、技術、認定
![Zero Trust Integrations  ](https://cf-assets.www.cloudflare.com/slt3lc6tev37/2Oomvz9nxbYQ6wGDcwQwFl/c451752ef1193f42716653c3629a394b/Enterprise.svg)
Cloudflareのビジネスにおいて基盤を成しているのは信頼です。私たちは当社のネットワーク上を移動する個人データの重要性を尊重し、そうしたデータをどのように取り扱い、安全に保つかについて透明であることで、ユーザーの信頼を得ています。
この信頼を支える当社のポリシー、技術、サードパーティの認定について詳しく知るために、ご一読ください。
![Zero Trust Integrations  ](https://cf-assets.www.cloudflare.com/slt3lc6tev37/2Oomvz9nxbYQ6wGDcwQwFl/c451752ef1193f42716653c3629a394b/Enterprise.svg)
