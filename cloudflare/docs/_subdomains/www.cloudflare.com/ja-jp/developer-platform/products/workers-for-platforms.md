# Workers for Platforms

プラットフォームをプログラマブルに

###### プラットフォームをプログラマブルに

Cloudflareのグローバルネットワーク上でカスタムコードをスケーラブルに記述、デプロイ、実行しよう。

[構築を開始する](https://dash.cloudflare.com/account-id/workers-for-platforms)

[ドキュメントを読む](https://developers.cloudflare.com/cloudflare-for-platforms/workers-for-platforms/)

## Workers for Platformsの利点

![ABM - Stryker - CloudflareでAIイニシアチブを保護 - 6つのアイコン - カード1 - アイコン](https://www.cloudflare.com/cdn-cgi/image/format=auto/https://cf-assets.www.cloudflare.com/v2/image/b429qo38r908hfbimtgte9ds52/icon_tile_internet-globe.png)

###### 大規模なカスタマイズ

顧客コード実行のために、専任インフラおよびエンジニアリングチームを構築する必要はありません。Workers for Platformsは、オンデマンドで自動的にスケールします。

![アイコンタイル - Successサービス](https://www.cloudflare.com/cdn-cgi/image/format=auto/https://cf-assets.www.cloudflare.com/v2/image/8a1rrgeek175javtc1gqoqj212/icon_tile_premium-success-offering.png)

###### 顧客の権限を強化

顧客によるエクスペリエンスのカスタマイズ、イベントに応じたアクショントリガー、エンジニアのコード記述不要のプラットフォームの拡張が可能になります。

![セキュリティシールド保護チェックマーク - アイコン](https://www.cloudflare.com/cdn-cgi/image/format=auto/https://cf-assets.www.cloudflare.com/v2/image/glu3so81dd4pv78hs6hfngvl7o/icon_tile_security-shield-protection.png)

###### 信頼できないコードを安全に実行

お客様のコードは隔離された環境で実行され、セキュリティおよびコンプライアンスのリスクを排除するために、組み込みの制御が可能です。

仕組み

## 顧客コードを大規模にデプロイして実行

Workers for Platformsは、Cloudflareのグローバルネットワーク上でお客様の顧客が独自のコードをデプロイし実行できる、管理された実行環境を提供します。

Workersやストレージ、データベース、ログ機能などの基本機能を使って、カスタムロジックやイベント駆動の自動処理、[フルスタックアプリケーション](https://www.cloudflare.com/ja-jp/developer-platform/solutions/hosting/)を構築。

![プログラム可能なプラットフォームのイラスト](https://cf-assets.www.cloudflare.com/v2/image/angic07pr57s18ma4okumbkh5n/programmable-platforms-2.svg)
