# アプリケーションホスティングサービス

Cloudflareでアプリケーションをホストして、グローバルにデプロイ。335か所のグローバルロケーションで、アプリケーションを保存、最適化、実行しましょう。

Cloudflareでは趣味のユーザー、スタートアップ、または即座にデプロイし、自動でスケールする環境を求める企業向けのアプリケーションホスティングソリューションを提供しています。

[無料で始めましょう](https://dash.cloudflare.com/sign-up/workers-and-pages%20)

## Pages

Cloudflare Pagesでコーディングをホストすることで、わずかな時間でフルスタックアプリケーションを構築。

ユーザー数無制限だから、開発でもコラボでもユーザー数を心配する必要はありません。Cloudflareの開発者向けツールやサービスをシームレスに統合し、静的・動的アプリケーションを最小限の構成で、即座に提供しましょう。

## 画像

シンプルに画像をホスティング。Cloudflare Imagesは、機能一体型製品を使用して、画像を効率良く大規模に保存、サイズ変更、最適化、配信できるエンドツーエンドソリューションを提供しています。

##  Stream

動画のホストは手間なく簡単、視聴者にはスムーズな鑑賞体験を。Streamを使用すると、1つのAPIコストで効率的にライブ動画とオンデマンド動画のアップロード、保存、エンコーディング、配信を実現できます。課金対象は配信および格納された動画の分数のみ。エンコーディングや帯域幅への追加料金は一切ありません。

[詳細を見る ](https://www.cloudflare.com/ja-jp/developer-platform/products/cloudflare-stream/)

## R2

Cloudflareではエグレス料金のかからないオブジェクトストレージで、Cloudflareに直接アプリケーションアセットを保存。アプリケーションがホストされている場所にアセットを保存することで、ラウンドトリップの量が減り、アプリケーションのパフォーマンスが向上します。

[詳細を見る ](https://www.cloudflare.com/ja-jp/developer-platform/products/r2/)

## Cloudflareアプリケーションホスティングに関するよくある質問

#### Cloudflareがアプリケーションホスティングに提供しているサービスとは？

Cloudflareは、趣味のプロジェクトから大規模な企業向けアプリケーションまで、幅広いニーズに対応したホスティングソリューションを提供しています。Cloudflare上で構築され、ホストされているWebサイトは、世界中どこからアクセスしてもセキュアで高速に動作します。

#### Cloudflare Pagesの仕組みは？

[Cloudflare Pages](https://www.cloudflare.com/ja-jp/developer-platform/products/pages/)は、フルスタックアプリケーションをシンプルかつ高速な構築、テスト、デプロイを支援するサービスです。フルスタックアプリケーションを構築し、コードを即座にデプロイできます。また、[Cloudflareの他の開発者向けツールやサービス](https://www.cloudflare.com/ja-jp/developer-platform/)とのシームレスな連携が可能で、最小限の構成で静的および動的なアプリケーションを構築できる環境を開発者に提供します。Pagesは無制限のユーザー数をサポートしているため、開発者がアプリケーションの開発で簡単に共同作業を行うことができます。

#### Cloudflare Imagesとは？

[Cloudflare Images](https://www.cloudflare.com/ja-jp/developer-platform/products/cloudflare-images/)は、画像をホスティングするためのエンドツーエンドのソリューションです。アプリ開発者は、このサービスによって画像の保存、サイズ変更、最適化、配信を、ひとつの仕組みで効率よく行えます。

#### Cloudflareで動画をホストするには？

Cloudflareのお客様は、[Cloudflare Stream](https://www.cloudflare.com/ja-jp/developer-platform/products/cloudflare-stream/)を使用することで、[ライブ](https://www.cloudflare.com/ja-jp/developer-platform/solutions/live-streaming/)およびオンデマンドの動画をアップロード、保存、エンコード、配信することができます。Streamの料金は、配信および保存した動画の長さ（分）に対してのみ発生します。エンコーディングや帯域幅に対して料金が発生することはありません。

#### Cloudflare R2とは？どのような仕組みでアプリのパフォーマンスを向上するのですか？

[Cloudflare R2](https://www.cloudflare.com/ja-jp/developer-platform/products/r2/)は、エグレス料金がかからない[オブジェクトストレージ](https://www.cloudflare.com/ja-jp/learning/cloud/what-is-object-storage/)です。アプリケーションがホストされているCloudflareにアプリケーションのデータを直接格納することでデータ読み込み時のラウンドトリップを回避できるため、全体的なパフォーマンスを向上させることができます。
