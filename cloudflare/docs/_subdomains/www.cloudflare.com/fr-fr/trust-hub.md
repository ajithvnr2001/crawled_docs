# Le centre de confiance de Cloudflare
##### Les politiques, les technologies et les certifications qui nous aident à gagner la confiance des clients
![Zero Trust Integrations  ](https://cf-assets.www.cloudflare.com/slt3lc6tev37/2Oomvz9nxbYQ6wGDcwQwFl/c451752ef1193f42716653c3629a394b/Enterprise.svg)
La confiance constitue la pierre angulaire de l'activité de Cloudflare. Nous gagnons la confiance de nos utilisateurs en respectant le caractère sacré des données personnelles qui transitent par notre réseau, ainsi qu'en faisant preuve de transparence sur la manière dont nous traitons et sécurisons ces données.
Poursuivez votre lecture pour découvrir les politiques, technologies et certifications tierces qui rendent cette confiance possible.
![Zero Trust Integrations  ](https://cf-assets.www.cloudflare.com/slt3lc6tev37/2Oomvz9nxbYQ6wGDcwQwFl/c451752ef1193f42716653c3629a394b/Enterprise.svg)
