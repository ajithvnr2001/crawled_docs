#### Learn about DDoS attacks
In a distributed denial-of-service (DDoS) attack, a network of computers work in tandem to overflow an access point and prevent legitimate users from accessing a service.
  * [What is a DDoS attack?](https://www.cloudflare.com/nl-nl/learning/ddos/what-is-a-ddos-attack/)
  * [What is a DDoS botnet?](https://www.cloudflare.com/nl-nl/learning/ddos/what-is-a-ddos-botnet/)
  * [How to DDoS](https://www.cloudflare.com/nl-nl/learning/ddos/ddos-attack-tools/how-to-ddos/)
  * [DNS flood](https://www.cloudflare.com/nl-nl/learning/ddos/dns-flood-ddos-attack/)


#### Learn about CDNs
In a content delivery network (CDN), a set of distributed servers work together to efficiently deliver Internet content, improving loading speed and reliability.
  * [What is a CDN?](https://www.cloudflare.com/nl-nl/learning/cdn/what-is-a-cdn/)
  * [CDN performance](https://www.cloudflare.com/nl-nl/learning/cdn/performance/)
  * [CDN SSL TLS security](https://www.cloudflare.com/nl-nl/learning/cdn/cdn-ssl-tls-security/)
  * [CDN reliability](https://www.cloudflare.com/nl-nl/learning/cdn/cdn-load-balance-reliability/)


#### Learn about DNS
The domain name system (DNS) is often referred to as a phone book for the Internet. It's the worldwide network that connects users to web content via domain names.
  * [What is DNS?](https://www.cloudflare.com/nl-nl/learning/dns/what-is-dns/)
  * [DNS security](https://www.cloudflare.com/nl-nl/learning/dns/dns-security/)
  * [DNS server types](https://www.cloudflare.com/nl-nl/learning/dns/dns-server-types/)
  * [DNS records](https://www.cloudflare.com/nl-nl/learning/dns/dns-records/)


#### Learn about web application security
The nature of the Internet makes web applications vulnerable to a number of attacks. Web application security involves using a holistic approach to mitigate attacks.
  * [What is web application security?](https://www.cloudflare.com/nl-nl/learning/security/what-is-web-application-security/)
  * [What is a data breach?](https://www.cloudflare.com/nl-nl/learning/security/what-is-a-data-breach/)

  * [Brute force attack](https://www.cloudflare.com/nl-nl/learning/security/threats/brute-force-attack/)


#### Learn about performance
Web applications that load quickly see higher conversion rates and better SEO performance. Learn about the factors that impact application performance.
  * [Why does site speed matter?](https://www.cloudflare.com/nl-nl/learning/performance/why-site-speed-matters/)

#### Learn about serverless
Serverless computing allows users to write and deploy code without the hassle of worrying about the underlying infrastructure. Learn why more and more developers are opting for a serverless architecture.
  * [What is serverless computing?](https://www.cloudflare.com/nl-nl/learning/serverless/what-is-serverless/)
  * [Why use serverless?](https://www.cloudflare.com/nl-nl/learning/serverless/why-use-serverless/)

#### Learn about SSL
SSL, known today as TLS, is an encryption protocol that runs on top of the HTTP protocol to protect Internet communication between servers and clients.
  * [What is SSL?](https://www.cloudflare.com/nl-nl/learning/ssl/what-is-ssl/)
  * [What is TLS?](https://www.cloudflare.com/nl-nl/learning/ssl/transport-layer-security-tls/)
  * [What is an SSL certificate?](https://www.cloudflare.com/nl-nl/learning/ssl/what-is-an-ssl-certificate/)
  * [What is HTTPS?](https://www.cloudflare.com/nl-nl/learning/ssl/what-is-https/)


#### Learn about bots
Bots are automated applications that can browse the web. Some bots, such as search engine crawlers, are helpful. But there are also malicious bots which can harm sites and applications in a number of ways.
  * [What is a bot?](https://www.cloudflare.com/nl-nl/learning/bots/what-is-a-bot/)
  * [What is bot management?](https://www.cloudflare.com/nl-nl/learning/bots/what-is-bot-management/)

  * [What is content scraping?](https://www.cloudflare.com/nl-nl/learning/bots/what-is-content-scraping/)


#### Learn about the cloud
"The cloud" refers to servers that are accessed over the Internet, and the software and databases that run on those servers. Cloud servers are located in data centers all over the world.

#### Learn about zero trust
Unlike traditional perimeter-based network security, Zero Trust security trusts no one and no device by default. Learn about the principles and technologies comprising Zero Trust architecture.

#### Learn about SASE
Secure access service edge (SASE) is an IT model that combines software-defined wide area networking with core security services, and delivers them on the cloud edge. Learn about the core capabilities of SASE solutions.
