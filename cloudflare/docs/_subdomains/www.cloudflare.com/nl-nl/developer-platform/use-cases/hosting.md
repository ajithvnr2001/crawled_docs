## Cloudflare application hosting FAQs

#### What services does Cloudflare offer for application hosting?

Cloudflare provides a range of application hosting solutions for various needs, from hobby projects to large enterprise applications. Websites built and hosted on Cloudflare are secure and fast-performing no matter where their user base is located.

#### How does Cloudflare Pages work?

[Cloudflare Pages](https://www.cloudflare.com/nl-nl/developer-platform/products/pages/) is a simple, fast way to build, test, and deploy. It allows you to build full-stack applications and deploy your code instantly. It offers seamless integration with other [Cloudflare developer tools and services](https://www.cloudflare.com/nl-nl/developer-platform/), enabling developers to construct both static and dynamic applications with minimal configuration. With unlimited seats, Pages makes it easy for developers to collaborate on applications.

#### What is Cloudflare Images?

[Cloudflare Images](https://www.cloudflare.com/nl-nl/developer-platform/products/cloudflare-images/) is an end-to-end solution for hosting images. It allows application developers to cost-effectively store, resize, optimize, and deliver images at scale using a single, unified product.

#### How can I host videos on Cloudflare?

Cloudflare customers can use [Cloudflare Stream](https://www.cloudflare.com/nl-nl/developer-platform/products/cloudflare-stream/) to upload, store, encode, and deliver both [live](https://www.cloudflare.com/nl-nl/developer-platform/solutions/live-streaming/) and on-demand video. Stream customers are only charged for the minutes of video delivered and stored, with no extra fees for encoding or bandwidth.

#### What is Cloudflare R2, and how does it improve application performance?

[Cloudflare R2](https://www.cloudflare.com/nl-nl/developer-platform/products/r2/) is [object storage](https://www.cloudflare.com/nl-nl/learning/cloud/what-is-object-storage/) that does not charge egress fees. By storing your application assets directly on Cloudflare, where your application is hosted, you can reduce round trips when loading data from the backend and improve the overall performance of your application.
