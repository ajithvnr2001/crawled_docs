Cloudflare 상표 지침
#### Cloudflare 브랜드는 단순히 제품과 서비스 그 이상의 의미를 보여줍니다. Cloudflare 브랜드는 더 나은 인터넷을 구축하기 위한 Cloudflare의 노력을 보여주는 중요한 상징입니다.
이 지침은 Cloudflare 고객, 개발자, 공식 리셀러, 기타 Cloudflare 상표 또는 로고를 판촉 목적, 상업적 목적, 교육적 목적, 참조를 위한 자료에서 사용하고자 하는 모든 단체를 대상으로 합니다. 이 지침에 명시적으로 권한이 부여된 경우가 아니거나 Cloudflare의 서면 허가를 받지 않은 경우에는 Cloudflare 상표 및 로고를 사용할 수 없습니다.
Cloudflare 상표 및 로고는 Cloudflare의 귀중한 지적 재산 자산입니다. Cloudflare 브랜드를 보존하고 보호하기 위해서는 상표와 로고가 올바르게 사용되어야 합니다. Cloudflare는 Cloudflare 상표 및 로고를 사용하여 생성된 모든 영업권을 독점적으로 소유합니다.

#### 허용되는 사용
##### Cloudflare 제품 및 서비스에 대한 텍스트 형식의 참조
Cloudflare 제품 또는 서비스를 식별하기 위해 단어 형식으로만 Cloudflare 상표(문자 상표, 로고 제외)만 사용할 수 있으며, 아래 지침의 제약을 받습니다. (아래에 설명되어 있는 웹 배지를 이용하는 경우가 아닌) Cloudflare 로고를 사용하려면 Cloudflare의 서면 허가가 필요합니다.  
  
  
  

##### 회사로서의 Cloudflare, Inc.에 대한 참조
Cloudflare, Inc.는 회사 이름입니다. 서면 자료에서 회사로서의 Cloudflare, Inc.가 처음 나올 때는 먼저 법인 기호가 포함된 전체 이름(즉, " Cloudflare, Inc.")을 사용하여야 하며, 동일한 출판물에서 계속 참조할 경우에는 법인 기호("Inc.")를 제외한 Cloudflare 만을 사용할 수 있습니다. Cloudflare를 회사로 언급할 때는 "Cloudflare"에 ® 기호를 쓰지 않습니다.  
  
  

#####    
Cloudflare 고객의 웹 배지 사용
귀사의 웹 사이트가 Cloudflare 서비스를 이용해 보호되며 가속화되고 있음을 방문자들에게 알리기 위해 Cloudflare 웹 배지를 이용할 수 있습니다. Cloudflare 웹 배지는 [이 페이지](https://www.cloudflare.com/ko-kr/press-kit/)에 있습니다. 어떤 형태로든 Cloudflare 웹 배지를 변형(예: 확대, 색상 변경 등)하지 마십시오.  
  
  
  

##### 공식 리셀러 및 파트너의 Cloudflare 상표 사용
Cloudflare의 공식 리셀러 또는 파트너이며 Cloudflare와의 계약에서 Cloudflare 상표를 사용할 수 있도록 된 경우에는 계약에 명시된 요구 사항을 준수해야 합니다. 계약과 함께 특별한 상표 사용 지침이 제공되지 않은 경우에는 아래의 지침을 따르십시오.
Cloudflare 서비스의 재판매에는 Cloudflare와의 리셀러 계약이 필요하니 양지하시기 바랍니다. 공식 리셀러 또는 파트너가 아닌 경우에는 Cloudflare 리셀러 또는 파트너로 표시하거나 Cloudflare 상표를 이용해 표시할 수 없습니다.  
  
  
  

##### Cloudflare 공급자 및 벤더의 Cloudflare 상표 사용
Cloudflare에 대한 공급자 및 벤더는 Cloudflare의 서면 허가 없이 Cloudflare에 공급되는 제품 및 서비스와 관련하여 Cloudflare의 상표를 사용할 수 없습니다. 승인 절차에 대해서는 Cloudflare 담당자에게 문의하시기 바랍니다. Cloudflare로부터 Cloudflare 상표를 사용할 수 있는 서면 권한을 받은 경우, 서면으로 특별한 상표 사용 지침을 제공받지 않은 한 아래 지침을 준수해야 합니다.
#### 허가된 경우에는 상표를 어떻게 이용할 수 있습니까?
  * 등록 상표가 텍스트에 처음 나타날 때 모든 Cloudflare 등록 상표에 적절한 기호(®, TM, SM)를 지정합니다.
  * 적절한 등록 상표 귀속 문장(예: "Cloudflare, Cloudflare 로고 및 Cloudflare Workers는 미국 및 기타 관할 지역에서 Cloudflare, Inc.의 상표 및/또는 등록 상표입니다.")을 포함합니다. 이 문장은 Cloudflare 등록 상표를 이용하는 첫 페이지의 하단에 위치해야 합니다.
  * Cloudflare 철자는 변경하면 안 되며 첫 "C"는 항상 대문자로 써야 합니다.
  * "Cloudflare"는 브랜드 이름의 일부로 쓸 수 없고 하이픈으로 연결할 수 없으며 응용 프로그램 및 기타 제품 이름에 쓸 수 없습니다. 대신 "에서 실행", "와 함께 사용" 또는 "와 호환" 등의 참조 문구를 이용합니다.
    * 잘못된 예: "iCloudflare”
    * 잘못된 예: "내 Cloudflare 앱"
    * 옳게 쓰인 예: "Cloudflare®용 내 앱”
    * 옳게 쓰인 예: “Cloudflare® 가입을 대상으로 한 호스팅 회사의 특별 프로모션”
  * 타사 로고와 함께 쓸 경우, "Cloudflare용"은 타사 로고보다 크기가 작아야 합니다.
  * Cloudflare 등록 상표는 형용사로 사용해야 하며 적절한 일반 용어가 따라야 합니다. 복수 또는 소유격으로 쓰일 수 없습니다.
    * 잘못된 예: "Cloudflare Optimizer"
    * 옳게 쓰인 예: "Cloudflare 서비스"
  * Cloudflare 등록 상표는 동사로 사용해서는 안됩니다.
    * 잘못된 예: "당사는 사이트를 Cloudflare했습니다."
    * 옳게 쓰인 예: “당사는 Cloudflare 서비스를 이용해 사이트의 속도, 안전성, 지능을 높이고 있습니다.”


#### Cloudflare 등록 상표를 사용할 때 피해야 할 것은 무엇입니까?
  * 진실되고 공정한 참조만 허용할 수 있습니다. 오도하는 참조는 금지됩니다. 예를 들어, Cloudflare 서비스 및 응용 프로그램을 사용하지 않는 사이트가 이를 사용한다고 말하면 안 됩니다.
  * 명시적인 서면 허가 없이 Cloudflare가 타사의 제품 또는 서비스와 연관되어 있거나 이를 지지, 후원, 지원함을 시사하도록 Cloudflare 등록 상표 또는 로고를 사용할 수 없습니다.
  * Cloudflare 등록 상표, 그래픽 기호, 로고, 문자체, 아이콘 등은 폄하하는 의도로 사용할 수 없습니다.
  * 어떠한 경우에도 Cloudflare 상표와 동일하거나, 거의 동일하거나, 혼란을 초래할 정도로 유사한 문자열을 도메인 이름, 사용자 에이전트, 쿠키의 일부로 사용할 수 없습니다. 예를 들어, cloudfliare.com은 거의 동일하며 혼란을 초래할 정도로 유사합니다. 이 규칙에 대한 예외는 CEO나 CTO나 CSO의 승인을 받아야 합니다.
  * 타사는 Cloudflare의 등록 상표를 변형하거나 철자를 바꾸거나 이에 대한 초기의 이해 관계 혼란을 초래할 수 있는 형태로 이용할 수 없습니다.
  * 공인 파트너 및 공인 리셀러를 제외한 타사는 Cloudflare의 상표 또는 변형된 철자를 키워드, Google AdWords, 기타 목표 광고 시스템에 사용할 수 없습니다. 또한, 타사는 도메인 이름, 검색 엔진 최적화, 메타 태그, 검색어, 코드 등에 Cloudflare 상표를 이용할 수 없습니다.
  * Cloudflare 등록 상표 또는 브랜드를 법률이나 규정을 위반하는 사이트 또는 자료에 표시할 수 없습니다.
  * Cloudflare 등록 상표 또는 브랜딩을 귀사의 제품 이름, 서비스 이름, 상표, 로고, 회사 이름에 통합할 수 없습니다.
  * 판매용 상품(예: 티셔츠, 머그 등)에 Cloudflare 상표를 사용할 수 없습니다.
  * Cloudflare 등록 상표를 수정하거나 축약하거나 다른 기호, 단어, 이미지와 결합하거나 태그라인 또는 슬로건에 통합할 수 없습니다.
