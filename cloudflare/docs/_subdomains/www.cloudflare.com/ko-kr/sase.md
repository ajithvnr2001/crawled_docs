## 복잡성은 보안의 적임

**레거시 SASE 아키텍처가 새로운 기술 부채가 되었습니다**

### 원격 액세스 최신화

하이브리드 근무의 속도를 늦추는, 투박하고 안전하지 않은 VPN에 의존하지 않습니다. 내부 애플리케이션과 인프라에 대해 ID 우선, 퀀텀 세이프 액세스를 제공합니다.

  * **온보딩 가속화** : 며칠이 아닌 몇 분 만에 계약자와 BYOD 직원에게 안전하고 원활한 액세스를 제공합니다.
  * **M &A 가속화** : 복잡한 IP 중복이나 방화벽 규칙 없이 인수한 네트워크를 보다 효율적으로 통합합니다.
  * **랜섬웨어 차단** : 광범위한 네트워크 액세스를 세분화된 Zero Trust 규칙으로 대체하여 위협이 내부망에서 확산되는 것을 방지합니다.



[자세히 알아보기](https://www.cloudflare.com/ko-kr/sase/use-cases/vpn-replacement/)

![원격 액세스 최신화](https://cf-assets.www.cloudflare.com/v2/image/3ji4n3rprp7at2kot2c9o5la5j/modernize_remote_access-image.svg)

### 이메일 피싱 공격 차단

위협이 사용자의 수신함에 도달하기 전에 AI 기반 이메일 보안에서 피싱, 가장, 맬웨어, 비즈니스 이메일 손상(BEC)을 차단합니다.

  * **정밀한 차단** : 네이티브 Microsoft 365 또는 Google Workspace 방어를 우회하는, 교묘하거나 대상을 지정하는 피싱 위협을 차단합니다.
  * **더 빠른 배포** : 최소한의 구성만 하면 되고 조정할 필요가 없는 유연한 MX 및 API 배포 방법을 사용하여 즉시 시작할 수 있습니다.
  * **워크스페이스 보안 강화** : 이메일 및 기타 협업 애플리케이션 전반에 걸쳐 위험한 웹 링크 격리와 같은 기본 SASE 제어를 추가합니다.



[자세히 알아보기](https://www.cloudflare.com/ko-kr/sase/use-cases/multi-channel-phishing/)

### 웹 브라우징 보호

DNS 및 HTTP 필터링을 구현하여 원격 사용자와 지사를 맬웨어, 피싱 공격, 악의적 웹 사이트로부터 보호합니다.

  * **즉각적인 결과 확보** : 인터넷 위협을 차단하는 동시에 경고 노이즈를 줄이는 유연한 배포를 통해 가치 창출 시간이 단축됩니다.
  * **마찰 없이 보호** : 세계에서 [가장 빠른 공용 DNS 확인자](https://www.dnsperf.com/#!dns-resolvers)를 지원하는 네트워크와 동일한 네트워크를 사용하여 유연한 보안 규칙을 시행합니다.
  * **허용 가능한 사용 강화** : 안전하고 개인적인 방문자 경험을 제공하는 기업 및 게스트 Wi-Fi를 보호합니다. DNS 설정을 업데이트하기만 하면 됩니다.



[자세히 알아보기](https://www.cloudflare.com/ko-kr/sase/use-cases/remote-workforces/)

### 커피숍 네트워킹 구축

어디에서든 커피숍처럼 이용할 수 있습니다. 원격 및 사무실 위치 전반에 걸쳐 일관된 연결을 제공합니다.

  * **장비 및 MPLS 최소화** : 보다 효율적인 '가벼운 분기, 견고한 클라우드' SASE 접근 방식으로 비용과 복잡성을 줄입니다.
  * **액세스 정책 통합** : 구성 가능한 [ZTNA](https://www.cloudflare.com/ko-kr/sase/products/access/) 및 [WAN](https://www.cloudflare.com/ko-kr/sase/products/wan/) 서비스를 사용하여 원격 및 로컬 사용자에게 동일한 보안 정책을 시행합니다.
  * **인프라 통합** : 더 단순한 인프라 스택을 사용하여 직원이 근무하는 모든 곳에서 Zero Trust 태세를 실행할 수 있습니다.

###### Zero Trust 및 워크스페이스 보안

웹, SaaS, 이메일, 프라이빗 애플리케이션 전반에 걸쳐 세분화된 보안 정책을 적용합니다.팀의 성능 저하 없이 내부망 이동을 차단하고 데이터를 보호합니다.

###### NaaS(Network-as-a-Service)

사설 글로벌 백본 및 퀀텀 세이프 SASE. 지사, 클라우드, 데이터센터를 빠르고 안전하며 DDoS 공격으로부터 보호되는 네트워크에 연결합니다.

###### AI 보안

안전하게 생성형 AI 도입. 가드레일을 선별하고 AI 에이전트를 관리하여 데이터 유출을 방지하고 비인간 권한을 관리합니다. 이 모든 것이 추가 요금 없이 제공됩니다.

###### 관리 및 구성

사용자 경험을 모니터링하고 주권을 관리합니다. 하나의 통합 대시보드, API, Terraform 공급자를 통해 가시성과 제어를 중앙 집중화합니다.

###### AI 기반 플랫폼

새롭게 떠오르는 위협을 감지하고 차단하며, DLP 정확도를 개선하고, AI 프롬프트 의도를 분석합니다. 모든 것을 자연어로 요약합니다.

###### 통합 및 프로그래밍

스택에 맞게 조정하세요. 타사 도구를 통합하고, 비즈니스 로직과 정확히 일치하도록 사용자 지정 코드 모듈을 사용하여 기능을 확장합니다.

## Cloudflare SASE FAQ

#### Cloudflare One은 무엇입니까?

Cloudflare One은 조직의 인력, AI 에이전트, 인프라를 연결하고 보호하도록 설계된 민첩하고 통합된 SASE 플랫폼입니다. 단일 제어 영역, 데이터 영역, 인프라 계층을 제공하여 레거시 보안 및 네트워킹의 마찰과 기술 부채를 해소합니다.

#### Cloudflare One 플랫폼에 포함된 주요 네트워킹 및 보안 서비스는 무엇인가요?

Cloudflare One은 Zero Trust 네트워크 액세스(ZTNA), 보안 웹 게이트웨이(SWG), 클라우드 액세스 보안 브로커(CASB), 서비스형 네트워크(NaaS), 서비스형 방화벽(FWaaS) 등 핵심 SASE 서비스를 통합합니다. 또한 원격 브라우저 격리(RBI), 데이터 손실 방지(DLP), 이메일 보안, 디지털 경험 모니터링(DEM)도 포함됩니다. AI 보안, 포스트 퀀텀 암호화(PQC), 부하 분산 등의 구성 가능한 기능이 기본으로 제공됩니다.

#### Cloudflare의 SASE 아키텍처는 1세대 솔루션과 어떻게 다른가요?

1세대 SASE 솔루션은 인수합병을 통해 임시방편으로 짜깁기된 프록시의 조합이거나, 일관성 없는 정책을 제공하는 경우가 많습니다. 반면 Cloudflare One은 설계 단계부터 글로벌 클라우드 연결성 위에 통합되어 구성 및 프로그래밍 가능한 아키텍처로 구축되었습니다. 덕분에 조직은 보안 및 네트워킹 기능을 수개월이 아닌 단 몇 시간 만에 배포할 수 있습니다.

#### Cloudflare One은 조직이 생성형 AI를 안전하게 도입하도록 어떻게 지원하나요?

이 플랫폼은 생성형 AI 사용에 대한 심층적인 가시성과 제어 기능을 제공하며, 승인되지 않은 도구를 탐지하여 섀도우 AI를 관리하도록 지원합니다. 최초로 모델 컨텍스트 프로토콜(MCP) 서버 연결을 보호하는 SASE 플랫폼으로, AI 프롬프트의 의도를 분석해 기업의 중요 데이터가 외부 퍼블릭 모델로 유출되는 것을 차단합니다.

#### Cloudflare One은 현대 기업을 위한 커피숍 네트워킹을 어떻게 구현하나요?

Cloudflare One은 과중한 작업을 클라우드로 전환하여 비용이 많이 드는 MPLS 계약과 복잡한 하드웨어의 필요성을 없애줍니다. "지점의 부담은 줄이고 클라우드의 역량을 극대화"하는 이러한 SASE 모델을 통해 모든 위치에서 동일한 수준으로 일관된 연결성과 보안을 제공할 수 있습니다. 사무실 네트워크는 번거로운 과정 없이 “그냥 연결됩니다”. Cloudflare의 글로벌 네트워크를 통해 트래픽을 라우팅함으로써, 기업은 인프라를 간소화하는 동시에 모든 사용자에게 고성능 보안을 보장할 수 있습니다.

#### Cloudflare의 SASE 플랫폼은 원격 액세스를 어떻게 최신화할 수 있나요?

Cloudflare One은 거추장스럽고 안전하지 않은 VPN을 ID 기반의 퀀텀 세이프 내부 애플리케이션 액세스로 대체합니다. 따라서 세분화된 Zero Trust 규칙을 통해 위협이 내부망으로 확산되는 것을 방지하고, 계약업체와 BYOD 직원에게 몇 분 만에 원활한 액세스 권한을 부여할 수 있습니다.

#### Cloudflare One은 이메일 기반 위협에 어떻게 대응하나요?

Cloudflare One은 AI 기반 이메일 보안을 사용하여 피싱, 사칭, 맬웨어, 비즈니스 이메일 침해(BEC)를 차단합니다. 이메일에서 발견된 위험한 웹 링크를 격리하는 등 네이티브 SASE 제어 기능을 추가하여 이러한 보호 기능을 확장할 수 있습니다.

#### Cloudflare One 플랫폼은 글로벌 규모와 성능을 어떻게 지원하나요?

Cloudflare는 전 세계 300개여 개의 도시에서 완전한 SASE 서비스를 제공합니다. 이러한 글로벌 입지는 웹의 약 20%를 보호하고 상위 생성형 AI 기업의 약 80%를 안전하게 지키며, 타의 추종을 불허하는 위협 인텔리전스와 zero-day 가시성을 갖춘 플랫폼을 제공합니다.
