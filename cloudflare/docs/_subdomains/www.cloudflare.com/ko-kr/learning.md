# 학습 센터
사이버 보안 및 Cloudflare에서 인터넷 작동 방식에 대한 자료. [Cloudflare란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/what-is-cloudflare/ "https://www.cloudflare.com/learning/what-is-cloudflare/")
#### DDoS 공격에 대해 알아보기
분산 서비스 거부(DDoS) 공격에서는 다수의 컴퓨터로 구성된 네트워크가 동시에 액세스 포인트에 과도한 트래픽을 보냄으로써 합법적인 사용자가 서비스를 사용하지 못하게 막습니다.
  * [DDoS 공격이란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/ddos/what-is-a-ddos-attack/)
  * [DDoS 봇넷이란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/ddos/what-is-a-ddos-botnet/)
  * [DDoS 방식](https://www.cloudflare.com/ko-kr/learning/ddos/ddos-attack-tools/how-to-ddos/)
  * [DNS 폭주](https://www.cloudflare.com/ko-kr/learning/ddos/dns-flood-ddos-attack/)


#### CDN에 대해 알아보기
콘텐츠 전송 네트워크(CDN)는 분산 서버로 이루어진 네트워크로, 서버들이 협력하여 인터넷 콘텐츠를 효율적으로 제공하고 로드 속도와 안정성을 개선합니다.
  * [CDN이란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/cdn/what-is-a-cdn/)
  * [CDN 성능](https://www.cloudflare.com/ko-kr/learning/cdn/performance/)
  * [CDN SSL TLS 보안](https://www.cloudflare.com/ko-kr/learning/cdn/cdn-ssl-tls-security/)
  * [CDN 안정성](https://www.cloudflare.com/ko-kr/learning/cdn/cdn-load-balance-reliability/)


#### DNS에 대해 알아보기
도메인 네임 시스템(DNS)은 인터넷 전화번호부라고도 불립니다. DNS는 도메인 이름을 통해 사용자를 웹 콘텐츠에 연결하는 전 세계 네트워크입니다.
  * [DNS란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/dns/what-is-dns/)
  * [DNS 보안](https://www.cloudflare.com/ko-kr/learning/dns/dns-security/)
  * [DNS 서버 유형](https://www.cloudflare.com/ko-kr/learning/dns/dns-server-types/)
  * [DNS 레코드](https://www.cloudflare.com/ko-kr/learning/dns/dns-records/)


#### 웹 응용 프로그램 보안에 대해 알아보기
인터넷 특성상 응용 프로그램은 다양한 공격에 취약할 수밖에 없습니다. 웹 애플리케이션을 보안하려면 종합적인 접근법으로 공격을 완화해야 합니다.
  * [웹 응용 프로그램 보안이란 무엇인가요?](https://www.cloudflare.com/ko-kr/learning/security/what-is-web-application-security/)
  * [데이터 유출이란 무엇인가요?](https://www.cloudflare.com/ko-kr/learning/security/what-is-a-data-breach/)
  * [Meltdown/Spectre](https://www.cloudflare.com/ko-kr/learning/security/threats/meltdown-spectre/)
  * [무차별 암호 대입 공격](https://www.cloudflare.com/ko-kr/learning/security/threats/brute-force-attack/)


#### 성능에 대해 알아보기
신속하게 로드되는 웹 응용 프로그램은 전환율이 높고 SEO 성능이 우수합니다. 응용 프로그램의 성능에 영향을 주는 요인을 알아봅니다.
  * [사이트 속도가 중요한 이유](https://www.cloudflare.com/ko-kr/learning/performance/why-site-speed-matters/)
  * [웹 사이트 속도로 SEO를 촉진하는 방법?](https://www.cloudflare.com/ko-kr/learning/performance/how-website-speed-boosts-seo/)
  * [웹 사이트를 모바일 친화적으로 만드는 방법](https://www.cloudflare.com/ko-kr/learning/performance/how-to-make-a-site-mobile-friendly/)
  * [대기 시간이란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/performance/glossary/what-is-latency/)


#### serverless에 대해 알아보기
사용자는 serverless를 사용하면 기본 인프라에 대해 우려할 필요 없이 코드를 작성하고 배포할 수 있습니다. serverless 아키텍처를 선호하는 개발자가 많아지는 이유를 알아봅니다.
  * [serverless 컴퓨팅이란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/serverless/what-is-serverless/)
  * [serverless를 사용하는 이유?](https://www.cloudflare.com/ko-kr/learning/serverless/why-use-serverless/)
  * [서비스로서의 기능(FaaS)](https://www.cloudflare.com/ko-kr/learning/serverless/glossary/function-as-a-service-faas/)
  * [에지 컴퓨팅이란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/serverless/glossary/what-is-edge-computing/)


#### SSL에 대해 알아보기
현재 TLS로 알려진 SSL은 HTTP 프로토콜 위에서 작동하는 암호화 프로토콜로서 서버와 클라이언트 사이의 인터넷 연결을 보호합니다.
  * [SSL이란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/ssl/what-is-ssl/)
  * [TLS란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/ssl/transport-layer-security-tls/)
  * [SSL 인증서란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/ssl/what-is-an-ssl-certificate/)
  * [HTTPS이란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/ssl/what-is-https/)


#### 봇에 대해 알아보기
봇은 웹을 탐색할 수 있는 자동화된 응용 프로그램입니다. 검색 엔진 크롤러처럼 유용한 봇도 있습니다. 그렇지만 다양한 방식으로 사이트와 응용 프로그램을 손상시킬 수 있는 악성 봇도 있습니다.
  * [봇이란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/bots/what-is-a-bot/)
  * [봇 관리란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/bots/what-is-bot-management/)
  * [자격 증명 스터핑이란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/bots/what-is-credential-stuffing/)
  * [content scraping이란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/bots/what-is-content-scraping/)


#### 클라우드에 대해 알아보기
"클라우드"는 인터넷을 통해 액세스할 수 있는 서버와 이러한 서버에서 작동하는 소프트웨어와 데이터베이스를 의미합니다. 클라우드 서버는 전 세계 데이터 센터에 위치합니다.
  * [클라우드란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/cloud/what-is-the-cloud/)
  * [멀티 클라우드란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/cloud/what-is-multicloud/)
  * [하이브리드 클라우드란 무엇인가?](https://www.cloudflare.com/ko-kr/learning/cloud/what-is-hybrid-cloud/)

기존의 경계 기반 네트워크 보안과 달리, Zero Trust 보안에서는 기본적으로 그 누구도, 그 어떤 장치도 믿지 않습니다. Zero Trust 아키텍처를 구성하는 원칙과 기술에 대해 알아보세요.

#### SASE에 대해 알아보기
보안 액세스 서비스 에지(SASE)는 소프트웨어로 정의된 광역 네트워킹과 핵심 네트워크 보안 서비스를 결합하여 클라우드 에지에서 제공하는 IT 모델입니다. SASE 솔루션의 핵심 기능에 대해 알아보세요.
  * [SASE란?](https://www.cloudflare.com/ko-kr/learning/access-management/what-is-sase/)
