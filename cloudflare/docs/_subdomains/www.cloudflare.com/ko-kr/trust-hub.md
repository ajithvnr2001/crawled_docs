# Cloudflare Trust Hub
##### 고객 신뢰 확보에 도움이 되는 정책, 기술, 인증
![Zero Trust Integrations  ](https://cf-assets.www.cloudflare.com/slt3lc6tev37/2Oomvz9nxbYQ6wGDcwQwFl/c451752ef1193f42716653c3629a394b/Enterprise.svg)
신뢰는 Cloudflare 비즈니스의 기반입니다. Cloudflare는 Cloudflare 네트워크를 통과하는 개인 데이터의 신성함을 존중하고 그러한 데이터의 처리와 보안에 대해 투명성을 유지함으로써 사용자의 신뢰를 얻습니다.
이러한 신뢰를 가능하게 하는 정책, 기술, 타사 인증을 알아보세요.
![Zero Trust Integrations  ](https://cf-assets.www.cloudflare.com/slt3lc6tev37/2Oomvz9nxbYQ6wGDcwQwFl/c451752ef1193f42716653c3629a394b/Enterprise.svg)
## 개인 정보 및 데이터 보호
![](https://cf-assets.www.cloudflare.com/brandfolder/accelerate-internet-globally-distributed-visitors-spot-illustration.svg)
Cloudflare는 모든 것에서 데이터 개인정보 보호를 구축합니다. Cloudflare의 개인정보 취급방침을 살펴보고 개인정보 중심 제품을 알아보고 GDPR 등의 같은 규제 요구 사항을 지원하는 방법을 살펴봅니다.
