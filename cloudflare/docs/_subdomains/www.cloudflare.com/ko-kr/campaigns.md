# Cloudflare for Campaigns
##### 입후보자 투표 웹 사이트 및 팀의 보안.
![CF for Campaigns Hero - General
](https://cf-assets.www.cloudflare.com/slt3lc6tev37/6cPS9gyxlMe66KH9OY6S8K/60359269dc12ad4e6026f39561aeefb1/campaigns-election-website-vote.svg)
유권자들은 일상적으로 인터넷을 통해 전 세계의 선거 입후보자들에 대해 알게 되고 이들과 소통합니다. 선거 유세 웹 사이트를 적대적 공격으로부터 보호하고 지속적으로 액세스할 수 있도록 보장하는 것은 매우 중요하지만 쉽지는 않은 일입니다.
Cloudflare는 내부 팀 및 데이터를 안전하게 유지하도록 설계된 솔루션을 추가하여 맞춤형으로 구성한 제품군을 제공하여 선거 입후보자의 웹 사이트를 보호하고, 가속화하고, 안정성을 보장하고자 합니다.

## 고객 캠페인에 맞게 구성된 솔루션
Cloudflare를 이용해 적대적 공격으로부터 웹 사이트를 보호하고 부하 분산 기능을 활용하며 팀의 중요한 내부 데이터를 보호할 수 있습니다. 이 모든 것이 하나의 직관적인 대시보드에서 이루어집니다.
사용 가능한 솔루션에 포함되는 내용:
연중 무휴 24시간 가동 지원 무제한 DDoS 완화 및 전용 지원 담당자 서비스 포함.
**웹 애플리케이션 방화벽** OWASP및 Cloudflare 독점 규칙 세트 포함, 사용자 정의 WAF및 방화벽 규칙 지원.
**사용자 정의 트래픽 차단** 지정된 사용자 에이전트 및 문제가 있는 트래픽이 감지된 지역을 차단합니다.
**속도 제한** 서비스 거부 공격, 무차별 대입 로그인 시도 및 응용 프로그램 계층을 표적으로 삼는 기타 유형의 악의적인 동작을 방지합니다.**I'm Under Attack™ 모드** 일제 공격에 대한 보호 기능을 즉시 배포하고 엔터프라이즈 수준의 "I Am Under Attack" 지원 서비스를 즉시 배포합니다.
**봇 방어** 자동화된 봇을 방지하고 실제 트래픽만 사이트에 도달할 수 있도록 캡차 인증 질문을 트리거합니다.
**하위 도메인 지원** 하위 도메인에 대한 Cloudflare 성능 및 보안 관리 기능을 단순화할 수 있습니다.
**글로벌 CDN** 125여 개 국가의 335개 도시에 걸쳐 있는 Cloudflare의 전역 네트워크를 활용하여 밀리초 단위로 응답합니다.
**Load Balancing** 트래픽을 다양한 서버 및 클라우드로 동적 라우팅합니다.
**Cloudflare Rules** Cloudflare 설정을 구성하고 일치하는 요청을 위해 특정 작업을 트리거합니다. 규칙 사용 사례의 예시로는 캐시 만료 설정, 사이트 섹션의 보안 수준 수정, URL 전달이 있습니다.
**감사 로그** 로그인 및 로그아웃 등의 계정 수준 활동과 Cloudflare Dash를 통해 작성된 구성 변경이 포함됩니다.
**사용자가 많은 조직** 다수의 계정으로 Cloudflare 계정을 관리하며 계정마다 권한을 상세하게 규정할 수 있습니다.
**Cloudflare Access** 선거 유세팀이 VPN을 사용하지 않으면서도 모든 도메인, 응용 프로그램, Cloudflare에서의 경로에 대한 사용자 액세스를 보호, 인증, 모니터링할 수 있습니다.
**Cloudflare Gateway DNS 필터링** 다양한 지점에서 악의적인 콘텐츠가 네트워크에 들어오지 못하도록 차단하여 인터넷을 탐색하는 사용자를 보호합니다.
**선거 보안 연락처** 선거 보안을 위한 이 연락처로 문의하면 Cloudflare의 지원 팀으로 연결되어 보안 팀으로 이관됩니다.
### 웹 사이트 보호 모범 사례 4가지
##### 2단계 인증(2FA)으로 계정을 보호하세요
로그인 시 신원 확인을 위한 두 번째 정보를 요구하면 무단 사용자가 계정의 중요한 데이터에 액세스하는 것을 방지할 수 있습니다.
[2FA 활성화](https://support.cloudflare.com/hc/en-us/articles/200167906-Securing-user-access-with-two-factor-authentication-2FA-)
##### DNS 레코드를 오렌지색 구름으로 표시하세요 
DNS 레코드를 오렌지색 구름으로 표시하면 Cloudflare가 도메인의 프록시 역할을 합니다. 따라서 원본 웹 서버를 예기치 않은 트래픽 급증 및 사이버 공격으로부터 보호할 수 있습니다.
[오렌지색 구름 활성화](https://support.cloudflare.com/hc/en-us/articles/205177068-How-does-Cloudflare-work-)
##### SSL 암호화로 내부 데이터를 보호하세요
보안 소켓 계층(SSL)은 웹 서버와 브라우저 간에 암호화된 링크를 생성하는 표준 보안 기술입니다. Cloudflare를 사용하면 클릭 한 번으로 사이트가 HTTPS 지원 사이트가 될 수 있습니다.
[Cloudflare SSL에 대해 자세히 알아보기](https://support.cloudflare.com/hc/en-us/articles/200170416-End-to-end-HTTPS-with-Cloudflare-Part-3-SSL-options)
##### 웹 응용 프로그램 방화벽을 켜세요
WAF는 웹 응용 프로그램과 인터넷 사이의 방어막 역할을 하면서 수신 및 발신 트래픽을 통과시킬지 여부를 결정할 수 있도록 해줍니다. WAF는 SQL 삽입 공격, 교차 사이트 스크립팅, 교차 사이트 위조로부터 보호해줍니다.
[Cloudflare Specials 활성화](https://support.cloudflare.com/hc/en-us/articles/200172016-Understanding-the-Cloudflare-Web-Application-Firewall-WAF-)

## 모든 유세팀을 위한 솔루션
Cloudflare for Campaigns를 통해 후보자의 웹 사이트 보호부터 내부 네트워크 및 데이터 보호에 이르기까지 선거 유세에 필요한 모든 사항이 충족됩니다. 사용할 수 있는 서비스에는 다음이 포함됩니다.
  * Cloudflare의 웹 애플리케이션 방화벽, DDoS 완화, 사용자 정의 차단 규칙으로 적대적인 행위자로부터 웹 사이트를 보호
  * 125여 개 국가의 335개 도시에 걸친 Cloudflare의 전역 네트워크를 활용하여 사이트 속도 및 안정성 보장
  * Cloudflare Zero Trust를 이용하여 네트워크를 통과하는 모든 트래픽을 모니터링하고 내부 응용 프로그램을 보호
