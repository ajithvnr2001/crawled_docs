##### WCAG 2.1 AA e Seção 508
O painel de controle da Cloudflare preenche o Modelo Voluntário de Acessibilidade do Produto (VPAT), em conformidade com os padrões internacionais estabelecidos pelas Diretrizes de Acessibilidade para Conteúdo Web (WCAG) 2.1 AA e conforme os padrões legais estabelecidos pela Seção 508 da Lei de Reabilitação.
Entre em contato com a equipe da sua conta para solicitar o VPAT.

### Recursos
![Padlock icon](https://cf-assets.www.cloudflare.com/slt3lc6tev37/4knCjnvTXGI67Tjt2pgWOB/5e9703961ea866cd33e94411f5105c7c/security-lock.svg)
##### Confidencialidade e disponibilidade de dados
Por padrão, a Cloudflare criptografa dados usando os protocolos mais recentes e oferece um controle detalhado sobre o local onde as chaves de criptografia são armazenadas e para onde os logs são enviados.
[Saiba mais](https://www.cloudflare.com/pt-br/application-services/products/ssl/)
![Padlock icon](https://cf-assets.www.cloudflare.com/slt3lc6tev37/4knCjnvTXGI67Tjt2pgWOB/5e9703961ea866cd33e94411f5105c7c/security-lock.svg)
##### Criptografia
A rede da Cloudflare é capaz de criptografar os dados ao longo de toda a viagem entre os servidores de origem e os usuários finais usando os protocolos mais recentes.
[Saiba mais](https://www.cloudflare.com/pt-br/application-services/products/ssl/)
![location pin](https://cf-assets.www.cloudflare.com/slt3lc6tev37/6TXVyxQpn8JDy6JnItQqnk/a9f2772160d33f5ebc4a603dd85105e5/location-pin.svg)
##### Localização de dados
Em muitas regiões — inclusive na União Europeia — a Cloudflare permite que as organizações controlem em quais data centers regionais seu tráfego é inspecionado e para onde são enviados os registros.
[Saiba mais](https://www.cloudflare.com/pt-br/data-localization/)
![performance validator](https://cf-assets.www.cloudflare.com/slt3lc6tev37/6yOU66g9c1Dj3PX55DGzHb/4ad68e1191cbd9cc51ea47a99d976595/performance-validator.svg)

Uma plataforma combinável que ajuda as empresas a simplificar a conformidade com controles de segurança extensíveis em sistemas que ajudam você a conectar, proteger e criar.
[Saiba mais](https://www.cloudflare.com/pt-br/data/)
