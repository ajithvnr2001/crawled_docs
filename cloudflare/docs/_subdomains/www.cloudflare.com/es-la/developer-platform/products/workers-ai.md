# Workers AI

Inferencia de IA rápida, asequible y global de código abierto

Workers AI facilita el desarrollo escalable y la implementación de aplicaciones de IA en el perímetro. Mejora la eficiencia y la experiencia del usuario ejecutando la IA más cerca de los usuarios para garantizar aplicaciones de IA de baja latencia y eficaces. Los clientes evitan la proliferación de herramientas y reducen el coste total de propiedad porque Workers AI se integra eficazmente con la plataforma para desarrolladores de Cloudflare, incluida nuestra base de datos vectorial, Vectorize, y AI Gateway para la supervisión y el control centralizados de las aplicaciones de IA.

## Inferencia de IA como servicio

Workers AI te permite ejecutar modelos de IA en la red de Cloudflare desde tu propio código, ya sea desde Workers, Pages o a través de la API de Cloudflare. Se integra completamente con Vectorize (base de datos vectorial), R2 (lago de datos) y AI Gateway en una plataforma unificada para reducir la proliferación de herramientas.

![Ilustración de gráfico modular de IA](https://www.cloudflare.com/cdn-cgi/image/format=auto/https://cf-assets.www.cloudflare.com/v2/image/jrph8pfldt4l10scidgntmca45/Ai-Composable_1.webp)
