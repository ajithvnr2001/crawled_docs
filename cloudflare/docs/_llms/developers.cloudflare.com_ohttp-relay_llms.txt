## Overview

- [Cloudflare OHTTP Relay](https://developers.cloudflare.com/ohttp-relay/index.md): Cloudflare OHTTP Relay is a managed Oblivious HTTP (OHTTP) relay service that hides client IP addresses from application backends.

## Get started

- [Get started](https://developers.cloudflare.com/ohttp-relay/get-started/index.md): Set up Cloudflare OHTTP Relay by configuring your server, client, and relay connection using the OHTTP standard.
