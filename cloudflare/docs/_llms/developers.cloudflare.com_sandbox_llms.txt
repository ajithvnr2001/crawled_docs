# Sandboxes

Isolated execution on Cloudflare using Containers and Dynamic Workers

> Links below point directly to Markdown versions of each page. Any page can also be retrieved as Markdown by sending an `Accept: text/markdown` header to the page's URL without the `index.md` suffix (for example, `curl -H "Accept: text/markdown" https://developers.cloudflare.com/sandbox/`).
>
> For other Cloudflare products, see the [Cloudflare documentation directory](https://developers.cloudflare.com/llms.txt).

## Overview

- [Sandboxes on Cloudflare](https://developers.cloudflare.com/sandbox/index.md): Execute untrusted or generated code in Linux virtual machines or isolated Workers.

## Run a Linux command

- [Run a Linux command](https://developers.cloudflare.com/sandbox/get-started/index.md): POST a command to your Worker and read stdout from Linux.
- [Build a coding agent runner](https://developers.cloudflare.com/sandbox/get-started/build-a-coding-agent-runner/index.md): Build a Worker that clones a GitHub repository into a Linux sandbox, runs Claude Code on a task in the background, and returns its changes as a diff.
- [Build an AI code interpreter](https://developers.cloudflare.com/sandbox/get-started/build-an-ai-code-interpreter/index.md): Let a Workers AI model write JavaScript and run it in a Dynamic Worker sandbox.
- [Run JavaScript](https://developers.cloudflare.com/sandbox/get-started/dynamic-workers/index.md): POST JavaScript to your Worker and read the sandboxed result.

## Choose a sandbox environment

- [Choose a sandbox environment](https://developers.cloudflare.com/sandbox/concepts/index.md): Compare Containers and Dynamic Workers for code that needs Linux or only calls methods that your Worker provides.
- [Sandbox lifetime](https://developers.cloudflare.com/sandbox/concepts/lifetime/index.md): Understand what keeps a sandbox running, what stops it, and which files the next instance starts with.
- [Sandbox security](https://developers.cloudflare.com/sandbox/concepts/security/index.md): Code in a sandbox can use everything your Worker places inside it, so each sandbox should hold only what that code may have.

## Run commands in a sandbox

- [Run commands in a sandbox](https://developers.cloudflare.com/sandbox/commands/index.md): Run Python code or a test suite, stream command output, keep a process running after the request ends, or open an interactive shell in a Linux sandbox.
- [Open a terminal in the browser](https://developers.cloudflare.com/sandbox/commands/open-a-terminal-in-the-browser/index.md): Connect a browser terminal to an interactive shell in a Linux sandbox over a WebSocket.
- [Run a server in the background](https://developers.cloudflare.com/sandbox/commands/run-a-server-in-the-background/index.md): Start a server in a Linux sandbox once for each container, wait until it answers, and stop it from later requests.
- [Run background processes](https://developers.cloudflare.com/sandbox/commands/run-background-processes/index.md): Start a background process in a Linux sandbox, then check it, read its output, and stop it from later requests.
- [Run Python code](https://developers.cloudflare.com/sandbox/commands/run-python-code/index.md): Run Python code in a Linux sandbox with the Python version and packages you choose, and return its output.
- [Run tests from a Git repository](https://developers.cloudflare.com/sandbox/commands/run-tests-from-a-git-repository/index.md): Clone a public Git repository into a fresh Linux sandbox, install its dependencies, and return the test results from your Worker.
- [Stream command output](https://developers.cloudflare.com/sandbox/commands/stream-command-output/index.md): Send stdout and stderr from a command in a Linux sandbox to a browser as server-sent events while the command runs.

## Work with files in a sandbox

- [Work with files in a sandbox](https://developers.cloudflare.com/sandbox/files/index.md): Move files in and out of a sandbox, keep a workspace after its instance stops, and share files through R2.
- [Back up a directory to R2](https://developers.cloudflare.com/sandbox/files/back-up-a-directory-to-r2/index.md): Save a directory from a Linux sandbox to your R2 bucket, and restore it into the same sandbox after its instance or image changes.
- [Move files in and out of a sandbox](https://developers.cloudflare.com/sandbox/files/manage-files/index.md): Stream a file from your Worker into a Linux sandbox, run a command on it, and stream the output file back to the caller.
- [Mount an R2 bucket](https://developers.cloudflare.com/sandbox/files/mount-an-r2-bucket/index.md): Mount a prefix of an R2 bucket in a Linux sandbox without giving the sandbox your credentials.
- [Save a sandbox automatically](https://developers.cloudflare.com/sandbox/files/save-a-sandbox-automatically/index.md): Save the filesystem of a Linux sandbox in a Container snapshot before it stops for inactivity, and restore the files on the next request.
- [Save and restore a sandbox with snapshots](https://developers.cloudflare.com/sandbox/files/save-and-restore-a-workspace/index.md): Save the filesystem of a sandbox as a Container snapshot, stop its Linux instance, and restore the files in a new instance.

## Preview a web application

- [Preview a web application](https://developers.cloudflare.com/sandbox/previews/index.md): Open a web server that runs in a Linux sandbox through your Worker, keep its WebSocket connections open, and share it with a link.
- [Serve previews on their own hostnames](https://developers.cloudflare.com/sandbox/previews/serve-previews-on-their-own-hostnames/index.md): Give each sandbox preview its own hostname, so code in one preview cannot use your application cookies or the storage of another preview.

## Credentials and network access

- [Credentials and network access](https://developers.cloudflare.com/sandbox/network/index.md): Add credentials in your Worker so the sandbox never holds them, and decide which services code in a sandbox can reach.
- [Call an authenticated API from a sandbox](https://developers.cloudflare.com/sandbox/network/call-an-authenticated-api/index.md): Let code in a Container or Dynamic Worker call an authenticated API without giving it the access token.
- [Clone a private repository](https://developers.cloudflare.com/sandbox/network/clone-a-private-repository/index.md): Clone a private GitHub repository into a Linux sandbox without giving the sandbox the access token.

## Manage sandboxes

- [List a user's sandboxes](https://developers.cloudflare.com/sandbox/manage/list-sandboxes/index.md): Record each user's sandboxes in a Durable Object, and report which ones are running.
- [Run code when a sandbox stops](https://developers.cloudflare.com/sandbox/manage/run-code-when-a-sandbox-stops/index.md): Record when and why a sandbox stops, including stops that happen while no requests arrive.
