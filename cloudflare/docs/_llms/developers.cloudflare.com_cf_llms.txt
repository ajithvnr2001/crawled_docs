# Cloudflare CLI

Manage Cloudflare resources from one command-line interface

> Links below point directly to Markdown versions of each page. Any page can also be retrieved as Markdown by sending an `Accept: text/markdown` header to the page's URL without the `index.md` suffix (for example, `curl -H "Accept: text/markdown" https://developers.cloudflare.com/cf/`).
>
> For other Cloudflare products, see the [Cloudflare documentation directory](https://developers.cloudflare.com/llms.txt).

## Overview

- [Cloudflare CLI](https://developers.cloudflare.com/cf/index.md): Use one command-line interface for the public Cloudflare API and for Workers projects.

## Get started

- [Get started](https://developers.cloudflare.com/cf/get-started/index.md): Install the Cloudflare CLI, sign in, and run your first command.
- [Deploy your first Worker](https://developers.cloudflare.com/cf/get-started/first-worker/index.md): Create a Workers project with cf init, develop it locally, and deploy it with the Cloudflare CLI.
- [Manage resources from the command line](https://developers.cloudflare.com/cf/get-started/resources/index.md): Find a zone, list, create, and delete DNS records, and find other commands with the Cloudflare CLI.

## cf for Wrangler users

- [cf for Wrangler users](https://developers.cloudflare.com/cf/wrangler/index.md): Learn what stays the same and what changes when you move from Wrangler to cf, and decide when to migrate a project.
- [Migrate a Wrangler project](https://developers.cloudflare.com/cf/wrangler/migrate/index.md): Convert a Wrangler project to cf with cf migrate, resolve the follow-up items, and deploy it with cloudflare.config.ts.
- [Wrangler to cf reference](https://developers.cloudflare.com/cf/wrangler/reference/index.md): Find cf equivalents for Wrangler commands, and map Wrangler configuration, build settings, and environments to cf.

## Develop, build, and deploy

- [Develop, build, and deploy](https://developers.cloudflare.com/cf/projects/index.md): Run, build, and deploy Workers projects with the Cloudflare CLI, including modes, prebuilt deploys, and previews.
- [Programmatic configuration](https://developers.cloudflare.com/cf/projects/cloudflare-config/index.md): Configure Workers projects with a typed cloudflare.config.ts file.
- [Configuration explorer](https://developers.cloudflare.com/cf/projects/config-explorer/index.md): See how cloudflare.config.ts describes each part of an application, and what each typed field means.

## Use cf with coding agents

- [Use cf with coding agents](https://developers.cloudflare.com/cf/agents/index.md): Set up the Cloudflare CLI for coding agents, and help agents find, inspect, and safely run the right commands.

## Use cf in CI

- [Use cf in CI](https://developers.cloudflare.com/cf/ci/index.md): Run the Cloudflare CLI in continuous integration with an API token, predictable non-interactive behavior, and a build that you deploy once.

## Environment variables

- [Environment variables](https://developers.cloudflare.com/cf/environment-variables/index.md): Reference the environment variables that control Cloudflare CLI authentication, targeting, output, and telemetry.
