# Routing

Last updated Nov 4, 2026|Copy as Markdown|[View as Markdown](https://developers.cloudflare.com/index.md)|[Agent setup](https://developers.cloudflare.com/agent-setup/)

Routing lets you configure how AI Gateway selects models. In the dashboard, select your gateway, then go to **Routing** to manage model aliases and dynamic routes.

[Auto Router](https://developers.cloudflare.com/ai-gateway/features/routing/auto-router/)

Automatically route each request to the most cost-effective model that can handle the task while maintaining response quality.

Use Auto Router

[Model aliases](https://developers.cloudflare.com/ai-gateway/features/routing/model-aliases/)

Give one or more models a stable name such as `custom/support-fast`. Use an alias to try models in a default order or use smart routing without updating your application.

Use Model aliases

[Dynamic routes](https://developers.cloudflare.com/ai-gateway/features/routing/dynamic-routing/)

Build a routing flow with conditional branches, percentage splits, rate limits, and budget limits. Use a dynamic route when requests need to follow different paths based on rules you define.

Use Dynamic routes
