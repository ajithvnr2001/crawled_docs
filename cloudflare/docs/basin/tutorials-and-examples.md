## Connect an Iceberg engine

Choose a configuration example for your existing engine:

Goal | Resource  
---|---  
Use a local SQL engine | [DuckDB](https://developers.cloudflare.com/basin-catalog/config-examples/duckdb/)  
Use a distributed SQL engine | [Trino](https://developers.cloudflare.com/basin-catalog/config-examples/trino/) or [StarRocks](https://developers.cloudflare.com/basin-catalog/config-examples/starrocks/)  
Use Python | [PyIceberg](https://developers.cloudflare.com/basin-catalog/config-examples/pyiceberg/) or [Apache Spark with Python](https://developers.cloudflare.com/basin-catalog/config-examples/spark-python/)  
Use Scala | [Apache Spark with Scala](https://developers.cloudflare.com/basin-catalog/config-examples/spark-scala/)  
Use a data warehouse | [Snowflake](https://developers.cloudflare.com/basin-catalog/config-examples/snowflake/)  
  
For all supported examples, refer to [Connect to Iceberg engines](https://developers.cloudflare.com/basin-catalog/config-examples/).
