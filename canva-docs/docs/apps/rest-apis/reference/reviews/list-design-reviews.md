# List design reviews

Copy page

This API is currently provided as a preview. Be aware of the following:

  * There might be unannounced breaking changes.
  * Any breaking changes to preview APIs won't produce a new [API version](https://www.canva.dev/docs/apps/rest-apis/versions/).
  * Public integrations that use preview APIs will not pass the review process, and can't be made available to all Canva users.



To use this API, your integration must act on behalf of a user that's on a Canva plan with design approvals (such as Canva Pro, Canva Teams, or Canva Enterprise). This API isn't available to Canva for Education users.

Lists design reviews where the user is an assigned reviewer. This doesn't include reviews that the user has requested from others. Reviews can be sorted and paginated.

## HTTP method and URL path

GET` https://api.canva.com/rest/v1/reviews`

### Rate limit

This operation is rate limited to 100 requests per minute for each user of your app.

## Authentication and authorization

This endpoint supports public or private apps, and requires a valid OAuth access token that acts on behalf of a user (OAuth authorization code flow). For more information, see [Generate an access token](https://www.canva.dev/docs/apps/rest-apis/reference/authentication/generate-access-token/).

### Scopes

The access token must have all the following [scopes](https://www.canva.dev/docs/apps/rest-apis/scopes/) (permissions):

  * `design:meta:read`



## Header parameters

`Authorization``string`

Required

Provides credentials to authenticate the request, in the form of a `Bearer` token.

For example: `Authorization: Bearer {token}`

## Query parameters

`status``string`

Required

Filter reviews by their current status. Currently, only `needs_review` is supported, but other values will be added in the future.

**Available values:** The only valid value is `needs_review`: Filter for reviews awaiting a decision from the reviewer..

`sort_by``string`

Optional

The field and direction used to sort results. Determines both what property the results are ordered by and whether the order is ascending or descending. If omitted, results are sorted by `created_ascending`.

**Default value:** `created_ascending`

**Available values:**

  * `created_ascending`: Sort by review creation time, earliest first.
  * `created_descending`: Sort by review creation time, latest first.
  * `due_at_ascending`: Sort by due date, earliest deadline first. Reviews with no due date are returned last.
  * `due_at_descending`: Sort by due date, latest deadline first. Reviews with no due date are returned last.



`continuation``string`

Optional

If the success response contains a continuation token, the list contains more reviews you can list. You can use this token as a query parameter and retrieve more reviews from the list, for example `?continuation={continuation}`.

To retrieve all reviews, you might need to make multiple requests.

`limit``integer`

Optional

The maximum number of reviews to return. The presence of a continuation token in the response indicates that more reviews are available, even if the number returned is less than this limit.

**Minimum:** `1`

**Maximum:** `25`

**Default value:** `25`

## Success response

Expand all

If successful, the endpoint returns a `200` response with a JSON body with the following parameters:

`items``DesignReview[]`

The list of design reviews matching the specified filters.

Properties of **items**

`design``DesignSummary`

Basic details about the design, such as the design's ID, title, and URL.

Properties of **design**

`id``string`

The design ID.

`urls``DesignLinks`

A temporary set of URLs for viewing or editing the design.

Properties of **urls**

`edit_url``string`

A temporary editing URL for the design. This URL is only accessible to the user that made the API request, and is designed to support [return navigation](https://www.canva.dev/docs/apps/rest-apis/return-navigation-guide/) workflows.

This is not a permanent URL, it is only valid for 30 days.

`view_url``string`

A temporary viewing URL for the design. This URL is only accessible to the user that made the API request, and is designed to support [return navigation](https://www.canva.dev/docs/apps/rest-apis/return-navigation-guide/) workflows.

This is not a permanent URL, it is only valid for 30 days.

`created_at``integer`

When the design was created in Canva, as a Unix timestamp (in seconds since the Unix Epoch).

`updated_at``integer`

When the design was last updated in Canva, as a Unix timestamp (in seconds since the Unix Epoch).

`title``string`

Optional

The design title.

`url``string`

Optional

URL of the design.

`thumbnail``Thumbnail`

Optional

A thumbnail image representing the object.

Properties of **thumbnail**

`width``integer`

The width of the thumbnail image in pixels.

`height``integer`

The height of the thumbnail image in pixels.

`url``string`

A URL for retrieving the thumbnail image. This URL expires after 15 minutes. This URL includes a query string that's required for retrieving the thumbnail.

`page_count``integer`

Optional

The total number of pages in the design. Some design types don't have pages (for example, Canva docs).

`status``string`

**Available values:**

  * `needs_review`: The review is awaiting a decision from the reviewer.
  * `approved`: The reviewer has approved the design.
  * `requested_changes`: The reviewer has requested changes to the design.



`team_id``string`

The ID of the team that owns the design.

`requested_at``integer`

Optional

When the review was requested, as a Unix timestamp (in seconds since the Unix Epoch). Absent if the review request date isn't available.

`requested_message``string`

Optional

A message from the author to the reviewer, provided when the review was requested. Absent if no message was included.

`due_at``integer`

Optional

The deadline for completing this review, as a Unix timestamp (in seconds since the Unix Epoch). Absent if no deadline was set for the review.

`updated_at``integer`

Optional

When the review was last updated, as a Unix timestamp (in seconds since the Unix Epoch). Absent if the review has never been updated.

`continuation``string`

Optional

A continuation token. If present, more reviews are available and can be retrieved by passing this token in a subsequent request.
