# getBrandTemplateMetadata

API reference for the getBrandTemplateMetadata method.

Copy page

Return metadata for a brand template given its ID.

## Usage: Get brand template metadata
    
    
    import {
    
      getBrandTemplateMetadata,
    
      requestBrandTemplates,
    
      type BrandTemplateId,
    
    } from "@canva/design";
    
    
    
    
    const selection = await requestBrandTemplates();
    
    if (selection.status === "aborted") return;
    
    
    
    
    const templateId = selection.brandTemplates[0]?.token as BrandTemplateId | undefined;
    
    if (!templateId) return;
    
    
    
    
    const metadata = await getBrandTemplateMetadata(templateId);

TYPESCRIPT

Copy

## Parameters

`id``BrandTemplateId`

RequiredView type definition

A unique identifier that references a brand template.

## Returns

Expand all

Metadata for a brand template. This is a `Promise` that resolves with the following object:

`domain``string`

View type definition

The only valid value is `"brand"`.

`dataset``DataField[]`

OptionalView type definition

Metadata for a data field in a design or brand template.

Properties of **dataset**

`label``string`

View type definition

`type``string`

View type definition

**Available values** :

  * `"image"`
  * `"text"`
  * `"chart"`



`keywords``string[]`

View type definition

A list of keywords contained in a template.
